# 【跨设备交接包 · 兰香如故 · 英文有声剧集介绍】

> 本块自包含：另一 AI 会话只读本块即可接手本项目。**但本块只讲"做什么"，具体的"怎么做、音色与篇幅怎么锁"全部交给随包文件 `工具/gen_story.py` 与 `工具/制作规范.md`——请先读这两个文件再动手。**

## 一、项目目标

给电视剧《兰香如故》（官方英文名 *The Fragrance of Orchids Remains*，已更新至第 37 集）制作**英文有声剧集介绍**，逐集推进，最终覆盖 EP01–EP37。每集做成「母语英语小说体叙述 + 逐段可点击播放音频 + 逐段默认折叠中文翻译」。

## 二、核心需求与风格约定（硬规则）

1. **小说体叙述**：像一个人给另一个人讲故事，连续英文、中间不插翻译，不是分块列点的说明书。
2. **地道母语英语，零 Chinglish**：用 native speaker 真正会用的表达，杜绝翻译腔。
3. **中文翻译逐段折叠**：每段英文下紧跟一段中文翻译，用 `<details>` 默认收起，逐段配对（不是集中放全文末尾）。
4. **内容贴合原剧、不篡改**：情节/人名/关键台词以公开分集剧情为准，只保证英文地道，不自行加戏改剧情。
5. **音频可点击播放**：每段英文可点击——点哪段从该段开头播放，正在播该段时再点一次即暂停；顶部保留全局播放/暂停、进度条、倍速。
6. **音频不要内嵌 base64**（预览面板/部分浏览器会拦截大 data-URI），用外链同目录 mp3。
7. **★ 音色与篇幅由随包脚本锁定，禁止自创流程**：所有新集**必须**用 `工具/gen_story.py` 生成，**必须**按 `工具/制作规范.md` 执行。不要另写 TTS 脚本、不要改 voice/语速、不要凭记忆发挥。

## 三、已做的关键决策（本沙箱定稿，沿用）

- **英文剧名**：*The Fragrance of Orchids Remains*。
- **每集独立文件**：`EP0X.html` + `EP0X_audio.mp3` + `EP0X_英文剧集介绍.md`，不合并。
- **纯本地、不进 git/Gitee**：只保留本地 `兰香如故/` 文件夹，无版本库、无凭据。
- **音色锁死**：`en-US-AriaNeural`、语速 `-4%`，写死在 `工具/gen_story.py` 里。**只要用该脚本跑，全 37 集音色 100% 一致。**（之前"音色不一致"正是因为没有把脚本打进交付物、接手方重建了 TTS 流程所致。）
- **内容量化**：每集英文 ≥ 1400 词、8–14 段、单集音频 ≥ 5 分钟；并预列了 EP06–EP10「必覆盖剧情节点」与「人名译法对照表」（见制作规范 §4/§6）。（之前"内容偏少/人名漂移"正是因旧包只写意图、没量化、没列节点所致。）
- **听声环境限制**：WorkBuddy 预览面板（沙箱）禁媒体，必须**用本机浏览器直接打开 HTML 文件**才能发声。

## 四、产出格式与命名规则

**目录**：`兰香如故/`（独立文件夹，不含 `.git`）

**每集三件套**：
- `EP0X.html` —— 有声版成片。顶部金色播放器 + 正文「英文段（可点击）→ 其下 🇨🇳 中文翻译折叠块」逐段配对。
- `EP0X_audio.mp3` —— 单文件外链音频（逐段 edge-tts 合成 + ffmpeg 拼接）。
- `EP0X_英文剧集介绍.md` —— 标准源文稿（逐段英文 + 逐段折叠中文），由 `gen_story.py` 读取生成上两者。

**工具目录**：
- `工具/gen_story.py` —— ★ 唯一生成器（音色锁死）。
- `工具/制作规范.md` —— ★ 硬核规格（量化篇幅 + 必覆盖节点 + 人名表 + 校验清单）。

## 六、续做指令（粘贴到新对话）

> 接手《兰香如故》英文有声剧集项目。请先读 `工具/制作规范.md` 与 `工具/gen_story.py` 再动手。
> 按规范 §3 的 SOP：读前集 → 查本集分集剧情 → 列必覆盖节点 → 按 §2 量化指标扩写为标准源 markdown（`EP0X_英文剧集介绍.md`）→ 跑 `python3 工具/gen_story.py EP0X` 生成 html+mp3 → 过 §8 校验。
> 从 EP06 开始，严格使用随包脚本，禁止另写 TTS 流程、禁止改音色参数、禁止凭记忆省略剧情节点。

## 七、为什么之前会"音色不一致 / 内容偏少"

旧交接包只写了**意图文字**（"用 AriaNeural"、"按分集剧情"），但没把生成脚本打进交付物、没量化篇幅、没列必覆盖节点、没定人名表。接手方只能重建流程、自由发挥，于是音色漂移、内容越写越短。本次已将**脚本 + 量化规格 + 节点清单 + 人名表**一并固化进交付物，从根上解决。
