# 【跨设备交接包 · 兰香如故 · 英文有声剧集介绍】

> 本块自包含：另一 AI 会话只读本块即可接手本项目，无需翻阅原聊天记录。所有产出文件已随本包存入资料库（同一文档节点附件），到电脑端在库内该文档下下载即可拿到完整成果。

## 一、项目目标

给电视剧《兰香如故》（官方英文名 *The Fragrance of Orchids Remains*，截至对话时**已更新至第 37 集**）制作**英文有声剧集介绍**，逐集推进，最终覆盖 EP01–EP37。每集做成「母语英语小说体叙述 + 逐段可点击播放的音频 + 逐段默认折叠的中文翻译」。

## 二、核心需求与风格约定（硬规则）

1. **小说体叙述**：像一个人给另一个人讲故事，连续英文、中间不插翻译，不是分块列点的说明书。
2. **地道母语英语，零 Chinglish**：用 native speaker 真正会用的表达（如 *reads the room*、*the ground gives way*、*lets it roll off*、*cluttering up the place*），杜绝翻译腔。
3. **中文翻译逐段折叠**：每段英文下紧跟一段中文翻译，用 `<details>` 默认收起（点开才显示），逐段配对，**不是集中放全文末尾**。
4. **内容贴合原剧、不篡改**：情节/人名/关键台词以电视猫、百度百科等分集剧情为准，只保证英文地道，不自行加戏改剧情。
5. **人名双轨**：拼音 + 角色说明（如 Shen Jialan / 沈嘉兰，许兰香 Xu Lanxiang）。
6. **文化专有项括号解释**：如「教坊司」注 state-run brothel，方便海外读者。
7. **音频可点击播放**：每段英文可点击——点哪段从该段开头播放，正在播该段时再点一次即暂停；顶部保留全局播放/暂停、进度条、倍速。
8. **音频不要内嵌 base64**（预览面板/部分浏览器会拦截大 data-URI），用外链同目录 mp3。
9. **听声环境限制**：WorkBuddy 预览面板（沙箱）禁媒体，必须**用本机浏览器直接打开 HTML 文件**（mp3 在同目录）才能发声；单独打开 mp3 也可。

- **每集独立文件**：`EP0X.html` + `EP0X_audio.mp3` + `EP0X_英文剧集介绍.md`，不合并。

## 四、产出格式与命名规则

**目录**：`/workspace/兰香如故/`（独立文件夹，不含 `.git`）

**每集三件套**：
- `EP0X.html` —— 有声版成片。顶部金色播放器（全局播放/暂停 + 进度条 + 倍速）+ 正文为「英文段（可点击）→ 其下 `🇨🇳 中文翻译` 折叠块」逐段配对。
- `EP0X_audio.mp3` —— 单文件外链音频（逐段合成后用 ffmpeg concat 拼接，时长约 6–7 分钟/集）。
- `EP0X_英文剧集介绍.md` —— 纯文本底稿：英文叙述 + 文末 `<details>` 折叠的中文全文，作为 TTS 合成与回溯的源。

**辅助文件**：`README.md`（项目索引）、`跨设备交接包.md`（本包）。

**HTML 模板关键规格（点击段落播放）**：单 `<audio id="au" src="EP0X_audio.mp3">`；每段英文包成 `<p class="seg" data-i="i" data-start="s0" data-end="s1">`，引言块用 `<blockquote class="seg live" ...>`；JS 内嵌偏移数组 `const OFF=[[s0,e0],...]`，点击该段即 `au.currentTime=OFF[i][0]+0.02; au.play()`，若 `active===i && !au.paused` 则 `au.pause()`；`timeupdate` 按当前时间高亮对应段（加 `.active`，暂停加 `.paused`）。

**TTS 合成命令（已验证的坑点）**：
```
# 逐段合成（注意是 --file 不是 --text-file；--rate 用等号写法）
edge-tts --voice en-US-AriaNeural --rate=-4% --file seg_i.txt --write-media seg_i.mp3
# ffmpeg 拼接（list.txt 写 file '绝对路径'）
ffmpeg -y -f concat -safe 0 -i list.txt -c copy EP0X_audio.mp3
# ffprobe 取每段时长算偏移
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 seg_i.mp3
```
