# 《兰香如故》英文有声剧集 · 制作规范（硬核版）

> 本文件是**唯一权威规格**。接手方（人或 AI）必须**严格照此执行**，不要凭记忆或自行发挥。
> 目标：逐集产出「母语英语小说体叙述 + 逐段可点击播放音频 + 逐段默认折叠中文」，全 37 集在**音色、篇幅、人名、笔调**上保持一致。

---

## 1. 音色硬锁（最重要：防止「音色不一致」）

- **唯一生成入口**：本仓库 `工具/gen_story.py`。**禁止另写 TTS 脚本、禁止换工具。**
- 脚本内参数**写死、禁止修改**：
  - `VOICE = "en-US-AriaNeural"`（温暖母语女声）
  - `RATE  = "-4%"`（略缓，更像讲故事）
- 流程固定：逐段 `edge-tts` 合成 → `ffmpeg` concat 拼接 → `ffprobe` 算逐段偏移 → 生成 HTML。
- **绝对禁止**：换 voice、整集一次性合成（音色可能同但点段跳转会失效）、用别的引擎（如 gTTS/azure 其他 voice）、改语速。
- 只要用本脚本跑，全 37 集音色 100% 一致，与 EP01–05 完全相同。

---

## 2. 内容量化规格（防止「内容偏少 / 不一致」）

| 指标 | 下限 | 标杆（已定稿） |
|---|---|---|
| 每集英文正文词数 | **≥ 1400 词** | EP01≈2100 / EP02≈2400 |
| 段落数（英文段） | **8–14 段** | EP01=11 / EP02=14 |
| 单段英文长度 | 150–260 词 | — |
| 单集音频时长 | **≥ 5 分钟** | EP01≈6:47 / EP02≈9:35 |
| 中文翻译 | 逐段配对，篇幅与英文相当 | 全部 `<details>` 默认折叠 |

- 禁止为求快而**过度合并场景**导致段数 < 8、总词数 < 1400。
- 禁止**漏掉**本集「必覆盖剧情节点」（见 §4）。
- 小说体叙述：像一个人给另一个人讲故事，连续英文不插翻译；地道母语英语，零 Chinglish；可适度用母语习语（reads the room / lets it roll off / the ground gives way）。

---

## 3. 每集写作 SOP（必须按顺序执行）

1. **读前情**：先读前 1–2 集的 `EP0X_英文剧集介绍.md`，把握人物关系、笔调、已埋伏笔，保证连贯。
2. **查剧情**：联网查本集分集剧情（优先来源：HK01、今日头条、vocus、百度百科、搜狐），列出**必覆盖剧情节点清单**（≥ 6 个节点）。
3. **扩写**：每个节点写成 1 段英文（150–260 词），保持小说体、地道母语英语。
4. **自检**：词数 ≥ 1400？段数 8–14？节点全覆盖？人名符合 §6 对照表？中文逐段配对？
5. **产出标准源 markdown**（格式见 §5）。
6. **生成**：`python3 工具/gen_story.py EP0X` → 产出 `EP0X.html` + `EP0X_audio.mp3`，脚本自带校验。

## 4. 必覆盖剧情节点（已查公开分集剧情，EP06–EP10 已预列；EP11+ 按 §3 自列）

**EP06**（识破赵星棠私情）
- 小莲吐露不愿做林锦岐侍妾、渴望堂堂正正嫁人，兰香由此想起亡妹锦莲
- 许家父母买通当夜香妇的小莲之母，秘密把御寒冬衣传给兰香
- 林锦岐在荣宝阁查账发现异样，盯上赵星棠陪嫁商铺锦绣坊及其掌柜
- 赵星棠听出轨戏文动怒，烧坏心爱狐皮披肩，命兰香修补；兰香从其失态察觉她外面有人
- 林锦岐设局试印章，兰香暗藏印章又巧妙归还、助赵化解危机并获赏（银戒指）
- 兰香将印文拓在手臂上，主动请缨随赵星棠前往锦绣坊暗中调查

**EP07**（雪地罚跪 · 被迫做耳目）
- 兰香随行识破「钱小姐」实为男扮女装的表哥钱少泽
- 察觉林锦岐派人监视，故意在街头与顾客争执闹大动静，既打断私会又制造不在场证明
- 赵星棠罚兰香雪地罚跪，小莲等姐妹照料；兰香回家向养母筹钱补偿店铺损失，感念养父母至真亲情
- 九皋传召，林锦岐当面揭穿兰香识字，以养父母性命相胁逼其做内宅耳目；兰香滴水不漏应答应下
- 林锦岐拒绝出席赵母寿宴，夫妻嫌隙与阵营对立进一步激化

**EP08**（藏书楼捉奸 · 和离）
- 赵星棠带兰香、小莲回娘家参加母亲寿宴；钱少泽醉后失踪，赵赶往藏书楼
- 赵支开兰香、留小莲守门；兰香半路将赵行踪报给林锦岐手下，并折返救下小莲藏起
- 林锦岐以引荐名士守一先生为由，引导赵父、赵刚前往藏书楼
- 众人当场撞破赵星棠与钱少泽奸情；钱少泽反咬赵主动勾引，赵心寒
- 林锦岐借家丑施压，以「感情不和」逼和离，赵父为保颜面立字据

**EP09**（清洗 · 知春馆换血 · 入内书房）
- 兰香、小莲遇守一先生获名帖，凭草卜洗清嫌疑、保住性命
- 冯嬷嬷、紫堇被秘密处置；钱少泽出逃途中被截杀
- 赵星棠与父赵学德决裂，失娘家支撑
- 知春馆全面清洗，仅剩兰香、小莲、甘棠、宝盖四人，统一定为二等丫鬟并补八名三等
- 玉蝉回归主事；兰香主动请入内书房当差（凭识字之能争取出路）

**EP10**（杜翠雀登场 · 新线埋下）
- 林锦岐设宴款待曾舍命救他的部下杜正
- 杜正之妹杜翠雀即将寄居林府，野心勃勃、意欲为妾
- 临近年关，卫所冬衣迟迟未发（和离后依托赵家的官场便利消失，多方掣肘）
- 兰香在内书房当差展现才干，新的深宅算计悄然开启

## 5. 标准源 markdown 格式（脚本 `gen_story.py` 只认这种结构）

```
# 兰香如故 — The Fragrance of Orchids Remains
## Episode X · Told Like a Story

英文段 1（150–260 词，小说体）

<details><summary>🇨🇳 中文翻译</summary>

中文段 1（与英文段 1 配对）

</details>

英文段 2

<details><summary>🇨🇳 中文翻译</summary>

中文段 2

</details>

……（共 8–14 段，段段配对）
```

- 每个**英文段**紧跟一个含中文的 `<details>` 块，一一配对。
- 英文段之间、与 details 之间用**空行**分隔；英文段内部不空行分段（长段落用句子连接）。
- 文件名：`EP0X_英文剧集介绍.md`（X 为集数，两位补零，如 `EP06`）。
- 注意：EP01 是旧标杆（英文全文 + 末尾单个 details 全文），**不在本格式内，不重跑**。

## 7. HTML / 点击播放规则（禁止魔改）

- 复用 `gen_story.py` 内嵌模板：**单个** `<audio id="au" src="EP0X_audio.mp3">` + 每段英文 `<p class="seg" data-i data-start data-end>` + 顶部金色播放器（播放/暂停 + 进度条 + 倍速）+ 内嵌 `const OFF = [...]` 偏移数组。
- 点击某英文段 → 从该段 `data-start` 起播放；再点一次暂停；`timeupdate` 高亮当前段。
- **禁止**：改 CSS/JS 结构、把音频内嵌成 base64（部分环境拦截）、改播放器逻辑。

### 为什么之前会出现「音色不一致 / 内容偏少」？

旧交接包只写了**意图文字**（"用 AriaNeural"、"按分集剧情"），但：
1. **没把生成脚本打进交付物** → 接手方只能重建 TTS 流程，音色参数极易被改；
2. **没量化篇幅、没列必覆盖节点、没定人名表** → 接手方自由发挥，越写越短、人名写法漂移。

本规范与随包脚本一并解决上述三点：**跑脚本 = 锁音色；按 §2/§4 写 = 锁篇幅与剧情；按 §6 = 锁人名。**
