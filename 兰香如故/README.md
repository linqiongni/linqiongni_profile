# 兰香如故 · 英文有声剧集介绍

个人创作副线：为电视剧《兰香如故》逐集撰写**母语英语小说体介绍 + 逐段可点击播放的音频 + 逐段默认折叠的中文翻译**。

- **剧名**：《兰香如故》／英文名 *The Fragrance of Orchids Remains*
- **主创**：谭松韵 / 刘学义 主演；2026-09-11 开播，全 **47 集**（上部 31 + 下部《香气长传》16）；截至 2026-10-01 电视已播约 **32 集**（下部未播）
- **原著**：《兰香缘》禾晏山 ｜ 编剧 桐华 / 箫楼 ｜ 导演 黄颖湘 / 陈丹
- **官方英文名沿用**：*The Fragrance of Orchids Remains*（备选简洁版 *The Orchid's Scent Endures*，未启用）

## 格式约定（现行，以 EP01.html 为准）

1. **小说体叙述**：像一个人给另一个人讲故事，连续英文、中间不插翻译，不是分块列点的说明书。
2. **地道母语英语，零 Chinglish**：用 native speaker 真正会用的表达，杜绝翻译腔。
3. **中文翻译逐段折叠**：每段英文下紧跟一段中文翻译，用 `<details>` 默认收起（点开才显示），**逐段配对**——不是集中放全文末尾。（早期 `EP01/EP02_英文剧集介绍.md` 底稿沿用「全文末尾翻译」旧约定；EP01.html 已改为逐段，EP02 起底稿与 HTML 统一为逐段。）
4. **内容贴合原剧、不篡改**：情节/人名/关键台词以电视猫、百度百科等分集剧情为准，只保证英文地道，不自行加戏改剧情。
5. **人名双轨**：拼音 + 角色说明（如 Shen Jialan / 沈嘉兰，许兰香 Xu Lanxiang）。
6. **文化专有项括号解释**：如「教坊司」注 state-run brothel，方便海外读者。
7. **音频可点击播放**：每段英文可点击——点哪段从该段开头播放，正在播该段时再点一次即暂停；顶部保留全局播放/暂停、进度条、倍速。
8. **音频不外嵌 base64**：用外链同目录 mp3（预览面板/部分浏览器会拦截大 data-URI）。
9. **听声环境限制**：WorkBuddy 预览面板（沙箱）禁媒体，必须**用本机浏览器直接打开 HTML 文件**（mp3 在同目录）才能发声；单独打开 mp3 也可。

## 产出三件套（每集）

- `EP0X.html` —— 有声版成片。顶部金色播放器（全局播放/暂停 + 进度条 + 倍速）+ 正文为「英文段（可点击）→ 其下 🇨🇳 中文翻译折叠块」逐段配对。
- `EP0X_audio.mp3` —— 单文件外链音频（逐段 edge-tts 合成后用 ffmpeg concat 拼接，约 6–7 分钟/集；EP01 = 407.5s）。
- `EP0X_英文剧集介绍.md` —— 纯文本底稿：英文叙述 + 中文翻译，作为 TTS 合成与回溯的源。

**音频合成**：`edge-tts --voice en-US-AriaNeural --rate=-4%` 逐段合成 → `ffmpeg -f concat -safe 0` 拼接 → `ffprobe` 取每段时长算偏移数组内嵌进 HTML（实现「点段跳转播放」）。
