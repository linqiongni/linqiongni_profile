# 录屏素材采集清单 · 分镜表（一次过场，产出视频号 B-roll 素材库）

> 用途：你按本表**一次流畅点击**走完全站，把录屏丢给我，我负责切成「不同段素材」并拼成多条可发短视频。
> 核心原则：**录「诱饵」不录「备份」**——每条只展示该板块最狠的一段，引观众去 linqiongni.top 看全文。

## 一、录制前准备（必做，否则素材不可用）

| 项 | 要求 | 原因 |
|---|---|---|
| 浏览器缩放 | **150% 以上**（电脑 14px 字在手机竖屏才可读） | 不缩放 → 划走率飙升 |
| 浏览器环境 | 退出登录态以外的无关网页；清掉 cookie 弹窗、广告插件浮层 | 避免录到杂讯 |
| 合规红线 | **不点开任何真实合同/客户文件**；案例页只展示已脱敏的网站页面 | 保密义务 + 不泄露雇主商业信息 |
| 屏幕只留网站 | 关闭微信/邮件/通知；录前开「勿扰」 | 防隐私泄漏 + 防打断 |
| 分辨率 | 系统 1920×1080 或更高；录屏选「整个屏幕」 | 后期转 9:16 不糊 |
| 麦克风 | 建议**静音录操作**，口播后期配（你口误不怕重录） | 最省事；想边录边讲也行 |

## 二、录制纪律（让我能干净切段的关键）

1. **每个板块之间停顿 2 秒**（画面静止即可），方便我精准下刀。
2. **进每个板块先停在标题 1 秒**，让画面自带"章节标记"。
3. 点击节奏匀速，不要快速乱滑；**重点页面多停 1–2 秒**（如 16 周计划的首页、案例数据卡）。
4. 若边录边讲：每进一个板块**先说一句板块名**（如"这是餐饮法务的 16 周计划"），我后期好对齐字幕。
5. 全程控制在 **5–8 分钟** 最佳；想扩哪段，单独补录那段即可。

## 五、我收到后会怎么做（流水线）

1. 按 S0–S13 时间戳**切成独立素材段**，存 `06-资产素材/分段/`。
2. 对照 `03-脚本库` 的口播稿，挑素材段**拼成 30–90s 成片**。
3. 每条加：前 3 秒钩子标题卡 + 字幕烧录 + 关键点击圆圈高亮 + 结尾引导条。
4. 导出**竖屏 1080×1920 mp4**，直接能传视频号。
5. 同一段素材（如 S6 的 16 周计划）会被复用到多条视频，最大化利用率。
