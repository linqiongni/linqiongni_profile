# 录屏拍摄与剪辑 SOP

> 本号 80% 内容是「录屏展示 + 口播」。把「展示」做干净，比买设备重要。
> 目标：单条成片 25 分钟内完成（不含真人出镜段化妆）。

## 一、核心红线（先读）
- ⚠️ **录屏可读性**：电脑 14px 字，手机竖屏里几乎不可读。录屏前浏览器必须 **缩放 150%+**，关键页用剪辑软件再放大局部。
- ⚠️ **保密**：涉及真实合同 / 客户 / 公司内部文件，全程打码或换脱敏样例。宁可少展示，不可泄密。
- ⚠️ **标注**：AI 辅助生成的内容，口播或字幕注明「AI 辅助，人工校验」。

## 二、设备清单（极简起步）
| 项目 | 说明 |
|---|---|
| 电脑 | Mac/Win 均可，录屏用系统自带（Mac: Cmd+Shift+5；Win: Xbox Game Bar / OBS） |
| 手机支架 + 补光灯 | 仅真人出镜段需要，自然光也可 |
| 剪映（桌面版） | 剪辑、字幕、高亮标注 |
| 安静环境 | 口播后期配，无需现场收音完美 |

## 三、拍摄前（5 分钟检查）
- [ ] 浏览器缩放到 **150%+**
- [ ] 关闭微信 / 邮件 / 所有弹窗通知
- [ ] 清理书签栏，只留要展示的标签页
- [ ] 录屏区域固定（竖屏 9:16 或横屏 16:9，不留黑边）
- [ ] 真人段：支架固定、背景干净、补光正面
- [ ] 准备脱敏样例文件（如要展示合同/手册）

## 四、录制中
- [ ] **先录静默操作**：鼠标慢移、关键点击停顿 1 秒，口播后期配，避免口误重来
- [ ] 重要步骤标记：心里记「这里要加圆圈标注」
- [ ] 涉及文件：确认已打码 / 用脱敏版
- [ ] 一条录不顺，分段录，剪映拼接

## 五、剪辑（剪映桌面版）
1. **前 3 秒钩子**：大字字幕 + 冲击画面（网站截图 / 真人困惑脸）
2. **自动字幕** → 人工校对专业术语（如「特许经营」「HKIAC」）
3. **高亮标注**：关键点击加「圆圈 / 局部放大」
4. **配色统一**：香槟金高亮，背景米白 / 暗底
5. **结尾 3 秒**：固定「关注 + linqiongni.top」引导条（视觉锤）
6. **导出**：竖屏 1080×1920，码率够清即可

## 六、封面 & 发布
- [ ] 封面模板统一：大字标题（左）+ 网站截图缩略（右）
- [ ] 标题带「数字 / 结果」：如「16 周，从 0 到餐饮法务总监」
- [ ] 文案首句点价值，正文放网站链接 + 引导关注
- [ ] 发布后 24h 记录数据（见 `05-排期与复盘/数据表模板.csv`）

## 七、一条成片的标准时间分配
| 环节 | 时间 |
|---|---|
| 准备 + 录屏 | 8 min |
| 粗剪 + 字幕 | 8 min |
| 高亮 + 封面 + 发布 | 9 min |

## 八、避坑清单
- 不要边操作边长篇口播（容易乱，且声音与画面脱节）→ 静默录 + 后期配
- 不要全程无标注（观众不知道看哪）→ 关键处必加圆圈/放大
- 不要展示未打码的真实文件 → 一律脱敏
- 不要忽略结尾引导 → 每条第 45–60s 必须有「关注 + 网站」
