终审清单 · 让步底线 · 法源索引

前面八章是「怎么审」，这一页是「审完签不签」。
这一页的设计目标只有一个：让法务在 20 分钟内，对一份已经谈完的商业租赁合同做出「通过 / 有条件通过 / 打回」的判断，并且能清楚说出打回的理由。

四部分 · 硬否决 / 全量清单 / 让步底线 / 法源索引共 96 项校验可直接打印作为终审底稿
使用说明 · 先看这一页，再看合同

这份附录的用法是倒着用：不要从第一项开始逐条读，先看第一节「硬否决清单」。这 12 项是「不满足则不建议签署」的红线，通常 5 分钟就能扫完。任何一项不合格，直接进入「打回 / 补签补充协议」流程，不必再看后面。

如果 12 项全过，再用第二节的全量清单做系统性校验。这一节按八大模块组织，每项标注「必过 / 建议 / 加分」三档——「必过」项不合格同样不能签，「建议」项可作为与业务沟通的谈判清单，「加分」项是成熟度指标，不构成否决。

第三节是让步底线速查表，用于谈判现场。它的核心用途不是「告诉你能不能让步」，而是「让法务在业务部门面前有底气：这条我可以让，是因为我知道让了以后还剩什么。」

第四节是法源索引，用于合同条款的引注依据与异议论证。所有条号标注了复核提示，引用前请对照现行有效文本核准。

各节表格与清单均为原地展开：

一、硬否决清单（12 项 · 5 分钟扫完）

以下 12 项，任何一项不合格，不建议直接签署。处理方式只有三种：补签补充协议、取得甲方书面确认函、或打回业务重谈。没有第四种。

#否决项不合格的典型表现为什么是一票否决
1产权与签约主体一致性未核实签约方是运营公司，产权在项目公司名下，但无授权文件合同可能因无权处分陷于效力争议，后续所有约定都建立在沙地上
2收款主体与签约主体不一致且无约定租金付给第三方公司，合同未说明其收款依据形成资金断裂点：付了钱对方说「我没收到」，或主张已付租金冲抵其他债务
3交付标准无附件或附件为空泛表述附件只写「以现状交付」，无点位图、无机电条件表装修阶段必然扯皮，且甲方后续调整点位无约束
4面积与确权口径不一致合同写建筑面积，计租按套内，两者换算无约定每一期租金都有争议基础，长期累积成大额争议
5统一收银 / 数据接入义务缺失未约定收银通道、数据同步、核查权与罚则失去销售数据即失去抽成租金的基础，也失去发现瞒报的手段
6消防合规前置文件缺失或未作商户承诺未附整体消防验收 / 备案文件，未约定二次装修报审义务行政责任可穿透至出租方，并可能触发停业整改与连带赔偿
7无「无需催告即解除」或催告程序约定只有「甲方有权解除」，无程序、无情形清单解除权行使会被程序瑕疵打掉，导致明明的违约解除被判不成立
8无送达条款或送达条款缺「变更未通知视为有效」仅写了地址，未写拟制送达与变更义务所有通知、催告、解除的法律效力都无法证明
9管辖约定与不动产专属管辖冲突约定在甲方总部所在地或其他非租赁物所在地法院该约定无法产生效力，且暴露合同起草质量问题（影响整体可信度）
10保证金抵扣顺序未约定或未约定不足部分继续追索只写「保证金不予退还」，无抵扣顺序、无差额追索保证金没收可能被整体调减，同时丧失对超额损失的主张能力
11复原标准无量化依据无交付影像、无复原单价表、无验收程序撤场阶段唯一能依靠的两个证据都没有，复原费用无法主张
12无完整协议条款（排除口头承诺）合同无「本合同构成双方全部约定」条款招商口头承诺将成为争点，且举证责任倒向甲方
法务的一句话结论模板 前 12 项用于形成终审结论。建议表述为：「本合同【第 X、Y、Z】项存在硬否决情形，建议在补签补充协议或取得书面确认前不予签署。其余条款的意见见全量清单。」——明确指出项号，业务部门才知道要回到谈判桌上谈什么。

二、全量终审清单（八大模块 · 84 项）

标记含义：必过 = 不合格不可签；建议 = 谈判清单，可带条件通过；加分 = 成熟度指标，不构成否决。

模块一 · 基础租赁核心条款（14 项）

展开：主体资质 / 交付 / 租期免租 / 租金递增
  • 必过　产权证或有效权属证明已核验，出租人与权属记载一致，或已取得权利人书面授权（授权书作为附件，载明期限与权限范围）。
  • 必过　签约主体、收款主体、开票主体三者一致；不一致的，已取得收款方与开票方的书面委托及对甲方的不可撤销承诺。
  • 必过　如出租人为受托管理方，委托管理协议或授权文件已作为附件，且明确授权范围包含签署本条租赁合同、收取租金、行使解除权。
  • 必过　租赁房屋的规划用途与商户实际经营业态一致；如不一致，已确认可由出租方协助办理并明确责任归属。
  • 建议　已核查该房屋是否已设定抵押；存在抵押的，已取得抵押权人同意出租的书面文件，或至少有出租方的书面声明与承诺。
  • 必过　交付标准以附件形式量化：点位图、机电条件表（供电容量、给排水、燃气、排烟、荷载）、交付状态（毛坯 / 精装 / 现状）、交付时间点。
  • 建议　交付时双方共同签署《场地交付确认书》并留存影像资料（含日期水印、覆盖地面、墙面、天花、门窗、机电末端）；此为后续复原验收的唯一基准，务必执行。
  • 必过　面积口径唯一且明确（建筑面积 / 套内面积 / 计租面积），如涉及换算，约定换算系数与争议处理方式；超出偏差区间（建议 ±3%）的处理规则已写明。
  • 必过　租期起止以确定日期表述（不用「以交付为准」等浮动表述），或明确约定起租日的确定规则（最迟起租日、以特定条件触发）。
  • 建议　免租期明确适用边界：仅免租金不免物业费与能耗费；免租期内是否计入履约考核、是否可在违约解除时回溯主张（建议约定为可回溯）。
  • 必过　开业硬性节点明确（最迟开业日），并配有逾期开业的违约责任（非仅口头要求）；如涉及装修期与开业期的衔接，已约定验收与整改程序。
  • 必过　租金计价基数清晰（固定租金 / 保底与抽成取高 / 纯抽成），固定部分与抽成部分的结算顺序、抵扣关系已写明。
  • 建议　递增周期与比例可验证：明确递增基准（首年租金）、递增方式（按比例 / 按金额）、递增时点，避免「按市场行情调整」等不可执行的表述。
  • 加分　已设置欠费止损机制（逾期天数节点、催告程序、暂停服务范围、增补保证金触发条件），且与第八章违约梯度衔接一致。

模块二 · 收银系统与 POS 专项（16 项 · 核心风控）

展开：统一收银 / 终端管理 / 数据核查 / 结算分账 / 舞弊罚则
  • 必过　强制接入统一收银：明确适用业态范围、接入方式（收银机 / 收银软件 / 聚合支付）、接入时限，以及「所有经营收入必须通过统一通道结算」的概括性义务（不能只列举几个渠道）。
  • 必过　禁止私收私账的条款同时覆盖四种情形：不接入系统、接入后另设个人收款码、以现金收付不入账、以第三方账户或他人账户收款；并明确「以规避统一收银为目的的行为均构成违约」，避免只堵住已知手法。
  • 必过　系统权属与数据权属明确：收银系统、终端机具、账号、交易数据的所有权或使用权限归属，以及合同终止后的数据处理（数据归属、导出口径、删除义务）。
  • 建议　系统使用费的收取依据、计费方式、调整机制已明确；如为免费提供，已写明为「服务内容」而非「权利授予」，避免被主张不得撤回。
  • 必过　终端机具管理：配发与领用登记、保管责任、禁止改装与破解（含刷机、外挂、私自更换通讯模块）、损坏与丢失的赔偿标准。
  • 建议　机具故障处理流程已写明：报修渠道、响应时限、备用机提供、离线期间的收银替代方案（如手工单 + 事后补录）。这一条决定了「故障期间漏单」由谁承担。
  • 必过　销售数据实时同步义务：同步内容（交易金额、笔数、退换货、折扣、优惠）、同步时点（实时 / 当日）、同步方式（系统直连）。
  • 必过　三级核查机制：日检（系统与现场、异常交易预警）、月对账（系统数据与乙方财务数据核对、差异说明）、季度审计（抽取小票、库存、进销存数据交叉验证）。三级的触发条件、配合义务、差异处理结果已写明。
  • 必过　商户配合义务条款：提供小票存根、POS 签购单、库存台账、进销存系统权限、财务资料；明确「拒不配合即视为确认甲方数据」——这是让核查机制真正生效的开关，缺失则三级核查全是空转。
  • 建议　甲方进入店铺核查的权利范围、方式、保密义务已约定（含是否可查阅财务账目、是否需提前通知），并兼顾商户的商业秘密保护，降低执行阻力。
  • 必过　结算分账规则完整：结算周期、结算触发条件、计算方式（固定租金与抽成租金如何抵扣、抵扣顺序）、差额补付与超额返还的处理。
  • 必过　前置抵扣范围明确：从结算款中可优先扣除的项目（租金、物业费、能耗费、系统使用费、违约金、滞纳金、赔偿款），并明确扣除通知义务（一般应事先或同步告知）。
  • 建议　对账异议的程序化：异议提出时限（收到账单后 X 日内）、形式要求、逾期未提异议的法律后果（建议约定为视为确认）、争议金额的处理（争议部分暂缓、无争议部分照付）。
  • 建议　发票权责清晰：开票主体、票种、开票时间与结算周期的关系；如采用「甲方代收代付」模式，须明确「商场方不代表商户向消费者开票」的边界，避免被主张构成销售主体。
  • 必过　瞒报舞弊罚则设置梯度：首次发现（补缴 + 违约金 + 警告）、二次发现（提高抽成比例 / 增补保证金）、情节严重或多次（构成根本违约，可解除并没收保证金）。避免「一次即解除」导致条款不敢用，也避免「只补缴」导致违规成本过低。
  • 加分　已明确抽成租金的最低保证基数（即无论实际销售多少，抽成部分不低于某一金额），形成「保底 + 抽成」的双层结构，覆盖瞒报风险。
模块二 · 资金合规提醒（法务必读） 统一收银在商业上是风控工具，在法律上有一个必须守住的边界。当商场代收消费者款项、再与商户结算时，资金流与信息流的关系决定了这属于「支付服务外包 / 账户体系」还是可能触及「无证从事支付结算业务」的边界。
实务上的三条底线：① 资金通道应由持牌支付机构或银行提供，商场方承接的是「系统与对账服务」，不是自建资金池；② 商户结算款应通过约定的结算路径与周期划付，不宜以「商场自有账户长期占用商户货款」的模式运作；③ 合同中应明确各方在支付链条中的角色，并避免出现「商场即销售方」的表述。
涉及具体资金设计与结算模式时，须由支付合规专业人员与外部律师共同评估，本页不构成合规意见。

模块三 · 商场维护与物业服务（10 项）

展开：服务边界 / 能耗 / 装修管控 / 维保划分
  • 必过　物业服务范围以清单形式列明：基础服务（公共区域保洁、安保、垃圾清运、公共照明、电梯运行、绿化）与商业专项服务（推广、活动、导视、会员、外摆管理）分别成表。
  • 必过　物业费不含项目单独列明（如店内保洁、店内消防器材、专用设施维保、超时空调、专线网络），避免「已交物业费为什么还要收」的争议。
  • 建议　服务标准可衡量：保洁频次、安保在岗时间、维修响应时限、投诉处理时限。是甲方义务的边界，也是乙方主张服务不达标的抗辩靶点——写清楚反而对甲方有利。
  • 必过　水电能耗计费标准：计价方式（独立表计 / 分表 / 按面积分摊 / 按约定单价）、抄表周期、单价构成（是否含损耗、线损、公摊）、调整机制。
  • 建议　涉及分摊的费用明确分摊依据（面积 / 人数 / 营业时长）与公示义务，避免被主张「分摊不透明」。
  • 必过　空调开放时段以明确时段表述，延时 / 加班空调的申请程序与收费标准一并写明（含最低计费单位）。
  • 建议　欠费与服务中止的关系：明确「可暂停的服务范围」（商业专项服务）与「不可暂停的范围」（消防、安全、电梯等基础安全设施），并写明暂停前的催告程序。
  • 必过　装修改造报备制度完整：图纸报审范围、报审受理时限、开工许可、施工时间与噪音限制、动火作业审批、施工人员管理、材料进场与运送通道。
  • 必过　禁止改造项清单明确（主体结构、承重构件、防火分区、消防设施、外立面、公共管线），并配违约责任。禁止改造项必须逐项列举，不能只写「不得影响结构安全」。
  • 必过　维保责任切割清晰：公共区域与公共设备（电梯、扶梯、中央空调主机、消防主机、公共照明、给排水主管）由甲方或其指定单位负责；店内区域与专用设备（店内配电、给排水支管、专有空调末端、厨房排烟）由乙方负责，并约定乙方维保的备案与配合义务。

模块四 · 消防安全合规（10 项 · 一票否决）

展开：前置资质 / 二次装修 / 日常管理 / 禁止行为 / 追责
  • 必过　建筑整体消防验收或备案凭证已作为合同附件；未取得的，租赁合同中已明确双方责任划分与乙方风险自担的声明。
  • 必过　乙方业态的消防合规承诺：承诺其经营业态符合消防技术标准要求，并自行负责业态所需的所有消防手续。
  • 必过　二次装修消防流程完整：消防设计图纸报审（含受理与批复时限）、施工过程监督、完工查验、取得消防验收 / 备案文件或许可后方可开业。「二消合格证取得前不得开业」必须写成硬性条件。
  • 建议　消防系统联动规则：乙方二次装修中涉及喷淋、烟感、防火卷帘、排烟、防火门等系统的改动，须由甲方指定或认可的施工单位实施，改造后须由乙方承担检测费用并完成联动测试。
  • 必过　消防器材配置责任明确（灭火器、应急照明、疏散指示、独立烟感等），配置标准以附件列明，更新与年检责任归属清晰。
  • 建议　巡查配合义务：乙方应配合甲方及主管部门的消防检查，收到隐患整改通知后在约定时限内整改完毕并回复。整改时限必须明确，否则无从认定违约。
  • 必过　隐患整改闭环机制：整改通知 → 限期整改 → 复查 → 未整改的后果（违约金 / 暂停服务 / 报主管部门 / 根本违约）四级递进已写明。
  • 必过　禁止行为清单逐项列明：封堵或占用疏散通道与安全出口、遮挡或拆除消防设施、违规使用明火与电热设备、违规储存易燃易爆物品、私拉乱接电线、超负荷用电、在非指定区域充电（含电动自行车及电池）、遮挡消防标识。
  • 必过　事故追责条款：因乙方原因导致的行政处罚、损失、第三者赔偿、连带赔偿责任，由乙方承担并赔偿甲方由此产生的全部损失（含律师费、鉴定费、停业损失）。
  • 加分　乙方已提供其业态所需的消防责任声明，并约定乙方应投保公众责任险（保额不低于约定金额、将甲方列为附加被保险人）。这是把安全责任从「事后追偿」转为「事前覆盖」的关键一步。

模块五 · 经营规范与品牌管控（10 项）

展开：品牌业态 / 营业时间 / 营销活动 / 价格服务
  • 必过　经营品牌与业态以附件形式固化（品牌名、商标、业态、面积、店招设计），并约定变更需事先书面报批。
  • 必过　禁止私自换牌、经营非报批品牌、销售来源不明商品（杂牌、水货、假冒）、擅自引入联营合作方；并明确违约后果。
  • 建议　乙方应保证其使用的商标、字号、装潢不侵害第三方权利；如因侵权导致甲方被牵连，乙方承担全部责任（此条对甲方极为重要，商场可能因侵权行为被列为共同被告）。
  • 必过　统一营业时间要求明确：开闭店时间、节假日安排、临时调整的通知与审批规则。
  • 必过　擅自停业与空铺的违约责任：未按约定营业、擅自歇业、长期空铺（约定连续闭店或累计闭店天数阈值）的违约金与解除条件。空铺阈值必须写数字。
  • 建议　装修期与过渡期的营业安排（如部分区域试营业）已写明，避免「装修期未营业是否构成空铺」的争议。
  • 必过　营销活动报备制度：店庆、促销、路演、外摆、快闪、派发、直播带货等活动的报备范围、受理时限、审批依据；明确禁止未报备的大型营销。
  • 建议　涉及外摆与公共区域的占用，明确区域范围、时段、撤收责任、场所复原责任与费用承担。
  • 建议　价格与服务的规范要求：明码标价、不得虚假宣传、不得实施价格欺诈、不建议在商场内进行恶性低价竞争（可约定为「不从事针对相邻同类商户的定向低价倾销」）。
  • 加分　会员与数据合作条款：乙方在商场会员体系中的参与义务、消费者数据的合规使用与共享边界（须符合个人信息保护相关法规，不得约定违反法定要求的强制共享）。

模块六 · 费用与保证金体系（10 项）

展开：保证金分类 / 各项费用 / 逾期规则
  • 必过　保证金采取「总额 + 内部按用途分类管理 + 跨项扣除授权」的结构，并写明「分类仅为内部管理口径，不构成对扣除用途的限制」。
  • 必过　保证金条款因涉及免除甲方事先通知义务，属格式条款中的重点提示对象：建议加粗，并由乙方单独签字确认（这一点在争议中直接决定条款能否被认定为有效约定）。
  • 建议　保证金金额与业态风险匹配：高风险业态（餐饮、娱乐、儿童、大面积主力店）增加消防与复原预留；大面积或长租期店铺可要求品牌方或实际控制人提供连带保证。
  • 必过　保证金抵扣顺序明确：欠租 → 物业及能耗费 → 系统使用费 → 违约金与滞纳金 → 损失赔偿 → 复原费用。
  • 必过　保证金不足时的补足义务与时限；不补足的后果（视为违约、可解除）。
  • 建议　保证金退还的条件与时限：明确退还前提（结清全部费用、完成复原并验收、无未决争议），以及退还期限与无息约定的说明。
  • 建议　各项费用清单化：物业费、能耗费、系统使用费、推广费、垃圾清运费、外摆位费用等，每项明确计费标准、支付节点、调整机制。
  • 必过　逾期规则的起算点明确：自约定付款日次日起计收滞纳金；日息比例明确（建议万分之三至万分之五），并明确不计复利（避免被整体认定为过高）。
  • 必过　累计逾期的解约条件：连续逾期或累计逾期达到约定天数 / 金额阈值，构成根本违约。阈值必须写数字，且与第八章梯度一致。
  • 加分　费用调整的程序约束：涉及公共性费用调整的，约定调整依据（成本变化 / 政策调整）与通知程序，降低被主张单方变更的风险。

模块七 · 转租、续租与撤场（8 项）

展开：转租 / 续租 / 撤场复原
  • 必过　转租、分租、转让、联营、挂靠、托管、承包、合作经营等一切实质转移经营权的行为，均须事先取得甲方书面同意；并列出「变相转租」的识别标准（如未变更承租人但实际经营者变更、由第三方收款、第三方派驻管理人员等）。
  • 建议　未经同意转租的处置路径：甲方可选择解除合同，也可选择维持合同并向乙方追索违约金——保留选择权比写死「必须解除」更实用。
  • 必过　转让时的程序与条件：受让方资质审查、甲方审批时限、转让费用（如有）、原乙方对转让前债务的连带责任不因转让而免除。
  • 必过　续租条款：不得直接排除承租人的优先承租权，只能程序化——约定续租申请时限、申请形式、「同等条件」的界定标准（租金水平、租期、付款方式、保证金、业态要求）、甲方答复时限。
  • 建议　续租的调价规则：明确续租租金的确定方式（参照市场 / 参照同期同类铺位 / 按约定比例递增），避免续租谈判无据可依。
  • 必过　复原标准量化：以交付状态为基准，附《复原工程验收标准》与《复原单价表》（或计价方式），并约定复原的方案报送与审批程序。
  • 必过　逾期复原的违约责任：复原期限、逾期违约金标准，并明确甲方有权代为复原、费用由乙方承担（或从保证金中扣除）。
  • 必过　遗留物品处置四步法：① 书面通知限期清理 → ② 公证或全程录像清点造册 → ③ 移入指定场所保管并再次通知 → ④ 逾期未取回的，甲方有权自行处置，所得价款扣除费用后保留提存或返还义务；并明确保管费用由乙方承担。

模块八 · 违约与争议解决（6 项 · 速查）

展开：梯度 / 救济 / 管辖 / 送达 / 不可抗力（详细校验见第 08 章）
  • 必过　违约分三档（轻微 / 一般 / 根本），各档明确对应处置，并设有「一次即根本违约」的例外清单。
  • 必过　违约金按类型分设、基数清晰；空置损失约定月数；损失赔偿范围逐项列明（招商佣金、复原费用、律师费、公证费、鉴定费）。
  • 建议　约定「甲方收回物业、更换锁具、重新招商之行为，不构成对合同解除事由的放弃或协商解除的默示同意」（此条可在关键案件中直接决定胜负）。
  • 必过　管辖写为「租赁物所在地有管辖权的人民法院」，未写死具体法院名称。
  • 必过　送达条款三层设计完整，且效力已延伸至诉讼、仲裁与执行程序的司法文书送达。
  • 必过　不可抗力条款含正面列举、反面排除（客流、市场、电商冲击、资金不足）、减免区间、政府强制与自主停业的区分；合同中不得出现「情势变更可要求调租」的约定。

三、让步底线速查表

这一节是谈判现场用的。使用方法是：业务部门说「这条对方一定要」，法务在这一页上找到对应行，看「可让到什么程度」以及「必须换回什么」。

条款主题让步档位可让到的程度必须换回 / 不可让的底线
租金递增比例可谈 比例可下调；递增周期可从每年调为每两年；首年递增可延后 必须保留递增机制本身；必须明确递增基准与时点，不接受「按市场行情调整」
免租期可让 可延长；可拆分使用（装修期 + 试营业期） 必须约定「违约解除时甲方有权回溯主张免租期租金」——这一条不可让
统一收银范围谨慎 可对特定业态（如美发美容、体验类、教育）约定替代方案（如提供经营数据 + 抽查权），但必须保留数据核查权 不可让：数据同步义务、三级核查权、拒不配合视为确认甲方数据、瞒报罚则。这四项是抽成租金的实现基础
结算周期可谈 可按业态分级设置（如高流水业态可短周期结算以稳定商户现金流） 不可让：前置抵扣范围、对账异议时限、逾期未提异议视为确认
物业费不含项目可让 可将个别项目从「不含」调整为「含」（如公共区域垃圾清运量的合理范围） 必须保留超时空调、店内保洁、专用设备维保三类作为「不含」项
空调延时收费标准可让 单价可下调、最低计费单位可缩短（如从 4 小时改为 2 小时） 必须保留「需提前申请 + 收费」的机制，不接受「无限制免费延时」
消防二次装修流程不可让 可优化流程时限（如报审受理时限缩短）、可指定多家认可单位供选择 不可让：图纸报审、完工查验、取得合格文件后方可开业、消防系统改造须由认可单位实施
保证金金额可谈 可分期缴纳（签约 / 交付 / 开业三个节点）；可对不同业态设置不同倍数 不可让：抵扣顺序、不足补足义务、分类管理 + 跨项扣除授权
违约金比例可谈 日息可从千分之一降到万分之五 不可让：空置损失约定月数、律师费与公证费由违约方承担
擅自停业的后果可谈 阈值天数可放宽（如从连续 3 日放宽至连续 5 日）；可增加一次整改机会 不可让：必须保留数字阈值（不能用「长期」「严重」等模糊表述）
复原标准可谈 可允许保留部分装修（如不影响结构的地面、隔墙），但须书面确认并约定折价或免复原 不可让：交付影像基线、复原单价表、复原验收程序。这三样缺一，复原条款就是空的
优先承租权的程序可让 申请时限可延长；「同等条件」可作更有利的界定（如以租金 + 租期两项为准，不含隐性条件） 不可让：不得约定「到期无条件不续租」或直接排除优先承租权的表述（法律上难以成立，且损害整体可信度）
催告程序可谈 可将大部分情形的「无需催告」改为「催告后解除」 不可让：欠付金额达到 X 个月租金、私自转租、瞒报销售数据三类情形必须保留「无需催告即解除」
送达拟制期可让 可从第 3 日延长至第 7 日或第 10 日；可增加指定联系人与地址数量 不可让：地址变更未通知则原址有效、拒收视为送达、张贴视为送达、效力延伸至司法程序
不可抗力减免可谈 可从「各承担 50%」调整到「甲方承担 60%」；可增加免租期顺延天数 不可让：「政府强制性要求」这一前提词、甲方仅承担租金（不含乙方经营损失）、乙方自主停业不适用减免
管辖不可让 —（不动产纠纷专属管辖，无谈判空间） 礼貌说明法律限制，不作筹码；可让的是「仲裁或诉讼」的选择（如双方均为商事主体且当地认可）
给法务的谈判心法 让步的价值在于「换」，不在于「给」。业务部门来要一个让步时，先问一句：「我们让这条，对方愿意在收银数据核查、消防报审、复原单价表这三件里，哪一件上让步？」
一份合同里，真正不能动的是四件事：数据（收银与核查）、安全（消防）、退出（复原与遗留物）、送达。这四件之外的绝大多数条款，都可以谈。把这条原则讲给业务部门听，比逐条解释一百次更有效。
