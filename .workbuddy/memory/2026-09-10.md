## 新增：全屏水面波纹背景
- 文件 `src/components/WaterRippleBackground.tsx`，挂在 `App.tsx` 根 div 内顶部；`<canvas>` fixed inset-0、`z-[45]`（低于 Navbar z-50）、`pointer-events-none`、`mix-blend-mode: soft-light`。
- 算法：高度场波动方程（`next=(上下左右)/2 - prev`，阻尼衰减）→ 梯度转明暗 → 小网格放大平滑。
- 用户首轮反馈「太明显、滑动很晕」→ 已收敛：CELL 8→14（更柔）、指针注入加节流（2.6 格 / 110ms）且去掉轨迹插值补点、drop 限幅 ±1.2、LIGHT_GAIN 3.2→1.0、MAX_ALPHA 0.6→0.16、环境波 1.5s/0.42 → 3.4s/0.2。
- **教训（重要）**：这类动效首版必须走克制参数。乱的主因是「每帧沿轨迹补多个点 + 高对比」，节流 + 单点注入即可解决。
- 调参入口：文件顶部常量区（CELL / DAMPING / POINTER_* / AMBIENT_* / LIGHT_GAIN / MAX_ALPHA）。
