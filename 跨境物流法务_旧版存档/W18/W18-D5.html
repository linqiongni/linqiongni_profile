四、「要不要在当地设公司」六问决策法

  1. 第一问：在当地有没有持续经营（≥1 年）的业务量？ 偶发/试水 → 先用服务商或母公司签约，不设。
  2. 第二问：客户/平台是否要求本地主体（如本地 VAT、本地退货地址、资质）？ 是 → 倾向设。
  3. 第三问：纯仓储还是有人做销售/签约？ 有人做销售 → 为隔离 PE 与责任，宜设本地主体承接。
  4. 第四问：用工规模是否触发当地强保护（如德 KSchG ≥10 人）？ 是 → 设主体便于合规雇佣。
  5. 第五问：银行/资金是否需要在当地落地（收付款、授信）？ 是 → 设主体+开户。
  6. 第六问：税负与协定是否算得过来（PE 利润税 vs 预提税 vs 维持成本）？ 算过来 → 设；算不过 → 暂缓或换国别。
六问全过 = 设；任一红灯（尤其第一、三问）先别设，用服务商/母公司过渡。我方立场：设主体是为长期合规底盘；客户立场：要求我方主体干净（资本实缴、受益所有人透明、用工合规），把「主体不实致损」写进赔偿条款。
本周收口口诀：主体合法存在、用工守住边界、税务管住 PE 与 TP、银行落地资金——四块闭环，海外仓才跑得稳。六问不过不设点，设之前先算账。下周末做《设立与年度维护手册》，把今天的手册变成可执行的年历。
