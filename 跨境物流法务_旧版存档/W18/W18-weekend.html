一、设定复述：这份手册是海外仓的「年度体检表」

我方是物流企业，德国已有 GmbH 海外仓，正评估波兰（Sp. z o.o.）/ 墨西哥（S. de R.L. de C.V.）扩张。这份《海外子公司设立与年度维护手册》的作用，像给公司办了一张「年度体检卡」：设立阶段是「办入院手续」（公证登记税务银行保险），年度维护是「每年复诊」（申报、公告、文档更新）。漏一次复诊，小则罚款、大则主体失信、银行账户冻结、仓被查——所以手册不是写给人看的，是写给人照着打勾执行的。

记忆点：设立=办入院，年度=复诊。手册的核心价值是「可执行的 checklist + 责任到人 + 时限到日」，不是论文。

R=执行、A=最终负责、C=被咨询、I=被告知。关键原则：当地董事是多数合规事项的 A（最终负责）——这也是为什么董事人选必须专业、不可随意派总部不懂当地法的人。母公司是预算与集团政策的 A，但不能替董事背当地个人责任。

六、常见失误清单（15 项）

  1. 董事任命随意、不懂当地法 → 三项迟延个人责任爆发；正确：聘专业董事或本地资质者。
  2. Transparenzregister 不登记/不更新 → 罚款+账户冻结；正确：年度复核更新。
  3. VAT 在首次交易后才登记 → 增值税罚款；正确：交易前完成。
  4. 纯仓储仓内人员做销售/签约 → 触发 PE；正确：仓内只按指令发货。
  5. 关联交易无定价依据/无同期资料 → TP 调整+罚息；正确：独立原则+Local/Master File。
  6. 预提税未查协定直接付 → 白交差额税；正确：先出税收居民证明+适用协定率。
  7. 假外包真雇佣 → 事实雇主责任；正确：外包合同隔离雇主责任+核验社保。
  8. 固定期限合同反复续签同一人 → 变无固定期限；正确：错峰/用正规派遣。
  9. 银行 KYC 无本地经营痕迹 → 开户被拒拖慢上线；正确：先租地址+聘本地代理。
  10. 年度财报逾期/不公告 → 罚款+资信受损；正确：日历提醒+双签。
  11. 商业登记信息不核对 → 登记异常；正确：年度确认。
  12. 用工合同不缴本地社保 → 董事连带+补缴；正确：雇佣即登记缴纳。
  13. 主体资本不实/空壳注资 → 资信质疑+客户反咬；正确：足额实缴留银行水单。
  14. 墨西哥外资未办 FOLIO → 主体效力瑕疵；正确：设前确认流程。
  15. 手册一年不更新 → 政策变动漏报；正确：每年由合规岗+顾问复核重发。

七、这份手册怎么用、谁更新

用法：设立阶段照「时间轴」逐步打勾；运营后照「年度日历」逐项执行；每次出事对照「失误清单」自查。 更新责任人：母公司合规岗牵头，每年 Q4 联合当地董事与外部顾问（律师/财税/HR）复核一遍，更新时限、税率、成本与法规变动，重新签发版本号。手册不是写完存档，是「每年复诊一次」的活文件。
实战口诀：设立照轴走、年度照历做、责任到人、成本待核、失误十五防。海外子公司不是设完就完，是「每年复诊」才活得久——这份手册，就是它的体检卡。
