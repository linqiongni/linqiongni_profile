# 开场白 — 贴给 WorkBuddy 就完事（全文可整段复制）

> 这份文件不解释任何东西，就是**一段可以直接粘贴给 WorkBuddy 的文本**。
> 什么时候用：换设备开机、新 clone 一台、隔了几天重新开工、要开一个新会话接手。
> 用法：整段复制 → 把 `<…>` 占位换成实际情况（路径、日期、这次要做什么）→ 粘进新会话。
>
> 为什么单独存一个文件：`MIGRATION.md` 第三节的开场白是**当时版**，写完就过期。
> 独立成文件后可以单篇维护，不用回头改迁移文档，避免两份漂移。

## 可复制全文

```
我接手 linqiongni_profile，接着干活。仓库在 <这台设备上的路径>，当前分支 <分支名>。

【开工，按顺序读完再动我】
1. process/CONTRACT.md —— 行为规则：开工读什么、收工写什么、怎么 push、禁止什么。第一份就读它。
2. process/README.md —— 项目是什么、现在挂了什么没解决、今日索引最后一行（上一个人干到哪）。
3. process/03-问题台账/OPEN.md —— 开工前先看有没有我该认领的。

要动 src/ 或发布相关，先补读 process/01-项目现状/workflows.md（八条红线，本地禁 npm run build）。
想知道某个做法当初为什么这么定，先读 process/02-决策日志/DECISIONS.md 再动手。

【这项目是什么】
Andy 的个人主页与法务作品集，发布在 https://linqiongni.top。
主体是 React 应用（个人主页 + 各法务领域的 iframe 子站），外加十几个纯静态 HTML 子站。
注意：这个仓库不是案件材料库，案件、合同、客户信息一律不进来。

【手上挂着六条没解决的（2026-09-27 快照，以 OPEN.md 为准）】
#01 案例卡要不要改成常驻彩色 —— 等 Andy 拍板
#05 本地终端跑 git 报 TCC 权限 —— 等 Andy 点一下授权
#02 鱼影层只覆盖主站，17 个子站没有 —— 先定要不要做
#04 深海军蓝色值没真正收敛（AboutTab 金色还靠 !important）—— 攒着，子站数量稳定后收口
#03 ip / foreign-contracts / ai-law / insurance 四站没有源目录 —— 下次谁改谁先查出处
#20 两条本地孤儿 stash + 一条从未 push 的分支 —— 等 Andy 拍板

认领判据：署名 Andy、写着「等他拍板」「等他点头」、需要他本人操作或外部权限的，我不动，最多提醒一次。
其余默认归我，做完在日志里写明。

【git 规矩，这仓库的自动同步 hook 已经接管了，不靠我记】
- 进仓库 / 切换分支 → 自动把线上最新拉下来。
- 提交之后 → 自动 rebase 到最新再推上去。所以收工只需要 git commit，别手写 git push（会和 hook 打架，还会漏掉 rebase）。
- 绝不把 pull 挪进 pre-commit：改动还挂在 index 上时 rebase 会把正在提交的这批搅散（实测过）。
- 推 main 等于触发 CI 把线上发一遍。做了一半的东西只开 wip/YYYYMMDD 分支，别碰 main。
- push 不通按顺序查 process/MIGRATION.md 第三节，四种根因其中有真网络问题，判定命令写在那里。

【收工五件事，按顺序】
1. 写 04-每日日志/{今天}.md —— 文件已存在就在末尾追加，禁止覆盖。
2. 更新 process/README.md 的「今日索引」—— 加一行。
3. 有真问题就提台账（新开 OPEN，解决了挪 SOLVED，编号连着来）；推翻或重定了某个做法就进 02-决策日志。
4. git commit —— hook 会自己 push。
第 5 步可以跳过（网络不通、凭据没配），其余四步跳过一次档案库就少一天。

【最后，两件事】
这次你要接着做什么？以及你今天收工前会做哪几件事？
```

> 最后那句 「**你今天收工前会做哪几件事**」别删，实测过：删掉它 AI 照样会做那些步骤，
> 区别只在它会不会**主动汇报**。**那句买的是你的知情权，不是它的自觉。**

## 换设备时，前面还得先在终端跑两行

开场白里没有 clone，因为那不是「说」的事。换设备/新 clone 一台时：

```bash
git clone https://github.com/linqiongni/linqiongni_profile.git
cd linqiongni_profile
bash scripts/setup-device.sh          # 装自动同步并当场自检六项，约 10 秒
```

三件事按顺序：clone → `bash scripts/setup-device.sh` → 贴上面的开场白。

**自动同步 hook 不进 git**，clone 必然不带，所以第 2 步每条设备都要跑一次。跑完就永久生效。

> 别用一个不存在的路径：`scripts/setup-device.sh` 必须先被 push 过，新设备才 clone 得到。
> 2026-09-27 实测踩过——新设备上报 `No such file or directory`，因为它只是本地新建、还没推。
