## 本次定型的新做法（与既有子站不同，别照抄旧套路）
1. **新站 style.css 自带双主题**（`:root` 浅 / `html[data-theme="dark"]` 暗），
   不挂 `apply-theme-kit.py`。理由：这次要「跟主站配色一致」而非套公开补丁块，
   变量表直接抄商事仲裁站口径（金 #B89F6B / 浅底 #FDFCF9 / 暗底 #1C1C1E）。
   → `sync:history` 脚本里**不要**串 `theme:check`，也没必要（theme:check 只查指定目录）。
2. **布局 B 的简化版**：`.layout` 用 `height:100dvh` + flex 列，顶栏是 flex 首项（不 sticky、
   不需 JS 测高），`.row` 承载 [左栏 aside / #mainwrap]，天然自适应，比「JS 实测顶栏高注入」更省。
3. **app.js 只注入顶栏**（`layout.insertBefore(topbar, layout.firstChild)`），
   **不要** `body.innerHTML=''` 重建——会把 `/theme-toggle.js` 的外链 script 抹掉导致主题失效。
4. **左栏用 HTML 骨架里已有的 `<aside id="side">`**，JS 里再 `el('aside')` 新建会插不进 DOM
   变成零链接（踩过：冒烟时 `#side a` 数为 0）。
5. **目录页与文章页共用 app.js**：`body[data-p]` 存在 = 文章页（左栏+进度条+上下篇），
   不存在 = 目录页（只注入顶栏 + 搜索过滤 `.cell`）。搜索只改元素自身 display，
   别改 `parentNode`（目录页 .cell 的父是 .grid，改父会把整个网格隐藏）。

## 上线后修的两处硬伤（15:4x，Andy 手机实测反馈）
1. **手机划不动**：首版手机端沿用「body overflow:hidden + 内层 div 滚动」，在主站的固定高度
   iframe 里 iOS Safari 上触摸常常失效。已改与商事仲裁等子站一致的写法：
   `@media (max-width:1000px)` 里 `html,body{height:auto;overflow:visible}`、`.layout/.row` 改
   `display:block`、`#mainwrap/#main` 高度 auto + 滚动可见，整页走**原生文档流滚动**；
   左栏改 fixed 抽屉 + `#scrim` 遮罩（点遮罩/Esc/点目录链接都收起，宽屏 resize 自动清状态）。
   640px 以下顶栏换行两排、`.grid` 单列。
2. **背景不是网站固定背景**：子站 body 铺了不透明 `var(--bg)`（同商事仲裁老套路），把主站那层
   fixed 深渊板 + 鱼影盖住了。改法：`html.embedded body{background:transparent}`，
   `html.embedded` 由 `app.js` 在 `window.self!==window.top` 时添加，**每个页面 head 另加一行
   内联 `if(self!==top)document.documentElement.classList.add("embedded")`** 防首帧闪色
   （独立打开时照旧铺自身底色，否则浅色露白、深色白底看不见字）。
   顺手把 `ThemeIframe` 的载入遮罩从实色改 `bg-white/80 + backdrop-blur` 半透，别糊死背景。
3. **顺带查出的真 bug**：目录页 HTML 写的是 `id="home"`，CSS 选的是 `.home` → 目录页样式一直没生效。
   已改 `class="home" id="home"`。

## 手机端验证手法（本次新跑通，可复用）
本机 Chrome（`/Applications/Google Chrome.app`）`--headless=new --remote-debugging-port=9222`
后台起，Node 22 自带 WebSocket 直连 CDP（`Runtime.evaluate` / `Emulation.setDeviceMetricsOverride` /
`Emulation.setTouchEmulationEnabled` / `Input.dispatchTouchEvent`）就能**发真实触摸事件**验证「划得动」，
不用装 playwright。两个坑：curl/node 访问 127.0.0.1 要 `--noproxy '*'` 且给 node 去掉代理环境变量；
本地静态服务器要 `run_in_background` 起，前台 `(... &)` 子 shell 在命令结束就被收掉。
实测：文章页触摸上滑 0→273、目录页 470→955，抽屉开合与遮罩都正常。
