## 23:31 主站导航固定观感修复（融资等 iframe tab 上「个人/法务实务」两行看着像没固定）
- 现象：用户确认融资 iframe 内 #topbar（总纲/01创业起步）已 sticky 后，发现主站 header 的两行（主 tab 行 个人/法务实务 + 法务实务子 tab 行 刑事/AI+法律/保险/融资）「不固定」。

- 真因（视觉错觉）：融资等 tab 是 iframe 内滚动、主页面不滚动 → `window.scrollY` 永远 0 → `isScrolled` 恒 false → header 始终 `bg-transparent`，透明浮在白色 iframe 上方，看着「没固定」；而 iframe 内 #topbar 是实色 sticky，对比之下像「它固定了、上面的没固定」。
- 修复：`Navbar` 加 `solid?` 开关，`scrolled = isScrolled || solid`；`App` 在 iframe 类 tab（`isFullBleed` 已含融资/保险/物流/IP/劳动/影视，另补 `criminal`/`ai-law` 这两个内嵌 iframe 但不在 isFullBleed 列表的 tab）传 `solid={headerSolid}`，使 header 默认显示实色+分隔线，明确钉住观感。`npx tsc --noEmit` 0 错。
- 待用户硬刷验证；若仍「真·滚走」则非此因，需截图排查浏览器特异性（代码与线上 bundle 均确认 fixed 生效）。
