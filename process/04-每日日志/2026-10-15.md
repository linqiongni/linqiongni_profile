## 做了什么

- 社区排查：搜 GitHub 社区，无可直接搬运的「多邻国韩语课程笔记」开源仓库；可用资源只有 duome.eu 的官方 Tips & Notes 镜像（版权内容，只外链不照搬）与一个导出自己词表的脚本。
- 导航接线：types.ts 加 `korean` / `korean-notes` / `korean-ref`；navConfig 的 `profile.subTabs` 加 `korean`、SUB_TAB_META 加三项、GROUP_OVERRIDES 加 korean-notes / korean-ref → profile；App.tsx 加导入、三个渲染分支、isFullBleed 与回顶部列表。
- 组件：新建 KoreanHubTab（两张卡片二选一）、KoreanNotesTab、KoreanRefTab（ThemeIframe 嵌 public 子站，深浅色随主站 postMessage）。
- `public/korean-ref/index.html`：公共领域韩语入门书面材料（19 辅音 + 21 元音字母表、发音规则、核心语法 SOV / 助词 / 이다 / 있다 / 否定 / 时态 / 敬语 / 数字、场景常用语、资源外链），B 布局左栏目录 + 搜索 + scrollspy。
- `public/korean-notes/index.html`：按 5 个单元排的可编辑笔记卡（新单词 / 语法点 / 我的例句 / 易错点 / 复习打卡），localStorage 自动保存 + 导出 Markdown + 可加自定义卡片。
