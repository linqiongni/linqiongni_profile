## 这是什么

`linqiongni_profile` 是 Andy 的**个人主页与法务作品集站点**，发布在 **https://linqiongni.top**。

人设：林琼霓 · 港企珠宝法务。站上所有内容都围绕这一身份展开——既是作品集，也是「一个法务怎么把自己的经验产品化」的实验场。

两种内容形态并存：

1. **个人主页**（React 应用）：主页 / 关于我 / 专业技能 / 案例展示 / 思考观点 / 日常分享
2. **十几个法务知识子站**：纯静态 HTML，被 iframe 嵌进主页的 tab 里。每个子站是一个完整专题（融资法务、商事仲裁、婚姻家事……），体量远超主页

## 这件事的难点在哪

不是写代码，是**内容**。技术动作已经很标准化（改源目录 → sync → tsc → commit），真正的成本在法条核校、内容脱敏、以及「这个专题该讲什么」的判断。

所以 `process/03-问题台账/SOLVED.md` 里记的大多是**工具环境坑**而不是代码 bug——代码的坑一天能查完，环境坑能卡你两小时。
