## 二、风险一：中文源目录与 `public/` 副本长期不同步 —— sync 方向是反的

`process/01-项目现状/sites-map.md` 写的是「改内容改中文目录，再跑 `npm run sync:xxx`」。
扫描下来这条约定**在当前状态下是危险的**。

### 事实

`rsync -a --dry-run` 逐站比对，8 个站里有 7 个存在大量文件不一致：

| 源目录 → 副本 | 不一致文件数 |
|---|---|
| `婚姻家事与遗产继承` → `public/family-law` | 28 |
| `商事仲裁` → `public/arbitration` | 22 |
| `商业运营法务` → `public/commercial-ops` | 21 |
| `融资法务` → `public/financing-legal` | 21 |
| `跨境物流法务` → `public/logistics` | 15 |
| `新零售与广告合规` → `public/retail-ad` | 10 |
| `身边的英语` → `public/english` | 2 |
| `经济犯罪辩护` → `public/econ-crime` | 0（刚同步过） |

抽查「不一致」的具体内容（`商事仲裁/ch01.html` vs `public/arbitration/ch01.html`，203 行差异）：

- 源目录：`<html lang="zh-CN" data-theme-default="light">`
- `public/` 副本：`<html ... data-theme-default="dark" data-theme="dark">`
  并且**额外注入**了三块手工补丁：`DARK_UNIFY_START v1`（暗黑配色块）、
  `SUB_THEME_KIT_START`（`<link theme-light.css?v=3>`）、`AQUATIC_BG_KIT_START v3`（水波纹）。
- 线上（`https://linqiongni.top/arbitration/ch01.html`）实测：**含 `DARK_UNIFY` ×2、不含 `#091A2E`**
  → **线上是带补丁的那版，中文源目录是没补丁的那版。**

也就是说：**补丁是手工打在 `public/` 上的，中文源目录从来没打过。**

### 为什么这是定时炸弹

任何人在中文目录改了一个字，再跑 `npm run sync:all-static`，
rsync 会用「没打补丁的源」覆盖 `public/` 里的同名文件 —— **那个子站的暗黑模式当场消失**。
而且它不会报错，线上照样 200，只是配色回退。**没人会发现，除非有人正好点开那一个站。**

全仓库 grep `DARK_UNIFY` 只命中 `MEMORY.md`、`workflows.md`、今日日志三个文档里，
**没有任何脚本负责注入** → 补丁是纯手工产物，不可重放。

### 建议（等 Andy 拍板，先别动手）

三选一：

1. **把补丁脚本化**（推荐）：写一个 `scripts/apply-subsite-theme.sh`，把暗黑块 + 水波纹 +
   theme kit 按同样位置注入中文源目录的全套 HTML，再 `sync`。以后源头就是干净的、可重放的。
2. **反过来**：承认 `public/` 是唯一真源，删掉中文源目录这个概念，全部直接在 `public/` 改，
   去掉所有 `sync:` 脚本。代价：丢掉「中文档案目录」这个可读性最好的结构。
3. **最省事**：至少在 `workflows.md` 加一条红字——「**动过中文目录内容后，不要跑 sync，
   先手动把暗黑补丁补回来**」。不推荐，这等于把纪律当机制。

## 五、My 结论

结构本身不差 —— `process/`（过程档案）/ `src/`（React 主站）/ public+中文源目录（静态子站）
三块职责是清楚的。**问题不在这四块怎么分，而在「同一份内容有两处真源、而且两处不等价」**。

优先级（Andy 定，我不擅自动）：

1. **风险一** —— 会静默破坏线上配色，优先级最高，建议先脚本化补丁。
2. **风险二** —— 已上线但无人访问的 92 页，顺手下掉，风险低。
3. 4.2 / 4.4 —— 纯清理，随时可做，不要紧。

**一个反复出现的规律**：这次两条风险都不是「文件放错了地方」，是「**有东西只有一处是对的，
但没有机制保证它一直是**」。手工补丁会丢、孤儿文件会飘上来，都因为它们是靠人记得，
不是靠跑命令。和 hook 静默失败、验线成靠记得，是同一个病根。
