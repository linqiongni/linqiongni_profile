## 一、一句话说清这是什么

`linqiongni_profile` = Andy 的个人主页与法务作品集站点，发布在 **https://linqiongni.top**。
主体是 React 应用（个人主页 + 各法务领域的 iframe 子站），外加十几个**纯静态 HTML 子站**（用 iframe 嵌进来）。

### 三个常见任务的路径

任务之间会跨文件，**下面是被验证过的路线，按序走**：

| 我要…… | 先看 | 再看 | 收尾 |
|---|---|---|---|
| **改某个子站的文字内容** | `sites-map.md` 确认它有源目录 | `workflows.md` 第一节 | `sync` → `grep` 核对 → push |
| **新增一个子站 tab** | `sites-map.md` 登记源目录与 slug | `workflows.md` 第二节（四步）→ `tech-stack.md` 确认加载方式 | 上线后用 `workflows.md` 第三节验证 |
| **改视觉（配色 / 字体 / 动效）** | `DECISIONS.md` 找同类先例，**别推翻没看过的决定** | `01-项目现状/` 无相关记录再看代码 | 改完回 `DECISIONS.md` 追加一条 |
| **换设备 / 新 clone 之后** | clone → `bash scripts/setup-device.sh`（装 hook + 自检六项）→ 贴 **`process/开场白.md` 里的可复制全文**（换设备要先跑的两行也写在那里） | `scripts/setup-device.sh` | 自动完成，每台设备一次 |
| **提交代码（收工）** | 只写 `git commit`——hook 会自动 rebase 到线上最新并推上去，**别手写 push** | `scripts/install-git-hooks.sh`（已装） | 自动完成 |
| **把做了一半的东西打包带走**（换电脑 / 中断） | 填 `HANDOFF.md` 前三节（脚本会拦空卡） | `python3 scripts/wip-pack.py -m "一句话"` 一条命令 | 自动从 `wip/` 分支 commit 并 push（**绝不推 main**） |

**为什么先说 sites-map 再说 workflows**：源目录在哪决定了一切。抄错了地方，改了也白改。

## 四、维护约定（以下六条不可破）

1. **入口只读 README。** 其余文件被 README 单向引用；不要在别处再写一份索引，否则必然腐烂。
2. **每日索引必须同步。** 写了 `04-每日日志/2026-09-28.md`，当天就要在本文件「今日索引」加一行。
3. **结论往上提，过程留在日志。** 一条一次性的发现别塞进 `01-项目现状/`，它是会变的。
4. **未解决必须写「下次第一步」。** 只写「待办」的条目三个月后没人认领。
5. **决策只记不可逆的。** 目标总量 ≤ 20 条。什么都记 = 没人读 = 没有。
6. **每次收工都写日志**，哪怕只改了一行。漏了就在第二天补，别攒。
7. **收工的具体动作以 `CONTRACT.md` 为准**（写日志 / 更新今日索引 / 提台账 / 提决策 / push）。本文件只定结构，不定动作。

## 七、验收记录

这份档案库做过一次**冷启动测试**：让一个全新的 AI 只读本文件，尝试回答「项目是什么 / 还挂着什么没解决 / 上个月在干什么 / 配色怎么定的 / 怎么加一个子站」。

结果（2026-09-27）：

| 问题 | 结果 |
|---|---|
| 项目是什么 | 仅读本文件即可答出 |
| 还挂着什么没解决 | 仅读本文件即可答出 |
| 上个月在干什么 | **不合格**，原因是当时没有月度复盘文件 |
| 配色怎么定的 | 跳读决策日志后答出 |
| 怎么加一个子站 | 跳读工作流后答出，但当时缺跨文件串联提示 |

**据此补的三处**：加了 `06-复盘/M09.md`（月度层）、加了「三个常见任务的路径」（跨文件串联）、加了「视觉基调速查」（把关键事实提到入口层，不留在本文件里靠猜）。

**结论**：一份"写完就不再看"的档案不是入口，入口要能被检索时机命中。下次改结构时，保持这三条：**查阅时机写具体、关键事实提到入口层、任务路径跨文件串联**。

### 第二轮：补的其实是「行为层」

第一次测试只考了**内容**（档案库里有没有答案）。但这次测试暴露了一个更根本的缺口：

> 就算一个新 AI 完整读到了本文件，它也不知道**自己有义务维护这个档案库**。
> 「有档案」和「会持续更新档案」是两件事——前者靠内容，后者靠契约。

所以补了 `CONTRACT.md`（行为规则）+ `MIGRATION.md`（换环境），并在 `AGENTS.md` / `MEMORY.md` 顶部挂了指路。
**没有这两处指路，前面所有内容都等于没写**——因为接手的 AI 压根不会打开这个目录。`AGENTS.md` 是每次会话必读的第一站，它不提 `process/`，这个档案库就是不存在的。
