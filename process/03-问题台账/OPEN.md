### #05 · 本地 Terminal 里跑 git 报 TCC 权限

- **现象**：Andy 在本机「终端」-app 的 `~/Downloads/linqiongni_profile` 里跑 `git status` 报 `fatal: Unable to read current working directory: Operation not permitted`；AI 侧同一命令 exit 0。
- **根因已定位**：不是仓库损坏，是 macOS TCC（完全磁盘访问）权限——git 在这里调用 `getcwd()` 被系统拒。AI 侧不报错是因为 Bash 跑在 WorkBuddy 宿主进程里、被授予了这些目录的访问权。
- **卡在哪**：需要用户授权，AI 改不了系统设置。
- **谁该动**：Andy。
- **下次第一步**：系统设置 → 隐私与安全性 → 完全磁盘访问 → 添加「终端」。加了之后重跑一次 `git status` 确认。
