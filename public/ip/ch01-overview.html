STATION 01 · OVERVIEW

总论：IP 到底是什么，老板为什么要在乎

一家公司最值钱的，往往不是厂房设备，而是它脑子里的东西——名字、款式、技术、客户名单。这些"看不见的资产"怎么变成"受法律保护的权利"，这一站讲清楚。这一步最便宜，但后面每一次被抄、被抢注，代价都由当初没护好的人付。

林栖在铜锣湾开了「栖梧珠宝」第一间店。店名是自己想的，款式是自己画的，生产找的是家门口的小作坊。一切都顺。

直到有一天，她在内地逛商场，看到一家店挂着几乎一样的"栖梧"招牌，卖着几乎一样的款式。她才发现：名字没注册、图纸只存在自己电脑里、所谓的"原创"在法律上什么都不是。这一站，就是回到那个什么都没护的早晨，把该做的事一件件补上。

一、IP 不是"一个权利"，是"四家人"

一句话知识产权是个大帽子，底下住着商标、专利、著作权、商业秘密四家人，各管一摊，规则完全不同。把款式当商标去注册、把名字当专利去申请，都会碰壁。

先解决第一个问题：为什么"知识产权"不能当成一个东西来保护。下面这张表以后你会反复用到。

权利护的是什么怎么取得保护期典型场景
商标区分商品"是谁的"申请 + 注册10 年，可无限续展品牌名、Logo、包装造型
专利技术方案 / 外观设计申请 + 授权发明 20 年 / 实用新型 10 年 / 外观设计 15 年链扣结构、镶嵌工艺、产品外形
著作权文学艺术作品（表达）自动产生（登记自愿）作者终生 + 50 年款式图稿、宣传大片、文案
商业秘密保密的技术 / 经营信息保密即存在只要保密就一直有客户名单、工艺参数、定价模型
打个比方 · 四家人

把一家公司想成一个人家。商标是这家人的姓氏——别人一看姓就知道是谁家；专利是这家人独门手艺的专利证书——别人不能照着做；著作权是这家人写的日记和画的画——落笔就有，但得证明是你写的；商业秘密是这家人关起门来说的悄悄话——只要不外传就一直算数，一旦说出去就没了。

法源

《民法典》第 123 条：民事主体依法享有知识产权，客体包括作品、发明实用新型外观设计、商标、商业秘密等。
《商标法》《专利法》《著作权法》《反不正当竞争法》分别规定四类权利的具体内容。

二、权利怎么"来"：三种取得方式

一句话记住三条路：自动产生（著作权）、申请确权（商标/专利）、保密存续（商业秘密）。搞错路径，等于没护。
自动保护Automatic
著作权天然附着于作品。但"有权利"和"能证明有权利"是两回事——没留证据，告人时先要证明"这图是我画的"。
确权（申请取得）Registration
商标、专利必须主动向主管部门申请。不申请 = 没有专用权，别人用同名同技术你管不了。
保密存续Secrecy
商业秘密靠"一直藏着"活着。一旦公开（无论主动还是泄密），权利立刻消失，且不可恢复。
法务对话对话 01 · 知识产权到底是个啥，我为什么要花钱护它？
林栖
老板

我开个珠宝店，卖的是真金白银，跟"知识产权"有什么关系？那不是科技公司才要管的吗？

法务
你

关系大了。你店里最值钱的，可能恰恰不是金子，是名字和款式。名字让人记住你、款式让人想买你——这两样被人抄了、被别人抢注了，你辛辛苦苦养的"识别度"就白养了。就好比你开了家面馆，汤底是你熬了三年的秘方、招牌是你起的名字。有人在你对面开一家同名面馆、用一样的汤底——顾客分不清，你的客流就被分走了。这时候你要能说"这名和这配方是我的"，前提是你早就把它们变成受保护的权利。

阿杰
合伙人

那是不是很贵、很麻烦？

法务
你

分三档：著作权免费自动有（但你得留证据）；商标几百块一件、十年一续；专利贵些但要护核心技术才值。最贵的永远是"没护，等到被抄才补救"。就好比装一把门锁几十块；等家里进了贼、丢了东西才想起装锁，那把锁的代价就是全部损失。

翻译成条款 把"名字 + 款式 + 技术 + 名单"四类资产分别映射到商标 / 著作权 / 专利 / 商业秘密四种保护路径，建立资产台账并排期申请。
落点：图 1-1 权利地图与自检清单。
法务对话对话 02 · 名字我不注册，先用着不行吗？
林栖
老板

"栖梧"这名字我都用一年了，注册还要等好几个月，先开着店不行吗？

法务
你

可以先用，但风险是你用了不等于你拥有。商标权看"谁先注册"，不是"谁先想到"。你不注册，别人抢先注册了，反而能禁止你用。就好比你给娃起了个小名天天叫，但没上户口。别人抢先去上了"这个名字"的户口，法律就认别人是"合法"的，你反而成了"重名"的那个。

阿杰
合伙人

那我现在注册还来得及吗？

法务
你

赶紧查、赶紧申。先在中国内地、香港以及你未来要卖的所有地方都检索一遍，没撞车就立即递交。注册有"优先权的窗口"，晚一天都可能被别人占先。就好比抢车位。你天天停的那个位没画线，别人拿漆画了线、挂了牌，那个位就成他的了。想保住，趁没画线赶紧占。

翻译成条款 名称 / Logo 在全部目标市场做可注册性检索 + 尽早递交商标注册申请（含多类别防御注册）+ 留意优先权期限。
落点：第 02 站与第 08 站。

三、权利地图：一次把"我家有哪些资产"画清楚

一句话给一款产品做"权利地图"：拆客体 → 配权利 → 排时间轴。这一步做完，你才知道缺哪块。
法务对话对话 03 · 我画的款式，别人抄了算不算侵权？
林栖
老板

我画的星轨项链图，隔壁店一模一样在卖。这不算侵权吗？

法务
你

算，但要分两层：第一，图稿本身你有著作权，别人复制销售侵害你的复制/发行权；第二，如果这款项式的"整体造型"有独创性，还能当美术作品护。关键是你得先证明"这图是你先画的、是你的"。就好比你写了首歌，别人拿去唱。你当然可以告；但如果你连草稿、录音、发表记录都没有，法庭上你怎么证明"先写的是你"？

阿杰
合伙人

那我现在该做什么？

法务
你

三件事：①给所有图稿做时间戳 / 区块链存证留创作时间；②在作品登记平台做著作权登记拿证书；③发现仿款立刻公证购买固定证据。就好比你拍了张珍贵照片，先存云端带时间戳、再冲洗一张盖章留底、看到有人盗用先偷偷买一份留作"赃物"证据——三步齐了，告人才有底气。

翻译成条款 图稿完成时即留存证（时间戳/区块链）+ 自愿著作权登记 + 监测到仿款立即公证购买固定证据。
落点：第 04 站与第 07 站。

四、专利和著作权，护的是同一个东西吗？

一句话同一个"链扣"，外形归著作权（美术作品），结构归专利（实用新型/发明），两者不冲突，可同时拿。但"想法"谁都护不了。
打个比方 · 想法 vs 表达

著作权护"你画出来的那个样子"，专利护"你造出来的那个结构"。但"我想做个更轻的链扣"这个想法，谁都不护——想法是公共资源，落地成具体图纸或结构才进保护范围。就好比谁都可以想"做一辆更快的车"，但只有把具体设计画成图、造出样车去申请，才有人拦得住别人抄。

法务对话对话 04 · 商业秘密和专利，我该用哪个护技术？
林栖
老板

我们的镶嵌工艺，是申请专利好，还是当成商业秘密藏着好？

法务
你

看这技术容不容易被反向工程。如果产品一上市，对手拆开就能学会——那藏着没用，别人学会了你还没法证明他"偷"，不如申请专利，用公开换独占。如果工艺藏在生产线里、对手看产品也学不会——那保密更划算，专利一公开反而把秘密交出去了。就好比一道菜。如果食客吃一口就能复刻，你别藏着，赶紧去注册商标、把配方写成专利（虽不能复刻细节，但占品类）；如果是独门火候、后厨才懂，那就锁在后厨、签保密协议，别公开。

阿杰
合伙人

那商业秘密会不会哪天突然没了？

法务
你

会。一旦公开，权利当场消失，且不可恢复。所以保密措施（加密、分级、签协议、物理隔离）不是形式，是权利的"命根子"。就好比你家的传家秘方，只要一天没外传，就一直是你家的；哪天你发朋友圈晒了全文，这秘密就归全人类了，再想要回来要不回。

翻译成条款 按"是否易被反向工程"在专利与商业秘密间二选一 + 选商业秘密则落实保密措施（分级/加密/协议/隔离）+ 选专利则在公开前完成申请。
落点：第 03 站与第 05 站。

五、两个老板最容易忘的"底牌"

一句话先用权是被诉时的盾，职务作品是权属的雷。两个都靠"提前留证据 / 提前写清楚"，临时抱佛脚都来不及。
先用权Prior Use
你在别人申请专利之前就在用同样技术，可以继续用。但必须能证明"先用"的时间点。
职务作品 / 委托作品Work for Hire
员工为工作画的图，权属可能归公司；外包给设计师画的，无约定则归设计师。约定不清，公司花钱养的设计却不是自己的。
法务对话对话 05 · 设计师离职，他画的图算谁的？
林栖
老板

我们请的自由设计师画的系列图，他离职了说版权是他的，要我们付费授权。这合理吗？

法务
你

看当初怎么签的。没写归属，默认归设计师（受托人）。你付了设计费，不等于买了版权——只买了"委托创作"。就好比你请人给你画了幅肖像，付了画师钱。没说"画完版权归你"，那这幅画著作权还是画师的，你想印在明信片上卖，得再问他买授权。

阿杰
合伙人

那以后怎么防？

法务
你

所有外包创作，合同里写明"著作权归委托方（公司）所有，含署名权以外的全部财产权"，并约定交付即转让。员工设计的，在劳动合同/保密协议里写清职务作品归属。就好比请人盖房，合同写清"房子和图纸都归你"。不写，图纸还是施工队的，你住进去还得求他别把图纸卖给别人。

翻译成条款 外包创作合同载明著作权归委托方 + 员工职务作品归属条款 + 交付即转让的时点约定。
落点：第 04 站与自检清单第 6 条。
法务对话对话 06 · 我们这套 IP，能不能拿去银行质押、或者作价入股？
林栖
老板

公司现在缺现金，但"栖梧"这个牌子、那些专利应该挺值钱。能不能拿它们换钱？

法务
你

能，而且这正是 IP 从"成本"变"资产"的关键。两条路：①质押——把商标专用权、专利权、著作权里的财产权押给银行换贷款，质权办了登记才设立；②作价入股——用知识产权评估作价，当成出资换合作方的股权。核心前提是你真的"持证"且能估价——没注册、没证书的，银行不认。就好比你想拿房子抵押贷款，银行要看房产证；没证的"权益"它不敢接。IP 也一样，证书就是它的房产证。

阿杰
合伙人

那评估会不会被高估坑了？

法务
你

法律要求评估作价、不得高估也不得低估，而且出资后如果 IP 实际价值明显不足，出资人可能要在差额范围内补钱（补足责任，依公司法与章程）。所以别为了撑估值乱评，后面要填坑。就好比你拿一幅画入股合伙，估太高大家开心，但真到分家发现画只值一半，你得来补那一半。

翻译成条款 梳理可用于质押/出资的已确权 IP 清单（商标证/专利证/软著证）+ 委托评估 + 办理质权登记或写入公司章程/投资协议。
落点：第 08 站（IP 资产入表与组合）。
法务对话对话 07 · 我们的官网域名 qiwu.com，要不要也护起来？
林栖
老板

域名算不算 IP？别人抢注 qiwu-jewelry.com 卖仿品，我怎么办？

法务
你

域名本身不是典型知识产权，但它是商业标识的延伸，三层都能护：①把域名核心词"栖梧 / qiwu"注册成商标，对方用近似域名造成混淆可依商标法打；②域名若与你有"一定影响的字号/域名"冲突，可依《反不正当竞争法》第 6 条（企业名称/域名混淆）维权；③通过域名争议解决机制（如 UDRP / 国内 CN 域名争议）投诉恶意注册。最稳的还是"商标 + 域名同步注册、核心词全占"。就好比你开店，门牌号（域名）和店名（商标）要一起占。只占了店名、门牌被别人挂了同名，顾客照样走错门。

翻译成条款 核心品牌词同步注册域名 + 商标（含第 35/42 类相关）+ 监测近似域名 + 遇恶意注册走商标侵权/反法第 6 条/域名争议程序。
落点：第 02、08 站。

八、民法典第 123 条逐个数：知识产权的客体到底有几种

一句话很多人以为"知识产权"就是商标 + 专利。其实《民法典》第 123 条把客体列了八类，商标专利只是其中两员。把全集看一遍，你才不会被"这东西归哪类管"卡住。
客体（民法典第 123 条）对应权利珠宝业相关度一句话
作品著作权★★★★★款式图稿、宣传大片、文案、小程序代码
发明、实用新型、外观设计专利权★★★★链扣结构、镶嵌工艺、产品外形
商标商标权★★★★★品牌名、Logo、包装造型、声音
地理标志地理标志（商标/专用标志）★★特定产地原料（如某地产黄金/珍珠），可做产地背书
商业秘密商业秘密权★★★★★客户名单、工艺参数、定价模型
集成电路布图设计布图设计专有权★自研芯片/智能首饰电路时用到
植物新品种新品种权—珠宝业基本不沾，列上是为了"全集完整"
法律规定的其他客体依特别法★数据权益、域名等新型客体，正逐步纳入保护视野
打个比方 · 八类客体

把知识产权想成一座八层楼。你平时只在一楼（商标）和二楼（专利）进出，但三楼（著作权）管你的图、四楼（商业秘密）管你的名单、五楼（地理标志）管你的产地——每一层都有人守着，只是你没上去过。遇到一个新资产，先问"它在第几层"，别一股脑往商标层塞。

法源

《民法典》（2020）第 123 条明确列举上述客体。《商标法》《专利法》《著作权法》《反不正当竞争法》及《地理标志产品保护规定》《集成电路布图设计保护条例》《植物新品种保护条例》分别规定各客体的取得与保护。
条号与特别法规请以现行文本为准。

九、权能全景：这项权利"到手"后到底能干什么

一句话拿到一个权利，不等于只能"别人不能用"。真正的价值在权能——你能自己用（专用）、禁止别人用（禁用）、授权别人用（许可）、卖给别人（转让）、押给银行（质押）、作价入股（出资）。老板最该懂的是后两项：IP 能当钱用。
专用权 / 禁止权Exclusive
自己用 + 禁止别人用。禁止权是 IP 的"牙齿"——没它，权利只是张奖状。
许可 / 质押 / 出资Monetize
IP 变钱的三种主流方式：授权收租（许可）、押给银行换贷款（质押）、作价入股换股权（出资）。
打个比方 · 权能

一个商标像一套房子：自己住（专用）、不让别人乱进（禁止）、租出去收租金（许可）、卖给别人（转让）、抵押给银行贷钱（质押）、作价入股和人合伙开公司（出资）。很多人只把 IP 当"奖状"供着，其实它是能生息、能抵押、能入股的资产。

法源

《公司法》（2023 修订）第 48 条：股东可用货币出资，也可用实物、知识产权、土地使用权、股权、债权等可以用货币估价并可以依法转让的非货币财产作价出资（法律、行政法规规定不得作为出资的财产除外）。
《民法典》第 444 条：以注册商标专用权、专利权、著作权中的财产权出质的，质权自办理出质登记时设立。
知识产权出资须经评估作价，不得高估或低估；具体以现行法及章程为准。

十、知识产权法与反不正当竞争法：谁是主、谁是补

一句话商标、专利、著作权是正面确权（持证上岗）；反不正当竞争法是兜底补救——那些"没注册但有点名气"的商业标识、那些"抄得不像侵权但让人混淆"的行为，靠它兜住。
案例 02｜"长得像"但不构成商标侵权，怎么办？

栖梧一款古法金手镯火了，竞争对手出了一款造型高度近似、但没用"栖梧"二字的镯子。商标层面（对方没用相同/近似标）未必构成侵权；但对方擅自使用与栖梧"有一定影响的商品装潢"近似的造型，可依《反不正当竞争法》第 6 条（混淆行为）打——只要栖梧能证明该造型"有一定影响"且足以引人误认。

就好比有人没用你家店名，但把门店装修、招牌配色、员工制服全抄得一模一样，顾客进去就以为是连锁。商标管不了"名字没抄"，但不正当竞争法管"整体让人混淆"。

法源

《反不正当竞争法》（2019 修正）第 6 条：擅自使用与他人有一定影响的商品名称、包装、装潢等相同或者近似的标识，引人误认为是他人商品或者与他人存在特定联系，构成混淆行为。
注意：反法保护的是"有一定影响"的商业标识，不要求注册，但需举证知名度与混淆可能性。

十一、自检清单

一句话这一站的自检，本质是在问：公司脑子里的资产，有没有一张看得见的账。
  • 品牌名 / Logo 是否在所有目标市场完成可注册性检索并提交申请？
  • 每款产品的图稿是否在完成时即留存证 + 著作权登记？
  • 核心技术是按"专利"还是"商业秘密"保护？选商业秘密的，保密措施是否落到了纸面？
  • 员工职务作品、外包设计的著作权归属是否在合同里写清？
  • 是否有"先用权"风险点（别人可能主张先用）？
  • 客户名单、定价模型等经营信息是否加密 + 签保密协议？
  • 出海计划是否排了马德里 / PCT 优先权时间窗？
  • 是否建立了"上新即填"的 IP 资产台账？
