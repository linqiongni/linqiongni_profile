第 32 周 自测卷

综合实战（二）　·　答案内嵌显示，无需点击展开
本周聚焦跨境案件、刑事控告、技术类案件三套演练，外加谈判调解与出师收官。每题答案直接附在题后，无需点击展开；重点检验双视角（权利方/被诉方）与中国香港/中国澳门/中国台湾的正确法域表述。
D1 · 自测
跨境案件演练
QD1-1中国香港店铺售仿款，我方在内地有注册商标，能否直接依据内地商标在中国香港主张侵权？判断
参考答案不能。商标权有地域性，中国香港是中国的单独法域，内地注册不在港自动有效，须在中国香港单独注册才能主张。不得把中国香港与外国并列称「国家」，应表述为「目标法域」。未注册时只能走平台规则或当地不正当竞争兜底。
QD1-2内地取得的证据想在美国法院使用，要经过什么认证程序？与用于中国香港有何不同？简答
参考答案用于美国属涉外，须公证后再办《海牙认证公约》Apostille（⚠ 中国 2023-11-07 加入，适用范围待核实）或领事认证。用于中国香港属区际，依内地与中国香港的区际司法协助安排转递/公证，不是同一套涉外程序。未认证证据境外法院通常不予采信。
QD1-3某珠宝品牌发现中国香港、美国两站点均有仿款，请列《跨境维权路径决策表》的四栏与每栏要点。实务
参考答案四栏：① 权利地图（各目标法域注册状态，中国香港须单注、美国须 USPTO/在先使用）；② 取证与认证（中国香港委托公证人、美国公证+Apostille）；③ 平台投诉（Amazon Brand Registry/投诉表，分站点提交）；④ 民事/刑事路径+成本周期（中国香港海关+区域法院、美国联邦诉讼，金额标待核实）。同时预判对方「无注册/平行进口/不近似」抗辩。
D2 · 自测
刑事控告演练
QD2-1前代工厂主管带走 3D 建模文件与模具图纸另产同款，只能定侵犯商业秘密罪吗？判断
参考答案不一定。核心是用侵犯商业秘密罪（刑法第 219 条，3D 文件/模具图纸属技术秘密）；若其产品还冒用品牌注册商标，另涉假冒注册商标罪（第 213 条），并可能连带销售假冒（214）、非法制造标识（215）、侵犯著作权（217）。报案须齐备「保密性+同一性+损失」三证。⚠ 各罪数额以现行司法解释为准。
QD2-2假冒注册商标罪「情节严重」的数额门槛是多少？公安不立案还有什么救济？简答
参考答案常见口径：非法经营数额 5 万（特别严重 25 万）、违法所得 3 万（特别严重 15 万），⚠ 以现行司法解释为准。公安不立案，可向检察院申请立案监督（要求说明不立案理由、通知立案）；同时先补正材料包（权利证明、保密措施、同一性鉴定、损失核算）再报。
QD2-3经侦报案被拒多因「三证缺一环」，代工厂场景应如何固定「接触」与「实质相同」？实务
参考答案① 接触：固定其曾任主管、能接触 3D 文件的证据（保密协议、权限分级、访问日志、离职时间）；② 实质相同：公证购买其产品并委托有资质机构做同一性鉴定（被诉品与秘密文件是否实质相同）；③ 损失：以其网店销量×毛利核算撑入罪门槛。三证齐备再报，不立则走立案监督。⚠ 鉴定与数额以现行规定为准。
D3 · 自测
技术类案件演练
QD3-1「可换戒托结构」专利案，被诉品少了一个必要技术特征但功能相同，构成等同侵权吗？判断
参考答案不构成。全面覆盖原则要求每一项必要技术特征都在被诉品中找到相同/等同对应；少一项必要特征即「未覆盖」，不成立侵权。等同只放宽「相同」、不豁免「缺特征」。若缺的是非必要特征则另论。⚠ 以现行专利法第 64 条及判例为准。
QD3-2禁止反悔原则如何锁死权利方的等同主张？被诉方还有什么王牌？简答
参考答案若权利方在授权/无效中为区别于现有技术明确限缩某特征（如强调「簧片防脱」区别于现有磁吸），侵权诉中不能再把被诉磁吸防脱主张为等同——禁止反悔封口。被诉方王牌：① 现有技术/现有设计抗辩（属申请日前现有技术则不侵权）；② 无效反击（向复审和无效审理部门提无效，专利无效则基础消失）。⚠ 无效时限以现行规定为准。
QD3-3复杂结构专利比对，要不要申请鉴定或技术调查官？二者意见性质有何不同？实务
参考答案复杂结构可申请司法鉴定（机构出具的鉴定意见属法定证据，质证看资质/检材/方法/逻辑）与请技术调查官（法院技术参谋，出技术调查意见仅供法官参考、非证据、不替代裁判）。两者常并用：鉴定打底+调查官把关。被诉方借专业追问暴露对方比对逻辑漏洞。⚠ 职权以现行规定为准。
D4 · 自测
谈判与调解
QD4-1双方自行签的侵权和解协议，对方违约我可以直接申请强制执行吗？判断
参考答案一般不能。自行和解的协议仅具合同效力，须先申请司法确认（⚠ 现行民诉法规定）经法院裁定后才具强制执行力；法院调解书签收即生效可强制执行。未确认的协议违约方可能翻车，关键条款务必走司法确认。
QD4-2什么是 BATNA 与 ZOPA？用珠宝仿款案说明怎么用。简答
参考答案BATNA 是谈崩后的最优替代（权利方=判决/下架，被诉方=败诉风险）；ZOPA 是双方可接受交集。仿款案权利方 BATNA 是判决赔 80 万但耗 2 年，被诉方 BATNA 是败诉+惩罚性；若 ZOPA 在 50—65 万则在此成交最优。算不清 BATNA 易被牵着走。
QD4-3跨境调解协议最容易漏什么条款？刑事案里「赔钱和解」能免刑吗？实务
参考答案跨境漏准据法、管辖与执行条款——涉及中国香港、美国等法域须约定适用法、管辖及判决承认执行路径（区际安排/外国判决执行，⚠ 待核实）并对境外资产加担保，否则赢了难执行，表述仍用「目标法域」、中国香港非外国。刑事案赔钱取得谅解只是量刑情节，不能「花钱买刑」抹罪。⚠ 以现行法为准。
D5 · 自测
出师清单与知识体系固化
QD5-1出师标准只看「权利方进攻能力」够不够？知识库要不要标法条版本？判断
参考答案不够。IP 法务既要攻（布局/维权/控告）也要守（抗辩/无效/和解），九大维度双视角都 ≥3 才算合格。知识库必须标「法条版本+核对日」，否则法条修订（如 2020 刑法修正案十一改商业秘密罪表述）后可能引用失效条文，须可审计可追溯。⚠ 以现行有效文本为准。
QD5-2常犯错误清单里哪条是「红线级」？正确表述是什么？简答
参考答案把中国香港、中国澳门、中国台湾当外国、按外国口径计数是红线级错误。正确表述：三者是中国的一部分、为单独关税区/单独法域，必须用「目标法域数」而非「国家数」计数，绝不与外国并列称「国家」。违反即政治与法律错误。
QD5-3出师后 12 个月计划为何先补「自评 <3 的薄弱项」再上真实案件？实务
参考答案自评 <3 表示还不能独立做，先填坑（补马德里/比对表/密点/报案等）再跟案最稳；带病跟案易在关键动作（丢优先权、密点不成立、数额不实）出错。薄弱项清零后，再走「跟 2 真实案→攻跨境/刑事专项→带教出新人与 SOP」四阶段。
WEEKEND · 实战复盘
周末实战复盘 · 出师能力自评与知识库
QWE-1如何把 32 周内容固化成可打分的《出师能力自评表》？给出分值定义。实务
参考答案九大维度（商标/专利/著作/商业秘密/反法/跨境/刑事/诉讼/谈判）各打 1-5 分：1 听过、2 了解框架、3 能独立按模板完成、4 熟练能优化、5 可带教定标准。求平均，<3 即薄弱项入补强清单；跨境/刑事/诉讼建议加权。双视角（攻+守）都 ≥3 才算合格。
QWE-2《个人 IP 知识体系目录树》为什么必须「双视角两栏并存」并单列跨境模块？实务
参考答案IP 法务既要攻也要守，只存权利方动作则公司被诉时知识库失灵，故每模块存「权利方动作+被诉方抗辩」防偏科。跨境单列因其有巴黎公约/马德里/海牙/PCT/区际安排/公证认证/平台投诉等专属知识，且与单法域差别大；表述坚持「目标法域」，港/澳/台为中国一部分。
QWE-3知识库的「更新维护触发机制」与「红线固化」分别解决什么问题？实务
参考答案触发机制防过期：新法/司法解释、经办案件新口径、平台规则变动都触发回写并标核对日，确保引用现行有效法条。红线固化防政治法律错误：港/澳/台表述规则写入知识库首页置顶，任何人引用前先读，明确其为中国一部分、单独法域，绝不当外国计数。⚠ 以现行文本为准。

产出物一：出师能力自评表（含打分标准，可直接打分）

分值行为定义状态
1听过名词，不知怎么用入门
2了解框架，不能独立做了解
3能独立按模板完成合格（底线）
4熟练并能优化模板熟练
5可带教他人、定标准专家

九大维度：① 商标布局与维权 ② 专利（含外观）申请与比对 ③ 著作权与实用艺术品 ④ 商业秘密保密体系 ⑤ 反法（混淆/数据/虚假宣传）⑥ 跨境（布局/取证/平台）⑦ 刑事控告（罪名/数额/报案）⑧ 诉讼（诉状/比对/鉴定）⑨ 谈判调解（BATNA/ZOPA）。每维度双视角（权利方进攻 + 被诉方防守）各打分；任一维度 <3 即薄弱项，列入补强清单；建议跨境/刑事/诉讼加权。

评分公式：加权总分 = Σ(维度分×权重)/Σ权重；合格线 ≥3。出师门槛：九维度双视角均 ≥3，且常犯错误清单能倒背、遇新案 30 分钟内定位法条与路径。

产出物二：个人 IP 知识体系目录树（九模块三级，可检索）

  • 模块一 商标：注册流程 / 异议·撤三·无效 / 马德里 / 侵权比对 / 惩罚性
  • 模块二 专利：申请 / 权利要求解释 / 全面覆盖 / 等同 / 禁止反悔 / 现有技术抗辩 / 无效 / 海牙
  • 模块三 著作权：作品类型 / 登记 / 实质性相似 / 实用艺术品 / 诉前保全
  • 模块四 商业秘密：三性 / 密点清单 / 保密措施 / 刑民交叉（刑法第219条）
  • 模块五 反不正当竞争：第6条装潢 / 第8条虚假宣传 / 第11条 / 第12条数据
  • 模块六 跨境：巴黎公约 / 马德里 / 海牙 / PCT / 区际安排 / 公证认证 / 平台投诉
  • 模块七 刑事：213-217、219 罪名 / 数额 / 报案 / 行刑衔接 / 立案监督
  • 模块八 诉讼：诉状 / 比对表 / 鉴定 / 技术调查官 / 专家辅助人 / 管辖

每模块统一结构：① 权利方动作（怎么布局/维权/控告）；② 被诉方抗辩（怎么无效/和解/不侵权）；③ 法条版本与核对日（⚠ 以现行有效文本为准，如反法第11条存废、刑法数额以最新司法解释）；④ 典型案例与模板链接。

红线固化：知识库首页置顶规则——中国香港、中国澳门、中国台湾是中国的一部分、为单独关税区/单独法域，一律用「目标法域数」表述，绝不与外国并列称「国家」、绝不用「国家数」计数。

产出物三：更新维护与 12 个月落地

  1. 版本管理：每模块标「最后核对日 + 法条版本」，半年一审；
  2. 触发更新：新法/司法解释、经办案件新口径、平台规则变动，立即回写并标核对日；
  3. 12 个月计划：第1-3月补薄弱项（自评<3维度）→ 第4-6月跟2个真实案件全流程 → 第7-9月攻跨境/刑事专项 → 第10-12月带教1名新人并产出 SOP。
交付定位：两份母本（自评表 + 知识库目录）是公司 IP 合规的「活字典」，后续所有新业务、新案件先查知识库再动手；知识库失真即重做，不凑合。⚠ 各法条条号与数额以现行有效文本为准。
