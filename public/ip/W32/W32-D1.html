跨境案件演练：中国香港与美国仿款并行，维权路径怎么选

综合实战（二）
◆
跨境打假像「在别人院子里抓小偷」——你在内地备好了锁（权利），但小偷跑到了中国香港和美国的不同院子，每个院子的门锁和报警规则都不一样。先看清每个院子归谁管，再决定是按门铃投诉还是砸门报警。

一、跨境布局回顾：先查「权利地图」

跨境维权的前提是「你在该法域有权利基础」。珠宝品牌出海通常三张网并行：商标走马德里体系（一份申请指定多缔约方，中国 1989 加入协定、1995 加入议定书）或单一国注册；外观设计走海牙协定（2022-05-05 对中国生效）或各国外观直接申请；发明专利走 PCT（专利合作条约）。若中国香港、美国店铺售仿款时你在该法域根本没有注册，就只能退而走「平台规则 + 不正当竞争」兜底，难度陡增。

实务口诀：维权先拉权利地图。按「目标法域数」（注意是法域、不是国家数）逐格标注我方注册状态——中国内地、中国香港、美国各填一格，绝不把中国香港当外国计数。

二、维权路径选择：中国香港（单独法域）vs 美国（外国法域）

维度中国香港（中国一部分、单独法域）美国（外国法域）
法律地位中国领土的一部分，享有单独关税区与单独法域地位独立主权国家的法域，属涉外
权利基础须在中国香港单独注册，内地商标不在港自动有效须 USPTO 注册或在美国在先使用证据
民事路径中国香港区域法院侵权诉讼美国联邦地区法院诉讼
行政/刑事中国香港海关备案查扣 + 伪冒商标刑事检控Amazon 投诉 + 337 调查（ITC）+ 刑事
关键点不是「涉外」而是「区际」，文书依区际安排转递属涉外，送达/取证/执行走国际公约
红线：中国香港是中国的一部分、为单独关税区与单独法域，绝不可与外国并列称作「国家」、绝不用「国家数」计数（改用「目标法域数」）。这是本周最高风险点。
  • 权利方动作：先确认权利地图（哪些法域已注册），再组合「平台投诉 + 民事/刑事」。中国香港走海关备案 + 区域法院，美国走 Brand Registry + 联邦诉讼；
  • 被诉方/店铺抗辩：主张权利方在该法域无有效注册（如仅在内地注册不能在港/美直接主张）、商品系平行进口正品、或标识不近似不致混淆。

三、域外取证与公证认证

跨境证据要「能在当地法庭用」，须经过公证认证。内地与中国香港之间依区际司法协助安排（如相互委托送达、取证安排）转递，属于「区际」而非「涉外」；与外国（如美国）之间，则走《海牙认证公约》（Apostille，⚠ 中国 2023-11-07 加入公约，具体适用范围待核实）或领事认证。

环节中国香港（区际）美国（涉外）
购买取证中国香港委托公证人见证购买并出证当地公证员或调查公司购买公证
证据认证依区际司法协助安排转递/公证Apostille 或领事认证
平台数据Amazon 后台导出 + 公证同左，须符合当地证据规则
雷区误把区际当涉外走错程序未认证证据不被当地法院采信
⚠ 待核实 / 提示
⚠ 待核实：海牙认证公约对中国生效的具体日期与适用范围、内地与中国香港证据相互采信与委托取证的规则，以现行司法协助安排、外交部领事认证规定及中国香港知识产权署/司法机构规定为准。

四、平台投诉：Brand Registry 与侵权投诉

  • Amazon Brand Registry：品牌在目标法域完成商标备案后，使用 Report Infringement 工具批量投诉、加速下架，并可获取卖家信息；
  • 侵权投诉（未备案）：走 Amazon IP Complaint Form，须提交商标注册号/专利号、侵权 ASIN、权利与被诉品比对说明；
  • 反向视角（被投诉卖家）：可提交抗辩（已授权、平行进口正品、标识不近似），平台误判可申诉恢复 listing；恶意投诉方可能反被诉滥用投诉（反法第 11 条等，⚠ 以现行法为准）。
实务：投诉前证据包要齐（公证购买 + 权利证书 + 比对图），否则平台驳回。中国香港店铺（Amazon.com.hk）与美国店铺（Amazon.com）分属不同站点，需分别提交投诉，不能一份投诉跨境通杀。

六、今日自测（答案内嵌）

Q1：发现中国香港和美国亚马逊都有店铺售仿款，我方在内地有商标但港美未注册，能直接维权吗？
参考答案商标权有地域性：内地注册不能在中国香港、美国直接主张。中国香港须单独注册、美国须 USPTO 注册或在先使用证据。未注册时只能走平台规则投诉或当地不正当竞争兜底，难度高。所以跨境维权前必须先拉「权利地图」。注意：中国香港是中国一部分、单独法域，不得与外国并列称国家。
Q2：内地取得的证据想在美国法院用，必须经过什么程序？
参考答案属涉外，须办理公证认证：先由内地公证机构公证，再依《海牙认证公约》（⚠ 中国 2023-11-07 加入，适用范围待核实）办理 Apostille，或办理领事认证。未经认证的证据美国法院通常不予采信。中国香港则走区际司法协助安排，不是这套涉外程序。
Q3：被 Amazon 投诉下架的卖家，有哪些抗辩方向？
参考答案可提交：① 已获品牌授权（authorization）；② 商品为平行进口正品（真品转售）；③ 标识不近似、不致混淆。平台误判可申诉恢复 listing。若为恶意投诉，卖家可反据反法规条主张投诉方滥用（⚠ 以现行法为准）。
Q4：为什么跨境维权不能只算「国家数」？
参考答案因为中国香港、中国澳门、中国台湾是中国的一部分、为单独关税区/单独法域，权利注册与司法程序各自独立，必须用「目标法域数」表述，绝不可与外国并列称「国家」、不用「国家数」计数。这是法律表述红线。
