你是我的知识产权实务教练。请基于本周 W13 内容，陪我做一次完整的「代理所稿件质量评审」实战推演：假设收到一份「一种防脱落耳钉」实用新型撰稿，逐步用质检四维度打钩，找出边界写窄、公开不足、权项超范围/多余、视图等问题，并产出一份书面评审意见与一封发给代理所的沟通函。

一、实战流程总图

  1. 收稿：代理所提交权利要求书 + 说明书 + 附图/视图，先登记申请号、类型、发明人；
  2. 过表：用《专利稿件质检表》四维度逐条打钩（通过/问题/退回）；
  3. 定位硬伤：标出「窄/空/悬/多」四类问题，每条写清后果（驳回/无效/被绕开）；
  4. 出意见：形成书面评审意见，引法条、提修改要求；
  5. 发函：发《代理所沟通函》，设回复期限，要求回改；
  6. 对账：开会逐条核对修改稿，签字确认后再提交。

二、样本评审：四类硬伤怎么抓

硬伤样本中的表现后果修改要求
窄独立权项写死「18K 金材质」竞品换材质即绕开材质下放从属，独立只留结构必要特征
空实施方式只写「弹性卡接，公知」公开不充分→驳回/无效补具体参数、步骤、实施例
悬权项写「任意限位结构」说明书仅一例得不到支持→缩范围改为说明书实际实施例对应特征
多非必要特征进独立权项无谓缩窄边界下移从属权项
珠宝实务：耳钉这类小结构，代理所容易把「材质/尺寸」写进独立权项图省事。法务评审的第一刀就是把这些非必要特征「请」到从属里，把独立权项的边界撑到结构层面。

三、书面评审意见要点（留痕）

  • 逐条对应：每条问题标明「对应质检项 + 法条依据 + 后果」；
  • 可操作：不只是「请修改」，而是「请将 X 特征由独立权项下放从属权项第 X 项」；
  • 留底：邮件/系统留痕，代理所回改后二次核对再签字。

四、代理所沟通函模板骨架

模板骨架（可直接套用）：① 标题「关于【申请号/名称】专利申请稿件的质量评审意见函」；② 引言「我方已于 X 日收悉贵所稿件，现依专利法及我司质检规范提出如下评审意见」；③ 正文分「权利要求/说明书/支持与必要特征/视图」四节，每条「问题—依据—要求」；④ 结尾「请于 X 年 X 月 X 日前回改并返稿，逾期视为未按约履行」；⑤ 落款与联系人。⚠ 具体法条序号以现行文本核对。

五、周末自测（答案内嵌）

Q1：收到代理所稿件，第一步该做什么而不是急于提交？
参考答案先过《专利稿件质检表》四维度打钩，定位「窄/空/悬/多」四类硬伤并写明后果，形成书面评审意见，再发沟通函要求回改。急于提交会埋下被无效/被绕开的隐患。
Q2：样本里独立权项写死「18K 金」，你作为法务怎么改？
参考答案属非必要特征写进独立权项（「多」类硬伤），应把材质下放从属权利要求，独立权项只保留结构必要特征（针体+弹性卡点+阻尼段），把边界撑到结构层面，避免竞品换材质绕开。
Q3：沟通函为什么要设「回复期限」并写「逾期视为未按约履行」？
参考答案把代理所义务书面化、设违约后果，便于逾期追责/扣费；同时倒逼对方及时返稿，不影响 18 个月公布与 3 年实审等死期。法务评审必须留痕。
Q4：一篇稿件「实施方式」只写「弹性卡接，属公知技术」，能否签字提交？
参考答案不能。属「空」类硬伤——公开不充分，违反第 26 条第 3 款，初审/实审会被驳，侥幸授权也会被无效。必须退回补全具体参数、步骤与实施例后再签。
