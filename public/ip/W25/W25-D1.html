直播带货与代购：IP 风险在镜头前爆发

互联网与新型 IP
◆
直播带货像把「电视购物 + 商场柜台 + 朋友圈」三合一搬进一部手机；镜头一开，主播说的每句话、背景放的每首歌、展示的每件珠宝，都可能踩到别人的 IP 红线。代购则像「人肉跨境搬运工」——搬正品是权利用尽，搬水货/假货就踩雷。
业务落点业务落点：上线一个直播项目或启动代购业务前，先用清单核验「主播身份 + 商品权属 + 素材授权 + 代购链路」四件事。
地基概念 · 水泥沙子（今日必背）

  • 商标侵权在直播场域（许诺销售、销售）
  • 平行进口与商标权利用尽
  • 代购的合规边界（正品代购 vs 售假）
  • 平台与主播的间接侵权责任
  • 通知-删除与避风港规则

一、四方角色：镜头前的 IP 责任归谁

一场直播不是一个人，是四方法的关系——商家（品牌/供货方）、主播、MCN 机构、平台。谁对 IP 侵权「兜底」，取决于各自角色。

角色典型 IP 法律定性主要风险
商家/品牌方商品经营者（电商法、广告法）所售商品本身的商标/著作权侵权——最直接责任
主播广告发布者 + 可能兼广告代言人口播虚假宣传、展示未授权素材、代言未审产品
MCN组织者/经营者对主播内容管理与审核义务，连带风险
平台网络服务提供者适用避风港——尽到通知-删除义务通常不担责
珠宝行业要点：自家品牌自播时，你既是商家也是主播，责任最重；找达人带货，要在合同中把「素材授权 + 正品保证 + 侵权赔偿」写死，否则达人一句「不知道」就甩给你。

二、直播中的商标侵权：镜头即「许诺销售」

直播展示商品、口播链接、上架橱窗，均构成商标意义上的使用与许诺销售/销售。重点盯三件事：

  • 商品真假：带假珠宝、仿款上播，直接落入商标法第 57 条（未经许可使用相同/近似商标）；
  • 背景素材：直播用的背景音乐、字体、PPT 模板、贴纸，若未经授权，分别侵犯音乐著作权、字体著作权；
  • 口播误导：宣称「专柜同款」「某大牌代工」却无依据，可能构成反不正当竞争法第 8 条虚假宣传 + 第 6 条混淆。
⚠ 待核实 / 提示
⚠ 待核实：直播带货中「许诺销售」与「销售」的时点认定、以及口播误导性表述构成虚假宣传（反法第 8 条）与混淆（反法第 6 条）的竞合边界，以现行《商标法》（2019 修正）、《反不正当竞争法》（2019 修正）及监管规则为准。

三、代购：正品搬运 vs 水货踩雷

代购的本质是「跨境搬运」。它能否免责，关键在搬运的是不是正品、有没有权利人的同意。

  • 正品代购（权利用尽）：商品由权利人自行或同意投入市场后，经合法渠道购入再转售，一般适用商标权利用尽，不侵权；
  • 平行进口（水货）：未经国内权利人同意、从境外合法市场购入再进口销售。我国对平行进口尚无统一成文规则，司法多采「国际权利用尽」倾向但个案分歧大——属⚠待核实领域；
  • 假货代购：以代购为名售假，落入第 57 条，且可能触及刑法第 214 条销售假冒注册商标的商品罪。
珠宝/时尚实战：代购「专柜同款」却给不出采购凭证、小票、通关记录，一旦被品牌方盯上，很难主张权利用尽。代购商必须留存完整正品链路（境外小票 + 支付记录 + 物流/通关），这是免责的唯一护身符。
⚠ 待核实 / 提示
⚠ 待核实：平行进口的合法性边界与最新司法口径（如涉及商标权人国内外市场区隔、翻新/改装后再售），请以现行判例与法律职业意见为准，切勿凭印象判断。

四、平台避风港：通知-删除与间接侵权

平台一般不直接为直播侵权买单，因为它只是网络服务提供者，适用「避风港」——前提是收到有效通知后及时采取必要措施（下架、断播）。

  • 权利方动作：向平台知识产权通道提交权属证明 + 侵权链接 + 初步证据，要求断播/下架；
  • 平台义务：收到通知后及时采取必要措施，否则对损害扩大部分担责（「红旗规则」——明显侵权仍不处理）；
  • 主播/商家抗辩（反向视角）：收到通知后可提反通知，说明不侵权理由，平台转送权利人，权利人未及时起诉则恢复。
⚠ 待核实 / 提示
⚠ 待核实：直播/短视频平台的「必要措施」具体范围（是否含断播、限制账号）、通知与反通知的处理时限（如电商法/信息网络传播权保护条例的 15 日规则能否直接套用直播），以现行规则与平台协议为准。
实务动作：发现直播间售假，第一时间录屏 + 平台投诉（成本最低、见效最快），比直接起诉更稳。投诉材料要含：商标证、侵权直播间链接、商品图、价格对比。

五、今日自测（答案内嵌）

Q1：自家品牌自播卖珠宝，背景音乐没买授权，谁担责？
参考答案品牌方（商家兼主播）直接担责，侵犯音乐著作权。自播模式下你既是经营者也是内容发布者，不能在合同里把锅甩给任何人。建议上播前建「背景素材授权清单」。
Q2：从境外专柜合法买正品再转售给国内客户（代购），是否必然不侵权？
参考答案一般是，属商标权利用尽——正品经权利人同意投入市场后转售不侵权。但你必须留存完整正品链路（小票+支付+物流通关），否则无法证明「正品」，且平行进口（未获国内权利人同意的跨境进口）本身仍有⚠待核实的边界风险。
Q3：平台对主播售假要不要赔？
参考答案通常不直接赔，适用避风港——平台收到有效侵权通知后及时下架/断播即免责；若明知（红旗规则）或收到通知后拖延扩大损害，对扩大部分担责。权利方应先用平台投诉而非直接告平台。
Q4：主播达人带货时口播「专柜同款某大牌」，但并无授权，品牌方可以怎么打？
参考答案两条路：① 反不正当竞争法第 6 条混淆（引人误认有授权/关联）；② 第 8 条虚假宣传（虚构同款/代工关系）。同时可追究商家与达人，并在达人合同中约定侵权赔偿与素材授权条款。
