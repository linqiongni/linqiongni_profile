一、三者分不清：游戏画面 / 虚拟财产 / 数字藏品

这三个常被混为一谈，但法律定性完全不同：

对象法律定性保护路径
游戏画面/直播视听作品（著作权）著作权法，含信息网络传播权
游戏装备/账号网络虚拟财产（民法典第 127 条）民法保护 + 用户协议约定
数字藏品/NFT定性模糊：可能是作品复制件/使用权凭证著作权 + 合同，金融监管⚠待核实

⚠ 待核实：数字藏品的法律定性（是作品、复制件、还是新型财产凭证）及相应权利内容，我国尚无统一明文，监管口径随政策变动，以现行法律与监管部门最新规定为准。

二、数字藏品：你买的是版权还是使用权

这是最大误区：买 NFT/数字藏品 ≠ 买到底层作品的著作权。NFT 只是把「某个数字文件的所有权记录」上链，著作权（复制、发行、改编、信息网络传播）仍归原作者，除非合同明确转让。

  • 典型授权：数字藏品多为「非独占、个人欣赏/展示」的使用许可，不含商用权；
  • 版权转移要件：要取得著作权，须有明示的著作权转让合同（书面），光买 NFT 不够；
  • 反向视角（发行方抗辩/风险）：若宣称「买 NFT 即拥有版权」却无转让约定，可能构成虚假宣传（反法第 8 条）与消费者误导。
珠宝实战：发行「NFT 数字珠宝」时，合同必须写清——买家得到的是「该数字藏品的展示/收藏权」还是「底层款式图的版权」。绝大多数情况只授展示权，版权仍归品牌；想卖「版权」须另签转让协议并明示。

三、平台合规与金融风险

数字藏品曾因「二级市场炒作、涉虚拟货币、非法集资」被强监管。发行与平台运营要避开红线：

  • 不得挂钩虚拟货币：用代币/虚拟货币交易属高危，我国禁止代币融资；
  • 二级市场限制：开放自由炒作的二级市场对接近「违规金融化」，多被叫停；
  • 不得承诺增值/投资回报：明示「收藏品非投资品」，防非法集资与虚假宣传；
  • 底层作品权属：上链作品须权属清晰、已获授权，否则发行方侵权。
⚠ 待核实 / 提示
⚠ 待核实：数字藏品相关的金融监管口径（是否允许二级市场交易、与虚拟货币/非法集资的边界）随政策调整，以人民银行、文旅/网信等监管部门最新规定与法律职业意见为准，切勿凭旧资讯操作。

四、虚拟财产与游戏：珠宝企业的两个落点

  • 游戏合作：品牌与游戏联名出「虚拟穿戴/皮肤」，要明确游戏内使用权范围与著作权归属（品牌方 vs 游戏方）；
  • 虚拟资产保护：公司持有的游戏道具、账号、数字藏品，依民法典第 127 条受保护，但举证依赖平台数据与用户协议；
  • 用户权益：玩家对装备的权利以用户协议约定为主，企业须避免单方随意封号/回收引发纠纷。
实务动作：发行任何数字藏品/虚拟穿戴前，先填《数字藏品 IP 风险评估表》——发行主体资质、底层作品权属链、授权范围（版权/使用权）、二级市场交易限制、金融监管与消费者提示五栏全过。合同模板留痕，防虚假宣传与侵权。

五、今日自测（答案内嵌）

Q1：我花 999 买了一个 NFT 数字珠宝，是不是就拥有了那张珠宝款式图的著作权？
参考答案不是。买 NFT 通常只取得该数字藏品的展示/收藏使用权，著作权（复制、发行、改编等）仍归原作者，除非有明示的著作权转让合同。光买 NFT 不发生版权转移。
Q2：游戏直播里播放游戏画面，侵犯游戏公司著作权吗？
参考答案一般经游戏公司许可或落入其允许的直播政策不侵权；游戏画面作为视听作品受著作权保护，未经许可的商业性直播/录音录像可能侵权。具体看平台规则与授权。⚠ 以现行法为准。
Q3：公司想发 NFT 数字珠宝并开放二级市场炒作，要注意什么？
参考答案高危。二级自由炒作近「违规金融化」、与虚拟货币/非法集资红线相邻，⚠待核实监管口径。建议：不挂钩虚拟货币、不承诺增值、限制二级、明示收藏非投资、底层作品权属清晰。
Q4：民法典第 127 条能直接让我告赢虚拟财产被侵吞吗？
参考答案第 127 条只宣示保护网络虚拟财产，未给具体操作规则。真要维权，多靠用户协议约定 + 平台数据举证 + 反法/合同法路径，⚠具体以现行法与判例为准。
