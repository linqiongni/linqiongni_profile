转让与质押登记

IP 合同
◆
转让是「把房子整个过户」——所有权易主，名字换人；质押是「用房子抵押贷款」——所有权还在你手里，只是把它押出去借钱，还不上债权人才可就这房子优先受偿。两者都要「办手续」才算数，但生效时点完全不同。
业务落点业务落点：公司并购/资产重组中的 IP 转让、用商标/专利给银行融资做质押，必须知道登记/公告才生效，否则钱和权都没保障。

一、转让：所有权易主，何时算数

客体生效时点依据要点
专利权转让自登记之日起生效专利法第10条第3款（2020 修正）当事人订书面合同并向国务院专利行政部门登记、公告
商标权转让受让人自公告之日起享有专用权商标法第42条（2019 修正）转让人与受让人共同向商标局申请，核准后公告
著作权转让合同生效时转让（无强制登记生效）著作权法第10条第3款、第25条（2020 修正）应订书面合同；登记仅具证明/对抗效力
实务口诀：专利看登记、商标看公告、著作权看合同。 没办手续的「转让」只是债，不是物权变动——买方付了钱却没拿到权，等于钱货两空。

二、转让合同的强制要素与「一并转让」陷阱

  • 书面合同是硬性要求：专利法第10条、商标法第42条、著作权法第25条均要求书面形式；
  • 商标一并转让：商标法第42条第2款，商标注册人对其在同一种商品上注册的近似商标，或在类似商品上注册相同/近似商标，应当一并转让——防止「拆卖」造成混淆；
  • 近似商标排查：转让前必须做近似商标检索，漏转的近似标可能成为日后权利瑕疵；
  • 软件著作权转让：依《计算机软件保护条例》须向中国版权保护中心申请登记⚠待核实具体条号，否则对抗力弱。
⚠ 待核实 / 提示
⚠ 待核实：软件著作权转让/专有许可的合同登记具体条号（《计算机软件保护条例》相关条款）及是否影响合同效力；著作权普通转让对抗规则。请以现行条例核对。

三、质押：不丢所有权，押出去融资

质押是把 IP 财产权「押」给债权人融资，所有权不转移，但债权人取得质权。民法典第444条规定：以注册商标专用权、专利权、著作权等知识产权中的财产权出质的，质权自办理出质登记时设立。

客体质权登记机关设立时点
注册商标专用权国家知识产权局（商标局）办理出质登记时设立
专利权国家知识产权局办理出质登记时设立
著作权（含软件）国家版权局 / 中国版权保护中心办理出质登记时设立
质权实现：债务人不履行到期债务，质权人可与出质人协议以 IP 折价，或就拍卖、变卖的价款优先受偿。注意 IP 价值波动大，质权人通常要求评估+定期复核+违约加速到期条款。

四、转让/质押实操清单（谁/何时/做什么）

  1. 转让：检索近似商标/权利瑕疵 → 签书面转让合同 → 共同向主管机关申请（商标双方申请、专利单方申请登记）→ 等公告/登记生效 → 交接权属文件与秘密信息；
  2. 质押：评估 IP 价值 → 签书面质押合同 → 向登记机关办出质登记（取得登记证）→ 放款 → 到期解押或实现质权；
  3. 反向视角（受让方/出质人）：要求转让方保证权利无瑕疵、无质押无许可冲突；出质人保留使用收益权、约定解押条件，防止债权人滥用质权。
⚠ 待核实 / 提示
⚠ 待核实：专利权/商标权质押登记的办理时限、所需材料清单（如评估报告、主体资格证明）以国家知识产权局最新办事指南为准；各地窗口有差异。

五、今日自测（答案内嵌）

Q1：A 公司与 B 签了专利转让合同并付款，但没去国知局登记，B 算拿到专利权了吗？
参考答案不算。专利法第10条第3款：专利权转让自登记之日起生效。未登记仅产生合同债权（可主张违约），物权未变动，B 还不是专利权人。
Q2：转让「星河」商标时，同类的近似商标「星河·臻」必须一起转吗？
参考答案必须。商标法第42条第2款：同一种商品上的近似商标、类似商品上的相同/近似商标应一并转让，防混淆。漏转会被商标局不予核准。
Q3：用专利质押向银行借钱，质权什么时候设立？所有权归谁？
参考答案质权自办理出质登记时设立（民法典第444条），所有权仍归出质人；只有债务人到期不还、质权实现时，债权人才可就折价/拍卖/变卖款优先受偿。
Q4：著作权转让没做登记，受让方能对抗原作者再转卖给第三人吗？
参考答案著作权转让自合同生效时即转让（无强制登记生效），合同有效的受让方取得权利；但未登记对抗力弱，若原作者又卖给善意第三人并登记，受让方可能难以对抗。⚠ 以现行条例与登记规则为准。
