一、五类第三方 IP 场景与雷点

场景主要 IP 风险必备授权文件
广告公司素材字体/图库/BGM 未获商用授权字体商用授权书、图库授权截图、BGM 许可
明星代言肖像权/姓名权越界使用肖像权+姓名权授权书、竞品限制条款
品牌影视短片音乐/脚本/演员肖像音乐同步许可、演员肖像、剧本权属
软件采购盗版/超许可数/开源传染正版授权书、许可数量、开源合规审查
店铺 SaaS数据归属/服务中断/源码托管SaaS 订阅协议、数据处理协议、SLA
实务口诀：用别人的东西，先问「授权范围到哪」。用途、地域、期限、媒介四要素缺一不可——一份「仅供微博使用」的音乐授权，你放到 TVC 里就是超范围侵权。

二、代言合同：肖像权 + 姓名权 + 竞品限制

  • 权利授权：明确代言人肖像、姓名、声音在约定媒介/期限/地域内的使用权，超范围（如用到未约定的产品线）即违约；
  • 竞品限制：代言期内不得为直接竞品代言，区分「品类竞品」与「品牌竞品」；
  • 道德条款：代言人涉违法/负面舆情，品牌方可解约并追责（时尚珠宝最怕代言翻车）；
  • 反向视角（代言人方）：限制授权范围防过度商用、约定合理使用报酬、保留个人社交账号自主。

三、广告/影视素材：授权范围四要素

  • 用途：仅用于本次 campaign / 全渠道 / 二次剪辑？
  • 地域：中国境内 / 全球？跨境投放须单独授权；
  • 期限：1 年 / 永久？超期继续使用即侵权；
  • 媒介：社媒 / 电商 / 户外 / TVC？跨媒介须追加授权。

四、软件采购与 SaaS：许可还是转让

类型权利性质关键条款风险
软件永久授权许可（非转让）居多许可数量、版本、可否复制超装、转售违法
SaaS 订阅云端订阅许可SLA、数据归属、解约导出服务中断、数据被锁
开源组件受开源协议约束GPL 等具「传染性」闭源产品被迫开源⚠待核实
⚠ 待核实 / 提示
⚠ 待核实：不同开源协议（GPL/LGPL/MIT/Apache）的「传染性」边界与商业使用限制，以及我国司法实践中对开源协议违约的认定口径，请以协议文本与典型判例核对。

五、侵权归责与追偿条款写法

品牌方护身三句话写进每一份第三方合同：① 供应商保证其交付物不侵犯任何第三方 IP；② 若因此导致品牌方被诉/被罚，供应商全额赔偿（含律师费、和解金）；③ 品牌方有权直接从应付款中扣减。这一条是「把锅甩回去」的法律依据。

六、今日自测（答案内嵌）

Q1：广告公司交来的海报用了未授权商业字体，品牌方被字体公司起诉，谁担责？
参考答案对外品牌方作为使用方可能先被诉；但品牌方可在与广告公司的合同中约定 IP 瑕疵担保与追偿，向广告公司全额索赔（含律师费、和解金）。前置动作是签约时就要求广告公司交付字体商用授权书。
Q2：代言人肖像仅授权「用于产品包装」，品牌方放到 TVC 里算什么？
参考答案超范围使用，既违约（违反授权范围）又可能侵犯肖像权。授权必须按「用途/地域/期限/媒介」四要素写死，跨媒介须追加授权。
Q3：SaaS 服务突然停了，品牌方店铺数据取不出来怎么办？
参考答案靠签约时的数据处理协议（DPA）与解约导出条款：约定服务终止后一定期限内供应商须提供数据导出，否则承担违约与损失赔偿。选型时就应评估「数据可携」与源码托管。⚠ 以合同与个保法核对。
Q4：产品里用了 GPL 开源组件会有什么后果？
参考答案GPL 具「传染性」，若产品整体构成衍生作品可能被迫开源源代码，危及闭源商业秘密。应在采购/研发环节做开源合规审查，区分传染性协议与宽松协议。⚠ 以协议文本为准。
