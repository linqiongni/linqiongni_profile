第 18 周 自测卷

IP 合同　·　答案内嵌显示，无需点击展开
本周聚焦 IP 许可（独占/排他/普通与备案）、转让与质押登记、供应链 IP 条款（OEM/ODM/经销）、第三方 IP（广告/代言/影视/软件/SaaS）与违约救济条款设计。每题答案直接附在题后，无需点击展开。
D1 · 自测
许可：独占 / 排他 / 普通与备案
QD1-1品牌把「星河」商标独占许可给 A 厂做联名，自己又悄悄上线同系列，A 厂能告品牌违约吗？判断
参考答案能。独占许可下许可人自己也不能使用（除非合同特别保留）。品牌自用构成违约，A 厂可主张违约救济；若已备案，品牌再许可第三人的行为也不得对抗 A 厂。
QD1-2商标许可合同没去备案，合同效力如何？能否对抗善意第三人？简答
参考答案合同在双方间自签字生效；但未备案依商标法第43条第3款「不得对抗善意第三人」——不能对抗不知情的后续被许可人。备案是「对抗主义」非「生效主义」。⚠ 以现行条文为准。
QD1-3经销商拿到普通商标许可后，商品上要不要标明自己是被许可人？依据哪条？实务
参考答案要。商标法第43条第2款：经许可使用他人注册商标的，必须在使用该注册商标的商品上标明被许可人的名称和商品产地。这是法定义务。
D2 · 自测
转让与质押登记
QD2-1A 公司与 B 签了专利转让合同并付款，但没去国知局登记，B 算拿到专利权了吗？判断
参考答案不算。专利法第10条第3款：专利权转让自登记之日起生效。未登记仅产生合同债权，物权未变动，B 还不是专利权人。
QD2-2转让「星河」商标时，同类的近似商标「星河·臻」必须一起转吗？依据？简答
参考答案必须。商标法第42条第2款：同一种商品上的近似商标、类似商品上的相同/近似商标应一并转让，防混淆。漏转会被商标局不予核准。
QD2-3用专利质押向银行借钱，质权何时设立？所有权归谁？实务
参考答案质权自办理出质登记时设立（民法典第444条），所有权仍归出质人；只有债务人到期不还、质权实现时，债权人才可就折价/拍卖/变卖款优先受偿。
D3 · 自测
供应链 IP 条款：OEM·ODM·经销
QD3-1品牌方委托代工厂做 ODM，合同没写设计稿归谁，代工厂能主张著作权吗？判断
参考答案有风险。ODM 中代工厂提供设计，若合同未明确权属，代工厂可能主张设计稿著作权归己，品牌方仅获使用权。务必明示「所有设计成果归品牌方」并交付源文件。⚠ 以著作权法委托作品规则核对。
QD3-2经销商把国内正品串到海外卖，品牌方能否以侵权起诉？简答
参考答案一般难。正品经同意投入市场后转售属权利用尽，不侵权。但品牌方可用合同「区域限制+窜货违约金」追究合同债，而非侵权。两者性质不同。
QD3-3代工厂辩称「只是学了通用工艺」，品牌方如何防反向工程？实务
参考答案合同明示禁止反向工程（拆解/测绘/逆向样品与技术资料），区分「定制设计」与「通用工艺」归属；对定制部分主张权属，对泄密主张违约/商业秘密（反不正当竞争法第9条）。⚠ 以现行法核对。
D4 · 自测
第三方 IP：广告·代言·影视·软件采购·SaaS
QD4-1广告公司交来的海报用了未授权商业字体，品牌方被字体公司起诉，谁担责？判断
参考答案对外品牌方作为使用方可能先被诉；但可在与广告公司的合同中约定 IP 瑕疵担保与追偿，向广告公司全额索赔（含律师费、和解金）。前置应要求交付字体商用授权书。
QD4-2代言人肖像仅授权「用于产品包装」，品牌方放到 TVC 里算什么？简答
参考答案超范围使用，既违约又可能侵犯肖像权。授权须按「用途/地域/期限/媒介」四要素写死，跨媒介须追加授权。
QD4-3产品里用了 GPL 开源组件会有什么后果？实务
参考答案GPL 具「传染性」，若产品整体构成衍生作品可能被迫开源源代码，危及闭源商业秘密。应在研发环节做开源合规审查，区分传染性协议与宽松协议。⚠ 以协议文本为准。
D5 · 自测
违约与救济条款设计
QD5-1合同写「违约金 1000 万」，实际损失只有 50 万，法院会怎么处理？判断
参考答案依民法典第585条，违约金过分高于损失的，当事人可请求法院适当减少，通常以实际损失为基准裁量（超 30% 部分常调低，⚠ 具体口径待核实）。起草应让违约金与可预见损失挂钩。
QD5-2被许可方超地域销售，品牌方能直接要求「销毁全部库存」吗？简答
参考答案可在合同中预先约定超范围使用触发停止侵害+销毁库存与模具；但销毁须有依据（合同约定或法院/行政决定），自行强闯销毁可能违法。紧急情况可申请行为保全禁令先止损。⚠ 以程序法条文为准。
QD5-3争议解决写「提交仲裁」但没写哪个委、什么规则，有效吗？实务
参考答案大概率无效。仲裁条款须明确仲裁机构与适用规则，否则约定不明可能被认定无效而回到诉讼。务必写明具体仲裁委员会与仲裁规则版本。
WEEKEND · 实战复盘
周末实战复盘 · IP 许可合同 + 代工协议 IP 条款
QWE-1独占许可合同里，若没写「许可方自己不得使用」，会有什么后果？实务
参考答案漏洞。独占许可核心是连许可人自己也不能用（除非合同保留）。不写清，许可方可能辩称自己仍可用，削弱独占价值。应在范围条款明示「许可方保留/不保留自用权」。
QWE-2ODM 代工合同最该先焊死的是哪句话？实务
参考答案「所有设计成果（含草图、3D 模型、打样、模具）知识产权归品牌方所有，代工厂仅获履行本合同所需的有限使用许可，并须交付全部源文件。」不写，设计权属可能归代工厂。
QWE-3campaign 用了一份「仅供社媒」的音乐授权却投了 TVC，怎么补救？实务
参考答案立即下架超范围使用并补授权（追加 TVC 媒介授权并付费）；若已被主张，凭与广告公司的 IP 瑕疵担保+追偿条款向其索赔。前置应建授权四要素核查表。
本周核心产出物 · 参考标准答案
本周核心产出物参考标准答案 · IP 合同模板库 v1（含批注版）

产出物一：IP 许可合同（独占型 · 批注版）骨架

  1. 首部与定义：许可标的（商标核准号、核定商品）、许可类型（独占）
  2. 许可范围：地域、期限、媒介、是否含可分许可——批注：独占须明示排除许可方自用
  3. 许可费与审计：固定+提成、最低保证金、品牌方审计权——批注：防瞒报
  4. 质量监督：商标法第43条第1款许可人监督、被许可人保证质量
  5. 备案条款：约定由谁办理商标局备案及逾期责任——批注：对抗善意第三人
  6. 违约与救济：违约金、停止侵害、销毁、赔偿范围
  7. 争议解决：仲裁机构与规则——批注：涉商业秘密偏仲裁保密

产出物二：代工协议 IP 条款清单（OEM vs ODM）

条款OEM 版要点ODM 版要点
设计权属品牌方已提供，代工厂仅获履约使用许可明示所有设计成果归品牌方，代工厂仅有限许可
商标使用许可代工厂仅为本订单使用，标明被许可人/产地同左，并禁止将设计用于其他客户
模具与源文件订单结束返还/销毁，不得留存交付全部源文件并签权利确认书
保密与反向工程禁止泄露工艺、禁止反向工程同左，加重设计保密
竞业合同期不为直接竞品代工同类设计同左
批注第一雷：ODM 不写权属，设计就是代工厂的。必须用一句话把「设计成果归品牌方 + 代工厂仅有限许可 + 须交付源文件」焊死。

产出物三：第三方素材授权核查表（必附文件）

  • 广告公司：字体商用授权书、图库授权、BGM 同步许可、IP 瑕疵担保与追偿条款
  • 代言人：肖像权+姓名权授权书、竞品限制、道德条款
  • 影视制作：音乐同步许可、演员肖像、剧本权属转让/许可
  • 软件/SaaS：正版授权书（数量/版本）、SaaS 数据处理协议与解约导出条款、开源合规审查
实务结论：本周三份文件直接进公司《IP 合同模板库 v1》。每一条款都附「为何这么写」批注，并列出必须附上的授权/登记文件清单，下次签约替换变量即可复用。
