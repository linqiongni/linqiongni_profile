许可：独占 / 排他 / 普通与备案

IP 合同
◆
许可就像把门锁的钥匙多配几把——独占许可是把唯一一把钥匙只给一个人（连房东自己都不能进），排他许可是房东和一个人各有一把（但不能再配给第三人），普通许可是房东随便配给一堆人。配钥匙要不要「登记备案」，决定了对付陌生第三人时这把钥匙算不算数。
业务落点业务落点：品牌联名、动漫 IP 授权做首饰、商标许可给代工厂/经销商时，先定清楚是哪一种许可，再决定要不要备案、备案什么材料。

一、三种许可：谁能拿这把钥匙

类型许可人自己能否使用能否再许可第三人典型场景
独占许可（Exclusive）不能（除非合同特别约定）不能品牌把某 IP 独家授权给一家联名方，自己也不再做同款
排他许可（Sole）能不能品牌与一家核心供应商共用的限定授权，双方可用但第三人不可
普通许可（Simple / Non-exclusive）能能（可许可多人）商标许可给多家经销商、字体/设计软件批量授权
实务口诀：独占=排他+许可人自己也不用；排他=许可人自用但不许第三人；普通=随便发。 选错类型，等于拱手把市场让给对手或把自己锁死。

二、许可备案：对抗主义，不是生效主义

备案解决的是「对第三人」的效力，而非「合同双方」的效力。合同自双方签字盖章即成立生效，但不备案，就挡不住不知情的善意第三人。

客体备案机关法律效果（已核实/待核实）未备案后果
商标许可国家知识产权局（商标局）商标法第43条第3款：未经备案不得对抗善意第三人（2019 修正）合同在双方间有效，但不能对抗善意第三人
专利许可国家知识产权局专利法第12条要求订立实施许可合同；备案对抗效力见专利法实施细则⚠待核实未备案一般不影响合同效力，独占许可对抗受限
著作权许可中国版权保护中心（如软著）一般无强制备案；独占许可可登记以强化对抗⚠待核实合同有效，但对抗善意第三人能力弱
⚠ 待核实 / 提示
⚠ 待核实：专利法实施细则关于专利许可合同备案对抗效力的具体条号；著作权（尤指非软件作品）许可备案规则及登记机关。请核对《专利法实施细则》《著作权法实施条例》及国家版权局相关办法后落正式文件。

三、珠宝/时尚典型许可场景与反向视角

  • 品牌联名：某珠宝品牌用「星河」商标与设计师联名，给的是独占还是普通？独占则品牌自己不能再用「星河·联名」系列，需算清让利与曝光收益；
  • 动漫 IP 授权：拿动漫形象做首饰，授权范围（产品品类、地域、期限、媒介）必须写死，普通许可下 IP 方可能同时授权多家，你的独家卖点消失；
  • 商标许可经销商：经销商拿到的是普通许可，品牌可同时授权多家，且经销商必须标明被许可人名称与商品产地（商标法第43条第2款）。
反向视角（被许可方谈判点）：① 争取更宽的地域/品类/期限；② 要求许可方保证权利无瑕疵并承担侵权追偿；③ 若做排他/独占，坚持备案以对抗后续被许可人；④ 谈「可分许可」权（能否再转授权下游工厂）。品牌方则反之——用普通许可保留控制权、用备案锁定对抗。

四、许可合同必备条款骨架

  1. 标的范围：许可的是哪件商标/专利/作品、核准号或登记号、具体权利项（如著作权财产权第几项）；
  2. 许可类型与地域/期限/媒介：独占/排他/普通，覆盖国家与渠道、起止日；
  3. 许可费与支付：固定+提成、最低保证金、审计权；
  4. 质量监督（商标特有）：商标法第43条第1款许可人监督、被许可人保证质量；
  5. 备案义务：谁办理、费用谁出、逾期责任；
  6. 违约与终止：逾期付款、超范围使用、质量不达标的解约与赔偿。

五、今日自测（答案内嵌）

Q1：品牌把「星河」商标独占许可给 A 厂做联名，自己又悄悄上线同系列，A 厂能告品牌违约吗？
参考答案能。独占许可下许可人自己也不能使用（除非合同特别保留）。品牌自用构成违约，A 厂可主张违约救济；若已备案，品牌再许可第三人的行为也不得对抗 A 厂。
Q2：商标许可合同没去商标局备案，合同有效吗？能对抗善意第三人吗？
参考答案合同在双方间有效（签字即生效）；但未备案依商标法第43条第3款「不得对抗善意第三人」——若品牌又把商标普通许可给不知情的 B 厂并完成备案，A 厂可能无法对抗 B 厂。⚠ 以现行条文为准。
Q3：经销商拿到普通商标许可后，商品上要不要标明自己是被许可人？
参考答案要。商标法第43条第2款：经许可使用他人注册商标的，必须在使用该注册商标的商品上标明被许可人的名称和商品产地。这是法定义务，不标违法。
Q4：被许可方能自己再授权下游代工厂使用许可商标吗？
参考答案原则上不能。商标法第43条许可是「使用许可」，被许可人并非权利所有人；专利法则明确被许可人无权允许合同规定以外的单位或个人实施（专利法第12条）。要转授权须合同明示「可分许可」条款。
