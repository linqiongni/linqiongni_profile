供应链 IP 条款：OEM·ODM·经销

IP 合同
◆
代工就像「借别人的厨房做饭」——OEM 是你给配方让别人做（你出设计、厂只生产），ODM 是别人连配方都帮你设计好（厂出设计+生产），经销是别人只负责把做好的菜端出去卖。IP 归属和泄密风险在每一步都完全不同，合同不钉死就会翻车。
业务落点业务落点：珠宝/时尚品牌找代工厂（水贝/番禺）、设计外包、经销商渠道，合同必须把 IP 归属、保密、反向工程禁止、渠道管控写死。

一、三种模式 IP 风险点对比

模式谁出设计谁出品牌IP 归属默认核心风险
OEM 定牌加工品牌方品牌方归品牌方代工厂超范围生产、私留模具、仿款
ODM 原始设计制造代工厂品牌方易争议（合同未写则代工厂可能主张）设计稿权属被代工厂主张、撞款
经销 Distribution品牌方品牌方归品牌方窜货、平行进口、渠道售假
实务口诀：ODM 不写归属，设计就是代工厂的。 代工厂最易在「谁设计的」上反客为主——品牌方必须合同中明示「所有设计成果（含打样稿、3D 文件）归品牌方所有，代工厂仅获履行本合同所需的使用许可」。

二、OEM 条款核心：商标使用 + 质量 + 地域

  • 商标使用授权：明确品牌方许可代工厂仅为履行本订单使用商标，订单外禁用（普通许可逻辑）；
  • 标明义务：商品/包装标明被许可人（生产者）名称与产地（商标法第43条第2款）；
  • 质量管控：品牌方监督、代工厂保证质量，保留抽检与封存样品质检权；
  • 模具/模具图纸归属：订单结束代工厂应返还或销毁模具，不得留存私产。

三、ODM 条款核心：设计成果权属（最易翻车）

ODM 中代工厂提供设计方案。若合同未明确，代工厂可能主张设计稿著作权归己，品牌方仅获「使用权」。必须用条款把权属、载体交付、后续改进归属一次性锁死。

  • 权属宣告：所有设计成果（草图、3D 模型、打样、模具）知识产权归品牌方，代工厂仅获履约所需有限许可；
  • 交付载体：合同结束代工厂须交付全部源文件（CAD/3D/图稿）并签署权利转让/确认书；
  • 禁止撞款：代工厂不得将相同或实质相似设计提供给品牌方竞争对手；
  • 反向视角（代工厂）：可争取「通用工艺/基础结构」不归品牌方、保留为其他客户服务的通用能力，但须与「定制设计」明确切割。

四、经销条款核心：渠道管控与防窜货

  • 授权区域/渠道：限定经销地域与线上/线下渠道，越界视为违约；
  • 防窜货：赋予产品唯一溯源码，跨区销售触发违约金；
  • 平行进口/权利用尽边界：正品经同意投入市场后转售一般不侵权，但品牌方可用合同限制「跨区串货」并设违约金（合同债，非侵权）；
  • 打假配合：经销商发现仿款须及时上报并配合维权。

五、通用防护：保密 + 竞业 + 反向工程

三条底线条款：① 保密条款（设计图、工艺、客户名单不入代工厂系统、不传真外泄）；② 竞业限制（代工厂合同期内不为直接竞品做同类设计）；③ 反向工程禁止（不得拆解、测绘、逆向品牌方提供的样品与技术资料）。这三条是供应链 IP 保护的「三道锁」。

六、今日自测（答案内嵌）

Q1：品牌方委托代工厂做 ODM，合同没写设计稿归谁，代工厂能主张著作权吗？
参考答案有风险。ODM 中代工厂提供设计，若合同未明确权属，代工厂可能主张设计稿著作权归己，品牌方仅获使用权。务必用条款明示「所有设计成果归品牌方」并交付源文件。⚠ 以著作权法委托作品/职务作品规则核对。
Q2：OEM 代工厂把品牌方模具私留并接竞品订单，品牌方怎么堵？
参考答案合同须约定：订单结束代工厂返还或销毁模具、不得留存私产；超范围生产/接竞品触发违约与违约金；结合保密与竞业条款。发现后凭合同主张违约并保全证据。
Q3：经销商把国内正品串到海外卖，品牌方能否以侵权起诉？
参考答案一般难。正品经同意投入市场后转售属权利用尽，不侵权。但品牌方可用合同「区域限制+窜货违约金」追究合同债，而非侵权。两者性质不同，须分开设计。
Q4：代工厂辩称「只是学了通用工艺」，品牌方如何防反向工程？
参考答案合同明示禁止反向工程（拆解/测绘/逆向样品与技术资料），并区分「定制设计」与「通用工艺」归属；对定制部分主张权属，对泄密主张违约/商业秘密（反不正当竞争法第9条）。⚠ 商业秘密要件以现行法核对。
