侵犯著作权罪与刑事边界

著作权侵权与平台责任

一、刑民分界：哪些行为入罪

著作权民事侵权门槛低（未经许可 + 接触 + 实质相似即可），刑事则要求以营利为目的 + 违法所得数额较大 / 有其他严重情节。民事打不完的规模化盗版，才升格到刑事。

实务口诀：民事是「赔钱」，刑事是「坐牢」；先固定「营利目的 + 复制发行数量/金额」证据，再决定是否报案。

二、刑法第217条：侵犯著作权罪

刑法第217条规定，未经著作权人许可，复制发行、通过信息网络向公众传播其文字/音乐/美术/视听/计算机软件等作品，违法所得数额较大或有其他严重情节的，构成侵犯著作权罪。常见行为：盗版复制销售、网盘/网站传播、私服、破解软件。

  • 权利方动作：固定侵权实物、销售金额、传播量、鉴定报告，向公安报案或推动行政机关移送；
  • 被诉方抗辩：主张「非营利/教学」无营利目的、获利未达门槛、或作品不具独创性/权属有争议、或「复制发行」认定应限缩；
  • 情节抗辩：金额/数量未达立案标准，争取仅民事或行政。

三、第218条与单位犯罪

刑法第218条销售侵权复制品罪针对「明知是侵权复制品而销售，违法所得数额巨大」的行为——聚焦销售环节。第220条单位犯罪：公司售假侵权的，对单位判处罚金，并对直接负责的主管人员与其他直接责任人员依各条处罚（双罚制）。

罪名刑法条文核心要件
侵犯著作权罪第217条未经许可复制发行/信网传播 + 营利目的 + 数额较大/严重情节
销售侵权复制品罪第218条明知侵权而销售 + 违法所得数额巨大
单位犯罪第220条双罚：单位罚金 + 责任人依各条处罚

四、行刑衔接与刑事边界（双视角）

行政投诉/平台举报固定证据 → 涉嫌犯罪移送公安；权利人不自营侦查，而是提供权属、真假鉴别、价格证明配合。

  • 权利方动作：先平台下架止损 + 行政查处扣货，构成犯罪的坚决刑事报案，刑事附带民事一并索赔；
  • 被诉方边界防守：在立案前积极和解/获权利人谅解、证明销量与获利低、权属争议未决，争取不立案或轻缓；
  • 珠宝行业：水贝/番禺规模化仿款制售，单靠民事「九牛一毛」，应推动行政 + 刑事清场。
边界提示：并非所有「实质相似」都入刑——刑事须证明「复制发行」且达数额/情节门槛；近似擦边、非营利的二创一般只走民事。

五、今日自测（答案内嵌）

Q1：对方仿了我方设计图售卖，民事能赢，能直接刑事报案吗？
参考答案不一定。刑事需「以营利为目的 + 违法所得数额较大/有其他严重情节」。先固定销售金额与数量证据；未达立案追诉标准（⚠待核实最新数字）的，走民事/行政，达标才报案。
Q2：我只是「卖」侵权复制品，没复制，构成第217条吗？
参考答案可能构成第218条销售侵权复制品罪（明知 + 违法所得数额巨大），而非第217条。复制与销售是两条不同罪名，按行为定。
Q3：公司售假侵权，是个人还是公司担刑责？
参考答案单位犯罪（第220条）：对单位判罚金，对直接负责的主管人员与其他直接责任人员依各条处罚，双罚。
Q4：被诉后想避免坐牢，什么动作最关键？
参考答案立案前积极与权利人和解/获谅解、证明获利与销量低、厘清权属争议；同时平台下架止损。但规模化制售达到门槛的，和解不影响已涉嫌犯罪的侦查，应尽早合规整改。
