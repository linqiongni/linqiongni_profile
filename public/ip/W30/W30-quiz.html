第 30 周 自测卷

案源与专业标签　·　答案内嵌显示，无需点击展开
本周聚焦从法务到 IP 专业人的双通道路径、内部客户沟通与需求转化、报价与服务方案、专业文章与演讲分寸、个人知识管理与工具箱，以及周末的服务方案与文章实战。每题答案直接附在题后，无需点击展开。
D1 · 自测
从法务到 IP 专业人的业务路径
QD1-1企业法务的「案源」和执业律师一样，都是外部客户付费委托？判断
参考答案错。企业法务的案源是「内部业务需求 + 外部专业声誉」双通道——内部来自各业务部门，外部来自行业里挂出的专业标签；执业律师才是外部客户付费委托、按件计费。两者获客与考核逻辑相反。
QD1-2专业标签为什么要押注「珠宝时尚 IP」这种细分，而不是泛泛说「我懂 IP」？简答
参考答案行业里懂 IP 的人太多，「我懂 IP」无识别度。细分才有记忆点：珠宝时尚 IP 行业 IP 密度高（设计/商标/外观/肖像全占）、你已有行业语境与案例、外部复合标签稀缺。标签公式 = 行业 × 职能 × 差异点，要能一句话说清。
QD1-3企业法务对外以「IP 专家」名义写文章、演讲，有哪些合规红线？实务
参考答案⚠ 待核实。核心红线：你是企业法务非执业律师，对外表达须落「企业内部视角」，不出具具有对外法律效力的意见，避免触及「未经律所执业非法提供法律服务」的边界（《律师法》2017 修正）。实务做法：署名带公司职务、注明「基于企业实践、非对外法律意见」、不点评未决个案、不泄露客户/公司秘密。
D2 · 自测
客户沟通与需求转化
QD2-1业务方说「赶紧发函告他抄袭」，法务应立刻发函以显效率？判断
参考答案错。应先做需求访谈五问，确认权利基础与证据是否充分。贸然发函可能打草惊蛇、且若根本无权利基础或证据不足会反噬。先把模糊诉求变成有要件的案子，再定发函/投诉/起诉路径。
QD2-2需求访谈「五问」是哪五问？各自要挖出什么？简答
参考答案① 你想要什么业务结果（锁定目标）；② 发生了什么事实（固定要件）；③ 你手里有什么权利基础（查底数）；④ 时间多紧、预算多少（定路径与成本阈值）；⑤ 谁拍板、谁配合（排资源）。五问把模糊诉求变成有要件的案子。
QD2-3业务方问「这案子能赢吗」「多久能下架」，你怎么回应既不承诺结果又不得罪人？实务
参考答案用「动作 + 时限 + 阶段产出」：如「我先做胜诉率与证据评估，本周五给可行性结论」；下架取决于平台审核，「我会同步推进并每日反馈进度」。禁说「包赢」「一周搞定」「肯定赔 50 万」。把期望管理成可控，而非给结果。
D3 · 自测
报价与服务方案写作
QD3-1服务方案里「除外条款」可有可无，写了反而显得不专业？判断
参考答案错。除外条款是护城河，明确不含诉讼代理、不含中国港澳台等，防止越界承诺与白嫖。范围写得宽易被加塞、写得窄被说甩锅，除外条款正是平衡边界的工具，专业方案必备。
QD3-2计时、计件、包年三种计费分别适合什么场景（给出区间⚠）？简答
参考答案计时适零散咨询/疑难研究（约 2000-5000 元/小时 ⚠待核实）；计件适模板化交付如合同/注册/发函（单份联名合同约 8000-30000 元 ⚠待核实）；包年适常年顾问/持续需求（约 20 万-80 万/年 ⚠待核实）。企业法务自身不收费，仅用于量化对内价值与理解外部律师报价。
QD3-3风险代理在哪些案件被禁止？依据是什么？实务
参考答案⚠ 待核实。依据《律师服务收费管理办法》及《关于进一步规范律师服务收费的意见》，刑事诉讼、行政诉讼、国家赔偿、群体性诉讼案件不得适用风险代理；其他民商事案件风险代理收费比例有上限（通常不超过标的额 30%，⚠ 具体以现行规定为准）。本条仅用于理解外部律师报价，企业法务自身不收费。
D4 · 自测
专业文章与演讲
QD4-1专业文章选题追热点最安全，因为阅读量高、曝光大？判断
参考答案错。热点易空、易过时、易踩未核实信息；「选题从案来」最稳——你真办过的案自带细节与行业语境，难被挑错。没办过的先研究再写、标「研究型」。
QD4-2公开演讲「三不」红线是什么？被问未决个案怎么答？简答
参考答案三不 = 不泄露客户/公司秘密、不评价未决案件、不给出位法律意见。被问未决个案时答：「公开场合不对具体个案给意见，可会后私聊通用框架」，既守红线又不冷场。
QD4-3文章被同行指法条引用错误，怎么处理最专业？实务
参考答案不硬杠。24 小时内核查原文与法条，确有误则发「更正与说明」、保留修改记录、并把正确版本更新进知识库。硬杠只会放大错误，专业人用更正显严谨。⚠ 发表合规边界以《律师法》及公司制度为准。
D5 · 自测
知识管理与个人工具箱
QD5-1用 AI 辅助法务，可以把客户合同原文喂给公开大模型以提高效率？判断
参考答案错。凡含公司/客户名称、未公开合同、未决案件细节，一律不进公开大模型，违保密红线。可用脱敏/匿名材料做梳理论点、起草初稿、整理检索思路、翻译校对，但绝不让 AI 出具具法律效力的结论。⚠ 以公司数据安全制度为准。
QD5-2个人知识库为什么要分「案件/模板/研究」三层、法条库为何标版本+核对日？简答
参考答案三层分离让经验可搜、模板可抄、研究可查，散落微信邮件的经验等于零。法条常修订（反法 2019 修正、著作权法 2020 修正），过时法条比没有更危险，标版本+核对日、季度复核，确保引用现行有效条文。
QD5-3检索中国香港/中国澳门/中国台湾的 IP 信息，为什么不能混同大陆库？实务
参考答案港澳台各自独立 IP 制度（中国香港/中国澳门有独立注册体系、中国台湾有单独商标专利制度），与大陆不互通。须用当地官方系统（如中国香港知识产权署、中国台湾经济部智慧财产局）分别检索，表述写「中国香港/中国澳门/中国台湾」绝不当国家。⚠ 以当地官方规定为准。
WEEKEND · 实战复盘
周末实战复盘 · 服务方案与专业文章
QWE-1服务方案「除外条款」写「不含中国港澳台」为什么必须、怎么写不出错？实务
参考答案港澳台 IP 制度独立，不应纳入你的服务能力范围，列出可防越界承诺与责任。表述必须写「中国香港/中国澳门/中国台湾」绝不当国家，并建议加「不含诉讼代理、不含未列明监管申报」。
QWE-2文章首段为什么放「真实困境」钩子 + 非意见声明？实务
参考答案真实困境（脱敏）建立共鸣与专业可信度，比空泛开场强；非意见声明（基于企业法务实务、不构成对外法律意见、法条以现行版为准）守住合规红线，避免被当作出具对外法律意见。
QWE-3周末产出的「个人 IP 业务手册」为什么是本周核心交付物？实务
参考答案把 D1-D5 路径/沟通/报价/写作/知识库碎片钉成册，接活一拎就走、交接可复制、对外有实体证据，标签才立得住。手册 = 双通道（内部影响力 + 外部专业标签）的实体化。
