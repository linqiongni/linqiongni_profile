你是我的知识产权实务教练。基于本周 W30（D1 路径/D2 沟通/D3 报价/D4 写作/D5 知识库），陪我产出可直接照抄的两份交付物： 1) 一份「珠宝品牌电商打假支持方案」目录骨架（七段 + 计费对照）； 2) 一篇「珠宝品牌联名合同的 5 个 IP 雷区」文章完整大纲 + 首段示例（含钩子与非意见声明）； 3) 演示双视角：对内怎么套用、对外怎么反哺标签； 4) 每个不确定性点标⚠待核实并给核对渠道； 5) 出 4 道判断题并逐题讲评。

一、可直接照抄的服务方案目录

  1. ① 项目背景与目标
  2. ② 服务范围（具体做什么）
  3. ③ 除外条款（不含诉讼/不含中国港澳台）
  4. ④ 计费方式与报价（计时/计件/包年三选一或组合）
  5. ⑤ 工作方式与时间计划
  6. ⑥ 成果与验收标准（交付物清单 + 节点）
  7. ⑦ 对接人与变更机制
把 D3 的骨架直接套：例如「珠宝品牌电商打假支持方案」——范围=监测+取证+平台投诉；除外=不含诉讼代理、不含中国港澳台；计费=计件（单案 8000-30000 ⚠待核实）；验收=投诉下架率 + 证据包。

二、专业文章完整大纲 + 首段示例

段落内容
标题珠宝品牌联名合同的 5 个 IP 雷区
钩子「一次联名，赔了设计又赔了商标」的真实困境
主体① 商标许可范围 ② 设计著作权归属 ③ 代言肖像 ④ 保密与竞业限制 ⑤ 终止清理
结尾可抄的联名合同 checklist
声明非对外法律意见 + 法条以现行版为准

首段示例：「去年一家珠宝品牌和我们聊起一桩头疼事：和设计师联名的限量款卖爆了，却在分账时被对方拿走了整套设计著作权，连后续复刻都被卡脖子。这类纠纷的 root cause，往往不在『签没签合同』，而在联名合同里那几个被忽略的 IP 条款。本文基于企业法务实务，梳理珠宝联名合同最易踩的 5 个 IP 雷区，并给出可抄的条款清单（本文不构成对外法律意见，法条以现行版本为准）。」

首段铁律：钩子用真实困境（脱敏）+ 点出法律点 + 声明非意见。

五、周末自测（答案内嵌）

Q1：服务方案里「除外条款」写「不含中国港澳台」，为什么必须这么写、怎么写才不出错？
参考答案港澳台 IP 制度与大陆不同且各自独立，不应纳入你的服务能力范围，列出可防越界承诺。表述必须写「中国香港」「中国澳门」「中国台湾」，绝不当国家。同时建议列「不含诉讼代理、不含未列明监管申报」。
Q2：文章首段为什么要放「真实困境」钩子 + 非意见声明？
参考答案真实困境（脱敏）立刻建立共鸣与专业可信度，比空泛开场强；非意见声明（基于企业法务实务、不构成对外法律意见、法条以现行版为准）守住合规红线，避免被当作出具对外法律意见。
Q3：这套周末产出，对内对外分别怎么用、被挑战怎么挡？
参考答案对内——方案模板进知识库，业务方要打假直接套，显效率；对外——文章发行业渠道反哺「珠宝时尚 IP」标签。被挑战：方案被说范围窄 → 用除外条款解释边界；文章被指错 → 核查后发更正声明。
Q4：为什么周末要把「散装工具」钉成一只箱子（个人 IP 业务手册）？
参考答案本周 D1-D5 分别是路径/沟通/报价/写作/知识库，单看是碎片，合起来就是你的「个人 IP 业务手册」。固化成册后，接活一拎就走、交接可复制、对外有实体证据，标签才立得住。
