一、一句话定义

知识产权是民事主体依法就特定智力成果和工商业标记享有的专有权利（《民法典》第 123 条）。它保护的对象不是「物」，而是「信息」；保护的方式不是「占有」，而是「禁止他人做某些事」。

这个定义有三个关键词：特定（必须有明确客体，不能是抽象思想）、智力成果 / 工商业标记（两类客体，对应两套逻辑）、专有（排他权，不是自用权）。

二、为什么必须有知识产权：信息的两个特性

经济学上，信息具有非竞争性（我用不影响你用）和非排他性（一旦公开就很难阻止别人用）。有形财产天然排他——一把椅子你坐了我不能坐；信息不天然排他。

如果没有法律保护，结果就是搭便车：你花半年研发的镶嵌工艺、开模的系列款式，对手拍照后三天就能出货，售价只有你的三分之一。长期看，没人愿意投入创新——这是立法者给信息「人为制造稀缺性」的唯一理由。

知识产权不是让你「能做什么」，而是让你「能不让别人做什么」。 所有 IP 诉讼的本质都是禁止权的行使。这句话后面 31 周会反复用到。

四、两类客体，两套逻辑

智力成果（著作权、专利）工商业标记（商标、装潢、字号）
保护什么创造出来的新东西用来区分来源的标识
立法目的激励创新防止混淆、保护商誉
获取代价需要投入创造需要投入使用与宣传
保护强度相对弱（有合理使用等大量限制）相对强（核心是禁止混淆）
期限有限，到期进入公有领域可无限续展
典型问题够不够「新」会不会「混淆」
混淆这两套逻辑，是新手最常见的错误。 判断商标案件时不要用「独创性」思维（商标不要求独创）；判断著作权案件时不要用「显著性」思维（作品不要求识别来源功能）。

五、知识产权的三个特性（与物权对照）

维度物权知识产权
客体有体物，可占有信息，不可占有
排他性来源事实上的占有 + 法律确认纯粹由法律创设
期限原则上无期限法定期间（商标可续展、商业秘密为例外）
地域性无地域限制（物在哪儿都一样）严格地域性（内地商标只在中国内地有效）
公示方式占有 / 登记登记 / 公告 / 自动产生
冲突处理一物一权同一客体可并存多个权利（如设计图 + 外观专利）

地域性对你的港企背景尤其重要：在中国香港注册的商标、在中国香港完成的作品，不等于在中国内地自动受同样的保护。跨境业务必须逐法域布局（第 26 周展开）。

六、设权模式 vs 行为规制模式

中国知识产权保护有两套并行制度：

  • 设权模式：法律先规定「符合条件就给你一个排他权」——著作权、专利权、商标权。权利边界相对清晰，举证相对容易（拿出登记证书即可）。
  • 行为规制模式：不给你权利，只禁止他人用不正当手段损害你——反不正当竞争法。商业秘密、未注册的「有一定影响的」标识走这条路。

实务意义：没有设权权利时，反法是兜底。 比如门店装潢没注册商标、也没申请外观专利，仍可依反法主张「有一定影响的装潢」——但你必须自己证明知名度，举证难度高出一大截。

七、判断顺序（今天必须刻进脑子）

  1. 第一步 客体识别——客户的这个「东西」到底是什么？属于第 123 条里的哪一类？
  2. 第二步 是否有权——权利产生了吗（自动 / 登记 / 使用）？还在有效期内吗？地域覆盖吗？
  3. 第三步 谁有权——权属链完整吗（职务作品？委托创作？共有？）？
  4. 第四步 被侵害了什么——落入哪一项权能？
  5. 第五步 走哪条路——行政、民事、刑事？还是先发律师函？
这五步是后面 31 周所有案件分析的统一框架。任何时候卡住，回到第一步重新识别客体。

八、今日自测（答案内嵌）

Q1：《民法典》第 123 条列举了几类知识产权客体？
参考答案八类：作品；发明、实用新型、外观设计；商标；地理标志；商业秘密；集成电路布图设计；植物新品种；以及法律规定的其他客体（兜底）。这是整个 IP 体系的目录，遇新事物时的检索起点。
Q2：知识产权与物权在「地域性」上的差异，对港企意味着什么？
参考答案物权无地域限制，知识产权严格地域性——内地商标只在内地有效。集团在中国香港注册的品牌/完成的作品，不等于在内地自动受同等保护，必须逐法域（内地、港、澳、台）分别布局，否则易被抢注陷入被动。
Q3：判断商标案件能用「独创性」思维吗？为什么两套逻辑不能混？
参考答案不能。商标保护的是识别来源的标识，核心是显著性 + 混淆可能性，不要求独创；著作权才要求独创性。用著作权思维办商标案（或反之）是新手最常见错误。
Q4：反不正当竞争法保护属于「设权」还是「行为规制」？
参考答案行为规制。它不赋予排他权，只禁止他人用不正当手段损害你（如有一定影响的装潢）。举证难度高于设权权利——你必须自己证明知名度。无设权权利时，反法是兜底。
