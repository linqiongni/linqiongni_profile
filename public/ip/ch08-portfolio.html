IP 布局与组合策略

前面是"单个权利怎么拿到"，这一站讲"一群权利怎么排兵布阵"。单点商标容易被绕，组合拳才稳：核心标+防御标、商标+著作权+外观设计叠护、国内拿证+跨境布局、出海前抢优先权。用栖梧"出海东南亚"做沙盘。

一、单点易破，组合才稳

一句话只注册一个主商标，别人改一笔、换一字、换类别就可能绕开。要"组合拳"：主标 + 防御标 + 著作权（图样）+ 外观设计（款式）多层叠护。

纵向：一个品牌多层

  • 主商标：核心名/LOGO，全类别核心护
  • 防御商标：近似音/形/谐音（"栖梧/栖吾/七梧"）也注册
  • 著作权登记：LOGO、包装图样做作品登记，跨类别也能打

横向：一个款式多权

  • 外观设计专利：新款造型/包装（见第 03 站）
  • 著作权：款式图、宣传图做作品登记
  • 商标：把爆款名注册，防别人抢注款名
打个比方 · 组合

单点保护像只锁一扇门；组合像门+窗+院墙+监控。小偷撬不开门，还能翻窗；窗也焊死，还有院墙。他总有一处要碰，你总有一处能抓他。权利组合的意义：让他"绕无可绕"。

法务对话对话 01 · 主标都注册了，还不够吗？
林栖
老板

"栖梧"商标都拿下证了，别人总不能用了吧？

法务
你

主标只挡"一模一样"。别人用"栖吾""七梧"卖同类，你可能拦不住——除非你提前把近似变体也注册（防御商标），或他构成"傍名牌/混淆"（见第 05 站）。更稳的是把LOGO 图样做著作权登记，他哪怕换类别用相似图，你也能跨类打。就好比你家门牌"栖梧"登记了，别人挂"栖吾"你管不了；但你把整面招牌的设计图也登记了版权，他抄招牌样子，你照样能告。

翻译成条款 主标 + 防御标（近似变体）注册 + 核心图样著作权登记，形成"名+形"双层护。
落点：商标布局清单。

二、防御商标：堵"傍名牌"的缝

一句话把音近、形近、谐音、常见错写一并注册，是低成本堵缝。注意：防御标也要实际使用或合理布局，避免"囤标"争议（见第 02 站撤三风险）。
边界声明

大量注册近似标虽能防御，但若长期不使用，可能被他人以"连续三年不使用"申请撤销（撤三）。防御策略要配使用/续展管理，别只注不用。

三、跨境布局：出海前先"圈地"

一句话商标/专利地域性强——在中国拿证，在美国、东南亚不自动受保护。出海要提前在目标国布局，别等被人抢注才补。
权利国际路径一句话抢什么
商标马德里体系（基于国内申请/注册）一份申请指定多国抢先占位，防当地抢注
专利PCT（专利合作条约）一份申请留多国窗口抢优先权日
外观设计海牙协定（工业品外观设计国际注册）多国外观一次注册款式出海外观护
基础巴黎公约优先权首次申请后 6/12 月内同待遇抢时间差
打个比方 · 优先权

优先权像排队拿号：你在中国先提交了商标/专利申请，拿到"号"（申请日）；在约定时间内去其他国家，都按这个最早号排队，不算你后来才去。这样别人晚于你提交，也排你后面。所以"先在本国交，再出海"是关键动作。

法务对话对话 02 · 我们先在国内卖稳了再出海注册不行吗？
林栖
老板

等东南亚店真开了再注册商标，不行吗？省点钱。

法务
你

不行，反而更贵更险。很多市场是"先到先得"——你没注，当地代理商或抢注者先注了，你出海反而要花钱买回自己的名字（见第 02 站栖梧被抢注）。正确姿势：国内一提交，立刻走马德里/PCT 抢优先权，等店开起来权利已到位。就好比你要在新区开店，先在网上把铺位号占住（优先权），等装修好号还是你的；你不占，别人占了，你只能加价租回来。

翻译成条款 国内首次申请 → 12 月内（商标/外观）/30 月内（PCT 进入国）主张优先权 → 目标国布局。
落点：跨境 IP 时间表。

四、布局要"跟着业务走"

一句话IP 布局不是法务闭门画，要对齐业务节奏：新品类→补类别；新渠道（电商/直播）→补第 35 类（销售）等；新市场→补国别；联名/代言→提前清权（见第 04 站）。
条款 A · 联名前 IP 尽调（示意）
联名启动前：①双方商标/著作权权属清核；②联名款名/图样 pre-clearance（预检不撞权）；③约定联名成果权属与到期处理；④代言人肖像+著作权双授权（见第 04 站）。
法务对话对话 03 · 联名款上市前一天才发现撞标怎么办？
林栖
老板

和设计师联名的款明天要上了，今天才发现名字和别人撞了，急死！

法务
你

这就是"IP 尽调没前置"的代价。正确做法：联名一立项就做pre-clearance（预检）——查双方权属、查联名款名/图是否撞权，在设计和命名阶段就排雷，而不是上市前夜。今天只能临时改名/换图，或紧急谈授权，代价大得多。就好比盖楼前先勘地基，你非等封顶才发现地是别人的，只能拆。IP 尽调就是"开工前的地契核查"。

翻译成条款 联名/新品立项即做 IP pre-clearance + 权属清核，把排雷前移到设计命名阶段。
落点：新品 IP 评审节点。

五、代工/外包：布局前先"锁权属"

一句话代工、外包设计、KOL 投稿，不约定权属，成果可能不是你的（见第 04 站委托作品、第 05 站泄密）。布局前先签好：归属 + 保密 + 不得自用。
法源

《著作权法》委托作品、职务作品权属规则（有约定从约定，无约定归受托方）；《反不正当竞争法》商业秘密保护（保密措施+约定）。
具体归属与举证请核对现行文本。

七、IP 组合矩阵：核心 + 防御 + 联合（全类 vs 多类）

一句话商标不是"注册一个名"就完事。把品牌当资产组合来管理：核心商标打头阵、防御商标堵缝、联合商标防串类。钱要花在刀刃上——全类注册最稳但最贵，多类防御挑重点类更划算。

核心商标（主商标）

  • 品牌主名 / 主 Logo，全类别核心护
  • 显著性最强、使用最频繁，是"正门"
  • 续展、使用证据管理优先级最高

防御商标

  • 音近 / 形近 / 谐音 / 常见错写（栖吾、七梧、栖梧轩）
  • 低成本堵"傍名牌"的缝，防蹭流量
  • 要配使用或合理布局，防"撤三"（见第 02 站）

联合商标

  • 同一主体下围绕主牌的子品牌矩阵（如"栖梧·星轨""栖梧·古法"）
  • 用于分线、分系列、分渠道，隔离风险
  • 主牌出事，子牌还能独立跑

成本权衡

  • 全类注册：45 类全注，最稳，但官费 + 代理费最高
  • 多类防御：挑 10–15 个关联类，性价比高
  • 单类 + 按需补：初创试水，但易被绕
方案覆盖成本适合谁
全类注册（45 类）所有类别一把锁高（45 × 官费 + 代理）大牌 / 极易被全类傍
多类防御（核心 10–15 类）重点关联类中大多数出海品牌（推荐）
单类 + 按需补仅主营类低初创试水 / 预算极紧
打个比方 · 组合矩阵

核心商标是你家大门的正式门牌；防御商标是把"栖梧/栖吾/七梧"这些容易看错的门牌也先占下，免得别人挂个错字牌蹭你客人；联合商标是你给孩子（子品牌）也单独上户口，将来主牌有风波，孩子还能独立长大。全类注册像把整栋楼每层都上了锁——最稳，但每层一把锁都是钱；多类防御像只锁你真会用的那几层，其余楼层先空着，等要用再补。绝大多数品牌，多类防御够用，别一上来就砸全类。

法务对话对话 04 · 是不是把 45 类全注册最省心？
林栖
老板

法务，图省事，我把"栖梧"在 45 个类全注册了，是不是就高枕无忧？

法务
你

最稳，但最贵，而且不是注册了就完事。45 类每类都要官费 + 代理费，加起来不是小数；更关键的是，注册后三年不使用，任何人都能以"撤三"把它撤掉（见第 02 站）。你真用得到的也就珠宝、电商、加工那十来个类，其余类空挂着，既烧钱又可能被撤。就好比你给整栋楼每层都租了仓库，其实你只往 3 层放货。剩下 42 层空仓每月照交租金，物业还嫌你长期空置要收回去。聪明做法是只租你真用的几层，其余等业务到了再扩。

阿杰
合伙人

那我们具体该注哪几类？

法务
你

珠宝主标第 14 类必注；电商上架补第 35 类；代工定制补第 40 类；自有设计系统补第 42 类；再加几个易被傍的关联类做防御，凑成"核心 10–15 类"矩阵，比全类省一大半，覆盖也够。就好比先锁你真住的几间房，走廊、院墙用监控补上；等哪天真要开新房间，再临时配钥匙，不耽误事。

翻译成条款 按业务实际选"核心 + 关联防御类"组合（多为 10–15 类），而非盲目全类；防御标须有使用 / 合理布局以对抗撤三。
落点：商标布局清单 + 续展/使用管理。

八、商标布局：主副商标、类别矩阵、域名同步

一句话珠宝主标护第 14 类；电商上架要第 35 类（销售）；代工定制要第 40 类（加工）；自有设计/小程序要第 42 类（设计服务）。主副商标分档用，域名和商标同名同步抢注。
类别护什么栖梧场景
14珠宝、钟表、贵金属"栖梧"主品牌 / 爆款名
35广告销售、电商、零售天猫 / 抖音 / 独立站开店
40材料加工、定制镶嵌代客镶嵌、来图定制
42科技与设计服务设计系统、会员小程序
37维修、保养、清洗售后清洗保养服务
26链扣、饰针、小配件链扣 / 配件独立护
打个比方 · 类别矩阵

一个品牌在不同"类"上，像一个人在不同场合要不同的证件：开金店要珠宝证（14 类）、网上卖货要电商证（35 类）、帮人加工要工匠证（40 类）。你只拿了珠宝证，却去网上卖、还接定制——别人在 35 类注了同名，反而能告你"无证经营"。所以类别要跟着业务走，业务到哪类，商标补到哪类。

主副商标分档

主商标（栖梧）用在全线核心产品；副商标 / 联合商标（星轨、古法）用在系列或子渠道。主牌守住"正统"，副牌试水新风格，万一某个系列翻车，不波及主牌声誉，也方便单独转让或授权。

域名别漏

商标在国内注了，.com / .cn / .hk 等同名域名也要同步抢注。域名先被米农占走，你出海建站要么高价买回，要么换名（换名又伤品牌）。域名和商标"同名同注"是基本功。

法务对话对话 05 · 我只在第 14 类注了，网上卖为啥被投诉？
林栖
老板

"栖梧"第 14 类商标明明是我的，怎么我在抖音开店卖货，被人以第 35 类近似告了？

法务
你

因为商标按"类"保护，跨类不自动挡。你只在 14 类（珠宝）有证，但"网上零售 / 电商销售"落在 35 类，那一类你没注，别人抢先注了同名，就能在电商场景拦你。就好比你办了"餐馆营业执照"（14 类），却跑去"网上卖货"（35 类）没办证，市场监管说你超范围，一点不冤。补类要跟着渠道走。

阿杰
合伙人

那域名呢？我们官网 qiwu.com 还没买？

法务
你

赶紧查。商标一提交，同名域名同步抢，主域名 + 常见后缀（.com/.cn/.hk）+ 防 typo 的近似域名（qiwuu、qiwa）都先占。等品牌火了再买，价格翻几十倍。就好比你给孩子上了户口，同名的微博号、邮箱不立刻抢，等红了被人占了，你只能花大钱买回，或换个没人要的号——那还叫你的品牌吗？

翻译成条款 主标 + 关联类别（14/35/40/42/37/26 等）组合注册；商标提交同步抢注同名域名（含近似 typo 域名）。
落点：商标类别清单 + 域名台账。

九、专利布局：核心 + 外围 + 改进，包围式 + 抢申请时机

一句话一个链扣别只申一件专利。核心专利护主干、外围专利护变体、改进专利护下一代；产品一立项就布局，公开前必须递申请，否则丧失新颖性，谁都能用。

核心专利（主干）

  • 护"链扣怎么扣、怎么锁"的关键结构
  • 独占最宽，是谈判 / 维权主力
  • 对应发明或实用新型

外围专利（变体）

  • 同一思路的不同形状 / 尺寸 / 材质变体
  • 别人绕开核心，也撞外围
  • 形成"包围圈"

改进专利（下一代）

  • 核心基础上的升级（更轻 / 更牢 / 快拆）
  • 持续续命，挡后来者
  • 逐年补充，延长护城河

申请时机

  • 立项即布局：设计阶段就出专利方案
  • 公开前必递：展会 / 上架 / 发论文前先交
  • 晚一天公开，新颖性可能没了
打个比方 · 包围式

核心专利是城堡主塔；外围专利是周围一圈小碉堡——对手攻不进主塔，想从侧面溜，也被碉堡挡住；改进专利是你每年加高的新城墙。光一个主塔，别人挖条地道就绕了；主塔 + 碉堡 + 新城墙，他无论从哪个方向来都碰专利。而"公开前申请"是前提：你城堡图纸还没贴上网就先交专利局备案；一旦展会亮过、网上发过，图纸变公开，新颖性没了，谁都能照建。

法务对话对话 06 · 我们只在展会亮过链扣，还能申请专利吗？
林栖
老板

新链扣先在珠宝展亮了相，客户反响好。现在补申请专利，还来得及吗？

法务
你

危险。专利讲究"新颖性"——申请日前不能公开。你展会一亮，等于把结构公之于众，如果当时没留"展前已递交"的证据，别人后来也能以"早已公开"为由无效你的专利，甚至别人抢先申都能成。就好比你发明了一道菜，先在大排档公开卖了一个月，回头才去申请"独家配方专利"。这时满大街都吃过、都看得懂做法，专利局说"这早就不是秘密了"，不批。正确姿势是参展前先递申请，或走"展会有保密例外"的宽限期规则（以本国法为准），别先亮后申。

阿杰
合伙人

那链扣包围式，我们要申几件？

法务
你

至少"1 核心 + 3–4 外围 + 1 改进"打底：核心护主结构，外围护圆/方/异形和不同材质，改进护快拆版。这样别人抄圆扣撞 A、抄方扣撞 B、抄快拆撞改进，总有一件拦他。就好比你卖一把锁，同时申请"钥匙型/密码型/指纹型"三种专利，小偷换种开法也绕不开你的专利墙。

十、著作权布局：图稿登记 + 软著 + 宣传片视听作品

一句话图稿完成即存证 + 登记；若有会员小程序 / 设计系统，做软件著作权登记；品牌宣传片是视听作品，也登记。著作权自动有，但"有权利"和"能证明有权利"是两回事。
作品类型栖梧例子动作

为什么还要登记

打个比方 · 著作权登记

著作权像你落笔就有的"亲生关系"——孩子一生出来就是你的，不用办证。但万一有人抱走孩子说"是我的"，你要拿出生证（登记证书）+ 产检记录（时间戳存证）证明亲生。没这些，法庭上你怎么证明"先写的是你"？软著则是给"你写的代码"也上户口，小程序、设计系统别裸奔。

十一、商业秘密清单化：客户名单 / 工艺参数 / 定价模型常态化加密

一句话商业秘密靠"一直藏着"活着。把三类信息列成清单、分级加密、签保密协议、限访问——保密措施不到位，秘密一漏就归全人类，且不可恢复。

打个比方 · 商业秘密清单

商业秘密像你家的传家秘方：只要一天没外传，就一直是你家的；一旦你发朋友圈晒了全文，这秘密就归全人类，再想要回来要不回。"清单化"就是给秘方建一本台账——哪本秘方、锁在哪、谁能翻、翻了留痕，缺一不可。你连"我家有几本秘方"都数不清，谈何保护？

十二、跨境布局四通道详解：马德里 / 巴黎公约 / PCT / 海牙 + 单一国家

一句话出海四条国际通道：马德里（商标，一份管多国，有中心打击风险）、巴黎公约（优先权基础，12 月专利 / 6 月商标）、PCT（专利，30 月进国）、海牙（外观，一次注册多国）。单一国家注册作补充。
通道管什么基础关键期限注意
马德里体系商标多国国内基础申请 / 注册基础注册后 5 年内有效依赖有"中心打击"风险
巴黎公约优先权（商标 / 专利 / 外观）任一成员国首次申请专利 12 月 / 商标 6 月只给优先权，不直接授权
PCT专利多国任一成员国首次申请30 月进国家阶段国际阶段不授权，需进国
海牙协定工业品外观设计多国国内 / 成员国申请视指定国规则一次注册多国，省事
单一国家注册补充兜底各国直接申请各国不同重点国 / 非缔约方兜底
马德里 · 中心打击风险

马德里以"国内基础注册"为根。若国内基础在注册后 5 年内被撤或无效，国际注册跟着塌（中心打击）。所以国内基础要稳，必要时 5 年后转单一国加固。

巴黎公约 · 优先权日

在中国首次申请后，专利 12 月内、商标 6 月内去其他成员国申请，都按"最早那天的号"排队。抢的是时间差，防当地抢注。

打个比方 · 四通道

出海布局像出国前办证件：巴黎公约是"先在本国拿个号，凭号去别国插队"（优先权）；马德里是"一份申多个国签证"，省事但根在国内（中心打击=国内签证废了，多国全废）；PCT 是"专利的多个国签证"，30 个月内必须去每个国"落地激活"；海牙是"外观设计的多国签证"。还有个别国家不接这些"团体签"，你就得单独去办（单一国家注册）兜底。

法务对话对话 09 · 马德里"中心打击"是啥，会让我们白忙？
林栖
老板

法务，听人说马德里有个"中心打击"风险，我们走马德里会不会国内一出事，海外全没了？

法务
你

有可能，但要分情况。马德里国际注册依赖"国内基础"。如果国内基础商标在注册后 5 年内被撤销或无效，国际注册在那些指定国也跟着失效——这就是中心打击。对策有三：① 国内基础本身要做稳（别撞权、别撤三）；② 5 年后把关键国的国际注册转成单一国注册，脱离依赖；③ 重要市场本来就用单一国注册兜底。就好比你用"本国驾照"去办了一堆"国际驾照"，本国驾照被吊销，那些国际驾照也跟着作废。但 5 年后你把常去国的驾照转成"当地正式驾照"，就不受本国那条线牵连了。

阿杰
合伙人

那外观出海走海牙，专利出海走 PCT，对吧？

法务
你

对。款式出海用海牙协定一次注册多国外观；技术出海用PCT，但记住 PCT 国际阶段只"排号"，30 个月内必须进各国国家阶段才真拿证，别以为交了 PCT 就完事。就好比你办了"全球通票"（PCT），但每张票要在 30 天内去对应国家"兑成坐票"才有效；光拿通票不上车，等于没座。

翻译成条款 马德里（基础稳固 + 5 年后转单一国防中心打击）/ 巴黎公约优先权 / PCT 30 月进国 / 海牙外观 + 单一国家兜底，按目标国组合使用。
落点：跨境 IP 路径表 + 优先权日历。

十三、权利维持：续展 / 年费 / 逾期后果

一句话商标 10 年一续、专利逐年交年费、著作权不用续。逾期不是"提醒一下"，是权利可能直接没了：商标超宽展期注销，专利年费滞纳视为放弃。
权利维持动作周期逾期后果
商标续展10 年一续有 6 月宽展；超期未续 → 注销，别人可注
专利年费逐年（逐年递增）滞纳期后未交 → 视为放弃，技术变公开
著作权无需续展—财产权有期限（作者终生 + 50 年），到期入公共领域
马德里 / 海牙续展（国际段）10 年一续国际段不续 → 多国失效
最贵的"忘了续"

很多品牌死在"拿到证就不管"。商标第 9 年该准备续展，专利年费逐年涨、越往后越容易忘。建续展 / 年费台账 + 到期前提醒，比重新申请便宜百倍——尤其商标，注销后同名可能被抢，想买回天价。

打个比方 · 维持

权利像你租的铺位：商标是10 年一续的租约，到期前不续、宽限期还不续，房东收铺租给别人；专利是每年交的物业费，哪年忘了交，物业停你服务、铺子归公；著作权是你自家祖产，不用年年交，但传到孙子辈（作者殁后 50 年）也归公了。最冤的是——你花大钱拿的证，因为"忘了续"一夜归零。

十四、监测体系：商标监测 / 专利无效监控 / 电商侵权 / 海关备案

一句话拿了证不是终点。商标近似申请预警、专利被提无效要应对、电商平台侵权要投诉、进出口走海关备案（《知识产权海关保护条例》主动 + 被动备案）。不监测，权利是"纸面资产"。

商标监测

  • 定期查近似申请，抢注早发现早异议
  • 重点国 + 重点类常看公告
  • 发现傍牌，提异议 / 无效 / 发函

专利无效监控

  • 核心专利被提无效，及时答辩保权
  • 盯对手同领域新公开，评估撞权
  • 维护专利稳定性（缴费 / 举证）

电商 / 平台侵权

  • 天猫 / 抖音 / 亚马逊定期巡检
  • 平台知识产权投诉通道下架
  • 保留购买公证证据

海关备案

  • 进出口货物知识产权海关保护备案
  • 主动备案：海关主动查扣侵权货
  • 被动备案：依申请扣留（见条例）
法源

《知识产权海关保护条例》：知识产权权利人可将其知识产权向海关备案；海关依备案对进出口侵权货物采取扣留等保护措施（主动保护 + 依申请保护两种路径）。
具体备案条件、期限与程序请核对条例现行文本及海关最新规则。

打个比方 · 监测

拿证像装了防盗门；监测是门口的监控 + 小区巡逻。门装了不等于小偷不来——你得看监控里有没有人撬、巡逻发现仿货及时报。海关备案则是在口岸设卡，假货想出入境，海关按你备的案直接扣下。不监测的权利，等于装了门却从不上锁的监控，形同虚设。

十五、预算与 ROI：把 IP 当资产计量，方向性入表

一句话IP 是资产不是费用。计量三笔账：申请 / 维护 / 维权成本 vs 资产价值 / 许可收入。财政部关于数据资源 / 无形资产的相关规定，给"IP 资产入表"指明方向（不编造条号，以现行规则为准）。
账本记什么看什么
成本账申请费、年费 / 续展费、维权律师费花了多少、哪些该省
价值账品牌估值、许可 / 加盟收入IP 带来多少现金流
风险账被抄损失、抢注买回价不护的代价有多大
入表账符合条件计入无形资产 / 数据资源资产负债表体现
IP 资产入表（方向性）

财政部已就数据资源相关会计处理发布规定，无形资产相关准则也长期存在。对符合条件的 IP（如可控制的商标 / 专利 / 软著带来的经济利益），方向上是可以计入无形资产、体现在资产负债表上的。具体能否入表、怎么计量，须按现行会计准则与最新规定判断，本页不编造条号，请核对财政部现行文件。

打个比方 · 资产 vs 费用

很多人把 IP 当"花钱的窟窿"（费用）——注册费、年费年年出。但换个账本，IP 是"会下蛋的母鸡"（资产）：品牌估值涨、许可加盟收钱、被抄能索赔。你把它当费用，只看见支出；当资产，才看见它躺在资产负债表上增值。入表就是给这只母鸡"上资产负债表户口"，投资人一看就知道你家有会下蛋的鸡，而不只是流水花钱。

十六、优先级日历：从立项到出海的排期

一句话IP 布局要踩着业务节奏排期：立项即商标 → 图稿即存证 → 工艺定型即专利 → 公开前必递 → 出海抢优先权窗。下面用时间轴把顺序钉死。
T0 · 立项
确定品牌名 / 产品方向 → 立刻查可注册性 + 递主商标 + 防御标（第 14 类及关联类）。
T0+1 周
图稿完成 → 时间戳存证 + 著作权登记；同名域名同步抢注。
T0+1 月
工艺 / 结构定型 → 核心 + 外围 + 改进专利布局；任何公开 / 参展 / 发论文前必须先递申请。
T0+2 月
若有小程序 / 系统 → 软件著作权登记；宣传片成片 → 视听作品登记。
出海前 6–12 月
国内首次申请 → 依巴黎公约主张优先权（商标 6 月 / 专利 12 月）；启动马德里 / PCT / 海牙。
PCT 起 30 月内
进入目标国国家阶段（东南亚 / 欧洲），把"国际号"兑成"坐票"。
持续
商标监测 + 电商巡检 + 海关备案；第 9 年排续展、专利逐年缴费；商业秘密清单季度复核。
