一、技术特征比对表（Claim Chart）模板

把权利要求拆成必要技术特征，逐项与被诉产品对应，是侵权分析的标配产出物。模板如下，每一行填一项权利要求特征、对应被诉特征、结论与依据。

序号权利要求必要技术特征被诉产品对应特征比对结论依据 / 备注
1特征 A被诉对应 A相同 / 等同 / 缺少全面覆盖 or 等同
2特征 B被诉对应 B相同 / 等同 / 缺少同上
3特征 C被诉对应 C相同 / 等同 / 缺少同上
结论全面覆盖成立 / 不成立结合 D2-D3 判定
填表纪律：结论只能是三种之一——相同、等同、缺少。出现「缺少」且该特征无等同可能，则全面覆盖不成立，整表走向不侵权（除非其他路径）。

二、等同判断流程（四问法）

  1. 第一问·手段：被诉替代方式与技术特征手段是否基本相同？
  2. 第二问·功能：在方案中起作用是否基本相同？
  3. 第三问·效果：达到技术效果是否基本相同？
  4. 第四问·易想到：侵权发生时普通技术人员是否无需创造性劳动即能联想到？四问全过为等同；任一不过为不等同，并排查禁止反悔与捐献是否排除。

三、周末实战：跑通一张真实比对表

选你公司一项真实或假设专利（建议用「可调节链长项链扣」或一项镶嵌工艺），按模板分解独立权利要求，逐项填被诉特征与结论，再对「不同」的那项跑一遍等同四问，最后给「侵权成立 / 不成立」结论与理由。

珠宝行业落点：款式仿款优先走外观设计（D5）比整体观感；带结构创新的（扣头、镶嵌、链节）走发明/实用新型比技术特征。一张比对表同时支撑两条线，是法务给业务/代理所最值钱的交付。

四、周末自测（答案内嵌）

Q1：技术特征比对表里某一项结论写「缺少」，整体怎么判？
参考答案只要有一个必要技术特征缺少且无法用等同补足，全面覆盖即不成立，相同侵权不成立。需再看该缺失特征是否构成等同（四问法）；若不能，则整体不侵权。
Q2：等同四问法的四个问题是什么？
参考答案手段基本相同、功能基本相同、效果基本相同、侵权发生时普通技术人员无需创造性劳动即能联想到。四问全过为等同；任一不过为不等同，并排查禁止反悔/捐献。
Q3：为什么款式仿款和带结构的创新要用两张不同的比对逻辑？
参考答案款式仿款属外观设计，比整体视觉效果（整体观察综合判断）；带扣件/镶嵌/链节结构的创新属发明/实用新型，比技术特征逐一覆盖（全面覆盖/等同）。方法不同，表也不同。
Q4：比对表对权利人 vs 被诉方各有什么用？
参考答案权利人用它证明覆盖成立、锁定赔偿依据；被诉方用它找出「缺少/不同」的特征作为突破口，并预判原告会否走等同，提前备禁止反悔/现有技术抗辩。
