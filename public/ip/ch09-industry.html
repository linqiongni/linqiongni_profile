本页「对话」原地展开：

零、珠宝时尚的 IP「四高一短」

一句话这行 IP 风险有共性：被抄高（款式易仿）、泄密高（代工/图纸）、仿店高（电商）、权属杂（代言/联名）、生命周期短（爆款就一季）。通用打法要"本地化"。
打个比方 · 这行为什么特殊

珠宝时尚像时令水果：款式是草莓，红了就被摘（抄）、放两天就蔫（生命周期短）。你不能等"完全成熟"才保护，要在"开花期（设计阶段）"就布防——图样著作权、外观设计、保密协议一起上。慢一步，季都过了。

商标案例 T1 · Y5 商标被代理商抢注
林栖
老板

出海才发现"栖梧"在目标国被我们的代理商抢注了，怎么办？

法务
你

先核他在哪类、是否使用；能证明"他明知是代理关系仍抢注"可异议/无效；同时评估买回或改用子品牌。根因是出海前没走马德里抢优先权（见第 08 站）。就好比你托人帮你占铺位，他反过来把铺位挂自己名下——你能证明"是代你占的"，就能要回来；但最好当初自己先占。

落点第 02 站（抢注/异议）+ 第 08 站（跨境优先权）。
著作权案例 C1 · Y4 代言照片双授权
法务
你

代言人拍的宣传图，光有肖像授权不够——照片的著作权在摄影师/工作室。要"肖像权许可 + 著作权许可/转让"双授权，才能自由商用（见第 04 站）。就好比你请人给你画像，画是你（肖像）但不能随便印——因为画归画师（著作权）。两权分家，得一起买。

落点第 04 站（职务/委托作品 + 双授权）。
商业秘密案例 S1 · Y3 代工图纸泄密
法务
你

代工厂拿我们图纸私自生产"同源款"，靠保密协议 + 竞业限制 + 图纸标记密级 + 留痕交接追责（见第 05 站）。保密措施越具体，泄密越好打。就好比你借图纸给邻居，先立字据"不得外传、不得自用"，他违规你才有据。口头说"别外传"等于没说。

落点第 05 站（保密措施 + 竞业限制）。
专利案例 P1 · Y2 爆款造型被"微调"仿
法务
你

对手把我们的爆款"改一笔"仿，要看是否落入外观设计保护范围（整体视觉效果近似即可能侵权）。所以申请时独权圈得准、从属分层（见第 03 站），仿品微调也难逃。就好比你圈了块地，邻居往里挪半米种菜——还在你圈里，他就越界。

落点第 03 站（权利要求圈地 + 全面覆盖）。
维权案例 R1 · Y7 电商仿店维权 SOP
法务
你

仿店"栖梧精品"：平台投诉下架 + 公证购买 + 律师函（兼明知证据）+ 民事起诉 + 行为保全（见第 06/07 站）。把动作做成 SOP，监测到就跑流程，不临时抱佛脚。就好比灭火演练：平时练熟"报警→泼水→撤人"，真着火不慌。

落点第 06 站（赔偿/禁令）+ 第 07 站（程序/证据）。

四、行业"标配合同清单"（可直接抄）

对外

  • 代工/采购：保密 + 权属归属 + 不得自用/转售
  • 联名：pre-clearance + 成果权属 + 到期处理
  • 代言：肖像权 + 著作权双授权 + 使用范围/期限
  • 设计外包：委托作品归属归我方 + 保密

对内

  • 劳动合同：职务作品归属 + 保密 + 竞业限制
  • 保密制度：密级 + 接触审批 + 留痕
  • IP 台账：商标/专利/著作权/域名到期提醒
  • 监测机制：关键词 + 图样比对 + 定期扫
法务对话对话 01 · 这么多合同，小公司也要全签吗？
林栖
老板

我们才十几人，每份都签这么正式，会不会太重？

法务
你

不用"重"，但要"准"。小公司更要把最贵的几处用条款锁死：代工（泄密）、联名（撞权）、代言（双授权）、员工（职务归属）。其余可轻量模板化。把高风险点用条款钉住，比全面铺开更划算。就好比小店不用装全套监控，但收银台和仓库那两个最易丢钱的点，得有摄像头。钱花在刀刃上。

翻译成条款按"风险等级"配合同：高风险（代工/联名/代言/员工）必签关键条款，低风险模板化。

五、全站自检总清单

一句话九站走完，问自己：权利拿到了吗？组合护了吗？证据会固定吗？出海抢先了吗？合同锁权属了吗？维权有 SOP 吗？
  • 商标：主标+防御标+图样著作权，核心类别覆盖？
  • 专利：爆款用外观设计/发明护，权利要求圈得准？
  • 著作权：作品自动保护+关键登记，职务/委托归属清？
  • 商业秘密：保密措施具体+竞业限制合规（≤2年+补偿）？
  • 救济：四档赔偿+惩罚性+禁令路径熟？
  • 程序：三路径+管辖+公证/时间戳固证 SOP？
  • 布局：组合矩阵+跨境优先权+联名前置尽调？
  • 行业：代工/联名/代言/员工四类合同锁权属？
