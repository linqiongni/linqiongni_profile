零、珠宝时尚的 IP「四高一短」

一句话这行 IP 风险有共性：被抄高（款式易仿）、泄密高（代工/图纸）、仿店高（电商）、权属杂（代言/联名）、生命周期短（爆款就一季）。通用打法要"本地化"。

商标案例 T1 · Y5 商标被代理商抢注
林栖
老板

出海才发现"栖梧"在目标国被我们的代理商抢注了，怎么办？

法务
你

先核他在哪类、是否使用；能证明"他明知是代理关系仍抢注"可异议/无效；同时评估买回或改用子品牌。根因是出海前没走马德里抢优先权（见第 08 站）。就好比你托人帮你占铺位，他反过来把铺位挂自己名下——你能证明"是代你占的"，就能要回来；但最好当初自己先占。

落点第 02 站（抢注/异议）+ 第 08 站（跨境优先权）。
著作权案例 C1 · Y4 代言照片双授权
法务
你

代言人拍的宣传图，光有肖像授权不够——照片的著作权在摄影师/工作室。要"肖像权许可 + 著作权许可/转让"双授权，才能自由商用（见第 04 站）。就好比你请人给你画像，画是你（肖像）但不能随便印——因为画归画师（著作权）。两权分家，得一起买。

落点第 04 站（职务/委托作品 + 双授权）。
商业秘密案例 S1 · Y3 代工图纸泄密
法务
你

代工厂拿我们图纸私自生产"同源款"，靠保密协议 + 竞业限制 + 图纸标记密级 + 留痕交接追责（见第 05 站）。保密措施越具体，泄密越好打。就好比你借图纸给邻居，先立字据"不得外传、不得自用"，他违规你才有据。口头说"别外传"等于没说。

法务对话对话 01 · 这么多合同，小公司也要全签吗？
林栖
老板

我们才十几人，每份都签这么正式，会不会太重？

法务
你

不用"重"，但要"准"。小公司更要把最贵的几处用条款锁死：代工（泄密）、联名（撞权）、代言（双授权）、员工（职务归属）。其余可轻量模板化。把高风险点用条款钉住，比全面铺开更划算。就好比小店不用装全套监控，但收银台和仓库那两个最易丢钱的点，得有摄像头。钱花在刀刃上。

翻译成条款按"风险等级"配合同：高风险（代工/联名/代言/员工）必签关键条款，低风险模板化。

五、珠宝时尚四大高频场景深度拆解

一句话把"四高一短"落到四个最常被老板半夜电话吵醒的场景：款式被抄、代工泄密、电商仿店、代言图侵权。每个场景给「风险点 + 权利组合 + 标准应对清单」，照抄就能搭防线。

5.1 款式被抄：著作权 + 外观设计 + 反法「组合拳」

风险点爆款一出，三天全网同款：有人照图打版、有人"微调一笔"打擦边、有人把你的"特有造型"做成行业通用款还说是公版。
美术作品（著作权）
款式图稿、效果图若具独创性，自创作完成即受保护，可登记美术作品。护的是"那个具体表达"，别人复制图就侵权。
外观设计专利
产品的形状、图案、色彩设计，申请授权后护"整体视觉效果"。对手"微调"若整体观感近似，仍可能落入范围。
反法包装装潢
你的某一系列造型经使用已具一定影响、能让公众区分来源，别人仿冒造成混淆，可用《反不正当竞争法》第 6 条打。
打个比方 · 组合拳

护款式像给家门上三道锁：著作权是门里的贵重物品本身（谁拿你的图谁就是偷东西）、外观设计是整扇门的形状（对方换把锁芯也还认得是你的门）、反法是整条街都认得你家门脸（有人照你门脸开店骗邻居）。一道锁能撬，三道叠着，抄的人处处碰壁。

标准应对清单
  • 图稿完成即时间戳/区块链存证 + 著作权登记（美术作品），锁定"谁先画、哪天画"。
  • 爆款立项即递外观设计专利，权利要求圈准、从属分层，抗"微调仿"。
  • 对已成系列的"特有造型"做使用证据（销量、广告、获奖）留存，养出一定影响的包装装潢认定基础。
  • 监测到仿款：公证购买 + 网页取证同步固定；先发函，再评估平台/行政/民事路径（见 5.3）。
  • 内部建"上新即护" SOP：设计 → 存证 → 登记/申请 → 监测，一条龙，不漏一款。

5.2 代工泄密：保密协议 + 竞业限制 + 商业秘密三要件

风险点图纸、工艺参数、古法金配方外流：代工厂"同源款"私产、离职员工带图跳对手、样品拍照外传。泄密往往发现时已卖了大半年。
打个比方 · 商业秘密三要件

商业秘密要"三件套齐全"才算数：秘密性（这东西同行不知道）、价值性（拿着它能赚钱）、保密措施（你真当秘密在护）。就好比你有一把祖传钥匙：得是"别人配不出"的（秘密性）、能开锁取财（价值性）、你还真把它锁在保险柜并立了规矩"谁碰要登记"（保密措施）。三样少一样，法庭就不认它是"你的秘密"。

权利组合保密协议（NDA）+ 竞业限制（≤2 年 + 补偿）+ 图纸标记密级 + 留痕交接；根上是把信息养成立法意义上的商业秘密。
发现后应急
  • 先固定证据：交接单、邮件、带水印图纸、监控——别打草惊蛇前先把"他拿了什么、怎么拿的"留死。
  • 发律师函/警告函要求停止，并作为"明知"证据（后续赔偿用）。
  • 评估三路径：民事（侵犯商业秘密之诉）+ 行政（向市监举报）+ 刑事（情节严重、损失达标可报案）。
  • 同时止损：改密级、收权限、换产线、对已流出版做"反向公开"削弱秘密性损失。
法务对话对话 02 · 代工厂说"图纸我也能用"，我拿他没办法吗？
林栖
老板

代工厂拿我们星轨项链的图纸，自己开了条"同源款"在卖。我们没签什么保密协议，现在拦得住吗？

法务
你

能拦，但没签协议你会很被动。补救是看这图纸是否构成商业秘密：只要它"同行不知道 + 你能证明采取了保密措施"（哪怕只是邮件里写了"保密、不得外传"、图纸标了密级），就能主张侵犯商业秘密。就好比你借邻居一把限量钥匙，虽没立字据，但你微信里明说"这把别外配"，他偷偷配了卖——你说"我明示过不许外传"，法官也认你尽到了提醒。当然，立了字据你底气更足。

阿杰
合伙人

那以后怎么防？

法务
你

三件事写进每份代工合同：①保密义务 + 违约天价赔偿；②竞业限制（期限≤2 年、给补偿才有效）；③图纸"交付即标记密级 + 留痕交接单"。再把核心工艺参数放"仅产线可见"的内网，不落地到代工厂电脑。就好比你让邻居帮你修锁，先立字据"钥匙不得复配、不得自用"，锁芯结构只让他看一眼不让他拍照——规矩写清、东西不落地，他违规你一告一个准。

翻译成条款代工/采购合同必备：保密 + 权属归属 + 不得自用/转售 + 竞业限制（合规期限与补偿）+ 图纸密级标记与交接留痕。落点：第 05 站（保密措施 + 竞业限制）。

5.3 电商仿店：平台投诉 + 行政投诉 + 民事诉讼「三件套」

风险点"栖梧精品""栖梧珠宝官方"近似店名开店；详情页盗用你的图；客服话术引流到仿店。客户分不清，订单被截胡。
平台投诉（最快）
走电商平台的 IPR / 知识产权保护通道，提交商标注册证 + 近似比对，要求下架 / 关店。成本低、见效快，但只限该平台内。
行政投诉（兜底）
向市场监管 / 知识产权部门举报商标侵权或不正当竞争，行政机关可责令停售、罚款，并固定"明知"证据。
三件套打法
  • 平台投诉：商标证 + 权属证据 + 侵权链接，走平台 IPR 通道下架（见 5.1 固证）。
  • 行政投诉：市监 / 知识产权局举报，兼作"对方明知"的官方证据。
  • 民事诉讼：商标侵权 + 不正当竞争一并诉，主张赔偿 + 行为保全（先封后审）。
  • 三件套并行不冲突：平台止血、行政固证、民事拿钱，按紧迫度组合。

5.4 代言图侵权：肖像权 + 著作权「双授权」

风险点代言人肖像超范围用（详情页 / 直播 / 户外）；照片著作权其实在摄影师；代言人解约后物料还在卖；AI 换脸、二创踩线。
打个比方 · 双授权

代言图里藏着两权：肖像权是"人"（代言人本人），著作权是"画"（摄影师/工作室的拍摄成果）。光买肖像权，等于你买了模特的脸，却没买那张照片——印出去还是侵摄影师的权。两权得一起买，才叫"自由商用"。就好比你请人给你画像，付了模特钱不够，画师的著作权还在他手里，你想印明信片卖，得再向画师买授权。

权利组合《民法典》第 1018 条（自然人享有肖像权，可制作/使用/公开/许可他人使用）+ 第 1019 条（未经同意不得制作、使用、公开肖像）+ 照片著作权许可/转让双授权。
标准应对清单
  • 签肖像权许可 + 著作权许可/转让双授权，写明渠道、媒介、期限、地域、可否转授权。
  • 详情页使用边界：只在约定渠道放约定版本；促销图、海报另需单独确认。
  • 直播使用边界：直播中播放代言物料、口播"代言人推荐"须落在授权范围；解约后直播回放须下架含代言人片段。
  • 设授权到期自动下架机制 + 解约清单，避免"忘了撤"继续侵权。

直播背景音乐/字体授权 + 主播话术不贬损他人 + 代言物料在授权期直播即兴放歌、用他人图稿当背景
跨境目标国商标/外观优先权 + 海关备案 + 当地律师函通道出海前没查，被当地代理商抢注
  • 设计稿：上新即存证，登记"美术作品"，外包合同写"著作权归我方"。
  • 模具：模具图加密 + 接触审批；可反向工程的结构补专利，藏不住的当商业秘密。
  • 包装：系列包装做外观设计 + 留存"一定影响"的使用证据链。
  • 详情页：图片自产自拍留著作权；字体/音乐走商用授权，禁盗图。
  • 直播：背景乐、字体、贴图全授权；代言人出镜须落在授权期与渠道。
  • 跨境：出海前 6 个月走马德里/PCT/海牙 + 目标国海关备案。

八、行业真实案件（教学示例 · 以裁判文书为准）

一句话下面四起是公开报道的行业典型案件，用来对照珠宝时尚的同类风险。具体事实、案号与赔偿数额以官方裁判文书为准，本页不编造数字，读者请自行核对。
读前提醒

以下仅作教学类比，不指向任何珠宝主体，也不构成法律意见。如不确定细节，请以"行业典型案件"视之，并到"中国裁判文书网 / 法院公告"核对案号与现行文本。

姓名权 × 商标案件 A · 乔丹案（姓名权与商标冲突，最高法再审）

案情（教学概括）：自然人主张特定中文译名系其姓名，争议商标的注册损害其在先姓名权。最高法再审认可该译名与自然人稳定对应，相关商标应不予注册/宣告无效。

对珠宝的启示：你请的代言人、联名 IP 的"名"，若与特定自然人稳定对应，注册成商标前要先拿到姓名权许可，否则可能被提无效。就好比你想把一位明星的艺名注册成你家的款名，没经本人同意，人家一纸无效请求就能把你的商标撸掉。

法源：《民法典》姓名权相关条款 + 《商标法》第 32 条（损害他人现有的在先权利）。案号与结论以裁判文书为准。

反法第 6 条案件 B · 红罐凉茶（有一定影响的包装装潢，反不正当竞争）

案情（教学概括）：两经营主体就"红罐"这一特有包装装潢的权益归属发生争议。法院围绕"知名商品特有包装装潢"作出认定，强调装潢经使用产生的识别利益应受保护。

对珠宝的启示：你的"古法金红盒 + 鎏金纹"若用出识别度，就是有一定影响的包装装潢，别人仿你盒子造成混淆，可用《反不正当竞争法》第 6 条打。就好比整条街都认得你家的红盒子，对面开家店也用一模一样的红盒子，邻居进了错店——这就能算"擅自使用他人有一定影响的包装装潢"。

法源：《反不正当竞争法》第 6 条第（一）项。现行法表述为"有一定影响的商品名称、包装、装潢"。案号与结论以裁判文书为准。

著作权案件 C · 琼瑶诉于正（改编权 / 摄制权）

案情（教学概括）：编剧主张电视剧剧本抄袭其在先作品，法院认定侵害改编权、摄制权等著作权，判令停止侵权并赔偿。

对珠宝的启示：你拍的品牌微电影、联名短片，剧本/分镜若"借鉴"了他人作品，同样踩改编权。就好比你照着别人写好的小说改剧本拍片，没拿到改编授权，播出去就是侵权——珠宝品牌的"内容营销"也在这条线里。

法源：《著作权法》第 10 条（改编权、摄制权等）。案号与结论以裁判文书为准。

商标案件 D · 运动鞋"N 字"标识（相关商标纠纷，谨慎引用）

案情（教学概括，细节从略）：某运动品牌与其"N 字"鞋面标识相关的商标纠纷曾引发广泛讨论，涉及商标使用是否构成侵权、以及"商标使用不侵权"等抗辩的较量。

对珠宝的启示：你用一个"通用形状/字母"做款标，若与他人注册商标近似，同样可能被诉。Detail 我无法在此核实，请直接以"相关商标纠纷"视之并核对案号——本页不展开具体认定。就好比你在项链扣上刻个简洁符号，碰巧和别人注册的标近似，对方函来你就得证明"我这是正当使用、不造成混淆"。

法源：《商标法》第 57 条（侵权情形）+ 第 59 条（正当使用抗辩）。具体事实以裁判文书为准，本页不编造赔偿数额。

九、联名 / IP 授权专项

一句话联名是珠宝时尚的流量密码，也是权属雷区：联名方商标授权范围、联名款著作权归属、授权链条（被授权方再授权）三处最容易翻车。
常见坑
  • 联名方只给了"商标展示权"，你却拿去做了独立款。
  • 联名款著作权没写归谁，期满后对方自己卖同款。
  • 被授权方（你的代工厂/渠道）又转授权给第三方，链条失控。
标配打法
  • 授权范围逐渠道、逐媒介、逐期限写死，不写"全权"。
  • 联名款著作权约定归我方或双方共有 + 我方可商用。
  • 授权链条设禁止转授权条款，转授权须书面同意。
条款 B · 联名授权范围（写进每份联名合同）
授权方许可被授权方在约定商品类别、约定渠道、约定期限、约定地域内使用联名商标/IP；被授权方不得将权利转授权第三方（经书面同意除外）。联名合作产生的成果，其著作权归被授权方（栖梧）所有或双方共有，授权方在合作期内可在宣传中使用。
法务对话对话 03 · 联名方说"随便用"，我还能踩雷？
林栖
老板

联名的那家IP方口头说"你们随便用我们的图"，还用签那么细吗？

法务
你

"随便用"三个字在法庭上等于零。口头授权没法证明范围，真出了事他说"我只同意用在吊牌、没同意用在包装"。必须落纸面：用哪、用到哪天、能不能转授权。就好比朋友说"我家钥匙你随便用"，真丢了东西他改口"我只说你进门、没说你搬走"——白纸黑字写清"能进门 + 能借住到月底"，才不扯皮。

阿杰
合伙人

那联名款卖完，图能不能继续用？

法务
你

看合同默认。不写，期满后对方有权禁止你继续用，包括清库存都可能受限。所以联名款著作权要约定"归我方或我方可永久商用"，到期只停"新生产"，库存与宣传按约定处理。就好比你租了人家的画展位，租期到了画得撤；但若当初约定"画归你买断"，到期你照样能挂。

翻译成条款联名合同必备：授权范围（类别/渠道/期限/地域）+ 成果著作权归属 + 禁止转授权 + 到期处理（库存/宣传）。落点：第 04 站（委托/合作作品）+ 第 08 站（联名前置尽调）。

十、直播 / 短视频侵权新场景

一句话主播一开镜，侵权点就冒头：背景音乐、商用字体、他人图稿、代言人出镜、贬损式对比——都是高频雷。珠宝直播尤甚（画面精致、物料多）。
背景音乐
直播/短视频配乐需信息网络传播权授权。用"免费纯音乐"也可能未获商用授权，平台曲库才相对安全。
商用字体
字幕、贴图用的字体多有著作权，商用须授权。用开源/免费商用字体最稳。
他人图稿
把网红/同行的款式图当直播背景、当"对比款"展示，可能侵著作权 + 构成不正当竞争。
标准应对清单
  • 直播背景乐只用平台授权曲库或已购权音乐，禁随手放热门歌。
  • 字幕/贴图统一用免费商用字体，建品牌字体白名单。
  • 直播背景、口播不出现他人款式图/商标，"对比款"须用自产或已授权。
  • 代言人出镜直播须落在肖像授权期与渠道内；解约直播回放下架。
  • 主播话术培训：不贬损竞品（防不正当竞争）、不虚假宣传（防广告法）。
法务对话对话 04 · 主播随手放首歌，也侵权？
林栖
老板

我们主播直播时随口放了首流行歌当背景，这也要紧？

法务
你

要紧。直播是公开传播，放未授权音乐侵"信息网络传播权/表演权"，音乐公司批量发函是常态。就好比你在店里公开放别人的歌招揽客人，没买公播权，唱片公司能找你收钱甚至起诉。直播间也是"公开场合"，只是搬到了网上。

阿杰
合伙人

那字体呢？我们标题用了个好看的字体。

法务
你

字体也有著作权，商用要授权。最省心是建"免费商用字体白名单"，主播、设计统一用，别碰来路不明的字体包。就好比你印传单用了别人设计的艺术字，没买授权，人家能告你盗用美术作品——字体本质是"字的艺术设计"。

翻译成条款直播 SOP：平台曲库音乐 + 免费商用字体白名单 + 禁用他人图稿/商标 + 代言人授权期内出镜。落点：第 04 站（作品使用）+ 第 07 站（证据/合规）。
