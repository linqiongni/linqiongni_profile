侵权与救济通论
◆

一、为什么要单独讲归责原则

民法一般侵权以过错责任为原则（《民法典》第 1165 条第 1 款）：行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。四要件是：违法行为、损害事实、因果关系、主观过错。

但知识产权是绝对权、排他权。它的逻辑更接近物权：只要未经许可进入了权利人的排他范围，行为本身即具违法性。过错只影响赔不赔钱，不影响侵权是否成立。

一句话记住这个分离： - 判断「是否侵权」：看有没有落入排他范围 + 有没有法定免责事由； - 判断「是否赔偿」：再看有没有过错； - 判断「是否多倍赔偿」：再看是不是故意 + 情节严重。 三层递进，别混。

二、四类侵权构成要件对照

权利类型违法行为过错的作用法律依据（待核实条号）免责出口
著作权未经许可实施了受专有权利控制的行为（复制、发行、信息网络传播等）原则上不要求过错；复制品的出版者、制作者、发行者、出租者需自证合法授权 / 合法来源，否则担责著作权法第 52、53、59 条合理使用、法定许可、独立创作、权利用尽
专利权为生产经营目的，未经许可制造、使用、许诺销售、销售、进口专利产品（或使用专利方法及依该方法直接获得的产品）不要求过错；使用者 / 销售者 / 许诺销售者不知情且能证明合法来源的，不承担赔偿责任（第 77 条）专利法第 11、77 条第 75 条五项不视为侵权、现有技术、权利用尽、先用权

三、合法来源抗辩：被诉方最常用的出口

三个法定要件（以商标法第 64 条第 2 款、专利法第 77 条为代表）：

  1. 不知道——销售者不知道所售商品是侵权商品；
  2. 合法取得——能证明该商品是自己合法取得的（合同、发票、送货单、付款凭证、进货台账）；
  3. 说明提供者——能说明该商品的提供者（真实名称、地址、联系方式）。
效果是否免除
停止侵害不免除（通常仍需停止销售、下架）
损害赔偿责任免除
合理开支⚠ 司法实践有分歧，多数判决仍支持权利人合理开支由销售者承担一部分或全部。请以现行判例核对
销毁侵权商品视判决而定
对权利人的战术含义：起诉销售者时，把诉讼请求设计成「停止侵害 + 合理开支」两条腿——即使对方成功主张合法来源免除赔偿，你仍然拿到下架与费用。真正的赔偿额应当向制造者、品牌方主张。

四、帮助侵权与教唆侵权

《民法典》第 1169 条：教唆、帮助他人实施侵权行为的，应当与行为人承担连带责任。

主体可能构成的责任判定要点珠宝行业场景
代工厂直接侵权（制造）；明知仍代工的为共同侵权是否明知委托方无授权；是否审查了授权文件接受订单生产带他人商标的首饰
经销商 / 分销商销售侵权；可主张合法来源进货渠道与审查义务从不明渠道进货后在门店销售
商场 / 卖场帮助侵权（提供场所）接到侵权通知后是否及时采取必要措施柜台商户售假，商场收到律师函后未处理
电商平台间接侵权 / 帮助侵权通知—删除规则、"知道或应当知道"的认定平台内经营者售假，平台未下架
直播主播 / MCN代言或帮助推广；可能构成共同侵权是否参与定价、发货、分成主播在直播间销售仿款
平台责任的关键是「通知后的行为」。 收到有效侵权通知后及时删除、屏蔽、断开链接的，通常可免责（避风港）；收到通知后仍不作为的，对损害的扩大部分承担连带责任。平台责任的完整规则在第 11 周展开。

五、共同诉讼与被告选择策略

  • 纵向打穿：制造者 → 品牌方 → 总代 → 分销 → 终端门店，选 1-2 个最有赔付能力 + 最容易取证的；
  • 横向铺开：同一制造者供给的多个销售渠道，可分批起诉形成压力；
  • 先易后难：先用电商详情页与展会的许诺销售行为确立侵权，再追制造端；
  • 管辖考量：被告住所地与侵权行为地均可选，多被告时可择地诉讼（第 4 周展开）。
