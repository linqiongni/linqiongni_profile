你是我的知识产权实务教练。请基于本周 W9 内容，陪我做一次完整的设计稿被抄袭维权实战推演：从发现仿款开始，逐步给出每一步动作、文书要点与证据清单，并在关键节点提示被告可能提出的抗辩与我的应对。

一、作战流程总图

  1. 发现：监测（电商巡检、图反向搜、线下扫街）发现疑似仿款/外流图；
  2. 固定权属：确认设计图著作权归公司（特殊职务作品/委托合同约定，D2 落点）；
  3. 固定侵权：公证购买/时间戳网页 + 销量截图，固定「图/实物 + 销售链接 + 销量」；
  4. 威慑：发律师函（停止侵权 + 赔偿 + 披露上游）；
  5. 平台：电商/社媒知识产权通道投诉下架；
  6. 民事/刑事：损失大则起诉（四档赔偿 + 惩罚性），规模化复制发行则衔接刑法第 217 条。

二、各步动作与文书要点

  • 权属链自查：先确认「我是权利人」——设计图是否特殊职务作品、委托合同是否约定归委托方（D2）；
  • 取证清单：权属证据（底稿/源文件/登记/时间戳）+ 侵权证据（公证实物/网页时间戳/销量截图/代工往来记录）；
  • 发函要点：载明权属、侵权事实、停止要求、赔偿金额与计算、披露上游义务、时限；
  • 平台投诉：提交权属证书 + 侵权链接 + 比对说明，走电商/社媒 IP 通道；
  • 刑事衔接：以营利为目的复制发行他人作品，数额/情节达标的，衔接刑法第 217 条侵犯著作权罪。
珠宝行业最危险缺口：代工厂/经销渠道泄密。应在委托/保密协议里锁死「设计图著作权归委托方 + 禁止外流 + 违约披露下游」，否则维权时权属与接触证据都弱。

三、被告抗辩预判（打之前先想他怎么挡）

被告可能出的牌我的反制
「图是我独立创作的」反证：我方完成时间更早（时间戳）+ 双方代工往来（接触）+ 表达实质相同
「实物款式不受著作权保护（图物分离）」转而主张外观设计专利/反法包装装潢；若其复制了「图」本身则图侵权成立
「已获授权/合理使用」要求出示授权合同；核对是否落第 24 条情形
「原告不是权利人」出示职务作品认定/委托合同约定/登记证书

四、周末自测（答案内嵌）

Q1：发现代工厂把公司设计图外流给竞品做同款，第一步？
参考答案先固定权属（确认图纸著作权归公司：特殊职务作品或委托合同约定）与侵权证据（外流记录、竞品实物/页面公证），再发律师函要求停止 + 披露下游，并平台投诉下架。切忌先打草惊蛇致证据销毁。
Q2：对方辩称「图纸是我独立创作的」，如何应对？
参考答案反证：① 我方设计图完成时间早于对方（时间戳/首发）；② 双方有代工往来（接触）；③ 表达实质相同（抽象过滤后剩余独特部分相同）。同时查代工保密/竞业限制违约，可叠加违约/商业秘密路径。
Q3：民事不够，能否刑事？侵犯著作权罪（217）门槛？
参考答案可衔接刑法第 217 条侵犯著作权罪（以营利为目的，未经许可复制发行他人作品，违法所得数额较大或有其他严重情节）。⚠ 具体立案追诉数额标准须核实现行司法解释，勿照搬旧标准。
Q4：只抄了「设计图」没抄实物，著作权能管吗？
参考答案能。设计图是图形作品，未经许可复制/发行设计图本身即侵权。但若对方仅「照图做实物」未复制图，实物一般不受著作权保护（图物分离），需转外观设计专利/反法。
