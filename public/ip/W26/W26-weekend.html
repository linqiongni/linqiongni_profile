一、跨境布局决策树（四问分流）

  1. 问一·权利类型：商标走马德里/单一国；外观走海牙/单一国；功能性技术走 PCT/巴黎；
  2. 问二·国家数量：1-2 个核心国 → 单一国；3 个以上 → 马德里/海牙/PCT 集中；
  3. 问三·怕连坐吗：核心市场不能承受中心打击 → 单一国；可接受 5 年依附 → 马德里/海牙；
  4. 问四·预算与节奏：要 30 个月缓冲评估 → PCT；要快 → 巴黎/单一国。
决策树结论示例：「星河」商标进美欧+中国香港且目标法域多 → 马德里（指定美/欧/中国香港）；外观同批 → 海牙；若只进美国且怕连坐 → 单一国美国。

三、维权预案：备案 + 337/法院 + 海关

  • 日常止损：出海即在目标国完成商标/外观注册并做亚马逊品牌备案，防跟卖与盗图；
  • 进口拦截：规模化仿品从海外进口美国 → 337 调查（排除令堵口岸）+ 联邦法院索赔；
  • 海关备案：在美（IPR 海关备案）、欧盟、中国海关做知识产权备案，依申请/依职权扣留仿品；
  • 反向视角：若你被控 337 或商标侵权，可攻击对方国内产业要件不成立、主张权利无效/不侵权、或证明自有合法授权链。
珠宝/时尚出海三件套：商标防跟卖（备案）+ 外观防仿款（海牙/单一）+ 专利防技术抄（PCT）。三者齐备才叫「布好局」。

四、周末自测（答案内嵌）

Q1：决策树里「怕连坐」这一问怎么影响路径选择？
参考答案核心市场不能承受中心打击（5 年依附期内基础失效则指定国全塌）→ 选单一国；可接受依附风险、要集中管理 → 选马德里/海牙。
Q2：成本表为什么每项都要写核对渠道？
参考答案因为官费随年份与汇率变动，且各国/ WIPO 标准不同；标⚠待核实并注明 WIPO/各国官方渠道与日期，才能保证方案可执行、不被过时数字误导。
Q3：亚马逊备案和 337 调查能互相替代吗？
参考答案不能。备案是平台级止损（下架仿品、防跟卖），不判赔偿；337 是进口贸易救济（排除令堵口岸），也不判赔偿；要赔偿走联邦法院，三者互补。
Q4：被诉 337 调查，被告首要抗辩点可能是什么？
参考答案攻击申请人「国内产业要件」不成立（美国无相应生产/研发/许可活动），或主张涉案专利/商标无效、不侵权、或己方有合法授权链。
