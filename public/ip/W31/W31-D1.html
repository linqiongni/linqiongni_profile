一、接案访谈：先问清三件事

接案不是听委托人讲故事，而是用结构化问题把模糊诉求变成可诉目标。对星河珠宝法务/外聘律师，访谈核心是三问：① 你主张什么权利（商标「星河/XINGHE」第14类，2016年注册，经典款「星轨」系列镶钻戒指）？② 对方做了什么（店铺「星河臻选」销售近似款，标题用「星河同款」「星轨款」，月销数千；深圳水贝档口供货并提供3D建模文件）？③ 你到底要什么（先下架止血，再索赔，是否要震慑到刑事）？

实务口诀：诉求不清不接案，目标分档好排序。止血第一、索赔第二、震慑看证据。

⚠ 待核实 / 提示
⚠ 待核实：市场监督管理行政处罚案件办理期限（《市场监督管理行政处罚程序规定》第60条 一般90日，复杂可延长），以及电商平台知识产权投诉审核时效，以现行规定与平台规则为准。刑事上本案「星河同款」「星轨款」属近似商标致混淆，不同于「相同商标」，假冒注册商标罪（刑法第213条）要求「相同商标」，故刑事门槛高，需评估是否构成司法解释扩张情形，⚠以司法解释为准。

五、风险告知书（抗辩预判）

  • 商标不近似抗辩：被诉方称「星河臻选」与「星河」不近似、「星轨款」为描述性 / 反制：整体视觉效果+混淆比对报告+消费者误认证据
  • 合法来源抗辩（商标法64条第2款）：档口称有「授权」或不知侵权 / 反制：查授权链真实性，档口提供3D文件证明明知近似
  • 撤三/无效抗辩：拖延程序 / 反制：提前固化近三年使用证据
  • 诉讼时效：侵权持续中，时效从知道起算3年（民法典188条）/ 本案持续侵权，未过时效
双视角收口：接案阶段就把「被诉方四张抗辩牌」写进风险告知书，并附反制证据动作，等于把诉讼剧本先读一遍。

六、今日自测（答案内嵌）

Q1：接案后第一步该发函还是该取证？为什么？
参考答案先取证。监测发现后先做公证购买/时间戳固定证据，再发函或投诉。直接发函会打草惊蛇，导致店铺下架链接、销毁库存与3D文件，证据灭失。本案应先固证「星河臻选」戒指实物与网页，再启动平台/行政下架。
Q2：被诉方最可能用哪两张程序性牌拖延本案？权利方怎么反制？
参考答案① 撤三（商标法第49条 连续三年不使用撤销）——反制：接案即固化近三年使用证据链（销售合同、发票、广告、专柜照片）；② 商标无效（缺乏显著性/通用描述）——反制：证明「星河」非珠宝通用词、固有显著性较强，并备知名度证据。两张牌本质拖延，权利方提前拆弹。
Q3：本案为什么刑事门槛高，不宜一开始就报案？
参考答案假冒注册商标罪（刑法第213条）要求「相同商标」，本案店铺用「星河臻选」「星轨款」属近似商标致混淆，非相同商标，刑事立案门槛高；且一开始报案会打草惊蛇、证据灭失。应先民事/行政下架止血，把刑事作为谈判震慑筹码（主张惩罚性赔偿）而非首选路径。⚠ 近似商标入罪边界以司法解释为准。
Q4：平台投诉和行政投诉在「止血」上有什么不同，怎么排序？
参考答案平台投诉（电商法第42条 通知-删除）最快 3-7 日下架链接，但不赔钱、仅平台内；行政投诉（商标法第60条 市监查处）可责令停止+没收+罚款，有震慑但周期较长（一般90日）。排序：先平台投诉快速止血，同步行政投诉扩大震慑，再民事索赔。两者都快于诉讼，属「止血组合」。
