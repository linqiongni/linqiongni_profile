你是我的知识产权实务教练，我们现在做第 4 周周末实战。 场景：港资珠宝品牌「星河 STELLARIVER」发现抖音与拼多多上有 4 家店铺销售与其「星河·旋」吊坠高度相似的仿款，售价 198–298 元（正品 3,980 元）。经初步排查，4 家店铺发货地址均为深圳水贝同一工业区，客服手机号与收款账户存在重合，其中 2 家曾因售假被平台处罚后关闭，随后以亲属身份重新开店。月销量合计约 2,800 件，已持续 8 个月。公司计划双十一前完成维权。 请你扮演甲方评审，帮我完成： 1) **路径选择**：行政 / 民事 / 刑事如何组合？给出时间线与先后顺序，并说明理由； 2) **管辖选择**：本案有哪些可选连接点？建议在哪里起诉？是否需要考虑多被告？ 3) **证据链设计**：按"主体 → 行为 → 规模 → 获利 → 主观恶意"五个层次，逐层列出需要的证据、取证工具（公证 / 时间戳 / 区块链）、取证顺序与时间节点； 4) **主体关联证据**：如何把 4 家店铺串成一个侵权主体？列出至少五类可收集的关联证据； 5) **举证妨碍预埋**：在起诉状与举证阶段应如何预埋"请求责令被告提交账簿"的申请？写出申请要点； 6) **保全决策**：是否在双十一前申请诉前行为保全？列出支持与反对的理由，并给出你的建议； 7) 产出一份**《取证 SOP》**（10 步以内，每步含动作、工具、时限、责任人）； 8) Executive Summary：最大风险 Top 3 + 下周待办。 所有期限、条号与数值不确定处标注「待核实」，不得编造案号。

场景与数据

见上方指令中的虚拟场景。任务：90 分钟内产出《IP 案件证据清单模板》与《取证 SOP》。

第一步：路径选择（15 分钟）

阶段动作理由时间点
① 固定时间戳 + 公证固定 4 家店铺页面与销量防止删链接、改销量D1–D3
② 止损平台知识产权投诉（抖音 / 拼多多）最快下架，成本低D1–D7
③ 民事向有管辖权法院起诉 + 申请诉前行为保全（双十一前）拿禁令 + 索赔D7–D30
④ 举证妨碍起诉同时提交责令提交账簿申请拿到真实销量与获利举证期限内
⑤ 刑事评估按累计销售额评估是否达到立案标准；达标则报案拿账簿、施压、追责证据齐备后
顺序不能反：先固定、后投诉。很多公司一发现侵权就先投诉，对方收到通知立刻删链接改数据，你连证据都拿不到。固定证据永远排在第一步。

第二步：管辖选择（10 分钟）

连接点可用性说明
被告住所地可用需先通过平台披露获取主体信息
侵权行为实施地（发货地 · 深圳水贝）可用且优先4 家店铺均从水贝发货，可在此起诉
侵权结果发生地谨慎网络收货地作为管辖依据存在争议，不宜作为唯一依据
多被告建议将 4 家店铺运营主体及可能的制造者列为共同被告，夯实管辖与连带责任

第三步：证据链五层设计（30 分钟）

层次要证明什么证据工具时点
① 主体谁在卖平台店铺主体信息、工商登记、发货地址、客服与收款账户平台披露 / 公证 / 工商查询D1–D5
② 行为卖了什么、是否相同或近似商品详情页、实物购买、外观比对表、商标比对表公证购买（含收货封存）D3–D10
③ 规模卖了多少、卖了多久页面销量、评价数量与时间分布、历史快照公证 + 时间戳 + 第三方数据D1–D10
④ 获利赚了多少平台后台数据（需调取）、进货价与售价差额、行业利润率申请责令提交 + 调查令 + 酌定举证阶段
⑤ 主观恶意是否明知、是否重复律师函与送达记录、平台处罚记录、换店重开时间线、亲属关系公证书 + 平台投诉记录 + 工商关联查询全程
第⑤层是惩罚性赔偿的入口，必须在起诉前完成。 律师函不是可选项——它是"故意"的核心证据。如果还没发，今天就去发，并做公证送达。

第四步：主体关联证据（15 分钟）

关联类型收集方式
发货地址多笔订单的快递单据、物流信息，比对发货地址与联系人
收款账户不同店铺订单的收款方 / 提现账户（需平台或法院调取）
客服信息客服手机号、微信号、客服话术的一致性
进货渠道上游供应商证言、物流单据、包装与吊牌的一致性
人员关系工商信息中的股东 / 法定代表人 / 联络人重合；亲属关系线索
时间线老店被处罚关闭日 vs 新店开设日的衔接
商品一致性商品图、详情页文案、价格策略的高度一致
"换店重开"的证明公式：老店处罚时间 + 新店开设时间 + 主体关联（亲属 / 同一手机号 / 同一收款账户）+ 商品高度一致 = 重复侵权 + 恶意。这四组证据凑齐，惩罚性赔偿就有了骨架。

第五步：举证妨碍预埋（10 分钟）

要点写法
时点起诉状中即提出，或在举证期限内提交书面申请，不要等到庭审
内容具体化「请求责令被告提交自 20XX 年 X 月至 20XX 年 X 月，涉案 4 家店铺的销售台账、进货凭证、财务账簿及对应银行流水」
说明已尽力举证列明原告已自行收集的材料（公证书、时间戳、页面销量）
说明不可获得性后台数据仅平台与商家掌握，原告无法自行取得
提示法律后果明确引用举证妨碍条款，请求按原告主张确定赔偿数额

第六步：保全决策（10 分钟）

支持申请诉前行为保全反对 / 需谨慎
双十一销售窗口具有强烈季节性，错过不可逆若权利基础为未经实质审查的外观设计，存在被无效风险
侵权持续 8 个月且规模大（月销 2,800 件）保全范围过宽可能被驳回或部分驳回
已有 2 次平台处罚后换店重开，重复侵权明显需提供担保，占用资金
下架链接对被申请人的影响可量化、可控若败诉或被无效，面临反索赔
建议：先做专利权 / 商标权稳定性评估（外观专利做检索或评价报告），若稳定性良好则申请，且请求范围限定到 4 家店铺的涉案商品链接，不扩大到被告其他业务。担保优先选择保险保单或保函，减少资金占用。

第七步：取证 SOP（今日产出物）

步动作工具时限责任人
1全量页面固定（4 店详情页 + 店铺页 + 销量）时间戳（即时）+ 公证（3 日内）D1法务
2查询店铺主体与工商关联平台披露 + 国家企业信用信息公示系统D2法务
3公证购买 4 店商品并收货封存公证处D3–D10法务 + 公证处
4制作外观与商标比对表内部D10法务 + 设计
5发出律师函并公证送达EMS + 公证 / 电子存证D10法务
6整理处罚记录与换店时间线平台记录 + 工商D10法务
7平台知识产权投诉抖音 / 拼多多平台入口D12法务
8稳定性评估（外观检索 / 商标状态核验）代理所D12法务 + 代理所
9起诉 + 责令提交账簿申请 + 保全申请法院D15–D20代理律师
10评估刑事立案可能按累计销售额证据齐备后法务 + 律师

自检清单

  • 取证是否排在投诉之前？
  • 五层证据链是否每一层都有对应工具与时点？
  • 主体关联证据是否达到五类以上？
  • 律师函是否已发出并做了送达固定？
  • 举证妨碍申请是否写明了具体材料与时间段？
  • 保全申请前是否做了权利稳定性评估？
  • 所有期限、条号是否标注了「待核实」？
