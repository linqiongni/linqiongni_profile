三条路径：行政 / 民事 / 刑事的启动与衔接

程序与证据地图
◆
同一个侵权行为，你可以走三条不同的路：找市场监管局（快、能没收、不判赔偿）、找法院（慢、能赔钱）、找公安（最狠、门槛最高）。三条路不是三选一，而是可以组合出拳——真正的打法是「行政先封货 → 民事索赔 → 够罪了移送」。
业务落点业务落点：拿到侵权线索的第一件事不是写起诉状，而是判断"这案子走哪条路最划算"。

最容易被忽略的一条：行政路径不能判赔偿，只能调解。所以行政查处的主要价值是「快速止损 + 拿到对方的生产销售数据 + 形成官方认定」，为后续民事索赔铺路——而不是"让政府帮我拿钱"。

二、行政路径：快、狠、但不管钱

以商标侵权为例，《商标法》第 60 条规定：商标注册人或者利害关系人可以请求工商行政管理部门处理。工商行政管理部门处理时，认定侵权行为成立的，责令立即停止侵权行为，没收、销毁侵权商品和主要用于制造侵权商品、伪造注册商标标识的工具；违法经营额五万元以上的，可以处违法经营额五倍以下的罚款，没有违法经营额或者违法经营额不足五万元的，可以处二十五万元以下的罚款。⚠ 具体数额以现行条文核对。

要点说明实务提示
调解赔偿行政部门可以就赔偿数额进行调解；调解不成的，当事人可另行提起民事诉讼不要指望在行政程序里拿到赔偿，但可以把调解当作谈判筹码
证据转化行政机关在查处中取得的现场检查笔录、扣押清单、询问笔录，在后续民事诉讼中是极有力的证据这是行政路径的隐藏价值——借用公权力取证
双轨并行行政查处与民事诉讼可以同时推进注意同一事实不重复受罚，但赔偿另计
救济当事人对行政处理决定不服的，可在法定期限内提起行政诉讼被投诉方常用"反诉行政机关"拖延时间

专利路径：《专利法》第 65 条规定，未经专利权人许可实施其专利引起纠纷的，由当事人协商解决；不愿协商或协商不成的，专利权人或者利害关系人可以向人民法院起诉，也可以请求管理专利工作的部门处理。管理专利工作的部门处理时，认定侵权行为成立的，可以责令侵权人立即停止侵权行为；当事人不服的，可以自收到处理通知之日起十五日内依照行政诉讼法向人民法院起诉。⚠ 条号与期限待核实。

三、刑事路径：门槛与威慑

罪名刑法条核心行为立案门槛（⚠ 待核实）
假冒注册商标罪第 213 条未经注册商标所有人许可，在同一种商品上使用与其注册商标相同的商标非法经营数额 / 违法所得数额达到司法解释标准
销售假冒注册商标的商品罪第 214 条销售明知是假冒注册商标的商品违法所得数额较大或有其他严重情节
非法制造、销售非法制造的注册商标标识罪第 215 条伪造、擅自制造他人注册商标标识或销售此类标识数量或数额达到标准
侵犯著作权罪第 217 条未经著作权人许可复制发行其作品等违法所得数额较大或有其他严重情节
销售侵权复制品罪第 218 条以营利为目的销售明知是侵权复制品违法所得数额巨大
侵犯商业秘密罪第 219 条以不正当手段获取、披露、使用或允许他人使用商业秘密给权利人造成重大损失
⚠ 待核实 / 提示
⚠ 各罪的立案追诉标准由司法解释规定，且历次修订数值有变化。正式引用前必须以现行有效的立案追诉标准（二）及相关司法解释核对。本计划第 24 周会系统展开。
刑事路径的最大价值是"查账"：公安机关立案后可以调取银行账户、生产台账、物流数据——这些是民事诉讼中你几乎永远拿不到的证据。所以常见打法是先行政或民事固定初步证据，达到门槛后报案，用刑事手段拿到财务数据，再回头支撑民事赔偿。

四、行刑衔接与民刑关系

问题实务口径
行政机关发现涉嫌犯罪怎么办应当依法移送公安机关（行政执法机关移送涉嫌犯罪案件的规定）
先刑后民还是民刑并行民事诉讼法规定本案必须以另一案的审理结果为依据时中止；知识产权案件中，若民事案件的基本事实需以刑事案件认定为前提，可能中止；但多数情形下可以并行推进
刑事判决认定无罪，民事还能认定侵权吗证明标准不同，刑事无罪不等于民事不侵权
刑事已追赃，还能民事索赔吗已追缴退赔的部分不再重复赔偿，未覆盖部分可另行主张
⚠ 待核实 / 提示
⚠ "先刑后民"并非法定原则，而是实践中的处理方式。是否中止民事案件，取决于民事案件是否必须以刑事案件结果为依据。不要轻信对方"已经刑事立案所以民事必须中止"的主张。

五、六类场景的路径选择

场景首选组合打法理由
电商仿款（多店铺、规模化）平台投诉 + 民事诉讼累计销量达标后报案平台投诉最快下架；民事索赔；规模化后刑事威慑
线下假货（批发市场档口）行政查处形成官方认定后民事索赔行政能当场查封扣押，效率最高
代工厂私自加单外流民事诉讼 + 诉前证据保全商业秘密达到损失门槛时报案账簿在对方手里，必须保全；加单规模大时够罪
前员工带走客户名单民事诉讼（商业秘密）证据充分时报案先固定设备与邮件；达到损失标准走刑事
包装标识印制厂行政查处 + 刑事—第 215 条专门针对标识，印制厂是典型打击对象
展会仿品展会投诉 + 诉前证据保全后续行政或民事展期只有几天，速度第一
组合打法的核心是"用最快的手段止损，用最重的手段施压，用最完整的证据索赔"。 一次成功的维权往往是三条路径的接力，而不是单打独斗。
