一、取证工具选型表

方式成本时长证据效力适用场景典型瑕疵
公证（线下购买 / 现场）高数天最强（公文书证，推定真实）线下门店购买、展会现场、实物封存跨区域执业、未做清洁性检查
公证（网页 / 录屏）中高数天强电商详情页、店铺首页、销量展示未全程录像、未显示网址与时间
可信时间戳低即时较强（需可验证）网页、图片、文档、设计稿未保留原始文件与验证路径
区块链存证低即时较强（需平台与过程可核验）网页、图片、视频、文件平台资质存疑、无法当庭验证
自行截图 / 录屏无即时弱（易被质疑真实性）辅助材料、内部线索无网址、无时间、可编辑性强
成本与效力的权衡原则：核心侵权事实（"他确实在卖"）用公证；辅助事实与批量证据用时间戳或区块链；内部线索与排查阶段用截图。一个案件的取证预算，通常 60% 花在最关键的一两次公证上。

二、公证购买：标准流程与七个要点

步骤要点易错点
① 申请向有管辖权的公证处提出申请，说明公证事项与用途跨区域执业问题（⚠ 公证执业区域规定待核实）
② 设备使用公证处提供的设备进行网络操作用自己的电脑可能被质疑可被篡改
③ 清洁性检查清除浏览器缓存、Cookie、历史记录；检查 hosts 文件；必要时重装系统或换机漏做清洁性是最常见的致命瑕疵
④ 全程录像从开机、联网、输入网址到下单、支付、确认订单全程连续录制录制中断、跳转剪辑
⑤ 信息固定显示完整网址、当前日期时间、店铺主体信息、商品标题与详情页只截商品图不截网址
⑥ 收货与封存收货过程一并公证，实物当场封存并拍照快递被代收、未当场拆封公证
⑦ 出证核对公证书内容与附件（截图、录像光盘、实物照片）附件与正文不一致
收货环节的价值被严重低估：收货公证能证明"这个东西确实从这个卖家寄出、实物长这样"，把线上主体与线下实物连接起来。只做网页不做收货，被告可以辩称"发的货与网页不一致"。

三、时间戳与区块链存证

可信时间戳区块链存证
原理由权威时间戳服务机构对文件哈希值签发时间凭证（RFC 3161）将文件哈希写入区块链，利用分布式账本不可篡改特性固定时间与内容
成本低（数十元级别，⚠ 以服务机构现行收费为准）低
验证通过签发机构官网验证证书与哈希值通过链上浏览器或平台验证
司法采信多数法院认可，要求可当庭验证需证明平台资质、存证过程规范、哈希可比对（⚠ 具体要件以现行司法解释与指引核对）
适用设计稿定稿、网页快照、文件版本固定批量网页、视频、图片固定
⚠ 待核实 / 提示
⚠ 司法实践对区块链存证的审查通常包括：存证平台的资质与中立性、存证过程的规范性与可回溯、哈希值的一致性验证、是否有其他证据佐证。仅有存证证书而无验证路径的，可能被质疑。

四、电子数据的审查规则

《最高人民法院关于民事诉讼证据的若干规定》对电子数据的真实性审查与推定真实作了规定。法院审查电子数据时通常综合考虑：

审查因素具体内容
生成、存储、传输所依赖的计算机系统的硬件、软件环境是否完整可靠是否处于正常运行状态、是否具备防止出错的监测与核查手段
电子数据的生成主体与时间是否明确是否具备有效的防止篡改措施
保存、传输、提取的方法是否可靠提取主体是否适当、是否由中立第三方保存
是否经过公证或由中立第三方记录保存由中立第三方平台提供或确认的，真实性更易被认可
⚠ 待核实 / 提示
⚠ 上述审查因素的条号与表述请以现行《民事诉讼证据规定》核对。

五、分类型操作要点

证据类型推荐工具操作要点
电商网页（详情页、店铺页）公证或时间戳完整网址 + 时间 + 店铺主体 + 商品标题 + 销量 + 全屏滚动录像
直播公证录屏 + 时间戳完整录制（含开播前进入路径）、记录主播 ID、商品链接、口述内容、销量变化
短视频时间戳 + 公证保存原始视频文件与 URL，不要只截封面
微信聊天记录公证（手机操作全程录像）+ 原始载体必须出示原始手机，展示登录状态、对方信息、完整对话；注意隐私与合法性边界
朋友圈 / 小红书 / 微博时间戳或公证含发布时间、账号主体、完整互动区
设计稿与源文件定稿即时间戳 + 保留分层源文件保留 PSD / AI / 3D 原始文件，只交导出件等于放弃最强证据
销售数据平台后台导出 + 公证 / 第三方数据自行导出的数据需公证固定，否则易被质疑
原始载体是电子数据的命门。 微信聊天记录、邮件、后台数据，法院几乎都会要求出示原始载体（手机、电脑）。截图打印件在任何时候都不够——这点是新手最容易犯的错。

六、五种致命取证瑕疵

  1. 未做清洁性检查——被告抗辩"你访问的可能是自己伪造的页面"；
  2. 截图无网址与时间——无法证明来自哪个网站、什么时间；
  3. 录屏中断或剪辑——连续性被破坏，真实性受质疑；
  4. 公证处跨区域执业——可能被质疑公证程序不合法（⚠ 以现行公证执业区域规定核对）；
  5. 未保存原始载体——电子数据无法核对原件。
