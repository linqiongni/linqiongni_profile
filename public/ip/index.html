一、为什么用「一条故事线」讲知识产权

知识产权的痛点从来不是"查不到条文"，而是四类权利是散的，业务是连的。单独看商标显著性，你背得下来；但真到了栖梧珠宝要推一款联名系列，你需要同时调取：这款式的著作权归谁、联名方的商标授权范围、代工厂会不会把图纸泄给竞争对手、电商上的仿店怎么关、代言人的照片能不能直接用在详情页。这五个知识点分散在商标、专利、著作权、商业秘密、不正当竞争五个不同的法律规定里，在现实里却是同一款产品的一天。

所以这套内容用一个品牌从一间门店到出海的完整生命周期串起来。每一站都有四件固定的东西：

① 剧情STORY
栖梧珠宝在这一步发生了什么，遇到什么坑，法务接到什么活儿。让你先有场景，再谈规则。
② 术语TERMS
中英对照 + 定义 + 它在这笔交易里解决什么问题。不是词典，是"会议室里这个词从谁嘴里说出来、他想干什么"。
③ 比方ANALOGY
大白话打比方。商标好比给产品起的"受保护的名字"——注册了，别人就不能随便叫；没注册，你养大的名字可能是给对手养的。
④ 结构STRUCTURE
权利地图 / 流程图 / 条款对照表。可以直接照着画给老板看。
⑤ 案例CASE
同一场景的两种写法 + 后果。左侧"这么签会出事"，右侧"这么签能救回来"。
⑥ 清单CHECKLIST
可直接落地的自检表 / 申请清单 / 维权清单，附法源索引。
⑦ 对话DIALOGUE
每站 6–8 组「法务对话」：老板只说大白话，法务先用大白话答、再翻成条款；每句法律腔后面紧跟一段金色底的「就好比」。

二、主线时间轴：栖梧珠宝的 IP 十年

记住这条时间轴，后面九站全部挂在上面。它是这本书的目录。
另有一站附录：第 9 站「行业专精 + 案例库」，用真实案件给前八站做注脚。

Y1 · 一间门店
林栖在铜锣湾开「栖梧珠宝」首店，自己画款式、自己起名。商标没注册、图纸存电脑。权利裸奔期。→ 第 1、2 站
Y2 · 多品类 + 电商
上线天猫 / 小程序，款式被抄、电商出现仿店。第一次意识到"名字和款式都要护"。→ 第 2、4、6、9 站
Y3 · 代工体系
把生产外包给深圳代工厂，图纸外发。泄密风险第一次爆发；同时研发了一款"可调节链扣"想申请专利。→ 第 3、5 站
Y4 · 联名 + 代言
请明星代言、做 IP 联名。代言照片版权、联名方商标授权范围、联名款著作权归属三件事一起砸过来。→ 第 2、4、5 站
Y5 · 商标被抢注
拓展内地市场时发现"栖梧"在内地被代理商抢先注册。陷入无效宣告 + 异议拉锯。→ 第 2、7 站
Y6 · 出海
进东南亚、欧洲。马德里商标国际注册、PCT 专利、海关备案一起排期。→ 第 2、3、8 站
Y7+ · 维权常态化
建立"权利地图 + 监测 + 函告 + 诉讼"的常态化维权机制，把 IP 做成可计量的资产。→ 第 6、7、8、9 站

4.2 每一站的固定收尾动作

  • 把该站的 Checklist 拷出来，对着自己手上正在做的项目勾一遍。
  • 把 条款 / 申请模板 改成自己公司的版本，存进自己的模板库——模板只有改成自己写的才算学会。
  • 把 法源栏 里的规则打开一次原文，确认没有被修订。
  • 问自己：如果栖梧珠宝这一步换成我现在的公司，会有什么不同？把这个答案写进自己的 MEMORY。
