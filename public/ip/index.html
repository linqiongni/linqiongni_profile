一、为什么用「一条故事线」讲知识产权

知识产权的痛点从来不是"查不到条文"，而是四类权利是散的，业务是连的。单独看商标显著性，你背得下来；但真到了栖梧珠宝要推一款联名系列，你需要同时调取：这款式的著作权归谁、联名方的商标授权范围、代工厂会不会把图纸泄给竞争对手、电商上的仿店怎么关、代言人的照片能不能直接用在详情页。这五个知识点分散在商标、专利、著作权、商业秘密、不正当竞争五个不同的法律规定里，在现实里却是同一款产品的一天。

所以这套内容用一个品牌从一间门店到出海的完整生命周期串起来。每一站都有四件固定的东西：

① 剧情STORY
栖梧珠宝在这一步发生了什么，遇到什么坑，法务接到什么活儿。让你先有场景，再谈规则。
② 术语TERMS
中英对照 + 定义 + 它在这笔交易里解决什么问题。不是词典，是"会议室里这个词从谁嘴里说出来、他想干什么"。
③ 比方ANALOGY
大白话打比方。商标好比给产品起的"受保护的名字"——注册了，别人就不能随便叫；没注册，你养大的名字可能是给对手养的。
④ 结构STRUCTURE
权利地图 / 流程图 / 条款对照表。可以直接照着画给老板看。
⑤ 案例CASE
同一场景的两种写法 + 后果。左侧"这么签会出事"，右侧"这么签能救回来"。
⑥ 清单CHECKLIST
可直接落地的自检表 / 申请清单 / 维权清单，附法源索引。
⑦ 对话DIALOGUE
每站 6–8 组「法务对话」：老板只说大白话，法务先用大白话答、再翻成条款；每句法律腔后面紧跟一段金色底的「就好比」。

六、知识产权的"权能"：它凭什么值钱

前面说"四类权利"，但老板真正要问的是：拿到这些权利，公司能干什么、能省什么、能赚什么？这一节把"权能"翻译成资产负债表能看懂的话。

禁止权Exclusive
别人未经许可不能用——这是 IP 的"牙齿"，也是维权的依据。没有它，注册证只是张奖状。
许可权License
授权别人用，收许可费（联营、IP 授权、代工贴牌都靠它）。栖梧做联名，本质是把商标/著作权许可给联名方。
转让 / 质押Monetize
可卖、可押给银行换贷款。已确权的商标/专利/软著是"有房产证的资产"，银行才认。
作价出资Invest
可评估后作价入股（公司法第 48 条）。很多初创公司用 IP 代替现金出资，撬动股权。
给老板的一句话

IP 不是"法务的麻烦"，是能上账、能抵押、能授权的资产。越早确权、越全布局，这块的"资产水位"越高；等到被抄才补，补的是窟窿不是资产。

七、知识产权官司的真相：成本、周期与举证门槛

很多人对"维权"有两种错觉：要么觉得"注册了就能一键封杀仿店"，要么觉得"打官司一定倾家荡产"。这一节把真实预期摆出来，免得你要么轻敌要么被吓住。

维度真实情况（参考）老板要有的心理准备
平台投诉（最快）持注册证投诉，数日–数周可下架快但只下架不赔钱，对方常换店重来
行政投诉市场监管局查处，数月能罚款/没收，赔偿仍靠民事
民事诉讼一审常 6–18 个月，技术类更久周期长、要垫律师费/公证费
举证门槛权属 + 侵权 + 赔偿额都要你证"算不清损失"多走法定赔偿（上限 500 万）
刑事门槛高（情节严重才入罪）适合规模化恶意仿冒，需公安立案
打个比方 · 维权预期

维权像抓小偷：平台投诉是"把人请出商场"（快但不罚）；民事是"上法庭要赔偿"（慢但要证据和律师费）；刑事是"报警抓人"（只管情节严重的大案）。最划算的是"平时装好监控（留存证、监测）+ 小偷一出现就请出去"，别等丢了大件才想起装锁。

别指望"一键封杀"

注册证不是"尚方宝剑"。它能让你有资格去维权，但每一次维权都要你出证据、出时间、出费用。所以前面九站反复讲的"留存证、建台账、早注册"，本质是把"维权成本"在事前摊薄——事前做一分，事后省十分。
