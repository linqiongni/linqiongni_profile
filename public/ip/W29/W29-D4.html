培训·内控·风险台账：制度要嵌进研发和采购的血管里

企业 IP 管理制度
◆
IP 制度写成一本手册锁抽屉里，等于「买了灭火器从不演练」——真着火没人会用。制度要嵌进研发、采购、营销的日常流程，才算活的制度。
业务落点业务落点：搭建分层培训体系 + 把 IP 控制点嵌进研发/采购/营销三环节 + 建风险台账红黄绿灯，让制度跑起来。

一、分层培训体系

IP 制度落地的第一杠杆是培训。按岗位风险分层，避免「全员念一遍手册」走过场。

层级对象核心内容频次
全员所有员工IP 基本概念、保密红线、举报渠道年度
研发设计师/工程师职务发明、FTO 检索、专利申请、开源合规季度
采购/供应链采购/跟单代工厂保密、供应商 IP 条款、模具管控半年度
营销/电商市场/直播肖像授权、仿款排查、代言到期清理季度
管理层总监及以上IP 战略、危机应对、制度问责年度
铁律：培训要留痕（签到、课件、考试）。日后发生泄密或侵权，完整的培训记录是证明「已采取保密措施」「已尽管理义务」的关键证据。

二、内控嵌入三环节

环节关键控制点触发时机
研发立项 FTO 自由实施检索、专利申请节点、职务发明申报、开源协议审查立项/结项/申请前
采购供应商保密协议、代工厂 IP 条款、模具与 3D 文件物理隔离下单/打样/量产
营销素材授权审查、代言到期清理、仿款监测、平台投诉上新/投放/日常
珠宝实战：研发立项前不检索，可能撞别人外观专利（被动侵权）；采购不锁代工厂 3D 文件，款被私单外流；营销代言到期不清理，触肖像权。每个坑都有对应控制点。

三、风险台账与红黄绿灯

等级定义处置例子
红已发生或高概率重大风险立即处置+上报代工厂泄密、被诉侵权
黄隐患待整改限期整改+跟踪商标临撤三、年费临缴
绿可控常规常规维护已授权在缴专利
风险台账字段：风险项、等级、发现日、责任人、整改时限、跟踪状态、闭环证据。每月更新，红项 48 小时内上会。

四、审计·巡检·举报·问责

  • 审计：年度 IP 审计（台账核对、权属复核）+ 代工厂突击审计（查私单、模具外流）；
  • 巡检：门店陈列、电商页面、展会样品的 IP 合规巡检；
  • 举报：设独立匿名举报渠道，保密保护举报人；
  • 问责：泄密/侵权按制度梯度问责（警告→扣绩效→解除→追责），与保密/竞业制度衔接。
⚠ 待核实 / 提示
⚠ 待核实：代工厂突击审计中「私单」取证的合法边界（避免侵犯经营自由/非法取证），以及内控留痕作为民事抗辩证据的采信尺度，以现行法与判例为准。

五、双视角：内控的攻防价值

权利方：靠内控把侵权风险挡在流程前，台账与培训记录是自证善意的证据；被诉方：若已尽内控（已检索、已审查、已培训），可主张无主观过错、减轻赔偿甚至不赔（尤其著作/商标过失情形）。内控不是纸面，是免责筹码。

六、今日自测（答案内嵌）

Q1：研发立项阶段应嵌入什么 IP 控制动作？
参考答案立项做 FTO 自由实施检索（避免撞他人专利）、规划专利申请节点、申报职务发明、审查开源协议合规。控制点触发在立项/结项/申请前，责任人是研发负责人。
Q2：风险台账的「红黄绿灯」怎么分？举例。
参考答案红＝已发生或高概率重大（如代工厂泄密、被诉），立即处置上报；黄＝隐患待整改（如商标临撤三、年费临缴），限期整改；绿＝可控常规（如已授权在缴专利），常规维护。
Q3：代工厂审计为什么要「突击」？常规审计够吗？
参考答案不够。提前通知的常规审计可被应付（临时补记录、藏私单货）。突击才能发现真实的私单多打、模具外流、3D 文件拷贝。珠宝业泄密高发在代工厂，必须突击。
Q4：内控里的「举报与问责」怎么落地才有效？
参考答案独立匿名举报渠道 + 举报人保密保护 + 明确调查流程 + 梯度问责（警告/扣绩效/解除/追责），并与保密、竞业制度衔接。光有制度不问责，等于无制度。
