一、十三项全景：三大家族

家族权项（第 10 条）英文 / 缩写
复制传播类复制权、发行权、出租权、展览权、表演权、放映权、广播权、信息网络传播权Reproduction / Distribution / Rental / Exhibition / Performance / Screening / Broadcast / Info-Network
演绎类摄制权、改编权、翻译权、汇编权Filming / Adaptation / Translation / Compilation
其他应当由著作权人享有的其他权利Other Rights
记忆法：八传播 + 四演绎 + 一兜底 = 十三项。珠宝时尚企业最常用的是复制、发行、展览、信息网络传播、改编这五项。

二、高频五项精读

  • 复制权：以任何方式固定作品（做样品、印图册、截图、3D 打印）——最基础、最易被忽视；
  • 发行权：向公众提供作品原件或复制件（卖货、发样册），行权一次后「发行权用尽」；
  • 展览权：公开陈列美术/摄影/珠宝设计原作或复制件；
  • 信息网络传播权：使公众可在选定时间地点获得作品（上架电商、发社媒）——最易踩雷；
  • 改编权：在原作基础上创作出有独创性的新作品（二创、联名、改款）。
一句话避险：上架一张产品图到淘宝或小红书 = 行使复制权 + 信息网络传播权，必须取得作者（或权利链上游）授权，否则即侵权。

三、发行权用尽 vs 权利用尽

制度适用边界
著作权发行权用尽作品原件/合法复制件经权利人许可首次销售后，后续转售不侵权仅限发行权；出租权、信息网络传播权不穷竭
商标权利用尽正品经同意投入市场后转售不侵权平行进口、改动翻新另论
关键差异著作权「发行」用尽；「网络传播」不穷竭，二次上传仍需授权商标「使用」用尽

四、许可合同必须「点名权项」

笼统写「授权乙方使用著作权」极易生争议——到底给了复制还是信息网络传播？专有还是非专有？地域与期限？应逐项数清许可的权项，并写明专有/非专有、地域、期限、转授权。

珠宝行业典型坑：找插画师约稿只说「买断」，没写清是否含信息网络传播权与改编权，结果插画师在别处授权同图、或公司想做联名二创被卡。

五、今日自测（答案内嵌）

Q1：公司把一批合法购买的珠宝画册转卖给客户，是否侵犯发行权？
参考答案不侵犯。发行权用尽——合法复制件经权利人许可首次销售后，后续转售不侵权。但不得另行复制或网络上传。
Q2：员工把公司产品图上传到自己的小红书账号宣传，是否要授权？
参考答案要。上传公号/社媒属于行使信息网络传播权（兼复制权），须经公司（权利链上游）授权，否则侵权。
Q3：许可合同只写「授权使用著作权」会有什么风险？
参考答案范围不清——到底给了复制、发行还是信息网络传播？专有还是非专有？易生争议。应逐项数清权项并写清专有/非专有、地域、期限。
Q4：把竞品珠宝款式「借鉴改一改」当自己宣传图，侵犯什么权？
参考答案可能侵犯改编权与保护作品完整权（若原设计仍具独创性）；「参考灵感」不等于「合理使用」，改编需授权。
