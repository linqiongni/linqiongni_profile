一、作战总图：五步产出方案

  1. 盘点：拉资产台账——已注册 / 申请中的商标类目、专利、著作权登记，标出缺口
  2. 定类目：补核心类目（第 14 / 35 类）+ 关联类目（18 / 25 / 26 / 40 / 42），输出类目布局表
  3. 排专利：核心方案 + 外围变体矩阵，外观为主、结构补刀
  4. 建证据：著作权登记 + 时间戳 SOP 固化高价值设计
  5. 算预算 + 定 KPI：三年预算模型 + 代理所考核表 + 跨境通道决策

四、周末自测（答案内嵌）

Q1：三年路线图为啥第 1 年先打「核心类目 + 核心款」而不是全类狂注？
参考答案预算与撤三双重约束：全类注册维持成本高且多数类目三年不使用反成撤三靶子；第 1 年先占核心（第 14 / 35 类）+ 核心款外观，第 2 年随业务扩关联类、第 3 年转维持防守，节奏更稳更省。
Q2：跨境出海第一年该直接全球狂注吗？
参考答案不该。先国内申请锁优先权（商标 / 外观 6 个月、发明 12 个月），窗口内看市场再定进哪些国；主力市场用马德里 / 海牙 + 关键国单注双轨防中心打击，省下大量无谓涉外费。
Q3：预算模型「维权备用金」留多少合理？
参考答案实务常预留年度 IP 总支出的 10-15% 作为维权 / 监测备用金（⚠ 比例待核实，按企业风险敞口定）；用于电商监测、发函、行政 / 诉讼突发支出，避免遇事无钱。
Q4：这份方案交老板前，哪三处必须标 ⚠ 待核实？
参考答案① 所有官费 / 年费数字；② 马德里 / 海牙 / PCT 规费与中心打击细则；③ 代理所市场报价。三处都须以现行公示与比价核对后再定稿，不能拿结构示意当报价。
