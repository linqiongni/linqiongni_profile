著作权登记与创作证据留存

布局与申请策略

一、先客体：著作权保护「独创性表达」，不护「功能 / idea」

著作权保护的是具有独创性的表达（珠宝设计稿、款式图、宣发图、3D 模型），不保护思想、功能、实用方案（那归专利）。一件珠宝的「设计图纸」是美术 / 图形作品，「成品造型」若具艺术美感可主张美术作品，但纯功能结构走专利。先客体：确认你要保的是「表达」还是「技术方案」。

二、自动保护 vs 登记：登记值不值

维度未登记作品登记
权利产生创作完成即产生（自动保护）同左，登记不改变权利产生时点
举证需自证创作完成时间 + 权属，容易被推翻登记证书是初步证据（著作权法），降低举证难度
成本无官费较低 + 代理费（官费⚠ 待核实，以版权保护中心公示为准）
适用场景内部留痕充足、低风险高价值设计、将维权 / 许可 / 出海
实务结论：著作权登记不是权利产生的要件，但它是维权时最便宜的「举证捷径」。对高价值核心款式，登记 + 时间戳双保险；对海量日常款，至少做时间戳 / 区块链存证留痕即可。

三、创作证据「三件套」：让「我是原创」站得住

  • 底稿与过程稿：设计草图、3D 源文件、修改版本记录、研发日志，证明「创作完成时间」与「创作过程」
  • 时间戳 / 区块链存证：对最终稿做可信时间戳或区块链存证，固定「在先公开 / 完成」的时间点，成本低、效力被司法认可
  • 公开发表留痕：官网 / 展会 / 社媒首次发表的截图与链接，配合前面形成完整时间链
  • 登记证书：高价值作品另行作品登记，拿到官方初步证据
⚠ 待核实 / 提示
⚠ 待核实：可信时间戳、区块链存证的证据效力认定口径与各地法院接受度，以《著作权法》（2020 修正）及最高人民法院民事诉讼证据司法解释现行文本为准；登记官费以中国版权保护中心最新公示为准。

四、权属先理清：职务 / 委托 / 合作作品

珠宝企业大量设计由员工、freelancer、代工厂完成。职务作品（员工本职工作中创作）一般权属归公司；委托作品若无约定，权利归受托人——务必在委托 / 设计合同中写明「著作权归委托方（公司）」。代工厂交付的款式图，若合同没写归属，公司可能只拿到「使用权」而非著作权，被人拿去注册 / 再授权就被动。

反向视角（被诉方抗辩）：如果你是代工厂或被诉方，可攻击对方「权属链不完整」——委托合同未约定著作权归属、职务作品认定有争议、或对方无法证明创作完成时间，从而瓦解其「自有作品」主张。

五、今日自测（答案内嵌）

Q1：一款珠宝造型没做著作权登记，被别人抄去，还能主张著作权侵权吗？
参考答案能。著作权自创作完成即自动产生，登记不是要件。但你要自证权属与创作完成时间（底稿、时间戳、发表记录）。没登记 = 举证更重、更易被推翻。所以高价值款建议登记 + 时间戳双保险。
Q2：委托 freelancer 画的设计图，著作权归谁？
参考答案无约定归受托人（freelancer）。公司必须在其委托 / 设计合同中写明「委托作品，著作权归委托方（公司）所有」，否则公司只可能拿到使用权，无权以著作权人身份维权或再授权。
Q3：著作权登记证书的作用到底是什么？
参考答案是初步证据（著作权法），在诉讼中降低你的举证负担——推定登记载明的权利人、作品、创作完成时间。但它可被反证推翻（如对方证明更早创作），所以仍要配底稿 / 时间戳形成时间链。
Q4：珠宝「成品造型」能受著作权保护吗？和外观设计专利什么关系？
参考答案若造型具艺术美感、可独立于实用功能存在，可主张美术作品著作权；同时也可申请外观设计专利。两者并行不冲突（著作权自动产生、专利需授权），构成「设计稿著作权 + 成品外观专利 + 品牌商标」的组合拳（详见 W27 专项）。
