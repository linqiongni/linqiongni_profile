一、先看交易结构：资产收购 vs 股权收购

IP 怎么进合同，先取决于交易结构。股权收购是「买公司」，IP 随公司走、权属不变、但历史 liabilities（含 IP 侵权之债）一并承接；资产收购是「买具体的商标/专利」，须逐件转让并变更登记，未列明的资产不转移。结构选错，IP 可能根本没买进来。

实务口诀：股权收购买「壳」带资产也带债；资产收购买「件」，清单外一律不归你。并购 IP 条款的第一问是：我到底买的哪一种？

二、四类核心 IP 条款

条款作用珠宝/时尚落点
陈述与保证 (R&W)卖方保证权属清晰、有效、无瑕疵无侵权保证核心商标无质押、外观无抄袭第三方
赔偿 (Indemnity)违约/侵权由卖方赔商标被无效或第三方索赔，卖方补偿买方
交割前提先满足条件再付款解押、年费补缴、代工厂资产转回
价款调整/托管风险对应减价或 escrow质押未解扣减对价、留尾款担保

三、许可 vs 转让：别把「用」当「买」

  • 转让（Assignment）：权利整体移转，须登记（商标/专利）或交付（著作权），买方可再处分；
  • 许可（License）：仅授予使用权限，分独占/排他/普通（⚠ 商标法关于许可备案对抗效力的条号待核实），许可不改变权利人；
  • 珠宝代工场景：OEM/ODM 合同须明确「代工厂不得留存模具/版单、不得自行生产销售、背景知识产权归委托方、衍生成果归委托方」，否则代工厂可能反向主张权属。
代工合同最容易埋雷的一句：「模具由代工厂提供」——若未约定权属，模具及据此生产的能力可能留在代工厂手里，换厂即断供。务必约定模具与版单归委托方并交付。

四、反向视角：作为被收购方/许可方怎么防

  • 卖方视角：R&W 要加「知情的例外」「赔偿设上限与时限（tail）」，避免无限期兜底；许可方保留自身使用与改进权；
  • 被许可方（抗辩）：若许可方权属有瑕，可主张许可合同无效或减价，并要求披露全部负担与诉讼。

五、今日自测（答案内嵌）

Q1：股权收购和资产收购，对 IP 权属有什么不同影响？
参考答案股权收购 IP 随公司走、权属不变，但历史 IP 侵权之债一并承接；资产收购只转移清单列明的商标/专利，须逐件转让登记，未列明的不归买方。
Q2：并购合同里卖方的「陈述与保证」该保什么？
参考答案保证 IP 权属清晰、持续有效、无质押等负担、不侵犯第三方、无未决诉讼。这是买方追责与索赔的基石，缺失则发现问题无救济。
Q3：OEM 代工合同不写 IP 条款会怎样？
参考答案代工厂可能留存模具/版单、自行生产销售，甚至反向主张权属，导致品牌方换厂即断供或被诉。须明确模具版单归委托方、代工厂禁用与保密。
Q4：作为被收购方，R&W 怎么防被无限兜底？
参考答案加「仅就卖方知情范围」例外、设赔偿上限与尾端时限（如交割后 12-24 个月）、重大事项才触发，避免对未知历史问题无限担责。
