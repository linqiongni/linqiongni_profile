一、报告总骨架

  1. 封面与保密声明（限交易相关方使用，依 NDA）；
  2. 执行摘要：资产总览 + 总体可否交易 + 1-3 个阻断性风险；
  3. 尽调范围与方法：查了哪些客体、用了哪些官方渠道；
  4. 资产与权属链核验：逐件填权属来源（职务/委托/共有/继受）；
  5. 法律状态与负担：有效/失效/质押/许可；
  6. 风险分级表：高/中/低 + 影响 + 建议；
  7. 交割前提与条款建议：解押、补缴、赔偿、尾款托管。

二、风险分级表（可直接套用）

风险项等级影响买方动作
核心商标已质押高资产可能被查封解押作为交割前提/作价扣除
核心外观专利年费逾期高权利已终止限期补缴或作价扣除
设计师名下款式图未转公司中权属瑕疵补转+补签职务/委托合同
代工厂留存模具版单中断供/反向权属合同补 IP 条款+交付模具
电商店铺主体与商标不一致中无法过户先统一主体或重开店铺
宣传图字体未授权低潜在侵权替换/补授权
珠宝并购实战结论：把「高风险」两项（质押、年费逾期）钉死为交割前提，中风险列为卖方承诺解决事项并留尾款担保，低风险记入知悉清单。报告价值不在篇幅，在「可决策」。

三、卖方隐瞒的高频点 + 买方反制

  • 隐瞒质押/许可：官方检索比对清单即可发现，反制＝解押前不付款；
  • 隐瞒代工厂资产：查模具/版单实际持有与合同，反制＝交割前转回+赔偿承诺；
  • 隐瞒侵权素材：反向搜图+第三方权利查询，反制＝R&W 保证+侵权赔偿条款。

四、周末自测（答案内嵌）

Q1：一份能支撑决策的 IP 尽调报告，最少要有哪三块？
参考答案执行摘要（可否交易）、资产与权属链核验、风险分级表（高/中/低 + 建议）。缺任一块都只是资料汇编。
Q2：核心商标质押和核心专利年费逾期，处置上有什么共性？
参考答案都列为高风险并钉死为「交割前提」：前者先解押，后者限期补缴；未解决前不付款，否则买来带债或归零。
Q3：卖方隐瞒代工厂持有模具，买方怎么发现并反制？
参考答案查模具/版单实际归属与代工合同；发现后要求交割前转回公司、补签 IP 条款，并以赔偿条款+尾款托管兜底。
Q4：低风险项（如一张图字体未授权）报告里怎么处理？
参考答案记入知悉清单并要求限期替换/补授权即可，不阻断交易，但须留痕避免日后被诉时主张「明知」。
