IP 尽调与权属链
◆

一、什么是 IP 尽调：先有客体，再查权属，最后看负担

IP 尽调（IP Due Diligence，IP DD）是交易前对目标无形资产做的产权调查。它的逻辑顺序和买房一模一样：先看这套「房」法律认不认（客体），再看「房本」上写的是不是卖家（权属），最后查有没有抵押、查封、租赁（权利负担与瑕疵）。跳过任何一步，都可能买到「纠纷产权」。

实务口诀：先客体、后权属、再负担。没有客体清单的尽调是盲查，没有权属链的证据是空谈，没有负担核验的交易是埋雷。

客体（民法典第 123 条）珠宝/时尚典型资产应收集的核心文件
商标主商标、防御商标、海外注册注册证、续展、许可/质押备案、使用证据

三、尽调三问：有什么 / 是谁的 / 有没有瑕疵

  1. 第一问——有什么：穷尽目标全部 IP 资产，按上表客体分类列全，防止「藏在代工厂/设计师个人名下」的资产漏网；
  2. 第二问——是谁的：逐件追溯权属链（职务/委托/共有/继受），确认登记权人与实际权利人一致，重点查设计师、代工厂、前员工的权属约定；
  3. 第三问——有没有瑕疵与负担：查法律状态（有效/失效/被无效）、权利负担（质押/独占许可/冻结）、侵权与诉讼、权属争议。
珠宝行业最易漏的「隐性资产」：① 设计师个人名下却为公司实际使用的外观/著作权；② 代工厂掌握的模具与版单；③ 电商店铺账号（绑定主体与商标不一致，过户受限）。这三项是并购尽调的高频雷区。

四、可交付产出：《IP 尽调清单 v1》长什么样

  • 商标类：主商标及防御商标清单（含类目、注册号、有效期）、续展提醒、许可/质押备案证明、近三年使用证据；
  • 专利类：外观/实用新型/发明清单（申请日、授权日、年费状态）、无效与侵权诉讼；
  • 著作权类：设计图与宣传物料清单、登记情况、创作底稿与权属来源（委托/职务合同）；
  • 商业秘密类：保密制度文本、保密协议签署率、密点清单；
  • 其他：字号登记、域名、电商店铺/账号主体一致性、社交媒体矩阵权属。

⚠ 待核实：各类权利的具体法律状态查询渠道与周期（如商标中国商标网、专利国家知识产权局、著作权中国版权保护中心）的官方名称与查询口径，请以现行官方平台与《商标法》《专利法》《著作权法》文本为准，本清单仅提供结构框架。

五、今日自测（答案内嵌）

Q1：并购一家珠宝品牌，只看商标注册证就够了？
参考答案不够。注册证只回答「有没有、归谁」，还要查法律状态（有效/被无效）、权利负担（质押/许可）、使用证据（防撤三），以及著作权、外观专利、商业秘密、电商资产等其它客体，否则可能买到残缺产权。
Q2：设计师个人名下有一款为公司设计的外观设计专利，并购时该专利归谁？
参考答案关键看权属链：若是职务发明或公司委托且合同约定归公司，则实际权利人为公司，需办著录事项变更；若约定归设计师个人且无转让，则不在交易资产内，属于权属瑕疵，应在报告中标红。⚠ 职务发明具体条号以待核实为准。
Q3：电商店铺账号算不算 IP 资产，尽调要注意什么？
参考答案算。要核验店铺主体与绑定商标是否一致、能否过户、平台对转让的限制（如天猫/抖音店铺转让规则），否则「买下品牌却带不走店铺」是高频坑。
Q4：尽调一开始就要把全部资料发给买方吗？
参考答案不应裸奔。正式尽调前应签署 NDA（保密协议）并限定资料使用目的与范围，敏感商业秘密可分阶段、脱敏后披露，防止买方借尽调窃取信息。
