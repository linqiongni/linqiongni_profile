第 17 周 自测卷

IP 尽调与权属链　·　答案内嵌显示，无需点击展开
本周聚焦 IP 尽调范围与清单、权属链审查、官方检索与法律状态核验、风险分级与报告撰写、交易结构中的 IP 条款。每题答案直接附在题后，无需点击展开。
D1 · 自测
IP 尽调范围与清单
QD1-1并购一家珠宝品牌，只看商标注册证就够了？判断
参考答案不够。注册证只回答「有没有、归谁」，还要查法律状态（有效/被无效）、权利负担（质押/许可）、使用证据（防撤三），以及著作权、外观专利、商业秘密、电商资产等其它客体，否则可能买到残缺产权。
QD1-2尽调三问是什么？每一问对应要收集什么？简答
参考答案① 有什么——穷尽目标全部 IP 资产按客体分类列全；② 是谁的——逐件追溯权属链（职务/委托/共有/继受），确认登记与实际权利人一致；③ 有无瑕疵与负担——查法律状态、质押/许可、侵权诉讼。
QD1-3珠宝并购里最容易被漏掉的「隐性 IP 资产」有哪些？实务
参考答案① 设计师个人名下却为公司实际使用的外观/著作权；② 代工厂掌握的模具与版单；③ 电商店铺账号（主体与商标不一致、过户受限）。这三项是高频雷区。
D2 · 自测
权属链审查
QD2-1公司外包插画师做了一张宣传海报，没签合同约定著作权，这张图的著作权归谁？判断
参考答案归插画师（受托人）。委托作品无约定或约定不明，著作权归受托人。教训：所有外部创作必须签《委托创作合同》明确「著作权归委托方」并附底稿交付。⚠ 条号以现行《著作权法》为准。
QD2-2职务作品、委托作品、法人作品三者在权利归属上有何不同？简答
参考答案职务作品一般归作者、单位仅在业务范围内优先使用（特定类型单位享除署名外权利）；委托作品有约定从约定、无约定归受托人；法人作品由法人主持、代表法人意志并承担责任，法人视为作者、整体归法人。⚠ 具体条号与款项以待核实为准。
QD2-3并购方发现目标一件核心专利是两人共有，会影响收购吗？实务
参考答案会。共有专利的重大处分（转让、独占许可、质押）通常需全体共有人同意；若缺一人授权，交易无法干净交割，应列为中/高风险并要求卖方先取得全体同意或分割。
D3 · 自测
官方检索与法律状态核验
QD3-1核心商标已质押给银行，能直接干净买下品牌吗？判断
参考答案不能。质押是权利负担，资产可能被查封或转让受限；须先解除质押（清偿或经质权人同意）或在交易中作价扣除并安排解押，否则买来带债。
QD3-2法律状态核验和权利负担核验，查的是两类不同的什么？简答
参考答案法律状态查权利存续（有效/失效/被无效/驳回/年费逾期/撤三）；权利负担查转让限制（质押登记、许可备案尤其是独占许可、冻结查封）。两者叠加才能判断资产「能不能干净过户」。⚠ 各官方渠道名称与期限以现行平台为准。
QD3-3商标到期前 2 个月并购交割要注意什么？实务
参考答案在交割前安排续展（期满前 12 个月内可办），并把续展作为交割前提；若已逾期进入 6 个月宽展，须立即补缴并加宽展费，否则资产归零。⚠ 具体期限以现行《商标法》为准。
D4 · 自测
风险识别与报告撰写
QD4-1风险分级只有「有/无」两档够不够？判断
参考答案不够。必须高/中/低（红黄绿）三档，分别对应阻断交易、价格调整或承诺解决、知悉即可，才能支撑决策与谈判。
QD4-2一份能支撑决策的 IP 尽调报告，标准结构是什么？简答
参考答案执行摘要（可否交易）→ 尽调范围与方法 → 主要发现（按资产/风险）→ 风险分级表（高/中/低+影响）→ 建议与交割前提（解押、补缴、赔偿、尾款托管）。
QD4-3尽调发现核心商标已质押，报告里应怎么写？实务
参考答案列为高风险，并建议将「解押」作为交割前提或在对价中作价扣除、安排解押后再过户；不能仅记作「知悉」。把法律动作和商业动作绑定。
D5 · 自测
交易结构中的 IP 条款
QD5-1股权收购和资产收购，对 IP 权属的影响一样吗？判断
参考答案不一样。股权收购 IP 随公司走、权属不变，但历史 IP 侵权之债一并承接；资产收购只转移清单列明的商标/专利，须逐件转让登记，未列明的不归买方。
QD5-2并购合同里卖方的「陈述与保证（R&W）」应当保证什么？简答
参考答案保证 IP 权属清晰、持续有效、无质押等负担、不侵犯第三方、无未决诉讼。这是买方追责与索赔的基石，缺失则发现问题无救济。
QD5-3OEM 代工合同不写 IP 条款会有什么后果？实务
参考答案代工厂可能留存模具/版单、自行生产销售甚至反向主张权属，导致品牌方换厂即断供或被诉。须明确模具版单归委托方、代工厂禁用与保密、衍生成果归委托方。
WEEKEND · 实战复盘
周末实战复盘 · 写一份 IP 尽调报告
QWE-1一份能支撑决策的 IP 尽调报告，最少要有哪三块？实务
参考答案执行摘要（可否交易）、资产与权属链核验、风险分级表（高/中/低 + 建议）。缺任一块都只是资料汇编。
QWE-2核心商标质押和核心专利年费逾期，处置上有什么共性？实务
参考答案都列为高风险并钉死为「交割前提」：前者先解押，后者限期补缴；未解决前不付款，否则买来带债或归零。
QWE-3卖方隐瞒代工厂持有模具，买方怎么发现并反制？实务
参考答案查模具/版单实际归属与代工合同；发现后要求交割前转回公司、补签 IP 条款，并以赔偿条款+尾款托管兜底。
本周核心产出物 · 参考标准答案
本周核心产出物参考标准答案

产出物一：IP 尽调报告模板（骨架）

  1. 封面与保密声明（依 NDA 限交易相关方使用）
  2. 执行摘要：资产总览 + 总体可否交易 + 1-3 个阻断性风险
  3. 尽调范围与方法：查了哪些客体、用了哪些官方渠道
  4. 资产与权属链核验：逐件填权属来源（职务/委托/共有/继受）
  5. 法律状态与负担：有效/失效/质押/许可
  6. 风险分级表：高/中/低 + 影响 + 建议
  7. 交割前提与条款建议：解押、补缴、赔偿、尾款托管

产出物二：IP 风险分级表（可直接套用）

风险项等级影响买方动作
核心商标已质押高资产可能被查封解押作为交割前提/作价扣除
核心外观专利年费逾期高权利已终止限期补缴或作价扣除
设计师名下款式图未转公司中权属瑕疵补转+补签职务/委托合同
代工厂留存模具版单中断供/反向权属合同补 IP 条款+交付模具
电商店铺主体与商标不一致中无法过户先统一主体或重开店铺
宣传图字体未授权低潜在侵权替换/补授权
实务结论：把高风险两项（质押、年费逾期）钉死为交割前提，中风险列为卖方承诺解决并留尾款担保，低风险记入知悉清单。报告价值不在篇幅，在「可决策」。⚠ 期限与条号以现行《商标法》《专利法》《著作权法》及官方平台为准。
