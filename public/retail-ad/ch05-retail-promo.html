CHAPTER 05 · STOREFRONT & PROMOTION REVIEW

零售终端宣传与促销合规审查

终端是合规链条的最后一米，也是最容易失控的一米——因为这里的物料和话术，是由几百家门店、几千名导购实时产生的，法务看不见。
本章要解决的核心问题：怎么让几百个终端在没有法务在场的情况下，也能产出合规的表达。答案是：模板化物料 + 会签过的口径 + 可执行的促销规则 + 抽查机制。

终端物料促销规则会员与储值导购话术户外与属地监管
终端合规的第一性原理：法务审不到的地方，要靠「模板」而不是靠「自觉」

总部审核能覆盖的是总部下发的物料。真正出事的是三类：门店自己打印的补充海报、导购自己加的一句话、店长自己定的临时规则。就好比连锁餐厅的食品安全不靠厨师自觉，靠标准配方、标准分量、标准流程——终端合规也一样，靠的是「只能从模板库里选」，而不是「大家注意一点」。

1.1 四类终端物料的合规与格式规范

【审核重点】明码标价的三条硬要求（依《明码标价和禁止价格欺诈规定》令第 56 号）
  1. 标示内容：销售商品应当标示品名、价格、计价单位。同一品牌或种类的商品，因颜色、形状、规格、产地、等级等特征不同而实行不同价格的，应当针对不同的价格分别标示品名，以示区别。
  2. 标示方式：应当以显著方式明码标价，明确标示价格所对应的商品或者服务；价格发生变动时应当及时调整相应标价；不得在标价之外加价出售商品或收取任何未予标明的费用。
  3. 赠品标示：赠送物品或者服务的，应当标示赠品的品名、数量；赠品标示价格或者价值的，应当标示赠品在同一经营场所的当前销售价格。

1.2 终端物料管控机制（防止「门店自制」失控）

  • 模板库制度：所有终端物料从公司模板库生成，模板已预置合规文案与格式；门店只能填空（价格、日期、门店名），不能改文案。
  • 自制物料审批：确需门店自制的，须经区域负责人 + 法务／合规岗审批，并留档。
  • 手写禁令：明确禁止在 POP、价签上手写补充价格、折扣、赠品信息；确需临时标注的，须使用公司统一的手写卡模板。
  • 巡检与抽查：区域巡店每月覆盖，按《终端物料审核表》逐项打勾；抽查结果进台账。
  • 撤除机制：每次活动结束后的物料撤除时限化，活动结束即触发撤除工单，未撤除计入区域考核。

二、促销活动规则

2.1 活动规则必备要素（缺一项即不完整）

  1. 活动名称与时间：起止日期、具体时段（如每日 10:00—12:00），含时区与平台时间口径。
  2. 参与条件：是否限会员、限新客、限品类、限门店、限渠道、是否需领券、是否可与其它优惠叠加。
  3. 优惠内容：折扣率、满减规则、赠品（品名、数量、价值）、返现方式与到账时间。
  4. 数量与库存：参与商品总数、限量数量、赠品总数、每店配额、售完即止的处理方式。
  5. 价格基准：如涉及价格比较，标明被比较价格的含义（原价／厂商建议零售价）与计算基准。
  6. 兑奖 / 兑换方式：抽奖规则、开奖时间、奖品名称与数量、兑奖方式与时限、税费承担。
  7. 退换货规则：参与活动商品退换后优惠如何返还、赠品是否需退回。
  8. 例外与限制：不适用商品清单、不适用门店清单、不可抗力或系统故障的处理。
  9. 争议处理渠道：客服电话／入口、处理时限、投诉路径。
  10. 规则公示位置：线下门店显著位置 + 线上一键可查，且不得置于折叠区或极小字号。
【红线条款】促销活动的四条禁止
  1. 禁止暗箱操作。公布的促销活动范围、规则与实际促销活动范围、规则不一致的，构成违法。规则必须与实际执行完全一致；系统配置须与公示规则逐项核对。
  2. 禁止「最终解释权归本公司所有」。该条款属于排除或者限制消费者权利、减轻或者免除经营者责任的格式条款，依法无效；且其本身会成为行政处罚与舆情的抓手。正确做法：删除该条，改为完整公示规则 + 明确争议处理渠道。
  3. 禁止虚构中奖与内定中奖。采用谎称有奖或故意让内定人员中奖的欺骗方式进行有奖销售，属违法；抽奖须有可核查的中奖机制与记录。
  4. 禁止超法定上限的有奖销售。抽奖式有奖销售的最高奖金额不得超过法定上限（原《反不正当竞争法》规定为五万元，2025 修订后条号与金额上限须以现行文本复核）；所设奖的种类、兑奖条件、奖金金额或者奖品等信息不明确影响兑奖的，同样违法。

三、会员与储值宣传

3.1 会员权益的如实表述

  • 权益内容须与实际一致：会员价、积分规则、生日礼、专属服务、优先购买权等，宣传的每一项权益都必须在系统中真实可兑现，并有对应的执行流程。
  • 禁止虚假承诺：不得宣传尚未上线的权益；不得以「即将上线」「敬请期待」作为已兑现权益宣传；权益缩减须提前告知。
  • 积分规则透明：积分获取比例、有效期、清零规则、折抵方式与上限，须完整公示；积分、礼券、兑换券、代金券折抵价款时不得拒不按约定折抵。
  • 等级与升降级规则：升级条件、保级条件、降级规则、有效期须明确；变更规则须提前公告并给予合理过渡期。
  • 个性化定价的合规：基于会员数据实行差别定价的，须注意不得在消费者不知情的情况下对同一商品或服务在同等交易条件下设置不同价格或收费标准（涉大数据杀熟规制）；算法与定价规则须留档备查。

3.2 储值 / 预付式消费的资金与宣传合规

【红线条款】储值业务的五条红线
  1. 书面合同：以收取预付款方式提供商品或者服务的，应当与消费者订立书面合同，约定商品或服务的具体内容、价款或费用、退还方式、违约责任等事项（《消费者权益保护法实施条例》对预付式消费有专门规定，条号以现行文本为准）。
  2. 不得虚假宣传诱导储值：不得以虚构的优惠、虚构的稀缺、虚构的限时诱导消费者大额充值；优惠力度须与实际可执行一致。
  3. 退款与余额规则透明：余额查询方式、退款条件与时限、是否可转让、是否设有效期、过期余额处理，须在合同中明确并公示。
  4. 禁止不公平格式条款：不得设置「概不退卡」「过期作废」「本公司有权单方变更规则」等排除或限制消费者权利的条款。
  5. 资金与信息合规：预收资金的存管、使用须符合相关规定；储值涉及的个人信息处理须符合个人信息保护相关法律；属地对单用途预付卡可能有备案、资金存管等专项要求，落地前须核查所在地规定。
储值宣传违规示例问题整改建议
「充 5000 送 2000，仅限今天」连续多天使用虚构限时；误导性饥饿营销标明真实活动起止；长期活动不使用「仅今天」
「充得越多省得越多」未标明赠送金额的使用限制弱化不利条件标明赠送金额的使用范围、有效期、可否叠加、可否退
卡面写「最终解释权归本公司所有」无效格式条款删除；附完整合同条款与争议渠道
「本卡一经售出概不退换」排除消费者权利删除；按法律规定设置退款规则并公示
会员卡过期后余额直接清零，未事先告知不公平条款 + 未履行告知义务到期前提醒；设置合理延期或余额处理方式并事先约定

四、终端人员话术

4.1 导购宣传口径规范

场景允许表述禁止表述
商品介绍 材质、成分、规格、工艺、产地、保养方式、证书与检测信息（须与商品知识卡一致） 未经验证的功效、技术效果；「最好」「顶级」；与竞品的优劣对比
价格说明 当前售价、可参与的优惠（须与系统一致）、赠品名称与数量 虚构原价；「全网最低」；口头承诺系统不支持的折扣
售后服务 与售后制度逐字一致的退换、维修、保养、清洗政策 「不满意随时退」（超出政策）；「终身免费」（无制度支撑的承诺）
库存与稀缺 系统显示的真实库存；限量款的真实编号数量 「只剩最后一件」（不实）；「以后买不到了」（无依据）
会员与储值 与公示规则一致的权益与条件 夸大权益；承诺未上线的服务；淡化限制条件
联名商品 「经授权使用〔IP 名称〕形象」，授权期内 「联合研发」「官方独家」等未经确认的表述；授权期外继续以此宣传
【红线条款】禁止承诺式销售

导购不得作出公司无法确保兑现的任何承诺。典型情形：

  • 承诺系统不支持的价格、折扣、赠品、赠品数量；
  • 承诺超出售后制度的退换、维修、保养、清洗；
  • 承诺确定的保值、升值、回收价格（涉贵金属、珠宝等品类的价格承诺风险尤高）；
  • 承诺未上市的商品、未确定的到货时间；
  • 承诺「包过」「保证」类无法客观衡量的结果。

就好比导购的一句话，就是公司的一份合同——消费者记的是导购说了什么，不是公司的制度写了什么。而举证责任在公司这边：你说没承诺过，拿录音、拿系统记录出来。

4.2 话术落地机制

  • 标准话术卡：每个品类一页纸，只允许照此说；话术卡随商品知识卡一同更新。
  • 禁说词卡：与直播一致，导购随身／柜台内张贴。
  • 培训与考核：入职培训 + 每季度复训 + 神秘顾客抽查；违规记分。
  • 可承诺清单：与直播同理，本店可承诺事项清单化；清单外须店长确认。
  • 争议留痕：门店录音、监控、系统记录按公司规定保存；客诉处理单归档。

5.2 属地口径差异的应对

【审核重点】全国统一物料 + 属地口径复核，缺一不可

户外广告、临时促销、外摆、预付卡备案等事项，各地城管、市场监管、商务部门的具体口径差异很大，同一套物料在一地合规、在另一地可能被要求整改。就好比同一道菜在不同城市的食品安全标准可能不同，连锁品牌必须有「总部标准菜谱 + 当地合规清单」两份文件。

  • 建立属地合规清单：按城市维护一张表，记录该地对户外广告、临时活动、外摆、预付卡的具体要求与对接部门。
  • 区域合规对接人：每个区域指定一名合规对接人，负责事前问询与事后整改。
  • 新城市首店流程：新城市开业前，由区域对接人出具《属地合规确认单》，法总部复核后方可启动物料制作。
  • 整改闭环：被要求整改的，24 小时内响应、限期完成、反馈凭证归档，并更新属地清单。

业务

这句话大家都在用，写在规则最后一句，就是为了万一有争议的时候我们说了算。你要我删掉，万一客人钻规则空子怎么办？

法务
你

这句话的问题不是「不好」，是它根本不产生你想要的效力。就好比你在合同里写「本合同的一切争议都由我说了算」——这句话写在纸上，但法官不会照它判，因为法律明确规定：排除或限制消费者权利、减轻免除经营者责任的格式条款，无效。也就是说，你写了它，争议发生时它帮不了你；但监管来检查时，它是一条现成的违法事实。净亏。

零售运营
业务

那客人钻空子怎么办？规则总有没写到的地方。

法务
你

靠规则写细，不靠一句话兜底。三件事：① 把规则写到没有空子——参与条件、时间、数量、库存、叠加规则、退换处理、例外清单，全部列明（就是本章 2.1 那十项）；② 留一个争议处理出口——写「活动咨询与投诉：〔客服电话〕，我们将在 〔N〕 个工作日内答复」，这句话既合法又实用；③ 对真正的边界情形预设处理口径——让客服手里有一张「边界情形处理表」，遇到规则没覆盖的情况按表处理，而不是靠店长自由发挥。就好比球场规则不是靠裁判说「最终解释权归裁判」，而是靠把越位、犯规、手球一条条写清楚——规则越细，争议越少；兜底条款越多，说明规则越粗。

给读者的大白话总结：「最终解释权」是一句听起来有用、实际无效、还会额外招罚的话。正确解法不是找一句更聪明的话替代，是把规则写到不需要解释。

对话 12展开：门店为了成交，导购口头承诺了系统不支持的折扣
区域经理
业务

客人跑了好几家店，我们导购为了留住这一单，口头说了「我给您申请个额外九折」。结果系统里没有这个折扣，客人来投诉了。这是导购的个人行为吧？跟公司没关系？

法务
你

有关系，而且关系很大。导购在工作时间、在经营场所、以公司名义作出的承诺，对消费者而言就是公司的承诺——这叫职务行为。就好比银行柜员跟你说「这笔业务我给您免手续费」，你事后发现被扣了钱，你去投诉的是银行，不是柜员个人。银行不能说「那是他个人行为」。所以现在的选择不是「认不认」，是「怎么收场代价最小」。

区域经理
业务

那怎么收场？

法务
你

三步：① 兑现或补偿。能按口头承诺执行的就执行（走特批流程）；不能执行的，给出等价替代并书面说明——履约成本远低于投诉升级后的成本。② 道歉并留痕。书面回复客人，说明处理结果与时限。③ 内部处理。导购记分、复训；但更重要的是区域经理也要记分——因为「导购敢随便承诺」说明该店的可承诺清单和授权边界没有传达到位。就好比员工给客户乱报价，罚员工之外，更要查为什么他手里没有一份「报价权限表」——没有表的授权，等于没有边界的授权。

区域经理
业务

那以后怎么防？总不能不让导购说话吧。

法务
你

不用不让说话，要把「能承诺什么」写清楚，把「不能承诺什么」变成红线：① 每店一张《可承诺清单》，写清价格权限、赠品权限、赠品数量上限、售后口径；② 清单外的承诺必须当场打电话给店长确认，店长确认即视为公司确认，并在系统中留一条备注；③ 话术卡 + 禁说词卡上柜台；④ 门店录音与系统备注作为留痕。就好比销售人员的报价权限表——给一万以内的自主权，超过要请示，既给了灵活度，也守住了边界。这样导购有空间成交，公司有边界可控。

给读者的大白话总结：导购的口头承诺 = 公司的合同。防的不是导购说话，是导购不知道边界。解法是「可承诺清单 + 店长即时确认 + 留痕」三件套。

七、本章终审 Checklist

  • 终端物料是否全部来自模板库？门店自制的是否已审批留档？
  • 价签是否做到品名、价格、计价单位三要素齐全、货签对位、变动及时调整？
  • 是否存在手写补充价格、折扣、赠品信息？
  • 促销规则是否具备十项必备要素，并经市场、IT、供应链、客服、法务五方会签？
  • 公示文本与系统配置是否已逐项比对并签署《一致性确认单》？
  • 是否含「最终解释权归本公司所有」或其他无效格式条款？
  • 有奖销售的奖品种类、数量、开奖时间、兑奖方式是否已公示？最高奖金额是否超法定上限？
  • 赠品是否已标示品名、数量；标示价值的是否为同一经营场所当前销售价格？
  • 会员权益宣传是否与系统实际可兑现一致？积分与券的折抵是否按约定执行？
  • 储值业务是否有书面合同、退款与余额规则公示、无「概不退卡」类条款，并完成属地备案核查？
  • 导购话术卡、禁说词卡、可承诺清单是否到位并培训留痕？
  • 户外广告点位是否已办理审批／备案并取得凭证？临时促销与外摆是否已报备、未占用消防通道？
  • 新城市首店是否已完成《属地合规确认单》？
