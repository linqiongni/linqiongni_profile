CHAPTER 06 · CASE STUDIES & FREQUENT DISPUTES

案例实务与高频争议焦点

这一章不讲故事，讲「出事之后怎么办」和「下次怎么不再出事」。
十二类高频争议，每一类给出：争议焦点 → 判定思路 → 整改动作 → 话术改写 → 制度修补。就好比飞行事故调查的目的不是追责，是让下一架飞机不再犯同样的错——案例的价值在于转化为规则。

二、四个深度案例（展开可看完整处置过程）

案例 01展开：详情页一句「销量第一」引出的连锁反应
场景（脱敏构造）：某季度主推商品的电商详情页首屏主图标注「〔某细分品类〕销量第一」，数据来源为公司内部销售台账，统计范围为上市后三周、单一线上店铺。同期，同一句话被同步用于信息流投放素材与门店 POP。

争议焦点

  • 「第一」是否属于绝对化用语？——属于排名类表述，须有客观依据。
  • 内部台账能否作为依据？——可以作为销售数据来源，但须标明统计主体、口径、时间、范围，且范围不得小于省级行政区域或国家标准行业分类。
  • 「某细分品类」的自定义口径是否有效？——地域小于省级、行业小于国标分类、无对应国标行标的，不适用豁免。
  • 同一句话用于三个渠道，风险是否被放大？——是，投放渠道越多，可查证性要求越高，且各渠道均需标明出处。

判定思路

三步走：① 该表述是否指向商品——是；② 是否属于豁免情形——自我比较不适用（这是与外部市场的比较），国家标准分级不适用，时空顺序限定因范围过小而不适用；③ 是否有客观可核查依据——内部台账范围过小、口径自定义，不满足。结论：构成无法验证的证明材料，且属绝对化用语，双重风险。

整改动作（按顺序执行，全部留档）

  1. 即时下架：三个渠道的该表述同步撤除（含投放素材库与门店 POP 工单）。
  2. 改为客观陈述：见下方话术改写。
  3. 系统硬拦截：把「第一」「销量第一」「销冠」加入禁用词库，投放系统与设计模板同步更新。
  4. 举一反三排查：全渠道检索同类表述，一次性清理。
  5. 复盘入册：本案例进违规台账，并在季度培训中作为示例。

话术改写

原表述改写后说明
「〔细分品类〕销量第一」「自 〔上市日期〕 上市以来，累计销售 〔N〕 件（数据来源：公司销售台账，统计口径：〔线上店铺 / 全渠道〕，统计时间：〔起止日期〕）」用客观数值替代排名；来源、口径、时间齐全
「销量遥遥领先」「本季度销售额同比增长 〔N〕%（数据来源：公司财务台账）」同比为自己与自己比，可核查
「爆款冠军」「本季度门店试戴量最高的三款之一」（且须有数据支撑）「之一」降低绝对性；仍须数据支撑

转化为规则：本案例应固化为一条内部规则——「任何排名类表述，其统计范围不得小于省级行政区域，行业口径不得小于国家标准行业分类；不满足的一律改为客观数值表述。」

案例 02展开：大促划线价被批量投诉
场景（脱敏构造）：大促期间，多个商品页面显示划线价，划线价取自「吊牌价」。经核查，其中部分商品在过去七日内无成交记录，另有部分商品的实际成交价长期低于划线价。促销结束后收到批量投诉，指向「虚构原价」。

争议焦点

  • 吊牌价能否作为被比较价格？——不能当然等同。未标明被比较价格详细信息的，被比较价格应当不高于同一经营场所价格比较前七日内的最低成交价格；七日内没有交易的，应当不高于本次价格比较前最后一次交易价格。
  • 以厂商建议零售价作比较时如何标注？——应当明确标示被比较价格为厂商建议零售价，且价格变动时立即更新。
  • 长期低于划线价销售意味着什么？——意味着划线价从未真实成交过，属虚假折价减价。

判定思路

① 确认划线价性质（成交价还是建议价）；② 调取前七日成交记录；③ 无成交或成交价显著低于划线价的，构成虚假价格比较；④ 同时构成以虚假或引人误解的内容误导消费者。结论：构成价格欺诈情形，且属可通过交易记录直接查实的类型，抗辩空间很小。

整改动作

  1. 立即停止：涉事商品的划线价全部下撤，改为单独标示现价。
  2. 系统改造（根本解）：划线价字段由系统按「同一店铺前七日最低成交价」自动取数；无成交记录时不显示划线价；使用建议零售价的，带出「厂商建议零售价」字样并同步更新。
  3. 预警机制：促销开始前 〔7〕 日内价格上调的，系统自动预警并阻断活动发布。
  4. 客服口径：统一答复口径（说明已整改、已退款差额或提供补偿方案），并对已下单消费者主动告知处理方案。
  5. 留档：取数规则文档、系统上线记录、整改前后截图、投诉处理台账。

话术改写

原表述改写后说明
「原价 ¥1,999　现价 ¥399」「本场价格 ¥399」或「厂商建议零售价 ¥1,999　本场价格 ¥399」无成交记录时不作价格比较；用建议价须显著标明
「直降 1,600」仅在有真实成交支撑时使用，并标明「较 〔日期〕 前七日最低成交价 〔金额〕 降低 〔N〕 元」降幅须可核查
「限时五折」「〔起止时间〕 期间，价格为原价的 〔N〕 折（原价指本店前七日最低成交价 ¥〔金额〕）」把原价含义写清楚，不留解释空间

转化为规则：「划线价一律由系统取数，禁止人工填写；无真实成交记录的商品，不得展示划线价。」这一条做成系统默认值，比培训十次都管用。

案例 03展开：达人直播内容失控，公司被同案调查
场景（脱敏构造）：公司委托服务机构安排达人直播，公司提供商品知识卡，服务机构提供脚本。直播中达人超出脚本，作出功效性表述与「全网最低价」表述，并展示了未经审核的对比图。回放已被平台存档。事后收到监管问询。

争议焦点

  • 达人超脚本表述，公司是否担责？——是。公司作为广告主对广告内容真实性负责；若构成商业广告，相关主体按广告法承担相应责任；直播间运营者亦负有事前合规审核与纠错义务。
  • 服务机构（MCN）是否担责？——服务机构负有招募核验、培训提醒、日常管理、不得组织虚假交易与虚假评价等义务；未履行义务的依法承担相应责任。
  • 公司能否以「达人个人行为」抗辩？——难以成立。公司享有内容审核权而未有效行使、未安排现场纠错、未及时更正，均说明管理义务未落实。

判定思路

① 该直播内容是否构成商业广告——是；② 公司在其中的身份——广告主（若自播则同时是直播间运营者）；③ 责任分配——公司对外承担，对内依合同向服务机构与达人追偿；④ 减轻情节——是否建立了事前审核机制、是否当场更正、是否主动下架与配合调查，这些直接影响处理结果。

整改动作

  1. 即时处置：下架回放与切片；在相关页面发布澄清；已下单消费者按其诉求妥善处理。
  2. 合同补强：补入发布前审核权、违规修改与下架义务、配合调查义务、违约责任与追偿条款；删除任何「减轻或免除服务机构法定责任」的表述。
  3. 流程补强：达人场次纳入与自播相同的合规流程（脚本送审 + 提示卡 + 现场值守 + 回放抽检）。
  4. 证据留档：脚本、审核意见、机构确认记录、直播回放、值守记录、处置记录（保存期限按不少于三年掌握）。
  5. 合作方管理：将本次服务机构列入风险名单，评估是否继续合作。

话术改写（给达人的 brief 模板）

本场直播内容构成商业广告，请务必遵守以下要求： 一、必须做：① 直播页面显著位置持续标明「广告」，或口播开始时说明「以下为广告内容」；② 商品信息以《商品知识卡》为准，只说卡上有的内容；③ 价格、赠品、库存以系统实时数据为准，只读数不报数；④ 赠品与抽奖活动须完整说明规则（条件、数量、时间、兑奖方式）。 二、禁止做：① 不作功效、安全性断言，不使用医疗、保健、美容功效类用语；② 不使用「最、第一、顶级、全网最低、绝对、永不、永久」等表述；③ 不点名或影射其他经营者，不作优劣对比；④ 不虚构销量、库存、限时、限量；⑤ 不现场加码任何未经确认的承诺；⑥ 不展示未经审核的图片、对比图、检测报告。 三、说错了怎么办：发现口误请当场清晰更正（「刚才口误，正确的是……」），并在评论区置顶书面说明。 四、未通过公司审核的内容不得发布；已发布的违规内容须在 〔N〕 小时内修改或下架。

转化为规则：「达人场次 = 自播场次的合规标准，不接受降级管理。」并且合同条款中不得约定减轻或免除服务机构依法应承担的责任——这类约定不仅无效，还会暴露公司的管理缺陷。

案例 04展开：联名到期后库存继续销售，被权利人发函
场景（脱敏构造）：联名系列销售期届满，线上已下架，但两家门店的柜台仍有陈列与库存，且门店 POP 未撤除。授权方通过市场监测发现后发函，要求说明并要求按合同约定销毁库存。

争议焦点

  • 销售期届满后的陈列是否构成使用？——是，陈列与宣传均属使用行为。
  • 公司是否有权继续销售？——取决于合同是否约定清仓期；无约定即无权。
  • 已生产但未售出的库存如何处理？——按合同约定的处理方式（销毁 / 去元素 / 其他）；无约定时应与授权方协商并留存书面确认。
  • 门店侧未执行下架，是否影响责任认定？——不影响对外责任，公司对外仍须承担；内部依制度追责。

判定思路

① 核对授权文件的期限条款（生产期 / 销售期 / 宣传期）；② 核对清仓期约定；③ 盘点实际库存与在售渠道；④ 判定构成超期限使用（违约 + 侵权）；⑤ 评估赔偿范围（许可费、库存成本、权利人损失或侵权获利）。

整改动作

  1. 立即停止：涉事门店下架、撤除 POP 与陈列道具，出具《下架确认函》。
  2. 全渠道盘点：所有门店、经销渠道、线上、直播回放切片、达人内容同步核查，形成库存与物料清单。
  3. 依约处理库存：按合同约定的方式执行；销毁的安排见证并出具证明。
  4. 书面回应：向授权方说明原因、已采取的措施、后续防范机制，并争取书面确认不追究或达成和解。
  5. 机制修补：建立到期前 〔60〕 日预警 + 下架工单 + 区域签字确认三重机制；到期自动下架由系统执行。

转化为规则：联名项目的到期管理比签约管理更容易出问题。固化三条：① 到期前 60 日启动库存与物料预案；② 系统到期自动下架，不依赖人工；③ 区域撤除后须签字确认，未确认的计入考核。

三、被投诉 / 被查处后的处置路径

阶段时限动作责任人
T0 收悉收到当日登记入《合规事件台账》；冻结相关物料（下架或暂停投放）以防止扩大；成立临时处置小组合规岗
T1 事实核查〔24〕 小时内还原事实：物料原文、投放渠道与范围、持续时间、成交情况、审核记录、授权与证据文件合规岗 + 业务部门
T2 法律定性〔48〕 小时内判断：是否构成违法、可能适用的法条、可能的后果区间、有无减轻情节法务
T3 处置决策〔72〕 小时内确定处置方案：整改、下架、澄清、退款或补偿、主动报告；重大事项报管理层法务 + 管理层
T4 对外沟通按监管要求统一对外口径（唯一发言人）；配合调查；提交整改材料法务 + 公关
T5 消费者处理同步主动联系受影响消费者；给出退款、换货、补偿方案；客服口径统一客服 + 业务
T6 复盘入册结案后 〔10〕 个工作日内归因分析、修订规则与词库、系统硬拦截、培训；更新本指引相关章节法务 + 业务
减轻情节：这几件事做得好，结果会完全不同
  • 主动停止并改正——发现问题后立即下架、撤除，是最重要的减轻情节。
  • 主动消除或减轻危害后果——主动退款、补偿、联系消费者。
  • 完整的合规管理证据——审核记录、培训记录、制度文件、整改记录，能证明公司已尽管理义务，而非放任。
  • 首次违法且危害后果轻微并及时改正——依法可能不予处罚（具体以《行政处罚法》及市场监管总局裁量意见为准）。
  • 配合调查、如实陈述——不隐瞒、不销毁证据、不串供。销毁或伪造证据会把一个行政案件升级成更严重的问题。

四、职业打假与批量投诉的应对

情形识别应对
确实存在违法点 自查后确认物料确有极限词、虚假表述、价格问题 先改后谈：立即整改并留档；对已购买消费者按法律与政策处理；对索赔要求按法律标准回应，不接受无法律依据的高额「和解费」，但也不拖延合法诉求
存在瑕疵但非违法 表述不规范但不足以认定违法（如表述模糊但不误导） 主动优化表述；书面说明判断依据；对投诉按客服流程处理
滥用投诉 批量、模板化、重复提交；诉求以金钱为主要目的；对同一问题反复投诉 统一归口（法务 + 客服）处理；完整留痕每一次沟通；依法依规回应，不私下交易；必要时向平台与监管部门说明情况
敲诈勒索性质 以曝光、举报相要挟索要高额财物 保留全部证据（录音、聊天记录），依法报警或举报；不单独接触、不私下转账
【红线条款】处置过程中的三条禁止（内部纪律）
  1. 禁止伪造、篡改、销毁证据——包括删除投放记录、修改系统数据、补做审核文件。这会把行政风险升级为更严重的责任。
  2. 禁止未经法务审核的对外表态——含客服话术、门店解释、公关声明、社交媒体回复。
  3. 禁止私下与投诉人达成金钱和解——所有处置方案须经法务审核并留档，避免形成「可被反复利用」的先例。

五、法务对话：被查之后，业务的第一反应通常是错的

对话 13展开：「先把物料撤了，别留证据」——这句话为什么最危险
市场部
业务

监管来问那句「销量第一」了。我让电商先把页面改了，把原来的截图也删了，别留下凭证。反正现在页面上已经没有了，他们也没法证明我们说过。

法务
你

停，立刻停。你这个动作会把一件可以改正的行政风险，变成一件性质严重得多的事件。就好比出了一起交通事故，正确做法是报警、保护现场、救人；你现在的做法是把车开走、把现场擦干净——事故本身可能只是剐蹭，但你这个动作让它变成了肇事逃逸。而且从技术上说，你删不掉：平台有缓存、有历史版本，第三方有截图和存档，广告监测有抓取记录，消费者手里有订单快照。

市场部
业务

那我不是完了？已经改了。

法务
你

还没完，但必须立刻做对三件事：① 保留原始版本。把原始物料、投放记录、审核记录、数据来源全部固定下来（导出、公证或时间戳），这是证明我们「说了什么、依据是什么」的材料，不是罪证。② 主动改正并留痕。下架或替换是可以做的，但要把「何时发现、何时改正、改了什么」完整记录——主动改正本身就是法定的从轻、减轻情节。③ 如实说明。配合调查时如实陈述事实与整改情况。就好比考试作弊被抓，坦白并改正的处理，和销毁试卷的处理，完全是两个量级。另外，我们必须同步做一件事：查清楚这句话当初是怎么过审的——是没送审、是审了没拦住、还是依据后来失效了。这个归因比这次处罚本身更重要，因为它决定了下次会不会再犯。

市场部
业务

明白了。那我接下来配合你整理材料，不再自作主张。

法务
你

对，还有一句要传达到所有人：发现问题后唯一的正确动作是「上报 + 固定证据 + 主动改正」，不是「掩盖」。我会把这条写进《合规事件处置 SOP》，并作为全员培训的必修内容。

给读者的大白话总结：出事之后的三句话——「别删、别瞒、别私下谈；要改、要说、要留痕。」主动改正和配合调查是最好的减轻情节，掩盖证据是最快的升级路径。

对话 14展开：业务说「竞品也这么干，为什么只查我们」
零售运营
业务

同样的说法，竞品在用的比我们还狠，为什么监管只来问我们？这不公平。要不我们也举报他们，大家一起整改？

法务
你

先说法律层面：「别人也违法」从来不是一个抗辩理由。就好比你闯红灯被拦下，你说「前面那辆车也闯了」——交警不会因为前面那辆车没被拦就放你走，他最多再多拦一辆。监管资源有限，执法必然有先后，被查到只能说明这次轮到我们，不能说明我们被针对。

零售运营
业务

那我们举报竞品总可以吧？

法务
你

可以，但要分清目的和方式，而且别把它当成对本案的回应。合法举报是权利，但要注意三点：① 必须基于真实、可核查的事实，不得编造——编造或传播虚假信息损害他人商誉，那是商业诋毁，反法 2025 修订第 12 条罚得不轻。② 不要把它写成公关动作——一旦对外宣称「我们也举报了竞品」，很容易被解读为转移视线，舆情上得不偿失。③ 不要把举报当成竞争策略——用它解决「我们被查」这个问题，方向是错的。就好比你考试不及格，正确做法是补课；你去举报同桌也作弊，你的分数不会因此变高。我们现在该做的是：把这次的物料改对、把审核流程补上、把同类表述全渠道清一遍。把注意力放在自己的合规能力上，比放在别人的问题上更有价值。

给读者的大白话总结：「别人也这样」不是抗辩；举报竞品是权利，但不能替代自身的整改，更不能以编造或夸大的方式进行。合规能力的提升，只能靠自己。

六、本章终审 Checklist（争议处置专用）

  • 是否已登记《合规事件台账》并冻结相关物料？
  • 事实核查是否完整（物料原文、渠道、时长、成交、审核记录、证据文件）？
  • 法律定性是否明确到具体法条与后果区间？
  • 处置方案是否包含：整改、下架、澄清、退款或补偿、是否主动报告？
  • 对外沟通是否已指定唯一发言人并统一口径？
  • 是否已固定原始证据（未删除、未修改、未伪造）？
  • 受影响消费者是否已主动联系并给出方案？
  • 是否已归因（没送审 / 审了没拦住 / 依据失效 / 执行偏差）？
  • 是否已转化为规则修订、词库更新与系统硬拦截？
  • 是否已纳入季度培训与年度复盘？
