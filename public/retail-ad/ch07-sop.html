CHAPTER 07 · REVIEW SOP & ACCOUNTABILITY MATRIX

合规审核流程 SOP 与责任划分

前面六章讲的是「审什么」，这一章讲「谁来审、多久审完、谁签字、谁担责、谈不拢怎么办」。
SOP 的目的不是把流程变长，是把责任变清楚——出事时能立刻知道是哪个环节漏的，没出事时知道该找谁。就好比手术室的清单不是为了拖慢手术，是为了让每个人都知道自己该在什么时候做什么。

SOP 的第一性原理：不是所有物料都要法务逐字看

法务的人力永远少于业务的需求量。如果把所有物料都塞进同一条终审通道，结果只有一个——业务开始绕过流程。所以本 SOP 的第一件事是风险分级：把法务的时间集中投放到真正会出事的地方，其余的用模板化自查解决。分级不是放松标准，是把标准做成默认值。

本章对话与模板可原地展开：

一、风险分级与通道选择

级别适用物料通道审核主体时限
L1 低风险 已审模板的复用；价格与日期变动的常规 POP；门店常规陈列；既有的长期物料续期 快速通道
（模板化自查）		 业务自查 + 系统校验；无需法务签署 即时
L2 中风险 新品常规图文与详情页；常规短视频；常规促销规则（无抽奖、无储值）；既有达人续约场次 标准通道 业务自查 → 法务专员复核 〔1—2〕 个工作日
L3 高风险 新品首发 campaign；明星 / 达人代言；IP 联名；直播大场；任何促销规则含抽奖、储值、预付；户外大牌；涉及功效或技术宣称；涉及对比；首次进入的新渠道 / 新城市 终审通道 业务自查 → 法务专员复核 → 法务负责人终审 〔3—5〕 个工作日
L4 特别风险 涉及敏感议题、重大舆情、监管问询、跨境投放、新品类首入、金额重大的联名、可能引发系统性后果的事项 终审通道 + 升级 法务负责人 → 管理层决策（必要时外部律师） 〔5〕 个工作日以上，按事项确定
【审核重点】分级的三个判断问题
  1. 有没有「不可撤回」的后果？——印刷、户外上画、直播开播、投放买量，一旦发生无法低成本撤回的，至少 L2。
  2. 有没有「对外承诺」？——涉及价格、赠品、售后、权益、储值、抽奖的，涉及承诺即至少 L2，含抽奖或储值的直接 L3。
  3. 有没有「外部权利」？——涉及 IP、代言人、达人、第三方素材、第三方数据的，至少 L2，涉及授权链条的 L3。

分级由业务初判、法务终判。业务对分级有异议的，以法务判定为准；业务不得通过「拆分物料」「分批次提交」等方式规避分级。

二、三级审核的节点、输入与输出

2.1 初审（业务自查）

项目内容
主体物料提出部门（市场 / 电商 / 零售运营 / 商务 / 直播运营）；部门负责人对自查真实性负责
输入创意简报、成品物料（设计稿 / 成片 / 页面）、文案全文、素材授权清单、数据来源文件、活动规则全文
动作① 按《业务自查表》逐项打勾；② 用公司禁用词库做全文检索（含图内文字、字幕）；③ 补齐授权与数据文件；④ 完成风险初判与通道选择
输出《物料送审单》+《业务自查表》+ 附件包（物料、文案、授权、数据、规则）
责任对材料的完整性、真实性负责。隐瞒、遗漏、提供虚假材料的，属重大违规，直接计入部门与个人考核

2.2 复核（法务专员）

项目内容
主体法务部合规专员 / 法务经理
动作① 五法扫描（广告法 / 反法 / 消保法 / 价格法 / 知识产权法）；② 六维度核查（文字、画面、声音、动态、交互、时间）；③ 证据链核验（授权、数据、检测报告、规则可执行性）；④ 标注红黄蓝三色意见；⑤ 给出替代表达建议
输出《合规审核意见表》（含红线项、需补证项、建议修改项、替代表达）
责任对法律判断的准确性与审核覆盖的完整性负责
权限可作出「同意」「修改后同意」「补证后同意」；对红线项无放行权；对 L3 事项须提交终审

2.3 终审（法务负责人）

项目内容
主体法务负责人（法务总监 / 法务负责人）
动作① 复核红线项是否已全部消除；② 复核需补证项是否已补齐；③ 审视口径一致性（同一 campaign 各渠道表述是否统一）；④ 评估声誉与舆情维度；⑤ 判断是否需要升级至管理层
输出《合规终审意见》（同意 / 有条件同意 / 不同意 / 升级）并签署
责任对终审结论与风险接受水平负责
权限唯一可作出「放行」与「有条件放行」的主体；对红线未消除的事项不得放行，只能升级

加急加急不改变审核标准，只压缩时限。加急须由提出部门负责人书面说明理由并经法务负责人同意；红线项不得因加急而放行；加急事项须在事后 〔3〕 个工作日内补齐全部留档材料
【红线条款】「已经印了 / 已经投了 / 已经排期了」不是理由

任何部门不得以物料已制作完成、已支付费用、已排期、已印刷、已上线为由，要求法务事后补签或倒逼放行。就好比不能因为房子已经盖到第十层，就要求规划部门补发施工许可证——程序不能倒过来走。

处理规则：① 已发生的事实不因事后补签而改变其性质；② 法务对已投入成本的物料提出修改意见的，业务部门应当执行；③ 因未送审导致返工、下架、罚款的，责任由未送审的部门承担，不得计入法务。

升级机制的关键设计：让「接受风险」成为一件需要签字的事

业务绕过法务的根本原因，往往是「法务不同意」这件事没有成本——大家口头争论一通，最后不了了之，业务照做。解决办法是把风险显性化、书面化、签字化：

  1. 量化：给出可能的行政处罚区间、下架与返工成本、消费者索赔敞口、舆情影响评估。
  2. 书面：《风险接受决定书》写明「法务意见：不同意；理由：〔法条与后果〕；业务决定：接受风险继续执行」。
  3. 签字：由有相应权限的管理层签字（按金额与影响设定阈值），法务意见附于其上并存档。
  4. 留痕：决定书编号归档，纳入年度复盘。目的不是追责，是让决策者看见自己签的是什么。

就好比手术同意书——医生不是推卸责任，是让病人在知情的前提下做选择。而且实践中，一旦需要签字，八成的「必须坚持」会变成「那就按法务说的改吧」。

【审核重点】法律变化扫描是年度复盘中优先级最高的一项

本指引涉及的领域，近两年法规更新极为密集：《反不正当竞争法》2025 年修订、《直播电商监督管理办法》2026 年施行、《广告引证内容执法指南》2026 年发布。任何一份内部制度，如果年度复盘时没有做法律变化扫描，就可能在条号和口径上整体失效。就好比导航地图不更新，你按它开车就会开进河里——不是你开错了，是地图过期了。建议指定专人按季度做法规跟踪，年度做全面比对。

九、法务对话：两个关于流程本身的冲突

对话 15展开：「明天就上线了，法务能不能今天给我过」
电商部
业务

大促明晚 8 点开始，页面今晚必须上线。法务能不能今天给过？我们改不动了，印刷和拍摄都做完了。

法务
你

可以今天过，但有三件事要说清楚。第一，「做完了」不是加快审核的理由，是风险变大的理由——因为现在改的成本最高，所以最容易出现的结局是「硬着头皮上」。就好比你不是提前体检，是已经躺在手术台上了才让医生看报告——医生能做的很有限，而且风险全在你身上。第二，我的审核标准不会因为加急而降低：红线项今天也过不了，只能改；能改的我现在就给你替代表达，你改完我立刻复核。第三，加急的代价是留档后补：今天先放行，〔3〕 个工作日内必须补齐全部材料，包括授权文件和数据来源——补不齐，我有权要求下线。

电商部
业务

那如果改不动呢？比如页面上那句话是印在包装上的。

法务
你

那就分情况处理：红线项——必须处理，包装可以贴标覆盖、页面可以撤图、话术可以改口播；实在无法物理修改的，就不上架、不投放，或者走《风险接受决定书》让管理层签字。非红线的需补证项——今天先上，三天内补齐证据，补不齐下线。就好比安检发现行李有问题，不是让飞机晚点等你整理行李，是先不让你上这班飞机——你可以改签，但不能带着问题上机。另外我们要复盘的是：为什么这件事到今天才送审？如果这是流程问题（大促没有提前排期），就要改流程；如果是人员问题（不知道要送审），就要培训。不然下次大促还是这样。

给读者的大白话总结：加急可以，但「加急只压缩时间，不降低标准」。红线项今天也过不了；非红线项可以「先上后补证」，但补不齐就得下。真正要解决的是「为什么总是最后一刻才送审」。

对话 16展开：「法务总是说不，业务怎么干活」
市场总监
业务

我直说吧，法务现在给我们的感受就是「这个不行那个不行」，但很少告诉我们「那怎么才行」。业务有 KPI，我们没有时间等法务慢慢研究。能不能给个明确的东西：什么能说什么不能说？

法务
你

这个批评我接受，而且这正是我要做的事。今天开始给你三样东西：① 一页纸的《能说／不能说对照表》——按品类分，左边是不能说的，右边是替代表达，业务自己就能查；② 模板库——常用物料的合规模板，填空即用，走 L1 快速通道，不用等法务；③ 明确的时限承诺——L2 两个工作日、L3 五个工作日，超时视为默认同意（红线项除外）。就好比交通管理不是靠警察站在每个路口拦车，是靠标线、信号灯和限速牌——把规则立在那儿，绝大多数人自己就知道怎么开。

市场总监

十、本章终审 Checklist（SOP 落地自检）

  • 是否建立了风险分级标准并向业务部门公开？业务是否知悉分级规则？
  • 三级审核的节点、时限、输入输出是否书面化并在系统中固化？
  • 是否存在「已印 / 已投 / 已排期」倒逼放行的情况？如有，是否已纠正？
  • 责任矩阵是否已明确到岗位，并纳入部门与个人考核？
  • 升级机制是否运行？《风险接受决定书》是否实际被使用并编号归档？
  • 留档材料清单与保存期限是否已执行？直播回放是否实际可检索？
  • 是否指定专人按季度做法律法规变化扫描？
  • 月度 / 季度 / 年度复盘是否运行，并产出了词表更新与模板修订？
  • 法务是否承诺「说不行必须给怎么才行」？业务部门是否认可？
  • 法务介入是否已提前到创意简报阶段？
