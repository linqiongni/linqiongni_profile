CHAPTER 04 · IP LICENSING & CO-BRANDING REVIEW

IP 合作与联名营销合规审查

联名是零售增长最快的品类，也是风险最容易被低估的品类——因为它的风险不在签约那一刻，而在签约之后的每一天：设计改了、渠道多了、库存剩了、合作到期了。
本章的核心主张：联名审查不是审一份授权书，是审一条链条 + 一个全生命周期。

授权链条核验联名标识规范衍生品与库存侵权防控终止善后
联名合规的第一性原理：授权是一个「范围」，不是一个「许可」

拿到授权书只是起点。真正决定风险的是四个边界：地域、期限、品类、渠道。绝大多数联名纠纷不是因为「没授权」，而是因为「做了授权范围之外的事」——多做了一个品类、多上了一个渠道、多卖了三个月。就好比租了一套房子，合同写的是自住、两年、不能转租——你住着没问题，但你把它改成民宿、转租给朋友、到期后继续住，这三件事每一件都让你从「合法使用」变成「违约 + 侵权」。

本章对话与条款模板可原地展开：

一、授权链条核查

1.1 权属证明核验标准

1.2 授权层级与转授权核验

【审核重点】链条核验的三条铁律
  1. 追到原始权利人。不接受「合作方说它有权」——必须看到从原始权利人出发的每一层文件。
  2. 每层都要「可转授权」。上游授权文件若未载明被授权人可再授权，下游授权无效。缺失任一层即链条断裂。
  3. 权利类型要对得上。「形象使用权」≠「衍生品开发权」≠「商品化权」≠「宣传物料使用权」。本次要做的每一件事，都要能在授权文件里找到对应的权利类型。

就好比转租房子要看原房东的租赁合同里有没有写「允许转租」——二房东拿不出这一条，你签的转租合同就是一张废纸，而且原房东可以随时让你搬走。

1.3 授权范围核验表（地域 / 期限 / 品类 / 渠道）

维度核验内容常见超范围情形防控动作

二、联名宣传合规

2.1 联名标识使用规范

  • 使用授权方提供的标准素材：形象、标识、字体、色彩、标准组合方式，以授权方提供的规范手册（Style Guide）为准，不得自行重绘、变体、拆解。
  • 标识摆放与占比：遵守授权方关于最小使用尺寸、安全边距、禁用背景、禁用配色的规定；联名双方标识的相对位置与大小比例须符合约定。
  • 组合标识的规范：联名专用标识（如有）须使用经授权方书面确认的版本，不得自行设计近似标识。
  • IP 名称与商标标注：按授权方要求标注权利归属声明（如「©〔权利人〕〔年份〕」「〔商标名称〕为〔权利人〕的注册商标」），且标注方式须经确认。
  • 宣传物料送审：所有含 IP 元素的广告物料（KV、短视频、详情页、门店 POP、包装）在投放前须经授权方书面确认，合同中约定审批时限与逾期视为同意的规则。
【红线条款】联名宣传的三条禁止
  1. 禁止单方过度宣传。不得夸大合作深度（如将「形象授权」表述为「联合研发」「共同设计」）；不得暗示 IP 权利人对公司商品作品质背书；不得使用「官方授权」「独家」「唯一」等未经确认的表述。
  2. 禁止篡改 IP 元素。不得对授权形象作变形、二创、拼接、恶搞、不当场景化使用；不得改变标准配色与比例；不得将 IP 元素与公司自有标识作可能引起混淆的组合。
  3. 禁止超范围使用。不得将 IP 元素用于授权品类、渠道、地域、期限之外的任何场景，包括但不限于：非联名商品的包装、门店长期陈列、公司品牌自身的形象宣传、员工制服、赠品与非卖品。

2.2 常见违规示例与整改建议

三、衍生品合规

3.1 联名产品设计审核流程

节点动作责任人交付物与留档

D2 设计稿完整设计稿送审（含三视图、配色、材质、工艺说明）设计《设计送审单》+ 授权方审批文件

D4 量产量产前核对封样，严格按封样生产，变更须重新送审供应链《量产确认单》+ 封样比对记录

3.2 生产与销售范围控制

  • 生产数量：合同约定的生产数量上限须留档；超出上限生产须书面同意；加单同样受限制。
  • 批次管理：联名商品单独批次编号，与常规商品区分，便于到期下架与库存清点。
  • 渠道白名单：销售渠道事前列入白名单并在系统中配置；白名单外渠道禁止铺货。
  • 防串货与防外流：联名商品不得流入未授权渠道（含团购、折扣渠道）；经销合同中约定串货违约责任。
  • 赠品与非卖品：赠品、内部领用、媒体样品是否计入授权品类与数量，须事前明确。

3.3 库存销毁与清仓规则

【审核重点】库存条款是联名合同里最容易被跳过、但最容易出问题的一条

联名项目结束时的典型困境：货还剩一批，卖还是不卖？答案是——合同没写清楚就只能销毁，写了清仓期才能卖。所以必须在签约时就把三件事写死：

  1. 清仓期（Sell-off Period）：授权期届满后允许继续销售的窗口期（如 〔30/60/90〕 日），以及清仓期内可用的渠道。
  2. 清仓后的处理：剩余库存的处置方式——销毁 / 去除 IP 元素后销售 / 捐赠 / 内部处理，以及每种方式的前置条件。
  3. 销毁的见证与证明：销毁须有双方见证或第三方见证，出具销毁清单、照片或视频、销毁证明，并按约定时限提交。

就好比租房到期，你不能把房东的家具继续留在店里卖，也不能自己搬走——合同里要么写「可以折价买下」，要么写「限期搬走并验收」。没写，就只能搬走，还得赔超期占用费。

四、侵权风险防控

4.1 第三方侵权排查（自有侧）

  • 近似性排查：联名设计定稿前，对 IP 形象、作品名称、标识作近似检索（商标近似检索、著作权登记检索、在先使用检索），避免与他人在先权利冲突。
  • 元素拆解排查：设计中除 IP 元素外的其他构成（字体、纹样、图案、色彩组合、其他品牌元素）同样须清权。
  • 合作方背景核查：核查授权方是否存在权利瑕疵、是否涉及权属争议或诉讼、是否为有权处分主体。
  • 共同创作的权利归属：联名过程中若产生新的设计成果（如联名专用标识、衍生图案），须在合同中约定其权利归属与后续使用规则。

4.2 被侵权侧的应对（他人仿冒）

  • 监测机制：联名期间建立市场监测（电商、社交、线下渠道），发现仿冒及时取证。
  • 维权分工：合同中约定由谁发起维权（权利人或被授权人）、维权费用承担、赔偿款分配。
  • 配合义务：约定授权方在维权时提供权属证明、授权文件的配合义务与时限。
  • 渠道投诉：利用电商平台知识产权投诉机制，须提前准备权属与授权证明材料包。

4.3 超范围使用的违约后果

超范围情形合同后果法律后果内部处理

5.2 遗留侵权责任的约定（签约时就要写）

  • 责任划分：因授权方权利瑕疵导致第三方主张权利的，由授权方承担并赔偿公司损失；因公司超范围使用导致的，由公司承担。
  • 存续条款：保密、知识产权、责任限制、争议解决、遗留责任条款在合同终止后继续有效，并约定存续年限。
  • 终止后仍可销售的情形：明确清仓期的范围与条件，避免终止后销售被追责。
  • 第三方索赔的处理机制：通知义务、抗辩控制权、和解同意权、费用分担。
  • 赔偿上限与除外：约定赔偿上限，但故意、重大过失、侵犯第三方知识产权、违反保密义务通常应排除在上限之外。

六、条款模板（可直接改写使用）

模板 01展开：授权范围条款（含四边界与设计送审）
许可范围：授权方许可公司在本协议约定的范围内使用许可素材，具体包括： （1）地域范围：〔中国大陆地区（不含港澳台）/ 全球 / 其他具体列明〕； （2）期限：生产期自〔 〕年〔 〕月〔 〕日至〔 〕年〔 〕月〔 〕日；销售期自〔 〕年〔 〕月〔 〕日至〔 〕年〔 〕月〔 〕日；宣传期自〔 〕年〔 〕月〔 〕日至〔 〕年〔 〕月〔 〕日； （3）品类：以附件一《许可商品清单》所列 SKU 为限，新增 SKU 须经授权方事先书面同意； （4）渠道：〔自营门店 / 品牌官网 / 指定电商平台 / 直播 / 经销 / 其他〕，未经授权方事先书面同意，公司不得通过清单外渠道销售或展示。 许可素材用于宣传推广物料（含平面、视频、门店陈列、社交媒体、达人内容）的，其渠道与期限与前述销售期、宣传期一致。 设计送审：公司应就每一款许可商品及其包装、宣传物料向授权方提交设计稿，授权方应于收到后〔 〕个工作日内书面回复；逾期未回复的，视为同意。经确认的设计稿，公司不得擅自变更；确需变更的，应重新送审。 禁止行为：公司不得对许可素材作变形、二创、拼接、恶搞或其他改动；不得将许可素材用于许可商品之外的任何商品、包装、赠品、非卖品或公司自身品牌宣传；不得宣称或暗示授权方对许可商品的质量、性能作任何背书，除非获得授权方事先书面同意。
模板 02展开：库存处理与终止善后条款
清仓期：销售期届满后，公司可在〔 〕日内（"清仓期"）继续销售库存的许可商品，清仓期内仅限通过〔渠道〕销售，且不得开展新的宣传推广活动。 清仓期届满后的库存处理：清仓期届满时仍未售出的许可商品，按以下第〔 〕种方式处理： （1）销毁：公司应在〔 〕日内完成销毁，销毁时授权方有权派员见证或委托第三方见证，公司应出具销毁清单、影像资料及销毁证明； （2）去除许可素材后处理：经授权方书面同意，公司在去除全部许可素材后，可将该等商品作为普通商品处理； （3）其他：〔 〕。 物料下架：本协议终止或到期后，公司应在〔 〕个工作日内停止一切含许可素材的宣传推广，包括但不限于下架线上页面、撤除门店物料、删除或替换社交媒体内容、通知达人及合作方删除相关内容，并向授权方提交《物料下架确认函》。 遗留责任：本协议终止后，任何一方因本协议终止前的行为对第三方承担的侵权责任，由引起该等责任的一方承担，并应赔偿另一方因此遭受的全部损失。因授权方权利瑕疵导致第三方主张权利的，由授权方负责处理并承担全部责任。 存续条款：保密、知识产权、遗留责任、责任限制、争议解决条款在本协议终止后继续有效，存续期限为〔 〕年。
模板 03展开：权利瑕疵担保与赔偿条款
权属保证：授权方保证其为许可素材的合法权利人或已获得完整、有效的授权，有权按本协议约定授予公司使用，且许可素材不侵犯任何第三方的著作权、商标权、专利权、肖像权及其他合法权益。授权方应向公司提供完整的权属证明文件及授权链条文件（可就商业条款作脱敏处理）。 第三方索赔：因许可素材存在权利瑕疵导致第三方对公司提出主张或提起诉讼的，公司应及时书面通知授权方；授权方应负责处理并承担由此产生的全部费用（含合理的律师费、公证费、调查费），并赔偿公司因此遭受的全部损失，包括但不限于已支付的许可费、生产与库存成本、下架与召回费用、行政处罚款项及商誉损失。 公司义务：公司应严格在本协议约定的范围内使用许可素材；因公司超范围使用、擅自改动或未履行送审义务导致的第三方主张，由公司自行承担，并应赔偿授权方因此遭受的损失。 赔偿上限的除外：本协议约定的赔偿责任上限不适用于因故意、重大过失、侵犯第三方知识产权、违反保密义务以及人身损害所引起的赔偿责任。

七、法务对话：两个最常见的谈判僵局

对话 09展开：业务说「合同条款谈不回来，对方很强势」
商务
业务

这个 IP 很抢手，对方给的合同是标准模板，一条都不让改。库存条款、权利瑕疵担保都是对方的免责版本。我们要是坚持改，对方就不签，这个档期就错过了。能不能先签，出了事再说？

法务
你

先说结论：可以签，但不能「裸签」。IP 方强势是行业常态，这我不反对让步；但让步要有顺序——先分清哪些能让、哪些不能让，然后用能让的换不能让的。就好比买房时房东不让你改合同，你确实改不动整份合同，但你可以把「交房时水电结清、户口迁出、家具清单」这几条单独写成补充协议——大合同不动，关键风险单独锁。

商务
业务

那哪些是不能让的？

法务
你

三条不能让：① 权利瑕疵担保——如果 IP 本身有权利瑕疵，第三方来告，公司是被告，而且是那个真金白银赔钱的人。这条不要，等于把对方的权利风险搬到公司账上。② 库存与清仓条款——这是钱。③ 遗留责任与存续条款——合作结束后的责任怎么分。这三条谈不下来，就用别的东西换：提高许可费、缩短排他期、增加授权品类、延长宣传期——把对方真正在意的商业条款让出来，换回风险条款。就好比房东不肯修水管，你可以说我加两百块房租，但水管你得修——用钱换风险，是谈判里最好用的一招。

商务
业务

对方连补充协议都不签怎么办？

法务
你

那就走书面确认函：把关键事项写成一封确认邮件或确认函，请对方回签。「请确认：许可素材的权属链条完整、可转授权、含宣传物料使用权」——对方只要回复确认，就构成书面证据。这比改合同容易得多，法律效力也够用。就好比房东不肯签补充协议，但他在微信里回了句「家具都是我的，你放心用」——这句话在法庭上就是证据。最后一道防线：如果连确认函都拿不到，那就把风险量化给决策层签字——预估库存金额、下架成本、索赔敞口，让业务负责人和 CFO 会签「已知风险，仍决定签约」。我不替业务承担这个决策，但我也不阻止公司做有知情的选择。

给读者的大白话总结：强势方不给改合同是常态，破解办法不是硬碰硬，是「大合同不动、关键条款单独锁、商业条款换风险条款、确认函留证据、实在不行量化签字」五步。法务的价值不是把合同改成完美，是确保每一个被接受的风险都是被看见、被量化、被有权的人决定的。

对话 10展开：合作快到期了，还剩一批库存，业务想继续卖
供应链
业务

这个联名系列还剩三千多件，成本压了一百多万。授权下个月到期，我们能不能继续卖？反正货是我们生产的，IP 元素也是印在我们自己产品上的。

法务
你

不能，除非合同里有清仓期。这一点必须先说清楚：商品是你生产的，但上面那个形象不是你的。就好比你买了纸和油墨，印了别人的照片做成海报去卖——纸是你的，油墨是你的，但照片不是你的，你不能卖。授权期满后继续销售，性质是未经许可的使用，同时构成违约和侵权。而且要提醒一句：这时候卖，赔偿标准会按侵权获利计算，还可能被认定为持续侵权，后果比合作期内超范围严重得多。

供应链
业务

那批货怎么办？销毁太可惜了。

法务
你

先看合同有没有清仓期条款。有——按约定窗口和渠道清完，到期即停，别超一天。没有——现在去谈补充协议，用「剩余库存清单 + 限定渠道 + 限定时间 + 不再宣传」去换一个短期清仓许可，这通常是能谈成的，因为对方也希望这批货别流向灰色渠道。就好比租约到期了你还有一批货在店里，正确做法不是继续开门营业，而是跟房东商量「给我两周把货清完，期间不挂招牌」——这个请求房东通常会同意。谈不下来再走第三条路：去除 IP 元素后作为普通商品处理（合同约定或对方同意的前提下）；或者履行销毁并出具证明。最后一条必须记住：这批货绝对不能流入团购、折扣、经销等非授权渠道——一旦外流，公司无法控制去向，风险敞口就无限大了。

供应链
业务

那下次怎么避免？每次都剩库存也不是办法。

法务
你

答案在签约前，不在到期时。三件事：① 首单保守、设加单机制——首单按保守预估下单，卖得好再走加单审批（合同里预留加单条款与审批时限）；② 生产期与销售期分开写——生产在前、销售在后，中间留出缓冲；③ 到期前 60 天启动库存预案——把「距今 60 天到期的联名项目库存」做成自动提醒，提前进入谈判或促销预案。就好比生鲜超市不是等菜烂了才想办法，是按保质期倒推补货和打折节奏——库存问题的解法永远在上游。

给读者的大白话总结：联名库存的三句口诀——「授权期内卖是权利，授权期满卖是侵权；清仓期要写进合同，没写就要去谈；到期前 60 天启动预案，别等到最后一周。」

八、本章终审 Checklist

  • 授权链条是否逐层核验至原始权利人，每层是否载明可转授权？
  • 权利类型是否覆盖本次全部使用行为（生产、销售、宣传物料、直播、达人内容）？
  • 地域、期限（生产期 / 销售期 / 宣传期）、品类（SKU 清单）、渠道（白名单）四边界是否明确并系统可校验？
  • 设计送审机制是否写入合同，并约定审批时限与逾期后果？
  • IP 元素使用是否遵守规范手册；有无擅自变形、二创、组合、超品类使用？
  • 宣传表述是否如实（不夸大合作深度、不使用未经确认的「独家」「官方」表述）？
  • 是否完成近似性排查与他人在先权利检索？
  • 权利瑕疵担保、第三方索赔处理、赔偿上限及除外是否约定？
  • 清仓期、库存处理方式、销毁见证与证明是否约定？
  • 终止后物料下架时限、渠道清单、确认函机制是否约定？
  • 遗留责任与存续条款是否约定？
  • 到期前 〔60〕 日库存与物料预案是否已启动？
