一、一句话立住：海外仓税务像「在别人家客厅放了个储物柜」——放东西没事，天天在那做生意就得出租费

把 PE（常设机构）想成「在别人国家放东西」：你只是寄存一个储物柜（纯仓储），房东（税务当局）通常不找你收「营业租费」；但你如果天天在柜子前摆摊卖货、签合同、收钱，税务局就认定你「在那儿做生意」了，要你按当地税交。最经典的坑是：我方德国海外仓本来只是存货，客户（卖家）的销售团队或我方人员开始在那儿接单、定价、发货指令，一脚踩进 PE，整个利润要在德国交企业所得税+增值税。怎么串到前三天：主体（D1-D2）解决了「合法存在」，用工（D3）解决了「谁干活」，今天解决「干这些活要不要在当地交税、怎么交、关联交易怎么定价才算干净」。

记忆点：纯仓储未必是 PE，加销售/签约人员就是 PE；PE 一触发，当地企业所得税+增值税全来。海外仓税务第一问永远是：我的人在那儿动了什么？

三、常设机构 PE：海外仓的「命门」

OECD 税收协定范本与三国国内法下，PE 一般要件 = 固定营业场所 + 企业通过它从事全部或部分营业。对海外仓的关键判断：

  • 纯仓储：存货储存、交付前的保管，通常被认定为「预备性/辅助性活动」，不构成 PE（协定范本第 5(4) 条精神，须核对三国国内适用）。
  • 加人员即危险：若我方或客户人员在仓内洽谈销售、签订销售合同、决定价格、管理客户信用，该场所很可能被认定 PE。
  • 存货管理权限：仅按指令发货一般安全；若有权修改订单、定价、选择客户，风险上升。
  • 服务型 PE / 代理型 PE：通过固定代理人（经常有权以企业名义签合同）亦可能构成代理型 PE。
自查动作（落到谁/何时/证据）：① 我方德国仓只做「收货-存储-按指令发货」，合同中写清无销售、无定价、无签约权；② 销售职能留在母公司或独立销售实体，仓内人员不碰客户合同；③ 留存仓内 SOP 与人员职责说明，证明「辅助性」；④ 一旦客户要求仓内人员代接单，立即评估 PE 并定价含当地税，否则后果：补企业所得税+利息+罚款（数额待核实）。

核心逻辑：没有 PE，就没有当地企业所得税。所以 PE 自查不是学术题，是直接决定「这仓的利润要在当地交多少税」。我方作为物流商，若被认定在德国构成 PE，不仅自家利润要交，还可能被认定为代客户从事经营而牵连客户——这是双向风险。

反制点（客户视角）：跨境电商卖家用我方海外仓，应确认我方仓不构成 PE（避免卖家被认定为在当地有经营从而触发其自身纳税义务）；可在仓储协议要求我方出具「仓内活动范围声明」。我方立场：严守辅助性边界，是对自己和客户双重保护。

五、预提税与税收协定

六、转让定价 TP：关联交易必须「像外人一样算账」

  • 独立交易原则：集团内我方海外仓与母公司/关联销售公司的交易，价格须等同非关联方（否则税务调整+罚息）。
  • 三种方法：可比非受控价格法 CUP（最优先，找可比市价）、再销售价格法（RPM，用下游毛利倒推）、成本加成法（Cost Plus，成本+合理毛利）。
  • 同期资料三层：主体文档 Master File、本地文档 Local File、国别报告 CbCR；触发门槛（合并营收、跨境关联交易额）须核对三国规定。
  • 关联服务费：母公司向海外仓收取管理费/IT 费/品牌费，须有真实服务基础、可量化受益、按市场费率——否则被认定为「利润转移」而调增。
落地动作：① 我方海外仓与关联方的仓储/服务费定价，签书面关联交易协议并留存定价依据（可比分析）；② 达门槛即备 Local/Master File，CbCR 按集团要求；③ 不做后果：税务稽查调增利润+补缴 CIT+利息罚款（数额待核实），且可能引发三国同时调整（双重征税）。

七、落到动作：两份清单

  1. 《常设机构风险自查表》：场所用途/人员职责/签约权/定价权/存货权限——逐项打勾，任一「销售/签约」即红灯。
  2. 《集团关联交易合规清单》：关联方清单、交易类型、定价方法、同期资料状态、税收居民证明、预提税协定适用。
  3. 证据留存：仓内 SOP、人员岗位职责、关联交易合同、定价分析、税务申报与缴纳凭证，保存至法定年限（须核对）。
  4. 年度复核：每年由三国税务顾问重评 PE 与 TP，政策/业务变动即更新。
今日口诀：纯仓储不 PE、加人即 PE；PE 触发当地 CIT+VAT；预提税先查协定再付；关联交易按独立原则定价、留同期资料。海外仓税务，先管住「人在仓里动了什么」，再管好「集团内部怎么算账」。
核心术语（中英对照）
VAT
Value Added Tax / 增值税
对商品与服务增值额征收的间接税；德国 19%、波兰 23%、墨西哥 16% 为标准税率（均须核对现行值）
PE
Permanent Establishment / 常设机构
税收协定下企业在一国设有固定营业场所并从事营业，即在该国产生纳税义务；海外仓是否构成是核心风险
CIT
Corporate Income Tax / 企业所得税
对企业利润征收；税率德（含附加税）~30%、波 19%、墨 30% 均待核实，仅就 PE 或居民企业利润征
Withholding Tax
预提税 / 预扣税
对跨境股息/利息/特许权使用费在源头的扣缴税；协定可降率，具体税率须核对税收协定
TP
Transfer Pricing / 转让定价
关联企业间交易须按独立交易原则定价；方法含 CUP/再售价/成本加成，须同期资料
Local File / Master File / CbCR
本地文档/主体文档/国别报告
转让定价同期资料三层；门槛（如合并营收、跨境关联交易额）须核对各国规定
