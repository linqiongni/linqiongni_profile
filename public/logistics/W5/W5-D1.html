货物保险：保什么、保给谁、赔多少

第 5 周主题：货运保险与责任险 —— 赔了以后找谁要回来
🪜
货物保险三档像医保档次：平安险只保全损和翻船这种大事（像只保骨折住院），水渍险加保部分损失，一切险把能保的都保上。以为买了「保险」就全赔，是最常见的误会。
怎么串到今天责任认定学完了，这周解决：赔出去的钱，能不能从别处要回来。

一、一句话立住：货物保险是「货主的保险」，不是「物流商的保险」

请搬家公司最经典的坑引入：你搬家花 200 块给电视机买了「搬家险」，师傅把电视摔了，保险公司赔你 5000 块买新机——这笔钱赔的是你（货主），跟搬家公司赔不赔你是两件事。货运货物保险就是这个「电视险」：保的是货物本身的价值损失，被保险人是货主（卖方或买方），赔的是货主的货物损失。它和「物流商赔别人」的责任保险是两条完全独立的线。这周要搞清：货主买了货险，出事先找保险公司；保险公司赔完，转头可能来找我们（物流商）代位追偿——所以货险表面不关我们事，链条末端却绕回我们。

记忆点：货物保险 = 货主给自己的货买保险，赔货主；责任保险 = 物流商给自己买兜底，赔别人后由保险公司补我们。两条线起点不同、终点不同，但会在「代位求偿」处交汇。 怎么串到今天：昨天讲完贸易术语（谁担风险），今天讲风险真的发生时，第一道「钱从哪来」——货主的保险。

二、PICC 三档：从「只保大的」到「几乎都保」

  • 平安险 FPA：只保全损、共同海损、施救/救助费用、转运落海等重大事故损失；自然灾害造成的部分损失不保。这是「最抠」的一档，近似 ICC(C)。
  • 水渍险 WPA：FPA 的全部 + 自然灾害（恶劣气候、雷电、海啸、洪水等）造成的部分损失。注意它不含偷窃、破碎、短少等一般外来原因——这是和一切险最关键的分界。
  • 一切险 AR：WPA 的全部 + 一般外来原因（偷窃提货不着、淡水雨淋、短量、破碎、渗漏、串味等）造成的全部/部分损失。但战争、罢工、交货不到、进口关税等特殊风险仍不保，需另投附加险。
  • 承保方式差异：PICC 三档都是「正面列举保什么」；一切险虽叫「一切」，实际上是「正面列举一般外来原因」，并非字面的一切。

三、ICC 三档：A 用「除外法」，B/C 用「列明法」

  • ICC(A)：列明「不保什么」（除外责任法），除列明除外外一切风险都保，是三档最宽。注意它与「一切险 AR」不等同——AR 是正面列举，ICC(A) 是反面排除，二者在部分风险（如某些人为疏忽、集装箱海水渍）上范围有差异。
  • ICC(B)：列明风险法，逐条列明承保的意外事故（沉没、触礁、碰撞、火灾、爆炸、地震、火山、海水入舱等），未列明的不保，范围窄于 A。
  • ICC(C)：仅保最重大的意外事故（沉没、火灾、爆炸、触礁、搁浅、暴力盗窃等），自然灾害部分损失不保，近似平安险。
  • 战争与罢工：ICC 三档均不含战争、罢工、暴动风险，须另加《协会战争险条款（货物）》与《协会罢工险条款（货物）》；PICC 三档同样需另投战争/罢工附加险。
⚠ 待核实 / 提示
⚠ 待核实：① PICC 现行货运险条款版本（常用为 2009 版）与 ICC 现行版本（ICC 1/1/09 取代 1/1/82）以保险人/ICC 官方文本为准；② 各档「近似对应」仅为便于理解的功能类比，法律文本范围以条款原文为准，切勿在合同里写「AR 等同于 ICC(A)」；③ 一般外来原因的具体清单、除外责任细节以所投保单载明条款为准。

五、保险金额：CIF 加成 10% 是通行做法，但须核对合同

  • 加成惯例：以 CIF 发票金额加成 10%（即按 110%）投保，这 10% 是覆盖买方预期利润与部分费用；也有加成 20%–30% 的情形，取决于买卖约定。
  • 须核对合同约定：加成比例是合同/信用证约定的事项，并非法定。若合同只写「按发票金额投保」则无加成；CIF 下卖方有投保义务但险别/加成须看约定（Incoterms 2020 仅要求 CIF 投最低险别，未强制加成）。
  • 保费计算：保险费 = 保险金额 × 保险费率；费率随货物、航线、险别浮动，高值/易碎/带电货费率显著更高。
  • 不在 CIF 的情况：FOB/CFR/CPT/FCA 下卖方无投保义务，买方须自行按货值投保；若买方漏保，货损自负——这是客户反制点来源（见下）。
物流商自保动作：① 凡是 FOB/CFR 等「卖方不投保」术语，交运前必须书面提醒客户「请自行投保货运险」，并留存提醒记录；② 我方绝不替客户「代投」而不留凭证，否则客户会说「你答应过保」。客户反制点：客户会以「货代未尽提醒义务」主张我方连带，所以提醒动作要留痕。

六、保险利益与保单背书转让：索赔权怎么转给买方

  • 保险利益（Insurable Interest）：投保时或损失发生时，被保险人须对货物有法律上经济利益（如拥有货权或承担风险）。CIF 下风险在装运港转移，因此装船前保险利益在卖方、装船后在买方——这是为何 CIF 保单必须能转让。
  • 背书转让（Endorsement）：CIF 卖方投保后，通过空白背书或记名背书把保险单随提单转让给买方，买方凭受让的保单在目的港向保险人索赔。未背书转让，买方无索赔权。
  • 空白背书最常用：卖方在保单背面签章不写被背书人，单据可自由流转，像提单空白背书一样。
  • 转让的是「索赔权」不是「保险利益」本身：买方须在自己承担风险时段（装船后）发生损失才有权索赔；装船前损失仍归卖方索赔。

核心术语（中英对照）
CIC
China Insurance Clauses / 中国保险条款
PICC 制定的货物运输保险条款，分平安险、水渍险、一切险三档；2009 版为现行常用版本【版本待核实】
FPA
Free from Particular Average / 平安险
只保全损、共同海损、施救费用等重大损失，不保单独海损（部分损失），近似 ICC(C) 但非等同
WPA
With Particular Average / 水渍险
平安险 + 自然灾害（恶劣气候、雷电、海啸等）造成的部分损失；无直接 ICC 对应，介于 B/C 之间
All Risks (AR)
一切险 / 综合险
水渍险 + 一般外来原因（偷窃、破碎、雨淋、短量等）造成的全部/部分损失；不含战争、罢工等特殊附加险
ICC(A)
Institute Cargo Clauses (A) / 协会货物条款 A
最宽承保，采用「列明除外责任、其余都保」方式，近似一切险但范围不同；现行版本 ICC 1/1/09【版本待核实】
ICC(B)
Institute Cargo Clauses (B) / 协会货物条款 B
列明风险承保（如沉没、碰撞、火灾、地震、火山等），范围窄于 A、宽于 C
ICC(C)
Institute Cargo Clauses (C) / 协会货物条款 C
仅保重大意外事故（沉没、火灾、爆炸、触礁等），不保自然灾害部分损失，近似平安险
Insurable Interest
保险利益
投保人或被保险人须对保险标的具有法律上认可的经济利益，无保险利益则保单无效，须在损失发生时存在
Endorsement
背书 / 保单背书转让
通过背书将保险权益随货权（提单）转移给买方，是 CIF 下卖方把索赔权转让给买方的法定方式
