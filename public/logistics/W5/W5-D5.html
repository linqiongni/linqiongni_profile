一、本周知识树（一图收口）

  • D1 货险：货物保险是货主的「电视险」，保货不保物流商；PICC 三档(FPA/WPA/AR) vs ICC 三档(A/B/C)，AR≠ICC(A)、FPA≠ICC(C)；CIF 加成 10% 须核对合同；保单背书转让索赔权。
  • D2 代位：保险公司赔货主后，用代位求偿(第 60 条)掉头找我们；追偿链六环节；24/48/72 小时证据动作是自卫弹药。
  • D3 责任险：责任险是我们赔别人时的钱袋子；FFL 十项除外是雷区；P&I 是船东互助、商业险是固定保费，别混。
  • D4 条款库：保价/免赔/限额三道闸门；严格/平衡/宽松三套条款对应三种谈判地位；间接损失永远排除。
  • 总纲：货险与责任险方向相反却同决定「谁掏钱」；没有责任险，代位的坑直接打穿利润。

答案要点

  • 1-B；2-C（AR 与 ICC(A) 不等同、FPA 与 ICC(C) 仅为功能近似，且均不含战争）；3-B（加成是惯例非强制，须核对合同/信用证）；4-B（第 60 条代位求偿；第 59 条是物上代位/委付）；5-B（P&I 为互助、交会费 call）。
  • 案例 6：FOB 下卖方无投保义务，客户未投保则损失自负；但客户会以「货代未尽提醒/管货不当」转向我方，我方须出示已书面提醒投保的记录 + 证明非我方管货过错（封志完好、交接单），否则在过错范围内赔。
  • 案例 7：保险人代位不得超过被保险人(货主)原本可向我方主张的范围；我方依法享有的责任限制对保险人同样有效，保险人不能主张高于法定限额——除非我方合同明示放弃限制（宽松版情形）。
  • 案例 8：延迟在 FFL 多为除外，客户旺季缺货属间接/利润损失，通常被拒；我方须在合同与保单双重排除间接损失，并留存保单除外条款页给客户确认。
  • 简答 9：除外含固有缺陷、包装不当、延迟、战争罢工、欺诈、超出法定责任、未披露、恐怖、间接损失、高值未申报等；自防=接货验包装留记录、合同限定延迟责任、如实告知、别乱承诺超法定责任。
  • 简答 10：严格版用于我方强势/低毛利/高损风险；平衡版默认对等；宽松版用于战略大客/争单。放弃限制通常允许（向货方有利），但欺诈/故意/重大过失常不可排除，须保留兜底例外。

四、可复制判断法：一票货出事，30 秒定位

先问两件事，再走四步： 两问：① 客户自己买了货险吗？→ 有：客户先找保险，我们只是被代位对象；无：客户直接找我们。② 我方买了责任险吗？→ 有：我们赔了有人补；无：自己扛。 四步（定责→定损→定限额→定追偿）： 1. 定责：损失是不是我们的过错/法定责任？（封志完好、交接单、检验报告说话） 2. 定损：受损货值多少、残值多少（以检验报告为准） 3. 定限额：我方最多赔多少 = min(损失−免赔, 申报值/法定限额)；无责则 0 4. 定追偿：我方赔后，向实际承运人/分包商追（看其 P&I/责任险）；客户有货险则保险人代位，我方以对货主抗辩对抗保险人。 三问答完 + 四步走完，谁先掏钱、我方最多掏多少、找谁追回来，立刻清楚。
