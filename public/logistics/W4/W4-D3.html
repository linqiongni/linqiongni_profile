一、一句话立住：提单就是「提货的取件码」，还能转让

快递柜取件码=凭码取货；提单更狠——它不只是一串码，还是可以背书转让的「货权证」：发货人把提单背书给银行，银行等于「拿着货」；银行再转给买方，买方凭它去港口提货。这就是「钱—单—货」三角的核心：钱走在单上、单跟着货走。怎么串到今天：昨天讲 L/C 银行「只看单不看货」，今天揭晓它看的到底是什么单——就是这张能代表货权的提单。AWB（空运单）、铁路运单、FCR 不是物权凭证，所以空运/铁路/快递结算基本没法像海运那样「凭单押汇」。

记忆点：提单 = 货物收据 + 运输合同证明 + 物权凭证。三功能里，只有「物权凭证」这一条让它能在信用证里当抵押品；AWB/运单/FCR 缺这一条，所以押不了汇、只能先款或先货。

三、核心问题：为什么提单要「三份正本」（3/3）

  1. 防丢失/被窃：海运航程长、单据靠快递流转，一份丢失可能导致货到港却无单提货；印三份互为备份，任一份有效即可提货。
  2. 流通与放货矛盾的解法：提单是可转让物权凭证，正本可能在银行间背书流转；设计上「任何一份正本提货后，其余各份自动失效」，避免同一票货被多人重复提取。
  3. 银行要「全套」的逻辑：信用证 46A 通常要求「full set (3/3) original clean on board B/L」。银行承付前提是拿到全部正本——若只交 2/3，少了的那份仍在流通，货权有被第三方提走的风险，所以银行有权以「短交正本」为不符点拒付（属第 14 条单证不符）。
  4. 实务权衡：三份正本由托运人/议付行持有并流转，买方付款赎单后拿任意一份去提货；承运人 system 在放货时核销该份、其余失效。

四、《提单在结算中的角色示意图》（文字版）

把「钱—单—货」三条线叠在一起看（→ 表示流转方向）：

发货人 ──(交货)──▶ 承运人 │ │ │ 签发 3/3 正本 B/L │ 货物装船出运 ▼ ▼ 发货人 ──(交单+背书)──▶ 议付行/通知行 ──(审单相符)──▶ 开证行 │ │ │ 拿到货款（或议付对价） │ 垫款承付 ▼ ▼ 受益人收款 ◀───────────── 申请人(买方) ──(付款赎单)── 开证行交付 1/3 正本 B/L │ ▼ 买方凭单 ──▶ 目的港提货（该份核销，其余失效） 货：始终随船/车流动，最终在目的港被「持单买方」提取。

关键耦合：银行付款的那一刻，买的是「提单代表的货权」；买方赎单，买回的是「提货权」。所以「全套清洁已装船提单」本质是信用证下银行的抵押品——单证一不符，抵押品不成立，银行不付，链条断。

六、物流商视角：我方在三角里的位置与卡点

货代签发 HBL，处在「承运人（MBL）」与「客户（HBL 托运人/收货人）」之间。我方既不是银行也不是买卖任何一方，却是「单」的实际制造者和流转枢纽——卡点全在这张单上。

  • 卡点一 无单放货：客户（HBL 收货人）没付款赎单却凭保函/电放要求我方放货，我方若放，HBL 下构成「无单放货」须对托运人承担全赔责任（远超运费）。对策：HBL 放货严格凭正本或书面电放授权，且电放前确认已收讫运费与货款状态。
  • 卡点二 客户不赎单、货压港：L/C 下买方拒付或 D/A 承兑后不付，货到港我方海外仓/代理手里，产生堆存费。对策：运输委托单列「目的港无人赎货/拒付时，我方有权转售、退运或拍卖，费用由客户承担」。
  • 反制点（物流商立场）：海外仓放货指令必须与「客户付款状态」绑定；对 OA 客户实行「款到释放最后一批」。客户反制：大买方会要求「凭提单副本+付款承诺先放货」，我方须用保函+尾款锁定，不裸放。
今日口诀：提单是取件码还能转让；三份正本防丢防重提，银行要全套才肯付；货代卡在单的中间，无单放货=全赔、不赎单=压港费自理。把「放货」和「收款状态」焊死，这票才安全。
