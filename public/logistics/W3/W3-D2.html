一、先立住：风险点和费用点是两把尺子，不是一把

新手最容易把「风险在哪儿转移」和「运费在哪儿截止」当成同一个点，结果在 C 组术语上反复吃亏。风险转移看「货在哪一刻脱手」，费用划分看「谁付钱把货运到哪」。这两把尺子在 E/F/D 组基本重合，但在 C 组（CFR/CIF/CPT/CIP）是故意分开的：卖方付运费到目的港/目的地，但风险早在起运港装上船（或交第一承运人）时就转给买方了。

术语风险转移点（何时脱手）费用划分点（运费付到哪）两点的关系
FOB装运港装上船目的港（买方付）重合
CFR装运港装上船目的港（卖方付）分离：卖方付运费但风险早转
CIF装运港装上船目的港（卖方付+投保）分离：同 CFR 且卖方买保险
CPT货交第一承运人目的地（卖方付）分离
CIP货交第一承运人目的地（卖方付+投保）分离
DAP/DPU/DDP目的地（交/卸/完税）目的地（卖方付）重合

三个「以为重合结果亏钱」的真实类型

  • 案例①：CIF 下货在海上全损，买方已按 CIF 价付款赎单；风险早转移，买方只能自己找保险公司，卖方不赔——买方误以为「卖方付保费就该卖方负责」。
  • 案例②：CFR 合同，货到目的港前运费市场暴跌，卖方已按合同价付了高运费，运费差额卖方自己吞——买方不补，因为费用划分点在目的港、买方只管收货。
  • 案例③：CPT 条款，货物在第一承运人处丢失，卖方说「风险已转移我不赔」，但买方还没拿到任何单据，买方两头空——根源是没理解 CPT 风险在交第一承运人时即转。

二、清关义务：EXW 与 DDP 是两个极端

  • 出口清关：除 EXW 由买方办理外，其余 10 个术语均由卖方办理。
  • 进口清关：只有 DDP 由卖方办理（含进口税费）；DAP/DPU 及之前术语均由买方办理。
  • EXW 的坑：规则写「买方办出口清关」，但境外买方在中国根本办不了出口报关。实务里常被迫让卖方代办，导致 EXW「名不副实」——卖方实际承担了本不该有的出口手续与合规责任。
  • DDP 的坑（无底洞）：卖方要办进口清关、交进口关税+增值税+反倾销税+EPR 注册费等。任何一项漏算或目的国政策变动，卖方自己贴钱。报价时若只估了关税没估 VAT 与反倾销税，一票可能亏掉全部利润。
反制点（站在物流商/货代视角）：客户选 EXW 却要你代办出口报关时，必须在委托合同里写明「代报关属代办、合规责任与费用仍由客户承担」；客户选 DDP 时，务必在报价前拿到目的国完整税费与合规清单，并把「政策变动风险」写进价格调整条款。

三、保险义务：只有 CIF / CIP 卖方必须买，险别还不同

  • CIF / CIP：卖方有义务投保。CIP 2020 要求 ICC(A) 一切险；CIF 通常投 ICC(C) 最低险（可约定提高）。
  • 其他 9 个术语：卖方无投保义务，仅有「及时通知买方、使买方能投保」的通知义务。风险转移后货损，卖方不赔、买方自行投保索赔。
  • 险别不足谁承担：CIF 下卖方只投了 ICC(C)（不含偷窃、破碎等），若损失属 C 险不保范围，买方只能自己承担——除非合同特别约定卖方须投 A 险。案例：只投平安险的茶叶受潮（非全损），买方索赔被拒。

四、《术语选择决策树》（四个变量推导）

  1. 运输方式：空运/铁路/公路/多式联运 → 排除 FAS/FOB/CFR/CIF（仅水运），在 FCA/CPT/CIP/DAP/DPU/DDP 中选。
  2. 我方（卖方）想不想控货：要控货/议付 → 选可转让单据友好的 FOB（水运）或 FCA（任何）；不关心控货 → CPT/CIP。
  3. 客户信用与收款风险：客户信用差 → 尽量 EXW/FCA 早脱手、早收款；或坚持预付。
  4. 我方能否控制目的港：能控制且愿担责 → DAP/DPU/DDP；控制不了 → 绝不选 D 组，防止在目的国被卡。
  5. 特殊：卖方想「包办到底」收溢价 → DDP（但要算清税费）；买方想「自己清关省税」→ DAP/DPU。
今日口诀：风险看脱手、费用看付到哪；C 组分开是铁律，DDP 完税是无底洞，EXW 代办要写清。 给客户建议术语时，先问「你控不控制目的港」再开口。
