一、为什么最后都找物流商：夹心饼干定律

买卖双方因贸易术语理解不同吵起来时，物流商（货代/承运人）往往是最先、也最容易被告的一方。原因很现实：物流商是「货在手里、单在手里、动作在手里」的那个人——卖方说「货已交」，买方说「没收到」，两边都拿物流商的交接记录、签收单、放货指令说事。所以术语用错，表面是买卖双方的账，最后常变成物流商的官司。

三个典型夹心场景

  • 场景①：FOB 下买方指定船公司，卖方负责把货送进港区装船。装船前货在港区受损，买方说「我没收到货不付款」，卖方说「已交你指定的承运人」，双方都让货代证明「到底谁的责任时段」——货代被拖进鉴定与举证。
  • 场景②：DDP 条款卖方委托货代办进口清关，货代报错 HS 编码导致海关罚没，卖方要货代赔，买方要卖方交货，货代两头受压。
  • 场景③：CIF 下买方以「货损」拒付货款，同时扣着运费不付，货代夹在卖方（要运费）和买方（要赔货）中间。

二、《术语误用风险清单》15 项（法务视角精选）

  1. 把 FOB 用于空运/铁路/公路 → 应为 FCA；错用导致风险转移点、单证性质全错。
  2. DDP 报价漏算目的国 VAT / 消费税 → 卖方自贴，利润归零甚至倒亏。
  3. DDP 漏算反倾销税 / 反补贴税 → 目的港被追缴，卖方承担。
  4. DDP 漏算 EPR / WEEE 注册费（欧盟电子电气）→ 清关受阻，货扣关。
  5. CIF 下买方以货损拒付货款 → 站不住（CIF 是象征性交货，交单即完成，付款义务独立于货损）。
  6. EXW 下境外买方无法办中国出口报关 → 实务被迫卖方代办，责任错配。
  7. FOB 却约定卖方负责目的港清关 → 与术语本质冲突，责任真空。
  8. 合同写「FOB」不写 Incoterms 2020 → 版本适用争议。
  9. FCA 却要求签发已装船提单却未约定 → 结汇受阻。
  10. CPT/CIP 误以为风险在目的地转移 → 中途货损买方找卖方错赔。
  11. DAP 与 DPU 混淆（卸货责任）→ 目的港谁卸货谁担损争议。
  12. CIF 投保仅 ICC(C) 却宣称「全险」→ 货损不保范围买方自担。
  13. 术语与结算方式不匹配（如 DDP + 后 T/T）→ 卖方又担税又担收款风险。
  14. 多式联运用了只适水运的 FOB/CFR/CIF → 陆段风险无术语覆盖。
  15. 客户口头说「按行业惯例 FOB」却无书面援引 → 争议时无据。

三、FOB 空窗期：最经典的衔接缺口

FOB 的分工是「买方订舱、卖方把货装上船」。但货从卖方仓库到装上船之间，要经陆运、进港区、堆存、吊装——这一段谁负责？ 规则上风险在「装上船」才转买方，所以装船前损失理论上卖方担。但买方指定的承运人/船代一旦接手货（如签收进港区），责任认定极易扯皮。货代若在空窗期为双方传递指令、代垫费用，最容易被认定为「实际参与了这一段」，从而被拉进责任。

硬规则：凡 FOB 业务，我方作为货代只做「订舱代理 + 港区交接见证」，所有装船前风险用书面交接单（receipt）固化在买卖双方之间，不越界替任何一方承担。

四、DDP 是卖方的无底洞，也是货代的高危委托

  • 税费不可控：目的国 VAT（如德国 19%）、反倾销税、EPR 注册，任一项漏算即亏损。
  • 合规不可控：进口资质、产品认证（CE/UKCA）、标签，缺一项清不了关。
  • 货代风险：代办公证错、税则归类错、注册遗漏，卖方追责货代。

五、《物流服务合同与贸易术语衔接检查表》+ 切割条款

  • 接单前必问客户：「你的买卖合同用的什么术语？」——我方义务边界由它决定。
  • 确认我方角色：是纯订舱代理（FCA/FOB 常见）、还是签 FBL 的承运人（多式联运）、还是代办清关（DDP 常见）。
  • 凡超出我方能控制范围的（如目的国完税、买方付款风险），不写进我方合同，或写「代办事宜，风险费用客户承担」。
  • 合同必备「责任切割条款」：明确我方仅按约定提供运输/代理服务，不入买卖双方贸易术语下的风险划分；因买卖术语引发的索赔，我方仅在自身过错范围内负责。
今日口诀：术语是买卖双方的分工尺，不是物流商的责任书。接单先问术语、再划我方边界、最后用切割条款把自己摘出来——这是货代法务保命三连。
