一、计费基础：为什么同一个箱子不同渠道价格差一倍

计费重量（Chargeable Weight）= 实际毛重（Gross Weight）与体积重（Volumetric / Dimensional Weight）取大者。这是全行业通行的规则，但「体积重怎么算」各渠道不同：

渠道体积重公式（厘米 / 公斤）泡货系数实务影响
国际快递（DHL / UPS / FedEx）长×宽×高 ÷ 50001:5000泡货（衣服、抱枕）按体积计费，利润被吃掉
空运（Air Freight）长×宽×高 ÷ 60001:6000比快递宽松，是泡货的首选渠道
海运拼箱 LCL按尺码吨或重量吨取大（1 CBM 或 1000 kg）W/M重货按重、泡货按方，临界点常被做文章
海运整柜 FCL按箱型（20GP / 40GP / 40HQ）按柜与重量无关，但受目的港限重约束
记忆点：分母越小，体积重越大，越贵。快递 5000 最狠，空运 6000 次之。同一批泡货走快递和走空运，计费重能差 20%。

为什么法务要懂这个？因为计费争议是最常见的合同纠纷。客户签的是「按重量计费」，实际按体积重收费，客户拒付 → 我方留置货物 → 客户反诉。报价单上没写清「以计费重（取大者）为准 + 体积重公式」，这个官司必输一半。

四、目的港无人提货产生的滞箱费，能不能回头找发货人 / 货代要？

这是跨境物流最经典的争议之一。结论不是简单的「能」或「不能」，取决于提单类型、谁是缔约托运人、货物最终如何处理三个变量。三种典型情形：

情形一：记名提单（Straight B/L），收货人明确且已联系上、但拒绝提货

倾向：承运人应先向收货人主张。记名提单项下，收货人是运输合同的第三方受益人，也是提单约定的提货义务人。此种情况下，承运人直接回头找发货人（托运人），法院支持度较低。我方可争点：若我方是缔约承运人，仍可能被上游船公司依订舱协议追收，因此必须在与客户合同中约定「托运人对目的港费用承担连带责任」。

情形二：指示提单（Order B/L）或收货人失联、无人提货

倾向：承运人可以要求托运人承担。因为指示提单下托运人仍是提单权利人，负有最终的处置义务；货物长期滞留产生费用，属托运人不作为造成的损失。我国《海商法》下承运人对货物享有留置权，并可在符合法定条件时申请拍卖，拍卖所得不足清偿的部分有权向托运人追偿（具体条文号与现行有效版本须核对）。

情形三：我方是货代（缔约承运人），货已由船公司放给第三方，或货物已被海关罚没 / 弃置

倾向：对我方最不利。船公司依订舱协议向我方收滞箱费（合同相对性），而我方向客户追偿时，客户往往已失联或无执行能力。结果：滞箱费落在我方头上。这就是轻资产货代最典型的死法——上游按合同收你，下游按人跑路。

⚠ 待核实 / 提示
给法务的三条硬规则：① 订舱协议里争取与下游客户合同「背靠背」，费用口径与免费期完全一致；② 合同中明确「目的港无人提货时，托运人授权我方代为弃置 / 拍卖，费用由托运人承担」；③ 建立目的港超期预警机制（如到港后 7 天未提货即触发客户通知与费用预估），把损失控制在早期。
