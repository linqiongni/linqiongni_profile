「模糊化但合法」十大起草技法（总部义务安全写法总纲）

依据：条例第11条第4项＋第14条＋北京高院68号文第13条（是否盈利非根本目的）＋本库 H4 节（持续服务三层结构、七技巧、证据力三档）。

技法写法防什么
① 三层结构合同正文只写"类别＋频次下限＋提供方式"；量化细则（次数/时长/单价/超次收费/触发条件）放《附件三·服务内容清单》；操作步骤放《运营操作手册》/SOP。手册是交付物不是承诺把"具体内容方式"落到附件，正文不被结果绑死
② "不少于"不写"每次""每季度不少于1次"而非"每季度1次"留弹性，偶发少一次不违约
③ 主动/响应分开写主动服务写频次下限；响应服务写"5个工作日响应""48小时响应"把"随时响应"改成可量化时限
④ 写触发条件（附条件）"乙方提出书面需求后""新菜品上线时"才触发把总部义务绑定乙方动作/客观事件
⑤ 额外服务收费超出附件三范围/频次的，另协商计费超额服务不进免费义务
⑥ 加盟商不配合免责乙方未参加培训/拒巡店/不整改→视为已履行，费用归乙方防"我方想服务你不让"被反咬
⑦ 只写行为义务"提供指导/培训/督导等行为"，不保盈利（68号文第13条）盈利不佳≠根本违约
⑧ 服务确认条款交付后5个工作日异议期，逾期视为确认制造"已提供"证据闸门
⑨ 合理调整权甲方有权据品牌/法规/食安调整内容形式（线下改线上），不降低实质即不违约应对104号令食安升级等变动
⑩ 引用手册/标准为准所有"标准"指向《运营操作手册》《单店营运标准》具体数字不写死在合同正文

第17条 总部义务总则（三层结构声明 + 模糊化总纲）

【条款文本】

17.1 甲方依据《商业特许经营管理条例》第14条，向乙方提供经营指导、技术支持、业务培训等持续服务。服务的具体内容、频次下限、提供方式与标准，以本合同正文、附件三《服务内容清单》及甲方现行《运营操作手册》《单店营运标准》为准；甲方有权根据品牌发展、食品安全规范（市场监管总局令第104号）及法律法规变化，合理调整服务内容与标准，调整前提前30日通过企业微信或系统公告通知乙方。

17.2 本合同约定之服务义务均为行为义务（提供指导、培训、督导等行为），不以乙方门店盈利或特定经营结果为承诺或保证（参见《条例》第11条及北京高院68号文第13条：是否盈利不属于特许经营合同根本目的）。

17.3 甲方提供服务后，乙方应在5个工作日内签署《服务确认单》或在系统中点击确认；逾期未提出异议的，视为乙方已确认甲方按约提供服务。

【起草说明：为什么这么写 / 防什么风险 / 加盟商反制点】

为什么这么写：第11条第4项要求写明"具体内容方式"，但不能写成结果承诺。17.1 用"三层结构"（正文＋附件三＋手册）把量化细则外移；17.2 把"不保盈利"落到法条（68号文第13条），避免被认定为隐含盈利保证；17.3 是 H4 七技巧⑧的服务确认闸门。

防的风险：加盟商以"总部未提供持续服务"为由，依民法典第563条第1款第(四)项解除并退费（H4 判决三档：部分提供＋双方过错按过错比例，成都青羊案特许人担70%；完全未提供→全额退）。

加盟商反制点：若甲方长期不服务、且乙方曾及时催告异议（西安(2025)陕01知民终178号：未举证曾催告=有过错，反推已催告无响应=甲方过错），确认条款不能对抗；确认单若系空白/代签/未实际培训则无效。

我的落地动作：签约时配套签署《附件三·服务内容清单》+《运营操作手册》收讫单（骑缝章+每页小签），使17.1的"以手册为准"有辅证；每次服务后5日内发《服务确认单》企微催签。
加盟商反制点：乙方可在签约时要求把"不少于"的下限（如集训每年2次、巡店每半年1次）明确写入附件三并作为合同一部分，防止甲方把义务无限稀释到手册里。

第18条 开业前义务（分级：开业前）

【条款文本】

18.1 甲方在乙方签约后、开业前，提供下列服务（具体频次与时长以附件三为准，不低于下列下限）：

（一）选址评估：对乙方候选商铺出具《选址评估意见书》不少于1份；

（二）装修设计：提供统一 VI/SI 标准图集及1次装修图纸审核；

（三）筹建培训：组织乙方及核心员工参加开业前培训不少于3天/24学时，含食安、出品、服务、系统操作；

（四）设备物料清单：提供统采设备与开业物料清单及供应商对接；

（五）系统开通：开通甲方统一收银/订货/会员系统账号并培训使用。

18.2 上述服务为甲方主动提供义务；乙方应按甲方通知的时间地点配合参与，逾期未参与的，视为甲方已履行该项义务，相关责任与费用损失由乙方自行承担。

【起草说明：为什么这么写 / 防什么风险 / 加盟商反制点】

为什么这么写：开业前义务是一次性/阶段性义务，最易举证（有签到、有交付物），写清下限即可。18.2"乙方不配合=视为已提供"是 H4 技巧⑥。

防的风险：加盟商称"总部没帮我选址/没培训"（H4：无记录=视为未提供，故每项下必须留签字证据）。

加盟商反制点：若甲方仅发模板图集、未实际出具评估意见或培训走过场（无实质内容），法院可认定未实质履行（H4：完全未提供任何服务→全额退，四川自贸区案退74,980元）。

我的落地动作：选址评估意见书、培训签到表、系统开通记录一律纸质+乙方签字+骑缝章；培训课件现场拍照带日期水印存档。
加盟商反制点：乙方可主张"3天/24学时"是下限，甲方只给1天即违约，故甲方须按上限留痕，不能反向缩水。

第19条 开业时义务（分级：开业时）

【条款文本】

19.1 乙方开业当日及前后各3日内，甲方指派营运督导到场支持，提供带店指导（含开业活动落地、人员排班、出品动线校准、系统对账）。

19.2 甲方在乙方开业后15日内，对门店进行1次开业验收，出具《开业验收报告》；验收不合格的列明整改项并约定复验时间。

【起草说明：为什么这么写 / 防什么风险 / 加盟商反制点】

为什么这么写：开业时义务是短窗口，明确"到场支持"与"验收"两个动作，留《带店记录》《验收报告》证据。

防的风险：加盟商称"开业没人管"，导致后续把开业不顺归咎总部。

加盟商反制点：督导仅到场拍照、未实质指导，乙方可举证主张未提供（需乙方留存现场记录反证）。

我的落地动作：《带店记录表》双方签字+现场照片；《开业验收报告》列整改项并约定复验日，归档入店档。
加盟商反制点：乙方可要求督导到场天数写入附件三（如"不少于2个工作日"），防止甲方派人不做事。

第20条 持续服务义务（分级：持续，模糊化核心）

【条款文本】

20.1 合同期内，甲方持续提供下列服务（具体频次下限、方式、触发条件见附件三）：

（一）经营指导：每季度不少于1次现场或线上经营诊断；乙方提出书面改进需求的，甲方在5个工作日内响应并出具改进建议；

（二）技术支持：涉及出品标准、设备运维、系统故障的技术支持，甲方在接到乙方通知后48小时内响应，一般问题7日内解决；

（三）业务培训：每年组织不少于2次总部集训（线上/线下），新菜品/新系统上线时另行组织专项培训；

（四）督导巡店：甲方每半年不少于1次现场巡店，出具《巡店报告》并双方签字确认；

（五）系统支持：统一系统持续运维、版本升级、数据备份；

（六）新品与营销：甲方根据品牌规划不定期推出新品与营销活动，相关物料与方案通过系统推送，乙方应按甲方统一要求执行。

20.2 甲方依本条提供的服务，按附件三标准执行；超出附件三范围或频次的服务（如乙方专项咨询、驻店辅导），双方另行协商并计费。

20.3 甲方有权根据经营需要调整服务形式（如线下改线上、集中改直播），不降低服务实质内容即不视为违约。

20.4 乙方应按甲方统一营运标准经营，配合巡店、整改与数据报送（详见第23条）；乙方连续2次无正当理由拒绝巡店或拒不整改的，视为甲方已尽持续服务义务。

【起草说明：为什么这么写 / 防什么风险 / 加盟商反制点】

为什么这么写：20.1 把"经营指导/技术支持/业务培训"三件套分别写，每类用"不少于＋响应时限＋触发条件"＝H4 技巧②③④落地；第(六)项用"不定期"＋"按统一要求执行"模糊化。20.2 额外服务收费（技巧⑤）。20.3 合理调整权（技巧⑨）。20.4 不配合免责（技巧⑥）。

防的风险：同时满足第11条第4项"具体内容方式"要求，又不被结果承诺绑死；防加盟商以"服务不达标"解约。

加盟商反制点：若甲方"多年未组织集训、从未巡店、对书面需求无响应"，即便有20.4，乙方能举证"曾催告且无响应"则甲方仍根本违约（H4：西安案未举证催告=过错，反推已催告无响应=甲方过错）；且20.1的"不少于"是甲方义务下限，甲方低于下限即违约。

我的落地动作：把20.1六项全部拆成附件三的量化表（次数/时长/单价/超次收费/触发条件）；巡店报告强制双方签字，乙方拒签则现场拍照+企微送达留证。
加盟商反制点：乙方可固化"甲方响应超48小时/7日未解决"的工单记录，作为甲方违约证据用于减费（民法典第582条）。

第21条 独立经营、自负盈亏（总部免责地基）

【条款文本】

21.1 乙方系独立经营主体，自主经营、独立核算、自负盈亏，以其自有全部财产对门店经营债务承担责任。

21.2 乙方与甲方之间仅为特许经营合同关系，不构成任何劳动、合伙、代理、联营或投资关系；乙方及其聘用人员并非甲方员工，甲方不承担乙方用工相关的工资、社保、工伤、人身损害等责任。

21.3 乙方按本合同约定支付各项费用、承担门店经营成本与税费后，门店经营收益归乙方所有，经营亏损由乙方自行承担；甲方不保证乙方投资回报或盈利。

21.4 乙方应自行办理并维护门店营业执照、食品经营许可等资质，自行负责门店场所租赁、装修、用工、采购（统配范围内）等事宜。

【起草说明：为什么这么写 / 防什么风险 / 加盟商反制点】

为什么这么写：21.1–21.3 是总部对加盟商债务/用工/亏损免责的地基；21.4 把办证、租赁、用工、采购的责任明确归于乙方。

防的风险：加盟商破产/欠款，债权人（供货商、房东、员工）向总部追索；员工工伤主张与总部存在劳动关系。

加盟商反制点（刺破面纱）：若甲方实际对门店人财物强控制（统一排班、代发工资、统一收银且资金进甲方账户），法院可能认定劳动关系或连带责任（公司法第23条人格混同；法释〔2025〕4号第5条消费者可请求特许人共同承担责任）。故"独立经营"必须真独立——统收统付须谨慎，工资由乙方发。

我的落地动作：工资、社保由乙方主体直接发放缴纳；收银系统资金结算至乙方对公/个体账户，甲方仅做数据归集不截留；合同加"乙方员工非甲方员工"明示告知。
加盟商反制点：乙方可举证甲方实际控制（排班表盖甲方章、工资甲方代发记录）来击穿21.2的免责。

第22条 合规经营（食安/消防/用工/税务）

【条款文本】

22.1 食品安全：乙方作为食品经营主体，承担食品安全直接责任，严格执行《食品安全法》及甲方《食安操作手册》，落实晨检、留样、4D/6S、进货查验、明厨亮灶等要求，接受甲方及监管部门食安检查。乙方发生食安事故的，应立即上报甲方并承担由此产生的行政、民事及赔偿费用。

红线甲方作为特许人，依据市场监管总局令第104号第9条第4款，不得通过本合同减轻或免除自身依法应承担的食品安全责任；甲方对体系内食安负有管理责任，相关责任依法律规定承担。

22.2 消防与场所安全：乙方负责门店消防、用电、燃气、疏散等安全，按规配备器材并年检，承担相应安全责任。

22.3 用工合规：乙方依法与员工签订书面劳动合同、足额缴纳社保、发放工资，不得拖欠；乙方用工纠纷自行负责，不得牵连甲方。

22.4 税务合规：乙方依法申报纳税，不得借甲方名义偷逃税款；统配采购应取得合规发票。

22.5 乙方违反本条第1–4款致行政处罚、民事赔偿或品牌损害的，甲方有权依违约责任条款追究，并可视情节要求整改、扣保证金或解除合同。

【起草说明：为什么这么写 / 防什么风险 / 加盟商反制点】

为什么这么写：22.1 是104号令第9条第4款红线的安全写法——不写"全由乙方自负"，写"乙方承担直接责任"＋括号内明示总部责任不免除（违反依104号令第27条罚5万以下）。22.2–22.4 把消防/用工/税务责任归于乙方。

防的风险：食安事故总部被牵连（法释〔2025〕4号第5条消费者可诉特许人共同责任；104号令总部管理责任）；用工/税务连坐。

加盟商反制点：若总部强推统配原料且原料本身不合规致事故，总部作为供货方/特许人仍担责，不能借本条免责；乙方可主张共同责任。

我的落地动作：把"食安直接责任+总部责任不免除"整段加粗；统配原料索证索票由甲方留底；门店食安检查纳入巡店报告（第20.1(四)）。
加盟商反制点：乙方可凭104号令第9条第4款主张合同中任何"食安与甲方无关"表述无效，并在事故中要求总部共担。

第23条 配合督导与检查

【条款文本】

23.1 乙方应配合甲方依第20.4条及《运营操作手册》进行的督导、巡店、稽核，按《巡店报告》限期（一般15日）完成整改并书面反馈；整改不合格的，甲方可再次巡店，费用（差旅+服务费 __元/次）由乙方承担。

23.2 乙方应按月（每月5日前）通过甲方系统报送真实、完整的营业额数据，并配合甲方依第9条（管理费稽核）进行的账簿/流水/税务/库存核查。

23.3 乙方门店应接受甲方及监管部门的不定期检查；甲方检查时，乙方应开放场所、系统、账簿，不得隐瞒或拒绝。

23.4 乙方拒不配合巡店、整改或稽核，或提供虚假数据的，构成违约，甲方可依违约责任条款处理；连续2次或情节严重的，甲方有权解除合同。

【起草说明：为什么这么写 / 防什么风险 / 加盟商反制点】

为什么这么写：配合督导是总部"持续性义务"（S节：特许人负维护区域秩序持续性义务）的对价，也是总部举证"已提供服务"的抓手（H4 证据力三档：乙方签字的巡店报告=强证据）。23.2 衔接第9条营业额稽核（瞒报按少缴管理费3倍）。

防的风险：加盟商隐瞒数据、拒绝整改，导致总部无法证明已督导、也无法核出瞒报。

加盟商反制点：巡店/整改要求超出合同与手册范围、或借巡店强制搭售，乙方可拒；整改费用须有合同依据（河南商丘(2025)豫14民终86号：未走完程序无权扣）。

我的落地动作：巡店报告双签+整改通知书送达回证；整改服务费标准写入附件三，避免"__元/次"留空被争议。
加盟商反制点：乙方可要求巡店频次、整改费用上限写入合同，防止甲方以巡店为名频繁扰店或变相收费。

第24条 经营资源保护与保密

【条款文本】

24.1 乙方应妥善使用甲方授权的商标、装潢、配方、手册、系统等经营资源，不得超范围使用、不得擅自改动、不得许可第三方使用。

24.2 乙方对甲方经营资源（含配方、成本、供应商、营销方案、系统数据）负保密义务（详见保密条款及《条例》第18条第2款、办法第7条），合同终止后保密义务持续。

24.3 乙方不得仿冒、抢注甲方商标/装潢/新媒体账号，不得诋毁甲方品牌（反法2025第7/12条）。

【起草说明：为什么这么写 / 防什么风险 / 加盟商反制点】

为什么这么写：保护经营资源=总部核心资产（N节）。24.2 衔接后合同保密义务（条例第18条第2款、办法第7条：终止后仍负保密义务）。

防的风险：加盟商学完即自立门户/抢注/泄露配方成本。

加盟商反制点：保密范围须合理（商业秘密司法解释第3条"不为公众所知悉"），若配方已公开则不受保密约束；竞业限制须有补偿，本条不写竞业，竞业另议。

我的落地动作：核心配方/成本给系统权限+水印+禁下载；纸质SOP塑封编号骑缝章；终止后3日内撤销权限并收回纸质手册。
加盟商反制点：乙方可主张已公开信息（如公开菜谱）不在保密范围，拒绝宽泛保密要求。

义务履行证据留存清单（谁控制谁举证 · 能签字绝不用单方记录）

① 特许人举证"已履行服务义务"→ 出示签字确认单/巡店报告/系统日志（H2 L4层、H4 证据力强档）。
