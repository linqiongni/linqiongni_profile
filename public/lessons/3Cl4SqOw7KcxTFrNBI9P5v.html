立场：特许人（品牌总部）。每条附「加盟商反制点」。

法规版本：《商业特许经营管理条例》（国务院令第485号，2007.5.1施行，现行有效）；《民法典》（2021.1.1施行）；《公司法》（2023年修订，2024.7.1施行）；《食品安全法》（2021年修正）；《备案管理办法》按2023版口径执行。

典型风险资金占用大、扩张慢；用工与食安责任全部自担特许经营合规（两店一年/备案/信披）；过度管控被认定实质控制而连带担责总部实际经营→食安、用工、消费者责任实锤；受托人善良管理人义务（民法典第929条）三重法律关系叠加定性混乱；员工离职股权回购争议；被认定实质特许分特许人的资格与备案问题；区域代理越权签约；两层加盟商管理失控

1.2 三个必须记住的边界

边界一：托管不是加盟，但更危险。 托管模式不受《条例》约束，看起来规避了「两店一年 + 备案」，但总部实际派人经营，食安、用工、消费者的责任全部落在总部身上，比加盟的风险敞口大得多。加盟最大的法律优势恰恰是「责任隔离」——托管把这个优势主动放弃了。

边界二：名为合作、实为特许，规避不掉。 不少品牌为规避备案，把合同写成《品牌服务协议》《供货协议》，只收「品牌服务费」「首批货款」。法院按实质重于形式认定：只要同时满足「经营资源许可 + 统一经营模式 + 收取费用」三要素（《条例》第3条第1款），即认定为特许经营合同。被认定后的后果是：行政处罚（未备案 1-5 万，逾期仍不备案 5-10 万并公告）+ 合同按特许经营规则处理（冷静期、退还费用等）。

边界三：分特许人的合规地位有争议，优先用「区域代理」结构。 商务部备案系统的备案类型本身就分「直接特许」与「分特许」两类。分特许人作为二级特许人从事特许经营活动，理论上应符合《条例》对特许人的要求（包括企业主体、经营资源授权链完整）。各地商务主管部门口径存在差异，落地前必须向属地省级商务主管部门核实。 规避方案：让区域代理只做「招商与督导服务」，加盟合同仍由总部与终端加盟商直签，代理收取佣金——法律关系变成服务合同，规避二级特许的合规负担。

二、米线加盟品牌全部收入项拆解

2.1 收入项全表

收入项典型金额（米线/快餐品类）法律定性是否可退退费争议高发度法院通常怎么判
加盟费（一次性）8-25 万元特许经营费（特许权对价），属于「销售无形资产」原则不退，但有 5 个例外高见 2.2
保证金3-10 万元履约担保，不是价外费用，收取时不开票不纳税条件成就应当退还高扣除欠付费用与应赔偿金额后必须退还；以「有争议」为由长期扣押通常不被支持；合同明确约定「争议解决后 X 日内退还」的，可被支持
管理费/特许权使用费月营业额 3%-8%，或固定 2000-8000 元/月特许经营费（持续性）已提供服务期间不退中已服务期间不支持退还；合同解除后继续占用品牌经营的，仍需支付

设备款15-40 万元买卖合同已交付不退中已交付不支持退还；设备存在质量问题的走买卖合同违约/质保路径，与加盟费退还无关
装修/设计费5-15 万元承揽合同 / 设计服务已履行不退中已履行部分不退；因总部原因解约的，可作为损失赔偿的一部分主张
培训费0.5-2 万元服务费未培训应退低未实际提供培训的，应退还。举证责任在总部——必须留存签到表与培训记录
推广宣传费营业额 1%-3%，或固定收取总部代收代付，或自营服务收入视定性中《条例》第15条：应按约定用途使用，使用情况应及时向被特许人披露。加盟商质疑「钱花哪了」时，总部负有举证责任——必须单独建账
系统/软件使用费2000-10000 元/年服务费低低已开通的不退

续约费加盟费的 30%-50%特许经营费不退低已续约并履行的不退
转让/过户费1-5 万元服务费视履行低已办理的不退；总部无正当理由拒绝同意转让的，加盟商可主张总部滥用权利

2.2 加盟费退还的裁判规律（核心，务必记住）

按解除事由分档，这是实务中判断案件走向的第一把尺子：

解除事由法院通常支持的退还比例依据与逻辑
冷静期内单方解除（《条例》第12条）80%-95%（扣除已提供服务的合理对价 5%-20%）冷静期是法定要求约定的条款，期限内解除是加盟商的权利；总部可扣除已实际发生的培训、选址等成本，但需举证
因总部欺诈（虚假宣传/收益承诺）撤销合同（《民法典》第148条）80%-100%，另可能赔偿部分直接损失撤销后自始无效，返还财产（第157条）。注意除斥期间：自知道或应当知道撤销事由之日起 1 年（第152条）
因信息披露不实解除合同（实质影响标准）50%-100%，取决于瑕疵对合同目的的影响程度北京高院指导意见、上海高院解答的「实质影响标准」：隐瞒或虚假的信息必须对合同目的实现产生实质影响
总部违约（未提供持续支持）30%-80%，按违约程度酌定已履行部分对应的对价不予返还，未履行部分返还
加盟商自身原因（经营不善、市场变化）0%-30%，多数不支持商业风险自担是基本原则。加盟费是取得特许权的对价，不是经营成果的保证
合同无效（总部不具备特许人资格，如企业以外的其他单位和个人作为特许人，违反《条例》第3条第2款）全额返还 + 按过错赔偿损失无效合同自始无效，但总部明知自己无资格仍签约的，可能被认定承担主要过错

⚠️ 上述比例是裁判经验区间，不是法律规定。个案差异很大，取决于合同条款、履行程度、双方过错、证据充分度。

加盟商反制点： 加盟商律师最常打的三个点——

  1. 把「加盟费」论证为「预收的特许权使用费」，主张按未履行期间比例返还；
  2. 把「保证金」论证为「变相加盟费」，主张一并返还；
  3. 把「设备款/首批货款」论证为「加盟的捆绑条件」，主张属于加盟损失的一部分。

总部防守： 在合同中明确每一笔款项的法律性质、对价内容、不退的理由，并让费用结构与信息披露文件完全一致。

三、个体工商户 vs 有限责任公司：总部的取舍

3.1 对总部的利弊对比

维度个体工商户有限责任公司
责任财产经营者无限责任：《民法典》第56条——个人经营的以个人财产承担，家庭经营的以家庭财产承担，无法区分的以家庭财产承担股东以认缴出资额为限。但一人公司可穿透：《公司法》（2023修订，2024.7.1施行）第23条第3款——只有一个股东的公司，股东不能证明公司财产独立于股东自己财产的，应当对公司债务承担连带责任
追偿便利性可追索经营者个人及家庭财产，穿透力强；但财产线索查找难（房产、车辆、存款需逐项查）只及于公司财产；认缴未实缴的，可在未出资本息范围内主张（《公司法》第54条加速到期规则）
诉讼主体个体工商户字号 + 经营者为共同诉讼主体公司为被告
注销后追责注销不免除经营者责任（《民法典》第56条）注销后主体消灭；违法注销（未依法清算）可追股东责任
合规能力弱：制度、台账、社保往往不完善 → 食安与用工违规率高，易牵连品牌较强：有财务、有制度
抗风险能力弱 → 更易弃店跑路，总部兜底压力大较强
多店发展一家个体户开多店，关系复杂便于股权设计与多店扩张
加盟商接受度高（成本低、设立快）→ 招商转化率高低（设立与维护成本高，加盟商有抵触）
税务增值税小规模纳税人为主；2022年《促进个体工商户发展条例》（2022.11.1施行）后仍有税收优惠，但核定征收已大面积转为查账征收一般纳税人可开专票，供应链进销项匹配规范

3.2 总部的推荐选择：要的不是主体类型，是「实际控制人连带担保」

结论先说：主体类型不是关键，担保结构才是关键。 无论加盟商用哪种主体，都必须把「实际控制人 + 其配偶」拉进来承担连带责任保证。

分层策略：

场景推荐主体配套要求
单店/首店、三四线城市、投资额 < 50 万接受个体工商户经营者本人 + 配偶作为共同签约人或连带责任保证人
多店/区域发展、一二线城市、投资额 > 80 万要求有限责任公司控股股东（持股 51% 以上）+ 其配偶提供连带责任保证
战略客户/区域代理有限责任公司，且注册资本实缴母公司或实际控制人担保 + 资产证明

理由：

  • 个体户的无限责任看起来是对总部有利的，但执行难度抵消了这个优势——个体户名下往往无财产，查线索成本高。真正的保障是「有财产的保证人」。
  • 一人公司的穿透规则（第23条第3款）虽然存在，但举证责任在债权人，且需要启动诉讼才能穿透，成本高。不如事前签保证合同。
  • 强行要求所有加盟商注册公司，会显著降低招商转化率——这是业务部门最在意的，法务不能只算法律账。

保证合同的关键条款（缺一无效力）：

  1. 保证方式必须写明「连带责任保证」——不写或写「一般保证」的，《民法典》第686条第2款规定视为一般保证，一般保证人享有先诉抗辩权，对总部极为不利。
  2. 保证范围：主债权 + 违约金 + 损害赔偿金 + 实现债权的费用（律师费、保全费、公证费）。
  3. 保证期间：约定为主债务履行期届满之日起3 年——未约定的，《民法典》第692条第2款规定为主债务履行期届满之日起6 个月，极短，务必写清楚。
  4. 配偶共同签署：涉及夫妻共同财产，《民法典》第1064条要求共同意思表示，配偶不签字则难以执行共同财产。

加盟商反制点： 加盟商会主张「要求配偶签字是格式条款加重对方责任、侵犯婚姻自主权」。 总部防守：

  • 保证合同单独签署，不并入加盟合同正文，避免被认定格式条款；
  • 加粗、下划线提示，并让保证人手抄「本人已充分知悉保证责任及法律后果」；
  • 在合同中说明合理性（担保的是品牌资产与消费者权益，非无因加重）。

五、今日三个可执行动作

  1. 查家底：把蒙自源（或你手上任何加盟品牌）现行的加盟合同、费用表、招商手册调出来，逐项对照第二节表格，看每一笔收入在合同里有没有写明「法律性质」和「不退理由」。写不清的，就是未来的退还敞口。
  2. 查保证结构：随机抽 10 份已签加盟合同，看保证合同是否单独签署、是否写明「连带责任保证」、保证期间是否写了 3 年、配偶是否签字。缺一项，那份合同的追偿能力就打折扣。
  3. 建费用对照表：把「合同 / 信息披露文件 / 备案合同样本 / 招商话术」四处的费用口径做成一张对照表，标红所有不一致的地方——这是最低成本、最高回报的一次风险排查。
