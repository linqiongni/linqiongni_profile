招商物料合规审查清单（8 维度 · 可复用）

适用范围：招商手册 / 官网落地页 / 招商会 PPT / 短视频直播 / 朋友圈社群 / 户外电梯 / 第三方平台 / 销售话术 · 特许人立场
使用方式：每份物料上线 / 交付前，逐维度勾选核查。任一项命中「常见违规」即打回修改；本清单为审查框架，不含具体案例答案。配套《物料审核意见表》走五步 SOP（提审→法务审→出意见→修改复审→归档≥3年）。

① 绝对化用语（最高级 / 唯一性 / 国家级）

审查要点

排查一切「国家级、最高级、最佳、第一、唯一、销量冠军、最值得、顶级、极致、万能、领导品牌、销量第一、领跑者、首选」等表述，含中英文变体、谐音、图形暗示。

常见违规表现

类型典型话术风险
最高级行业第一 / 最值得加盟 / 销量冠军绝对化用语，广告法第9条第(三)项
唯一性唯一推荐 / 独家配方 / 唯一指定同上，且易构成虚假
权威背书国家级 / 国家品牌 / 央媒上榜第9条第(二)项，借国家机关或媒体
驰名商标国家驰名商标 / 中国驰名商标商标法第14条第5款禁止用于宣传；广告法第9条

核查动作

1) 全文检索上表关键词；2) 删除或改为可证伪的相对表述（「区域能见度较高」）；3) 若有真实排名，改标「据 XX 机构 XXXX 年报告位列第 X」并备出处。

法条依据

《广告法》第9条第(二)(三)项 + 第57条（罚 20 万–100 万）；《商标法》第14条第5款（禁用「驰名商标」宣传）；市场监管总局《广告绝对化用语执法指南》(2023) 对招商「一般不认为轻微」。

② 收益承诺（回本 / 盈利 / 流水 / 单店）

审查要点

任何落「收入侧 / 回本 / 盈利」的结论性表述均禁写；只可客观列「投资预算（支出侧）」。单店营业额、日均单量配赚钱词、回本周期、包盈利、0风险、补差额一律红线。

常见违规表现

类型典型话术风险
回本周期8个月回本 / 半年回本条例第17条第2款 + 第27条
盈利保证包盈利 / 稳赚不赔 / 0风险同上 + 广告法第25条
具体收益月入3万 / 月净利润6万条例第17条 + 信息披露办法第6条
单店展示某店月流水42万 / 老王一年买房办法第6条「单个被特许人」+ 广告法第25条(二)
补差承诺赚不到总部补差额条例第17条 + 民法典欺诈风险

核查动作

1) 划掉所有「回本 / 盈利 / 月入 / 流水 / 稳赚 / 0风险 / 补差」；2) 收益测算页改为「投资预算表（含加盟费/设备/装修/物料/预留流动资金）」，注明「实际经营结果因人而异，本表不构成收益承诺」；3) 单店案例须脱敏并标注「个案，不代表普遍水平」。

法条依据

《商业特许经营管理条例》第17条第2款 + 第27条（责令改正，3万–10万；情节严重 10万–30万，处罚机关实务多为市监局）；《商业特许经营信息披露管理办法》(2012年第2号) 第6条；《广告法》第25条 + 第58条（10万–20万，情节严重 20万–100万）。

③ 数据引证（门店数 / 存活率 / 行业报告 / 第三方）

审查要点

所有统计数据须真实、可随时举证；引用第三方须标明出处 + 发布时间 + 有效期；自家统计可不标出处但须有台账支撑；过期 / 已关闭门店不得继续宣传。

常见违规表现

类型典型话术风险
无出处断言500家无一家亏损 / 存活率95%广告法第11条（未表明出处）
出处不全据《白皮书》显示…（无年份/机构）引证指南第8-9条，出处缺失
过期数据仍宣传已关闭门店数量广告法第28条虚假广告 → 第55条
无法举证遥遥领先 / 覆盖率第一（无统计）第11条 + 第28条

核查动作

1) 每张含数据的页核对「原始台账 / 报告扫描件」；2) 第三方引用补全「机构名 + 报告全称 + 发布年月 + 有效期」；3) 门店数加统计时点为「截至 XXXX 年 X 月」；4) 建立数据有效期台账，超期下架。

法条依据

《广告法》第11条（引证须真实准确并表明出处）+ 第28条（虚假广告认定）+ 第55条（广告费3–5倍，无法计算 20万–100万）；市场监管总局《广告引证内容执法指南》(2026.6.3) 第8-9、17-18条；《反不正当竞争法》(2025修订) 第9条虚假宣传。

④ 资质展示（荣誉 / 认证 / 专利 / 协会）

审查要点

所有荣誉、认证、专利、协会称号须有原件或官方截图佐证；禁止伪造、禁止用已失效资质；专利须标专利号；不得使用「驰名商标」作宣传；协会称号须为真实在册机构。

常见违规表现

类型典型话术风险
禁用宣传国家驰名商标 / 中国驰名商标商标法第14条第5款 + 广告法第9条
虚构荣誉假协会「五星推荐」「国家认定」反法第9条虚假 + 广告法第4、28条
专利缺失宣称专利但未标专利号广告法第12条（未标明专利号）
资质过期已撤销的认证仍展示第28条虚假广告

核查动作

1) 建《资质原件台账》，每份展示资质对应一份扫描件；2) 删除「驰名商标」字样；3) 专利表述改「本产品采用专利（专利号 ZLXXXX）」；4) 标注资质获取/有效期。

法条依据

《广告法》第12条（专利须标号）+ 第4、9、28条；《商标法》第14条第5款；《反不正当竞争法》(2025) 第9条。

⑤ 商标标识（™ / ® 使用规范）

审查要点

® 仅可用于已下证的注册商标；申请中只有受理通知书用 ™；未下证不得使用 ®，否则构成冒充注册商标。授权链未闭合时不得宣称「受国家保护」。

常见违规表现

类型典型话术风险
冒充注册受理中却标 ®商标法第52条 + 实施条例（冒充注册商标）
夸大保护受国家100%保护 / 别人仿不了绝对化 + 误导
超范围在核定外类别使用 ®同上

核查动作

1) 比对商标注册证核定类别与物料使用类别；2) 未下证统一改 ™ 并加「商标申请中」；3) 删除「100%保护」「仿不了」等绝对化。

法条依据

《商标法》第52条（冒充注册商标处罚）+ 第57条（侵权以同类近似为前提）；实施条例第63条使用标识规范。

⑥ 特许人信息（真实名称 / 关系标识 / 备案）

审查要点

物料须明示特许人真实企业名称、统一社会信用代码；加盟场景下须同时标明特许人与被特许人关系；不得只用品牌名代替法律主体。

常见违规表现

类型典型话术风险
主体缺失仅写品牌名「蒙食源」无公司名上海消保条例第26条（须标特许人+被特许人真实名称标记）
关系不清加盟店未标「特许经营」关系同上，消费者知情权
广告标识缺大众媒介物料未标「广告」广告法第14条

核查动作

1) 封面 / 页脚补「特许人：XX 公司（统一社会信用代码：XXXX）」；2) 加盟店门头 / 物料加「蒙食源特许经营加盟店」；3) 大众媒介广告角标「广告」。

法条依据

《上海市消费者权益保护条例》第26条（特许人须标明真实名称标记，加盟须同时标双方）；《广告法》第14条（广告须可识别）；《商业特许经营管理条例》第21-22条（信息披露含特许人基本情况）。

⑦ 风险提示（招商 / 投资回报广告）

审查要点

凡涉「投资回报预期」的招商广告，须有显著风险提示；招商物料整体应体现「投资有风险、加盟需谨慎」，且不可被收益表述冲淡。

常见违规表现

类型典型话术风险
缺失提示全册无「投资有风险」广告法第25条（须有风险提示）
提示不显著风险提示藏在末页脚注第25条「显著」要求
保本暗示配「稳赚」却无提示第25条第(一)项禁止保收益/无风险

核查动作

1) 手册 / PPT / 视频固定位加风险提示语（如「特许经营有风险，投资需谨慎，本资料不构成收益承诺」）；2) 视频口播同步念出；3) 提示语字号不小于正文、置于显著位置。

法条依据

《广告法》第25条（招商等有投资回报预期广告须显著提示风险，不得保收益/无风险/用受益者推荐）+ 第58条第(七)项（10万–20万，情节严重 20万–100万）。

⑧ 免责声明（格式条款 / 最终解释权 / 以合同为准）

审查要点

物料中的「最终解释权归本公司」类条款属无效格式条款；应设「本资料为邀约邀请，双方权利义务以正式签署合同为准」的有效免责/说明；不得用格式条款排除对方主要权利。

常见违规表现

类型典型话术风险
无效条款最终解释权归本公司所有民法典第497条（排除对方主要权利无效）+ 合同违法行为监督处理办法
单方免责一切以总部解释为准同上，格式条款规制
替代合同物料内容视为合同一部分与披露/合同冲突时效力瑕疵

核查动作

1) 删除「最终解释权」「一切以总部解释为准」；2) 改为「本手册为招商邀约邀请，所有投资测算不构成收益承诺，双方权利义务以正式《特许经营合同》及附件为准」；3) 合同加「招商人员口头/书面承诺未写入本合同者不生效」条款。

法条依据

《民法典》第496-497条（格式条款提示说明义务 + 排除主要权利无效）；《合同违法行为监督处理办法》第11条（经营者不得单方规定最终解释权）；《商业特许经营管理条例》第21-23条（信息披露优先于招商宣传）。
