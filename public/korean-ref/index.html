拼写方块（ syllable block ）

韩文以方块为单位，一个方块 = 初声（辅音）+ 中声（元音）+ 可选终声（辅音）。

布局规则：先左右、后上下。例：
한 = ㅎ + ㅏ + ㄴ ｜ 글 = ㄱ + ㅡ + ㄹ ｜ 사 = ㅅ + ㅏ（无终声）｜ 꽃 = ㄲ + ㅗ + ㅊ

初声永远在左上/左，中声在右或下，终声在底部。一个方块最多两辅音夹一元音。

PART 2 · 发音规则（基础）

终声连音（받침 연음）

终声（方块底部的辅音）后面若接一个以 ㅇ 开头（ㅇ 初声不发音）的音节，终声的发音会移到下一音节的初声。

책이 [chae-gi]（书-主格）→ 不是 [chae-gi] 读作 채기
말이 → 마리 [ma-ri]

紧音化 · 送气化 · 鼻音化

现象条件例子
塞音终声ㄱ/ㄷ/ㅂ/ㅈ 作终声 → 读作 k / t / p / t밥 [bap]
送气化ㅎ 与 ㄱ/ㄷ/ㅂ/ㅈ 相邻 → ㅋ/ㅌ/ㅍ/ㅊ좋고 → 조코
紧音化终声 ㄱ/ㄷ/ㅂ/ㅅ/ㅈ 后接 ㄱ/ㄷ/ㅂ/ㅅ/ㅈ → 紧音학교 → 학꾜
鼻音化终声 ㅂ/ㄷ/ㄱ 后接 ㅁ/ㄴ → 鼻音 ㅁ/ㄴ국물 → 궁물

这些是「听感」规则，读写时仍按原字母拼写，不必改写法——先能听懂、能猜，再慢慢练。

PART 3 · 核心语法

语序：SOV（主—宾—谓）

韩语谓语（动词/形容词）永远在最后。例：

나는（我-主题） 사과를（苹果-宾语） 먹어요（吃）= 我吃苹果。

核心助词（贴在名词后）

助词形式作用
主格이 / 가ㄱ/ㄴ/ㄹ/ㅁ/ㅂ/ㅅ 等辅音后 이，元音后 가
主题/对比은 / 는辅音后 은，元音后 는（은/는 强调主题或对比）
宾格을 / 를辅音后 을，元音后 를
属格「的」의나의 책 = 我的书
到 / 在에时间或目的地：학교에（去学校）
从 / 在（动作）에서动作发生的地点：집에서（在家里）
和와 / 과 / 하고 / 랑와/과 正式，하고/랑 口语
也도나도（我也）
尊称主格께서선생님께서（老师-尊称主格）

이다（是）· 아니다（不是）

非正式礼貌：이에요 / 예요（前音节元音后用 예요，否则 이에요）→ 학생이에요（是学生）。

正式礼貌：입니다 / 입니다 → 학생입니다。

否定：아니다 → 아니에요（不是）。过去：이었 / 였 + 어요 → 학생이었어요（曾是学生）。

있다（有 / 在）· 없다（没有 / 不在）

책이 있어요（有书 / 书在）｜ 책이 없어요（没书）｜ 집에 있어요（在家）

过去：있었어요 / 없었어요。人「在」也用 있다：선생님이 있어요（老师在）。

两种否定

① 안 + 动词词干：안 먹어요（不吃）。

② ~지 않다：먹지 않아요（不吃，更正式）。

时态与常用终结语尾

时态形式例
现在礼貌词干 + 아요/어요가요 / 먹어요
过去礼貌词干 + 았/었어요갔어요 / 먹었어요
将来词干 + (으)ㄹ 거예요갈 거예요
共动「一起」词干 + (으)ㅂ시다갑시다
命令礼貌词干 + (으)세요가세요

现在礼貌的 아요/어요：词干末元音是 ㅏ 或 ㅗ → 아요，其余 → 어요（오다→와요，하다→해요）。

敬语两档：존댓말 vs 반말

존댓말（敬语）：对陌生人、长辈、初次见面用。日常口语用 아요/어요，正式场合用 습니다/ㅂ니다。

반말（平语）：对晚辈、密友、家人用 아/어。对不熟的人用平语会显得无礼。

主语尊称 ~시/으시 与谦语

动词词干加 시/으시 表对主语的尊敬：가시다（去，尊称）。主语尊称助词 께서 替代 이/가。

谦语（抬高对方、压低自己）：드리다（给-谦，对应 주다）、주무시다（睡-尊，对应 자다）、말씀하시다（说-尊，对应 말하다）、드시다（吃-尊，对应 먹다）。

数字两套：固有数词 vs 汉字数词

固有数词（个数、年龄、点数）：하나 둘 셋 넷 다섯 여섯 일곱 여덟 아홉 열（1–10）。

汉字数词（日期、钱、电话、分钟）：일 이 삼 사 오 육 칠 팔 구 십（1–10）。

例：돈 5000원 → 오천 원（汉字）；나이 27살 → 스물일곱 살（固有）。
