PART II · 分合同类型

16 货物进出口（国际贸易）合同仲裁实务

涉外案件的第一风险不是输赢，而是赢了拿不到：仲裁地、公约与可执行性要在签约时就设计好

法条《仲裁法》第 78—88 条（涉外特别规定）《联合国国际货物销售合同公约》（CISG）《民事诉讼法》第 304 条
国际贸易争议的复杂性来自三层规则的叠加：合同与贸易术语（Incoterms）→ 准据法（CISG 或国内法）→ 争议解决与执行（仲裁地、《纽约公约》）。 新《仲裁法》第七章新增的仲裁地制度（第 81 条）与特别仲裁制度（第 82 条）正是为这类案件设计的。

二、起草要点：仲裁条款与实体条款

（一）仲裁条款：涉外案件的重中之重

涉外仲裁条款必须写全五要素

①仲裁机构（或明确的仲裁规则）②仲裁地（Seat）③仲裁语言 ④仲裁员人数与选定方式 ⑤适用的程序法与实体法。 只写"争议提交仲裁"或"仲裁地在北京"而未明确机构的，在中国法下存在被认定仲裁协议无效或无法执行的重大风险 （我国以机构仲裁为原则，新法第 82 条仅在特定情形开放特别仲裁）。

  • 机构选择：中国当事人常见的稳妥组合是 CIETAC／SCIA／SHIAC／BIAC；港资与跨境交易可考虑 HKIAC（香港为中国境内仲裁地，裁决可依《内地与香港相互执行仲裁裁决的安排》及《补充安排》在两地执行）；第三方中立地常用 SIAC、ICC。
  • 仲裁地明确写：新《仲裁法》第 81 条规定当事人可以书面约定仲裁地，仲裁地决定仲裁程序适用法与司法管辖法院，裁决视为在仲裁地作出。这直接决定境外法院能否依《纽约公约》承认与执行。
  • 语言与翻译：约定仲裁语言（中文 / 英文 / 中英双语）；双语庭审须约定翻译安排与费用负担。
  • 适用法：明确约定实体法（中国法 / 香港法 / 英国法 / 纽约州法），并明确CISG 是否适用（可约定"适用 CISG，并以中国法补充"或"排除 CISG，适用中国法"）。
  • 多合同一致：外贸合同、代理协议、供货协议、担保函使用同一仲裁条款；否则同一笔交易要拆成境内外两个程序。
  • 送达与在线开庭：约定境外当事人的送达地址、电子邮件、指定代理人，并同意在线仲裁（《仲裁法》第 11 条）。
涉外仲裁与法律适用条款范本

（二）实体条款

贸易术语

  • 写明Incoterms 版本与地点：如 "FOB Shenzhen, Incoterms 2020"。只写 FOB 不写版本与港口，极易争议。
  • 明确进出口清关、保险、运费、风险转移点，并与合同约定一致。

规格与质量

  • 以附件形式写详细规格（成分、含量、尺寸、公差、包装、标签、认证要求），并约定封样。
  • 约定检验机构（SGS / CCIC / Intertek）、检验时点（装运前 / 到港后）、复检期限与异议方式。

支付与信用证

  • 明确信用证类型（不可撤销、即期 / 远期、是否保兑）、开证期限、单据清单与提交期限。
  • 警惕软条款（如"以买方代表签署的检验证书为付款前提"），应尽量拒绝或改为双方约定的第三方检验机构。

装运与单据

  • 装运期与分批装运、转运是否允许；滞期费与速遣费的承担。
  • 单据清单（商业发票、装箱单、提单、保险单、原产地证、质检证、熏蒸证等）逐项列明。

不可抗力与制裁

  • 不可抗力定义、通知期限、证明文件（贸促会不可抗力事实性证明等）、后果与解除权。
  • 制裁与出口管制条款：约定任何一方被列入制裁 / 管制清单时，对方有权中止或终止履行且不承担责任；陈述与保证合规。

违约与责任

  • 违约金与损害赔偿（CISG 第 74 条含利润损失）；约定责任上限与间接损失排除。
  • 所有权保留与保险安排；汇率与税费承担（关税、增值税、反倾销税）。

组织思路

  1. 单据链优先：国际贸易是"单据交易"，把合同 → PI → 信用证 → 单据 → 付款 → 提货 → 检验的完整单据链按时间排列，缺哪一环就是争点所在。
  2. 双语对照表：中英文合同文本不一致的，制作对照表并注明合同约定的优先文本。
  3. 时间节点的法律意义标注：装运日、交单日、拒付通知日、到港日、检验日、异议通知日——每个节点对应不同的权利存续。
  4. 境外证据的公证认证：境外形成的证据应依规定办理公证认证或依条约办理；电子证据（邮件、平台数据）应公证或第三方存证。

五、常见抗辩思路与实务坑点

坑：仲裁条款只写"仲裁地"

只写"仲裁地为北京"而未约定机构的，我国以机构仲裁为原则（特别仲裁仅限第 82 条的特定情形），条款可能被认定无效或无法执行。机构与仲裁地要同时写。

坑：中英文本冲突

约定"中英文文本具同等效力"却内容不一致时，仲裁庭需解释。应约定优先文本（如"以中文文本为准"）。

坑：未及时发出不符通知

CISG 第 39 条：买方未在实际可行的最短时间内通知货物不符合同的，丧失主张的权利。到货后应立即检验并在约定期限内书面通知。

坑：信用证软条款

"须提交买方代表签署的检验证"等条款使付款完全受制于买方。应尽量删除或改为双方共同指定的第三方检验机构。

坑：FOB 指定货代无单放货

FOB 情形下由买方指定货代，卖方若接受货代出具的境外货代提单，可能丧失对承运人的控制权。应争取船公司提单（Master B/L）并核实货代资质。

坑：海事请求的一年时效

海上货物运输赔偿请求权的时效期间为一年（《海商法》相关规定），远短于一般三年。无单放货、货损索赔务必及时主张。

坑：制裁导致"双重违约"

一方因本国制裁无法履行时，同时面临合同违约与本国法禁止的双重风险。合同须写清制裁条款、中止权、免责与不可抗力条款。

坑：境外当事人送达

境外送达可能耗时数月且影响裁决执行（未获适当通知是《纽约公约》第五条的抗辩事由）。签约时约定送达地址、指定境内送达代理人并同意电子送达。

"仲裁协议无效 / 未约定仲裁机构"① 举证依约定的仲裁规则能够确定机构；② 举证双方实际参与组庭的行为构成认可（注意第 27 条第 3 款的提示与记录要件）；③ 涉外情形下说明报核制度下认定无效的高门槛《仲裁法》第 27、29 条；法释〔2017〕21 号报核规定
"仲裁庭无管辖权，主体不适格"① 适用第 925、926 条确定真正责任主体；② 核对该主体是否签署或并入仲裁条款；③ 未签署的只能另案处理，并考虑中止本案《民法典》第 925、926 条；《仲裁法》第 4 条
"裁决不应被承认与执行（境外执行抗辩）"① 举证仲裁协议有效、程序通知适当、未超裁；② 举证裁决已在仲裁地生效或当事人已放弃追诉；③ 应对公共政策抗辩时说明裁决不涉及我国根本法律原则《纽约公约》第五条；《民事诉讼法》第 304 条
裁判规则要点（供检索核校，不作案号引用）
  • CISG 适用：双方营业地在缔约国的货物销售合同默认适用 CISG，当事人可约定排除或减损；合同的效力、所有权归属不由公约调整，由准据法决定。
  • 异议通知：买方未在合理时间内通知货物不符合同的，丧失主张不符的权利，除非有合理理由；这一规则在国际贸易案件中被高频援引且后果严重。
  • 仲裁地：裁决籍属以仲裁地判断（与《纽约公约》标准一致），新法已明确裁决视为在仲裁地作出，不再以仲裁机构所在地为标准。
  • 仲裁协议效力：涉外案件认定仲裁协议无效适用逐级报核制度，实践中被认定无效的门槛较高。
  • 信用证独立性：信用证与基础合同相互独立，银行只处理单据；欺诈例外须经法院认定并作出止付裁定，且须符合严格条件。
  • 以上为现行法律、公约与公开裁判规则所体现的处理思路摘要，引用具体案件请核校案号与要旨。
