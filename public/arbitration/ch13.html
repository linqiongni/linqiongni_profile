PART II · 分合同类型

13 服务 / 委托合同仲裁实务

服务类案件的胜负手是「标准」两个字：标准写不进合同，验收就永远谈不拢

法条《民法典》第 467、919—936 条（委托）第 925、926 条（隐名代理）合同编通则
服务类合同（IT、咨询、营销、物业、物流、SaaS、代运营、检测认证、维修保养）多为无名合同， 《民法典》没有专门章节，适用合同编通则并参照最相类似合同（第 467 条）； 委托合同则有专章（第 919—936 条），其中任意解除权（第 933 条）与隐名代理规则（第 925、926 条）是实务中最容易踩的两处。

二、起草要点：仲裁条款与实体条款

（一）仲裁条款

  • 选择专业对口的机构与仲裁员：IT、金融、知识产权类服务可考虑约定仲裁员具备相应专业背景（在条款中写明"仲裁员应具备××领域专业经验"）。
  • 保密与仲裁的衔接：仲裁不公开进行（第 52 条）本身就是保密优势；但仍应约定裁决书与案卷的保密处理，并可约定"当事人协议不写明争议事实与裁决理由"（《仲裁法》第 67 条）——对技术秘密类争议尤其有用。
  • 跨境服务：约定仲裁地、语言、适用法律；境外供应商应约定中国境内的仲裁地或选择中国机构，避免境外执行成本。
  • 关联主体一并签署：集团采购、多家关联公司共同使用的服务，须让所有使用方 / 付款方签署或并入同一仲裁条款。
  • 费用负担：约定违约方承担律师费、公证费、专家费用——服务类案件举证成本高，此项价值明显。

（二）实体条款

范围与标准（SOW）

  • 以附件形式写《工作说明书》：交付物清单、里程碑、时间表、验收标准与方法。
  • 标准尽量可量化：可用性 99.9%、响应时间 ≤2 小时、缺陷率 ≤1%、并发数 ≥××。
  • 约定"验收期限＋逾期未提出书面异议视为验收通过"。

变更控制

  • 约定变更必须书面（Change Order），并明确对费用与工期的影响。
  • 未走变更程序的额外工作，双方对费用有争议时的处理机制。

服务级别与违约

  • SLA 指标与违约金（服务信用额度）挂钩，替代模糊的"赔偿损失"。
  • 约定违约金上限（如不超过合同总价的 100%），并明确排除间接损失与利润损失——同时注意格式条款的提示说明义务（第 496、497 条）。

知识产权与数据

  • 明确交付成果的著作权归属、许可范围与源代码 / 原始文件的交付。
  • 数据合规：约定个人信息委托处理的范围、目的、期限、安全措施、跨境传输与删除义务。

人员与分包

  • 关键人员名单与更换条件（更换须经同意或提供同等资质人员）。
  • 分包须经书面同意，受托人对分包方行为承担全部责任。

终止与过渡

  • 约定终止情形、通知期限、终止后的数据返还与迁移、过渡期服务、费用结算。
  • 委托合同如希望限制任意解除权，应明确约定（效力有争议，见本章第七节）。

组织思路

  1. 「标准—事实—结论」三段式：先把合同约定的量化标准摘出来，再用系统数据证明实际表现，最后给出违约结论。避免用形容词描述服务质量。
  2. 工单时间轴：把故障发生、响应、修复、复发的全过程画成时间轴，SLA 是否达标一目了然。
  3. 变更台账：所有超出原范围的请求与完成记录单独成册，是主张增量费用的基础。
  4. 损失限定：服务类案件损失常被责任上限条款拦截，主张方应优先论证该条款不成为合同内容或无效（格式条款、显失公平、故意或重大过失）。

四、常用法律与司法解释条文引用

《中华人民共和国民法典》第九百三十三条 · 委托合同的任意解除与赔偿 委托人或者受托人可以随时解除委托合同。因解除合同造成对方损失的，除不可归责于该当事人的事由外，无偿委托合同的解除方应当赔偿因解除时间不当造成的直接损失，有偿委托合同的解除方应当赔偿对方的直接损失和合同履行后可以获得的利益。 商事有偿委托的解除成本远高于一般认知：解除方可能要赔"可得利益"。这是服务 / 委托类案件最容易被低估的风险点。
《中华人民共和国民法典》第九百一十九条 / 第九百二十三条 / 第九百二十九条 委托合同是委托人和受托人约定，由受托人处理委托人事务的合同（第 919 条）。
受托人应当亲自处理委托事务。经委托人同意，受托人可以转委托。转委托经同意或者追认的，委托人可以就委托事务直接指示转委托的第三人……（第 923 条）。
有偿的委托合同，因受托人的过错造成委托人损失的，委托人可以请求赔偿损失。无偿的委托合同，因受托人的故意或者重大过失造成委托人损失的，委托人可以请求赔偿损失（第 929 条）。
《中华人民共和国民法典》第九百二十五条 / 第九百二十六条 · 隐名代理 受托人以自己的名义，在委托人的授权范围内与第三人订立的合同，第三人在订立合同时知道受托人与委托人之间的代理关系的，该合同直接约束委托人和第三人；但是，有确切证据证明该合同只约束受托人和第三人的除外（第 925 条）。
受托人以自己的名义与第三人订立合同时，第三人不知道受托人与委托人之间的代理关系的，受托人因第三人的原因对委托人不履行义务，受托人应当向委托人披露第三人，委托人因此可以行使受托人对第三人的权利……委托人行使介入权 / 第三人行使选择权后，对方可以向其主张抗辩（第 926 条）。 实务价值：采购代理、外贸代理、平台代运营场景下，正确适用这两条能直接解决"告谁"的问题；但仲裁中受仲裁协议相对性限制，须确保选定的相对方与自己之间有仲裁协议。
《中华人民共和国民法典》第四百六十七条 · 无名合同的法律适用 本法或者其他法律没有明文规定的合同，适用本编通则的规定，并可以参照适用本编或者其他法律最相类似合同的规定。 服务类合同多属无名合同，实务中常参照承揽、委托或买卖的相关规定处理，具体视服务内容而定。
《中华人民共和国民法典》第四百九十六条 / 第四百九十七条 · 格式条款 采用格式条款订立合同的，提供格式条款的一方应当遵循公平原则确定当事人之间的权利和义务，并采取合理的方式提示对方注意免除或者减轻其责任等与对方有重大利害关系的条款，按照对方的要求，对该条款予以说明。提供格式条款的一方未履行提示或者说明义务，致使对方没有注意或者理解与其有重大利害关系的条款的，对方可以主张该条款不成为合同的内容（第 496 条第 2 款）。
有下列情形之一的，该格式条款无效：（一）具有本法第一编第六章第三节和本法第五百零六条规定的无效情形；（二）提供格式条款一方不合理地免除或者减轻其责任、加重对方责任、限制对方主要权利；（三）提供格式条款一方排除对方主要权利（第 497 条）。 服务合同中的责任上限、间接损失排除、单方变更权等条款，常因未尽提示说明义务而被主张不成为合同内容。作为提供方，务必留存加粗、弹窗、单独确认的痕迹。

五、常见抗辩思路与实务坑点

坑：验收标准写"满足甲方要求"

主观标准必然争议。应改为可测量的指标＋客观测试方法＋验收流程与时限。

坑：没有"视为验收"条款

对方一直不验收又不提异议，服务方被迫长期垫资。约定"交付后 N 日内未书面提出异议视为验收通过"是必备条款。

坑：任意解除权的杀伤力

委托合同任何一方均可随时解除（第 933 条），且有偿委托的解除方要赔可得利益。服务方应争取约定解除通知期与补偿标准；委托方应在解除前评估赔偿敞口。

坑：责任上限被认定无效

上限过低、排除故意与重大过失责任、或作为格式条款未尽提示义务的，可能被认定不成为合同内容或无效。合理区间＋非格式条款呈现更稳妥。

坑：分包失控

未经同意的转委托（第 923 条）使受托人对第三方行为承担责任。委托方应约定禁止分包或分包须书面同意＋受托人负全责。

坑：损失举证不足

服务违约的损失往往间接（生产中断、商誉、客户流失）。须证明可预见性与因果关系，并注意责任上限条款的拦截。

坑：知识产权归属空白

定制开发成果未约定归属的，可能依《著作权法》归受托人（作者），委托人仅取得使用许可。合同必须写明著作权（含财产权）归委托人所有＋交付源码与文档。

坑：数据合规责任不清

服务过程中涉及个人信息处理的，须约定委托处理关系、安全措施、跨境传输、删除与审计义务，否则行政处罚与民事责任难以分配。

裁判规则要点（供检索核校，不作案号引用）
  • 验收与视为验收：合同约定了验收期限与逾期后果的，从约定；未约定但接受方实际使用、运行并获取收益的，通常认定为认可交付。
  • 任意解除的赔偿：有偿委托合同的解除方赔偿范围包括直接损失与可得利益，但以可预见性与已举证为限。
  • 责任上限条款：商事主体间约定的责任限制原则上有效；但排除故意或重大过失责任的条款无效，作为格式条款未尽提示说明义务的可主张不成为合同内容。
  • 格式条款：是否"合理提示"看形式（加粗、单独确认）与过程（是否协商、是否说明）两方面，线上服务还看是否有强制阅读与勾选环节。
  • 隐名代理：第三人订约时知道代理关系的，合同直接约束委托人与第三人；不知道的，受托人披露后委托人可介入、第三人可选择相对人，选定后不得变更。
  • 以上为现行法律与公开裁判规则所体现的处理思路摘要，引用具体案件请核校案号与要旨。

七、其他：服务 / 委托合同的两个特别议题

1. 能否约定放弃或限制任意解除权

第 933 条确立的任意解除权源于委托合同的人身信赖属性。商事实践中，双方常约定"非经协商一致不得单方解除，否则支付违约金"。 对该类约定的效力，司法实践存在分歧：一种观点认为任意解除权属强行法规定，约定排除无效；另一种观点认为商事委托中当事人意思自治应予尊重，可约定解除条件与补偿标准。 实务建议：不要指望靠一句"不得解除"锁死对方，更有效的是约定解除通知期（如提前 90 日）、解除补偿标准（如剩余合同价款的一定比例）、以及已完工作量的结算机制——即便解除权被认定有效，经济损失也能被覆盖。

2. 服务类案件要不要申请专家辅助人

IT 系统、工程造价咨询、检测认证、会计税务等专业服务争议，仲裁庭往往缺乏行业背景。 此时一位能讲清行业惯例与技术逻辑的专家辅助人价值极高（申请其出庭并就专业问题发表意见）。 同时，涉及技术事实的，还可考虑在合同中约定专家评审 / 第三方测评前置程序，把争议在进入仲裁前就交给专业机构定性——这比事后鉴定便宜得多。
