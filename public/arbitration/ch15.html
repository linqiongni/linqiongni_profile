PART II · 分合同类型

15 借款合同仲裁实务

本金怎么算、利息怎么叠、保证怎么落——借款案件的胜负在数字与担保，不在法理

法条《民法典》第 667—680 条（借款）、第 681—702 条（保证）民间借贷司法解释（2020 年修正）担保制度解释（法释〔2020〕28 号）
借款类仲裁的两条主线：金额线（本金、砍头息、利率上限、费用叠加、逾期利息）与担保线（保证方式、保证期间、公司对外担保决议、抵押登记）。 这类案件还最容易触发虚假仲裁审查——《仲裁法》第 61 条明确要求仲裁庭驳回捏造事实或恶意串通的仲裁请求。

二、起草要点：仲裁条款与实体条款

（一）仲裁条款

  • 让担保人一并签署：保证合同、抵押合同、质押合同、承诺函、差额补足协议每一份都要单独签署同一仲裁条款——仲裁无第三人制度，缺一份就只能另案诉讼。
  • 约定独任＋快速程序：借款案件事实相对集中，约定独任仲裁员与较短的审理期限能显著加快回款。
  • 送达条款：借款人失联是常态。约定送达地址、电子送达（邮箱、微信）、并约定"地址变更未通知的，按原地址送达即视为送达"。
  • 费用条款：明确律师费、保全费、担保费、公证费、催收费用由违约方承担。
  • 跨境与涉外：境外借款人或担保人的，约定中国境内仲裁地、中文为仲裁语言，并约定适用中国法，便于后续执行。

（二）实体条款

本金与放款

  • 放款金额、方式、时间、收款账户；不得预扣利息（第 670 条）。
  • 分期放款的，写明条件与期限；未按期放款的后果（第 671 条）。
  • 避免以"服务费""咨询费""保证金"变相预扣——会被合并计入利息审查。

利率与费用

  • 利率写成年化并注明计息基础（365 天 / 360 天）；明确单利／复利与复利的计算条件。
  • 所有费用（利息、服务费、违约金、罚息）设置合计上限，明确不超过司法保护上限。
  • 逾期利率与违约金择一或合并设上限，避免被整体调减。

期限、展期与加速到期

  • 借款期限、还款方式（到期一次性 / 分期 / 等额本息）、还款顺序（先息后本还是先本后息）。
  • 加速到期条款：列明触发事件（逾期 N 日、交叉违约、重大诉讼、担保物毁损、实际控制人变更）与通知方式。

保证条款

  • 必须写明"连带责任保证"并加粗——否则按一般保证处理（第 686 条第 2 款），债权人须先向债务人追偿。
  • 明确保证范围（本金、利息、违约金、实现债权费用）与保证期间（建议约定为主债务履行期届满之日起 3 年）。
  • 公司提供担保的，必须取得并留存股东会 / 董事会决议（依《公司法》对外担保规则与章程审查）。

担保物权

  • 不动产抵押必须登记（第 402 条）；动产抵押登记方可对抗第三人（第 403 条）。
  • 约定担保物价值不足时的补足义务与追加担保机制。
  • 避免流押、流质约定（第 401、428 条），改为约定折价、拍卖、变卖的优先受偿。

用途与陈述保证

  • 约定借款用途与违反用途的后果（可触发加速到期）。
  • 陈述与保证条款（主体资格、授权、财务真实性、无重大诉讼、担保物无瑕疵）＋交叉违约条款。

组织思路

  1. 一张本息计算表：本金（实际到账）→ 利率（年化，核对上限）→ 计息区间 → 已还款冲抵 → 欠付本息。所有争议都围绕这张表展开，务必与凭证逐笔对应。
  2. 资金链路图：出借人 → 借款人 → 实际用款人 → 担保人的资金流向。借款案件中"钱去哪了"往往是核心事实（也能识别虚假债务）。
  3. 担保时间轴：签约 → 决议 → 登记 → 主债务到期 → 保证期间起止 → 主张时点。保证期间是借款案件最常被忽略的致命点。
  4. 催告链：到期催告、保证人催告、加速到期通知，每次送达都要留痕。

五、常见抗辩思路与实务坑点

坑：保证方式没写明

民法典生效后，约定不明的按一般保证处理。债权人若未在法定期间内向债务人主张（诉讼或仲裁），保证人免责。合同必须写"连带责任保证"并加粗。

坑：保证期间已过

约定不明仅 6 个月，且不发生中止、中断。很多债权人因长期催债务人而忘了催保证人，最终保证人免责。建议约定 3 年并设提醒。

坑：公司担保无决议

法定代表人越权担保，相对人非善意的，担保对公司不生效。接受公司担保必须审查章程、取得决议、留存回避表决记录。

坑：费用叠加超上限

利息＋服务费＋咨询费＋违约金合计超过 LPR 四倍的，超出部分不予支持。拆分名目不能规避审查，反而增加"变相高利"的认定风险。

坑：砍头息

预扣利息、手续费的，按实际到账数额计算本金与利息（第 670 条）。放款路径设计须合规，转账备注要与实际一致。

坑：职业放贷与无效风险

同一出借人在一定期间内多次向不特定对象放贷的，可能被认定为职业放贷，借贷合同无效，利息不予支持（本金返还）。出借方应评估自身放贷频率与主体资质。

坑：抵押未登记

不动产抵押未登记的，抵押权未设立，债权人沦为普通债权人。签约后应立即办理登记并设置跟踪机制。

坑：虚假债务与虚假仲裁

《仲裁法》第 61 条要求仲裁庭驳回捏造事实或恶意串通的仲裁请求；第 8 条确立诚信原则。以仲裁确认虚假债权对抗另案执行的，风险极高且可能涉刑。

裁判规则要点（供检索核校，不作案号引用）
  • 利率上限：民间借贷利率的司法保护上限为一年期 LPR 的四倍；利息、违约金、其他费用合并计算后超出部分不予支持。
  • 本金认定：以实际到账金额为准，预扣利息的按实际数额返还并计息；"息转本"须满足原利息合法且不超过上限。
  • 保证方式：约定不明的按一般保证；一般保证人享有先诉抗辩权，须在保证期间内对债务人起诉或申请仲裁。
  • 公司担保：法定代表人未经决议擅自担保的，相对人非善意的，担保无效或对公司不生效；债权人负有合理审查义务。
  • 职业放贷：未取得放贷资格的出借人以营利为目的向社会不特定对象提供借款的，借贷行为无效，一般仅支持返还本金及合理占用费。
  • 以上为现行法律与公开裁判规则所体现的处理思路摘要，引用具体案件请核校案号与要旨。

七、其他：借款仲裁的两个特别议题

1. 仲裁程序对"效率型债权"的价值

借款债权最怕拖。仲裁的价值在于：① 一裁终局，避免二审拖延；② 可约定独任与快速程序；③ 不公开，避免债务人商誉受损引发连锁违约，也避免其他债权人挤兑。 配套动作：签约时同步约定送达地址条款与在线仲裁条款（《仲裁法》第 11 条），并在违约后第一时间启动仲裁前保全（第 39 条）。

2. 多主体、多合同的程序安排

一笔融资常涉及借款合同、保证合同、抵押合同、股权质押、应收账款质押、承诺函等多份文件，且各文件签署方不同。 仲裁中不能追加未签署仲裁条款的主体，因此：

  • 所有文件使用同一仲裁条款与同一仲裁机构，尽量约定合并审理（部分机构规则允许经当事人同意的合并）；
  • 无法合并的，采取「主案先行＋担保案跟进」的节奏，并以主案裁决作为担保案的核心证据；
  • 担保人未签仲裁条款的，只能走诉讼——这往往意味着两条战线、两套时间表，须在立案前就规划好。
