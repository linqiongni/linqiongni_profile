PART I · 通用全流程

06 开庭审理

家事庭审的胜负，一半在庭前——本人出庭、情绪管理、抚养方案表格，比临场发挥更决定结果

法条 《民法典》第 1079、1084、1086 条 婚姻家庭编解释（一）第四十四至四十八条、第六十六至六十八条 《民事诉讼法》（2023 修正，条号以现行文本为准）
家事庭审与商事庭审最大的不同，是人坐在庭上。离婚案件本人原则上必须到庭，情绪随时可能冲垮诉讼策略，八周岁子女的意愿要当庭征询， 财产发问里藏着对方没披露的账户线索。律师不能把家事庭审当商事庭审来打——它要求你在「法律攻防」之外，同时承担「情绪教练」「事实导演」「子女利益守门人」三重角色。 本章按下述顺序展开：本人出庭要求 → 不公开审理 → 庭审各环节家事版要点 → 当事人情绪管理 → 最后陈述与庭后工作。 涉及《民事诉讼法》的条文，因 2023 年修正后条文重编号，一律以「《民事诉讼法》相关规定」指代，条号以现行有效官方文本为准。

一、本人出庭要求

《中华人民共和国民事诉讼法》相关规定（离婚案件本人出庭） 离婚案件有诉讼代理人的，本人除不能表达意思的情形外，仍应到庭参加诉讼；确因特殊情况无法到庭的，必须向人民法院提交书面意见。
被告经传票传唤，无正当理由拒不到庭或者未经法庭许可中途退庭的，可以按撤诉处理（原告方）或依法缺席审理 / 拘传（被告方，依《民事诉讼法》相关规定）。 本条为《民事诉讼法》相关规定，2023 年修正后条文序号已重编号，写作时不再引用旧「第 62 条」等记忆条号，条号以现行有效官方文本为准。
  • 离婚案件强制本人到庭：这是身份关系案件的硬要求。即便委托了律师，当事人本人原则上仍须出庭，因为婚姻是否解除涉及身份确认，法院需当面核实本人真实意思。仅有「不能表达意思」（如严重精神疾病、意识不清）可豁免；其他「忙」「在外地」「不想见对方」都不构成不出庭的正当理由。
  • 特殊情况须提交书面意见：确因重病、境外无法按期回国等客观原因不能到庭，必须向法院提交书面意见（对是否同意离婚、子女抚养、财产分割的意思表示），否则法院可能不准许缺席审理，甚至影响程序推进。
  • 无正当理由拒不到庭的后果：原告方按撤诉处理；被告方（离婚案件）法院可依法拘传或缺席审理，视情形而定。家事案件中被告恶意躲庭的，律师应提前准备「下落不明 / 经传票传唤无正当理由拒不到庭」的应对材料，推动法院依法处理。
  • 继承案件的到庭意义：继承纠纷虽无「强制本人到庭」的同等硬规则，但继承人本人到庭对查清「被继承人真实意愿、赡养情况、遗产范围、特殊困难」至关重要。涉及必留份（民法典第 1141 条）、酌情分得遗产（第 1131 条）、尽主要赡养义务多分（第 1130 条）等事实，本人到庭陈述远比书面更可信。放弃继承的，须注意应在遗产处理前书面表示（第 1124 条），到庭时一并固定。
别让当事人「律师去就行」

家事当事人常以为「我请了律师，我自己不用去」。离婚案件这是错的：本人不到庭，法院可不准许代理人单独处理身份关系，案件可能卡住或被按撤诉处理。律师接案时就应把「开庭当天您本人必须到」写进委托事项确认书，并提前安排到庭时间，避免当庭才发现当事人人在外地。

二、不公开审理

  • 离婚案件依申请不公开：离婚案件涉及个人隐私，当事人申请不公开审理的，法院可以不公开（《民事诉讼法》相关规定）。注意是「当事人申请」启动，律师应在立案时或开庭前书面提出不公开审理申请，不要等法庭问。
  • 未成年人利益与隐私保护：家事审判实践中，凡涉及未成年子女姓名、肖像、就读学校、具体住址等信息的，法院普遍采取不公开或脱敏处理。律师也应在提交的文书、证据中主动脱敏（用「×子」「某校」），既是合规，也保护委托人子女。
  • 申请时点与做法：最迟在开庭前提交书面申请；当庭口头申请亦可，但书面更稳。申请理由写「本案涉及夫妻感情、个人隐私及未成年子女权益，申请不公开审理」即可，无需过度展开。
  • 不公开的边界：不公开审理不意味不出具文书——判决 / 调解书仍依法送达当事人，只是庭审过程与文书内容不对外公示。涉及家暴、出轨等敏感事实，不公开审理能显著降低对当事人及子女的二次伤害。
家暴案件的不公开叠加保护令

家暴受害人同时面临安全与隐私双重风险。除申请不公开审理外，应一并审查是否需申请人身安全保护令（详见 ch19）：保护令本身不要求以提起离婚诉讼为前提（人身安全保护令司法解释第一条），且违反保护令可追究拒不执行判决、裁定罪（刑法第 313 条，经保护令司法解释第十二条关联）。不公开 + 保护令，是家暴案件开庭前的标准组合拳。

三、庭审各环节家事版要点

3.1 法庭调查：婚姻缔结与感情过程如何陈述

法庭调查阶段，当事人陈述婚姻缔结、共同生活、感情变化过程时，律师要做的不是「背故事」，而是把事实逐项对号入座到民法典第 1079 条第三款的法定情形：

法定情形陈述要点（律师引导当事人落点）
重婚或与他人同居固定「持续稳定共同居住」证据（解释一第二条：不以夫妻名义、持续稳定共同居住）；时间点、地点、共同生活痕迹，对应用《民法典》相关规定与解释一第二条标准，区别于偶发出轨
家庭暴力或虐待遗弃伤情照片、报警记录、告诫书、诊疗记录、悔过书；经常性谩骂恐吓亦属家暴（反家庭暴力法第二条、保护令司法解释第三条）；持续性经常性家暴可认定虐待（解释一第一条）
赌博吸毒等恶习屡教不改公安机关处罚记录、戒毒记录、屡教不改的证人证言；偶发不算，须「屡教不改」
因感情不和分居满二年分居的起算时间、分开居住的独立证据（租房、居委会证明）；注意是「感情不和」分居，不是因工作、求学分居
其他导致感情破裂的情形如擅自中止妊娠引发感情破裂（解释一第二十三条，按第 1079 条第三款第五项处理）、严重性格冲突、隐瞒重大疾病（民法典第 1053 条）等
  • 主张判离的原告方：陈述须指向上述至少一项，并准备对应证据；若前次被判不准离婚，强调「判决不准离婚后双方又分居满一年再次起诉」（第 1079 条第五款）这一刚性判离情形。
  • 不同意离婚的被告方：陈述聚焦「感情尚未破裂、仍有和好可能、分居原因非感情不和」，把对抗点落在「不符合法定情形」上。

3.2 财产发问环节的攻防

家事案件的财产查明高度依赖当庭发问——对方在庭审中脱口而出的账户、公司、房产，往往是最值钱的线索。

  • 庭前准备好发问清单：围绕工资卡、公积金、养老金（解释一第八十条）、股权（解释一第七十三条）、保险、理财、名下公司与账户、对方父母转账（出资购房，解释二第八条）逐项发问。
  • 当庭说出的账户 / 线索立即记录：对方承认「我还有一张×行卡」「我司有笔分红」的，当庭记入笔录，休庭后立即书面申请法院调查令或依职权调查（《民事诉讼法》相关规定）。这是「打草惊蛇」前的最后窗口——一旦休庭对方醒悟，账户可能当晚清空。
  • 隐匿、转移财产的当场揭露：若发现对方在诉讼中转移财产，可主张适用第 1092 条（少分或不分），并申请财产保全。
  • 对方拒答 / 虚假陈述：家事案件中一方对财产情况拒绝陈述或作虚假陈述的，法院可结合已知证据与举证责任分配作出不利认定；律师应提示当事人如实陈述，同时针对对方不实处及时反驳并申请核实。
常见坑「对方当庭承认的账户，休庭后才去调，钱没了」

这是家事财产攻防最典型的失分点。正确做法：

  • 庭审中对方说出任何财产线索，当庭请求记入笔录，并口头申请「庭后×日内向法院提交调查取证申请 / 调查令申请」；
  • 如法院当庭可组织核对，争取当庭固定；
  • 休庭当日即提交书面《调查取证申请书》，列明账户开户行、卡号（能记多少记多少）、时间段，避免对方在「缓冲期」内转移；
  • 若已有初步证据显示转移，同步申请诉讼保全，冻结该账户。

时间差就是财产差。律师的反应速度在这一环节直接换算成客户回款。

3.3 辩论：围绕「是否判离」与「子女抚养」两大轴

家事辩论不要散。离婚案件就两个轴，其余都是附随：

  • 轴一：是否判离。围绕第 1079 条法定情形展开——原告证明「感情确已破裂且调解无效」，被告证明「不符合法定情形或仍有和好可能」。所有证据与法律意见都回到这一轴。
  • 轴二：子女抚养。八周岁以下按「最有利于未成年子女」（第 1084 条）；两周岁以下以母亲为原则（解释一第四十四条）；八周岁以上尊重真实意愿（第 1084 条）。辩论聚焦抚养条件、陪伴时间、教育规划、祖辈协助，而非「我更爱孩子」的情绪表达。
  • 财产与三项请求权：是附随轴，在判离前提下才处理。若法院倾向不判离，财产与赔偿请求可能被一并驳回，律师应预先告知当事人这一程序连锁，避免在「暂不判离」时孤立主张财产分割。

3.4 抚养权庭审的细节：出庭前帮当事人准备「抚养方案表格」

抚养权之争，赢在庭前准备，不在庭上发挥。律师应让当事人填一份「抚养方案表格」，把抽象「我能带好孩子」变成可质证的事实。

模块表格要点（当事人逐项准备，附证据）
住房条件现居住房屋面积、学区、与学校距离、是否稳定（产权 / 租约）、有无独立儿童房
接送与陪伴日常谁接送、作业辅导安排、周末陪伴计划、工作时间是否冲突（附作息表）
教育与医疗规划拟就读学校、课外安排、既往医疗记录与后续方案、保险覆盖
祖辈协助祖父母 / 外祖父母是否同住、健康状况、可协助时长（解释一第四十七条：祖辈单独带孙多年且有能力帮助的可作优先条件）
对方不利情形家暴、赌博吸毒、恶习、长期缺位、抢夺藏匿子女（解释二第十四条优先由另一方抚养的情形）的证据清单
子女意愿八周岁以上子女的真实意愿记录（注意以不施压方式取得，避免被认定为诱导）
  • 表格不是给法院「交作业」，而是让当事人庭上陈述有骨架、不乱、不漏，也让法官一眼看到「你确实准备好了带孩子」。
  • 对方有抢夺、藏匿子女行为的，应重点引用解释二第十二条至第十四条，主张由另一方直接抚养，并申请保护令或人格权侵害禁令。

3.5 八周岁子女意愿的征询程序

《民法典》第一千零八十四条（离婚后子女抚养） 离婚后，不满两周岁的子女，以由母亲直接抚养为原则。已满两周岁的子女，双方协议不成的，由人民法院按照最有利于未成年子女的原则判决。子女已满八周岁的，应当尊重其真实意愿。
  • 征询主体与方式：八周岁以上子女意愿由法院征询，通常在庭前或庭后单独进行，避免父母双方在场的压力环境。律师不应自行「带孩子去法院表态」，也不要在父母冲突场景下诱导孩子表态——法院普遍对此持审慎态度，诱导取得的「意愿」可能被否定。
  • 律师的配合：向法院提供子女日常表达的真实记录（如聊天、作业本留言），但避免包装成「_child 声明书」施压；尊重法院依职权征询的程序安排。
  • 意愿不是唯一决定：尊重真实意愿 ≠ 子女说跟谁就判给谁。若子女意愿与其切身利益（如随家暴方、随长期缺位方）明显冲突，法院仍按最有利于未成年子女裁量。律师应把「意愿 + 客观抚养条件」一并呈现。

四、当事人情绪管理

家事庭审最大的不可控变量是当事人情绪。律师的「情绪教练」角色，往往比法律意见更影响结果。

4.1 庭前演练

  • 模拟发问：把法官可能问的（「你们为什么分居」「孩子平时谁带」）和对方可能攻的（「你说过不出抚养费」）提前演练，让当事人有准备、不慌、不怒。
  • 陈述脚本：给当事人一份「法庭调查陈述要点」提纲，只写事实关键词，不写抒情长句，防止庭上跑题或被对方带节奏。
  • 边界约定：明确「庭上只回答与案件有关的问题，不回应对方的辱骂，不主动攻击对方人格」。

4.2 危险言语预警

  • 「我早就想杀了你」类：家暴 / 威胁类言语，无论真假，都可能引发保护令或刑事报案，必须庭前警示当事人绝对不说。
  • 「孩子不是他的」strong>：亲子关系异议需另案处理（解释一第三十九条双向规则），当庭无证据抛出只会激化且自伤，应提前评估是否作为诉讼策略。
  • 「我放弃所有财产只要离」：情绪性表态可能被记入笔录并作为调解基础，律师须当场拦住，提示「这是可反悔前的情绪话，但一旦进调解书就难回头」（见 ch05）。
  • 对法官的对抗性语言：家事法官裁量权大，当庭挑衅法官（「你凭什么这么问」）会直接损害当事人可信度，必须课前反复强调分寸。

4.3 与法官沟通的份寸

  • 程序问题主动、实体问题留庭：送达、举证期限、不公开审理申请等程序事项可庭前书面沟通；实体争议（判离、抚养）留给法庭调查与辩论，不私下「递话」。
  • 子女利益优先表达：向法官陈述时，把「对子女的影响」放在显眼位置，符合家事审判政策取向，也提升方案被采纳概率。
  • 不施压、不表演：家事法庭反感律师把商事庭审的「对抗表演」移植过来；以专业、克制、重证据的姿态更易获得法官信任。

五、最后陈述与庭后工作

5.1 最后陈述

  • 离婚案件本人到庭的，最后陈述是当事人本人表达离婚意愿、子女安排看法的最后窗口，律师应提前帮当事人拟好 3—5 句要点：明确「同意 / 不同意离婚」「子女由×方抚养」「财产按方案处理」。
  • 避免最后陈述变成情绪爆发——法官此时已在形成心证，一句克制、清晰、落到方案上的陈述，好过十分钟控诉。

5.2 庭后代理意见

  • 庭审结束×日内提交书面《代理词》，把法庭调查、辩论中的要点系统化为法律意见：判离法定情形对应、抚养最有利、财产分割依据（民法典第 1087 条照顾子女 / 女方 / 无过错方）。
  • 涉及三项请求权（1088/1090/1091）的，代理词中必须单列，避免「当庭提了但文书没写」导致后续主张困难。
  • 家暴、隐匿财产等需援引第 1091、1092 条的，代理词列明事实 + 法条 + 证据页码，便于法官写判项。

5.3 庭后调解窗口

  • 很多离婚案件是「判了一半、剩下调解」——法庭调查后法官常给双方一个调解窗口。律师应保留灵活空间，不要庭上把话说死。
  • 若庭审显示判离概率高但财产方案未定，庭后主动联系承办法官 / 调解员推进财产分割调解，比等判决更有利于锁定可执行条款（见 ch05）。

5.4 补充证据期限

  • 庭上发现的新线索（如对方承认的账户），按法院指定的补充举证期限提交；期限届满前书面申请延期，不要超期失权。
  • 涉及亲子关系鉴定、财产评估等的，庭后及时推动，避免因程序拖延导致二次开庭或事实无法查清。

常见坑「庭上说漏了，庭后补就行」

家事庭审里三类「庭后补」最容易失权：

  • 三项请求权没当庭提：离婚损害赔偿等原则上应在离婚诉讼同时提出，判不离的不支持，不离婚单独提不受理（解释一第八十六条规定精神）。庭后想补，常被告知另案不受理。
  • 财产线索没当庭记：对方承认的账户，休庭才申请调查，财产可能已转移（见 3.2）。
  • 抚养方案没准备：庭上被问「你具体怎么带」答不上来，法官直接把抚养权判给对方，庭后补表格毫无意义。

家事庭审的「补」成本远高于商事——因为身份关系一旦判下、子女一旦判走，逆转极难。庭前准备不是加分项，是生死线。

六、红线清单 / 自检清单

  • 离婚案件本人原则必须到庭；不能表达意思外不得豁免，特殊情况须提交书面意见，否则可能按撤诉或影响程序。
  • 不公开审理须主动申请（离婚案件依申请、涉未成年隐私），立案或开庭前书面提出，不要等法庭问。
  • 法庭调查把婚姻事实逐项对号第 1079 条第三款五项法定情形，主张判离就落在这五项上。
  • 对方当庭说出的账户 / 公司 / 房产，当庭请求记入笔录并休庭当日提交调查取证申请，时间差就是财产差。
  • 辩论只围绕「是否判离」「子女抚养」两轴，财产与三项请求权是附随轴，不判离时易被一并驳回。
  • 抚养权之争赢在庭前「抚养方案表格」：住房、接送、教育、祖辈协助、对方不利情形，逐项附证。
  • 八周岁子女意愿由法院征询，律师不诱导、不施压，且意愿非唯一决定，须配客观抚养条件。
  • 庭前演练 + 危险言语预警（威胁、亲子关系、情绪性放弃），与法官沟通重程序、重证据、不表演。
  • 庭后及时提交代理词，三项请求权（1088/1090/1091）必须单列，避免「当庭提了文书没写」失权。
  • 保留庭后调解窗口，判离概率高但财产未定的，主动推进调解锁定可执行条款，比等判决更优。
