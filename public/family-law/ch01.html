PART I · 通用全流程

01 首次接待与咨询

接待前三十分钟的事实筛查，决定后面三年是办案还是救火

法条《民法典》第 1049、1051、1052、1053 条《律师服务收费管理办法》相关规定《刑法》相关规定（条号以现行文本为准）
家事案件的第一次接待不同于普通民商事咨询：当事人带着情绪、带着不完整的事实碎片、带着「我听朋友说」的先验结论进来。律师在这一步的核心任务不是给答案，而是把当事人叙述的「事实」还原成可证成的「法律事实」，同时完成冲突检索、风险告知与报价框架。这一步做扎实，后续立案、举证、谈判才有锚点；做虚了，后面所有环节都会反复返工，甚至把律师自己拖进虚假陈述与证据合规的雷区。

一、接待前：材料预筛与身份核验

正式会谈前，先用一次简短电话或问卷完成最低限度的材料预筛，避免见面后才发现连基础身份文件都没有，白白浪费一小时的面谈窗口。预筛清单应要求当事人带齐以下原件：结婚证（或婚姻登记档案）、双方及子女身份证/户口本、房产证与购房合同、近一年银行流水、工资与社保记录、对方已知财产线索（车牌、公司股权、保单号）。

为什么要先核验身份，再谈方案

家事案件中「当事人」与「法律上的权利人」经常不是同一人：未离婚的想替配偶咨询、成年子女想替年迈父母咨询、同居关系者以「配偶」自居。律师必须在落笔委托前确认谁有处分权、谁有权签署委托代理协议。身份错位一旦进入委托阶段，后续形成的笔录、授权、甚至起诉状都会出现主体瑕疵，补救成本极高。

1.1 婚姻效力的第一道疑点筛查

当事人说「我们结婚了」，与法律上的「婚姻有效」之间隔着多道关口。接待时按以下顺序逐条排除：

  • 是否完成结婚登记：1994 年《婚姻登记管理条例》公布（2 月 1 日）之后，仅办酒、未登记的，不再按事实婚姻处理，需补办登记方产生夫妻法律关系；此前已符合实质要件并以夫妻名义共同生活的，可认定为事实婚姻（婚姻家庭编解释（一）第 7 条）。
  • 是否存在无效情形：重婚、有禁止结婚的亲属关系、未到法定婚龄。其中重婚在婚姻家庭编解释（二）第 1 条下为绝对无效——即便起诉时前婚已解除或前配偶已死亡，后一婚姻也不因此转为有效。
  • 是否处于可撤销窗口：受胁迫结婚的，撤销权自胁迫终止（被非法限制人身自由的，自恢复自由）起一年内行使；隐瞒重大疾病的，自知道或应当知道撤销事由起一年内行使（民法典第 1052、1053 条）。婚姻家庭编解释（一）第 19 条明确该一年为除斥期间，不适用诉讼时效中止、中断、延长。逾期则婚姻稳定，只能走离婚路径。
  • 是否存在登记程序瑕疵：冒名、虚假材料、非本人签字等。此类情况不走民事诉讼的「确认无效」，而应告知当事人通过行政复议或行政诉讼解决（婚姻家庭编解释（一）第 9—17 条相关规则）。
《民法典》第一千零五十一条 / 第一千零五十二条 / 第一千零五十三条 有下列情形之一的，婚姻无效：（一）重婚；（二）有禁止结婚的亲属关系；（三）未到法定婚龄。
因胁迫结婚的，受胁迫的一方可以向人民法院请求撤销婚姻。请求撤销婚姻的，应当自胁迫行为终止之日起一年内提出。被非法限制人身自由的当事人请求撤销婚姻的，应当自恢复人身自由之日起一年内提出。
一方患有重大疾病的，应当在结婚登记前如实告知另一方；不如实告知的，另一方可以向人民法院请求撤销婚姻。请求撤销婚姻的，应当自知道或者应当知道撤销事由之日起一年内提出。 接待中当事人主张「受父母胁迫结婚」，须立刻核实用胁迫手段的主体与持续时间，以及是否仍在一年除斥期内；超期的一律按离婚而非撤销处理，避免当事人误判可诉路径。

1.2 子女情况的三个维度

子女的「身份」与「现状」直接决定抚养、探望、抚养费以及遗产继承的多个走向，接待时必须分层记录：

维度需要记录的事实要点对后续的影响
身份关系婚生 / 非婚生 / 继子女 / 养子女；有无亲子鉴定争议；是否人工授精（婚内一致同意视为婚生，解释（一）第 40 条）决定抚养权归属基础与被告适格性；非婚生子女同等权利（民法典第 1071 条）
年龄节点是否不满两周岁、已满八周岁；是否「不能独立生活的成年子女」（高中及以下在读或丧失部分劳动能力，解释（一）第 41 条）不满两周岁以母亲直接抚养为原则；已满八周岁须尊重真实意愿（民法典第 1084 条），询问意愿的时机与方式直接影响裁判
共同生活与抚养现状实际随谁生活、就读学校、 Healthcare 承担方、祖辈协助带养情况两周岁以上「最有利于未成年子女」裁判中，改变生活环境是否明显不利是关键权衡（解释（一）第 44—48 条）

1.3 财产与家庭图谱：一张图胜过十段叙述

要求当事人在会谈中用一张家庭财产图谱穷列下列财产，并标注「登记名义 / 实际出资 / 取得时间 / 是否婚后」四要素：

  • 不动产：房改房、婚后共同还贷的婚前首付房、登记在一方父母名下的房改参与房（出资按债权处理，解释（一）第 79 条）；
  • 金融资产：银行存款、理财、证券账户、公积金、养老金个人账户实际缴纳部分；
  • 经营性资产：有限公司股权、合伙企业份额、个人独资企业、个体工商户；
  • 保险：投保人/被保人/受益人结构，现金价值归属；
  • 隐性资产：父母婚后出资购房（解释（二）第 8 条已实质更新规则，优先适用）、婚前父母出资（解释为对自己子女个人赠与，解释（一）第 29 条）；
  • 婚内借款协议：用共同财产出借给一方经营或个人事务，离婚时按协议处理（解释（一）第 82 条）。
别让图谱停在「大概有套房」

实务中最大的举证盲区是「知道有但说不清」：当事人知道配偶有公司股权，却给不出公司全称与统一社会信用代码；知道有保单，却报不出保险公司与保单号。接待阶段就要逼出可检索的关键字段，否则诉前财产摸排将无法启动，起诉后调查令申请也会因「指向不明」被退回。图谱不是摆设，是后续所有保全与举证的索引。

二、诉求预判：当事人嘴上要的 vs 法律能给的

家事当事人常把情绪诉求与法律诉求混为一谈。律师的价值在于把「他凭什么这么对我」翻译成「法院能判什么」，并在落笔前就管理好预期。下表是常见的「诉求—可诉性」映射，接待时逐项核对。

当事人常见表述法律上的可诉性判断律师的衔接动作
「我要让他净身出户」我国无「过错方一律不分财产」的法定规则。唯一对应少分或不分的是民法典第 1092 条的隐藏、转移、变卖、毁损、挥霍共同财产或伪造债务情形，且须以证据证成。告知「净身出户」是舆论概念；引导至「搜集转移财产证据 → 主张少分」的可证成路径
「我要他赔偿我青春损失费」无独立「青春损失费」案由。可归入离婚损害赔偿（民法典第 1091 条），但限于重婚、同居、家暴、虐待遗弃、其他重大过错五类，且须同时提出（解释（一）第 86—90 条）核对该五类是否落点；不构成则明确告知无法支持
「我不想离婚，只想让他写保证书」单纯以倡导性家庭美德条款（民法典第 1043 条）起诉的不予受理（解释（一）第 4 条）；但婚内财产分割须符合民法典第 1066 条情形方可区分「签协议」与「可强制执行」；提示婚内协议过户前可撤销的边界（解释（二）第 5 条）
「孩子必须归我，他没资格」抚养权以未成年子女利益最大化裁量，非当事人意志；抢夺藏匿子女反而可能成为不利于该方的考量（解释（二）第 12、14 条）劝阻抢孩子行为；建立「稳定共同生活事实」证据
「这套房是我爸妈买的，跟他无关」婚后父母出资购房的归属，解释（二）第 8 条已作实质更新，不能当然认定为一方个人财产，须看出资来源、比例、婚龄、孕育、过错、贡献综合判定调取出资凭证与赠与意思表示证据；避免凭经验下结论
「他外面有人，我要分他转移给小三的钱」违反忠实义务将共同财产赠与第三者的，可主张违背公序良俗无效、依民法典第 157 条返还，并可视情况依第 1092 条主张少分（解释（二）第 7 条）锁定转账流水与赠与合意证据；评估是否追加第三者
预判的两条铁律
  • 不替当事人制造伪诉求：当事人情绪上想要「惩罚」，法律只解决「分割与赔偿」，把边界讲在前面，避免委托后反复指责律师「没帮我出气」。
  • 可诉性先于策略：先确认该请求有没有对应的请求权基础与证据可能性，再谈怎么打；没有基础的请求，立案阶段就会被驳回或劝撤。
常见坑「我只咨询不委托」的当事人，能否直接给书面法律意见？

可以咨询，但要分清「咨询」与「代理」的边界：

  • 口头咨询不留痕也可，但一旦出具载明事实认定与具体策略的书面法律意见书，建议先签咨询协议并收费，避免后续被主张「律师曾承诺某结果」或卷入对方取证；
  • 对来「套方案」的对方当事人（对方已委托他人，却来探口风），应礼貌拒绝实质交谈并提示利益冲突；
  • 对代为咨询的亲属，明确告知其不是委托人，律师不对未签约方承担保密与代理义务，重要事项应约见本人。

三、接案风险评估

接案不是来者不拒。家事案件的风险具有双向性：一方面当事人可能隐瞒事实诱导律师作虚假陈述，另一方面极端的当事人可能把律师当作情绪出口甚至共犯。接待阶段必须完成四项风险评估。

3.1 冲突检索

正式接案前，在所内案件管理系统与公开渠道检索是否存在利益冲突：

  • 本所是否已代理对方（包括曾经代理、现仍代理）；
  • 本所律师是否与对方有近亲属、债权债务等其他利害关系；
  • 曾为双方共同亲友代理过关联案件，是否构成实质冲突；
  • 同一家事纠纷中，兄弟姐妹、父母子女互为对立当事人的，须分别评估能否同时代理。

发现冲突的，应主动披露并退出，或在取得双方书面豁免后谨慎承接。家事案件的冲突往往比商事案件更隐蔽——当事人之间常有亲属关系，利益冲突的边界更模糊。

3.2 对方是否已起诉 / 是否已存在生效文书

务必在接待时询问：对方是否已经向法院起诉？是否已经拿到离婚判决、调解书或抚养协议？这直接决定承接受理的策略：

  • 对方已起诉且尚未开庭 → 我方作为被告应诉，诉求表达窗口在答辩与反诉；
  • 已有生效离婚判决未处理探望权 → 可单独起诉（解释（一）第 65 条）；
  • 已登记离婚就财产分割反悔 → 应受理但受欺诈胁迫审查（解释（一）第 70 条）；
  • 判决不准离婚后分居满一年再诉应准予离婚（民法典第 1079 条），时间节点是核心证据。

3.3 刑事风险点的告知义务

家事案件中，当事人极易在「维权」冲动下踩到刑事红线。律师有主动告知义务，且应记入接待笔录，证明已尽到风险提示：

《刑法》相关规定（条号以现行文本为准） 与家事案件高度相关的刑事罪名包括：虚假诉讼罪（以捏造的事实提起民事诉讼）、帮助毁灭、伪造证据罪、拒不执行判决、裁定罪（人民法院依法作出的具有执行内容并已发生法律效力的判决、裁定，有能力执行而拒不执行，情节严重）等。婚姻家庭编解释（二）第 12 条亦引向《刑法》第 313 条，对拒不履行人身安全保护令且符合该条者以拒不执行判决、裁定罪定罪处罚。 本条所引《刑法》条号不在本手册法源基准表内，依规则仅列制度名称，具体条号以现行《刑法》文本为准。
风险行为当事人常见动机律师必须告知的法律后果
伪造、篡改聊天记录 / 借条 / 银行流水「证据不够，补一份就齐了」可能构成虚假诉讼或帮助伪造证据，轻则证据不被采信、被罚，重则追刑责
为争抚养权抢夺、藏匿子女「先抱走孩子就有筹码」不仅不当然获得抚养权（解释（二）第 14 条反列不利情形），情节严重的可被追究拒执责任
离婚诉讼期间恶意转移、变卖财产「趁没分割先转走」依民法典第 1092 条可少分或不分；情节严重的伪造债务涉嫌犯罪
胁迫对方签署「净身出户」协议「不签就不离婚」受胁迫方可撤销；以暴力威胁可能触及刑事，且协议效力存疑
告知必须「留痕」，不能只口头说说

刑事风险告知不能停留在面谈几句。应在《接案风险告知书》或接待笔录中逐条列明上述红线，由当事人签字确认。这既是保护当事人（让其知悉边界），更是保护律师自己——一旦出现当事人伪造证据，律师能证明确已履行提示义务，避免被牵连为共犯或从犯。

3.4 情绪极端当事人与拒绝接案情形

家事当事人情绪剧烈波动属常态，但以下情形应慎重甚至拒绝接案：

  • 明确要求律师「帮忙做假证据」「吓唬对方」：直接拒绝，并告知这已超出法律服务边界；
  • 反复要求承诺结果：「你保证我拿到孩子、保证分到房」——家事裁判裁量空间大，任何结果承诺都不专业且不合规；
  • 有自伤、伤人、跟踪对方倾向：评估其是否处于危机状态，必要时建议其先寻求心理或公安介入，律师不做其情绪的「执行工具」；
  • 委托目的本身是骚扰、报复：如仅为拖延对方、消耗对方，无真实权利主张，应拒绝承接；
  • 无付费能力与付费意愿却要求全风险操作：结合报价边界处理（见下节）。
常见坑当事人要求「你替我出面威胁他家人」

这是高频危险请求。家事律师常被当事人当作「合法施压代理人」使用。应当场明确：

  • 律师的沟通对象只能是对方律师或法院，不得对未委托的对方当事人及其近亲属实施威胁、骚扰；
  • 《妇女权益保障法》（2022 修订）第 29 条规定，离婚之后纠缠、骚扰妇女、泄露传播隐私和个人信息的，可申请人身安全保护令——律师若代为实施骚扰，自身可能成为被申请对象；
  • 任何「帮你出口气」的诉求，一律转化为「向法院申请、向公安机关报案、申请保护令」的合法路径。

四、报价思路

家事案件的报价比其他业务更考验预期管理。报价不当，要么把客户吓跑，要么把自己锁进「不承诺结果却要兜底」的困局。

4.1 计件收费 vs 标的额比例

家事案件通常按计件与标的额比例两类组合报价：

  • 不涉及大额财产分割的单纯离婚 / 抚养 / 探望：多采用计件，按阶段（一审、二审、执行）分别报价；
  • 涉及财产分割：对财产部分按标的额分段累计收取，与计件基础费叠加；
  • 继承案件：按继承标的额比例，但须注意全部继承人列为当事人后的工作量放大；
  • 非讼业务（代书协议、见证、谈判）：单独计件，不与诉讼挂钩。

4.2 风险代理的硬性边界

《律师服务收费管理办法》相关规定 该办法明确禁止对请求给付赡养费、抚养费、扶养费、抚恤金、救济金、工伤赔偿，以及婚姻、继承案件实行风险代理收费。即婚姻、继承类案件不得约定「胜诉或执行到位后按比例抽成」的风险代理模式。 《律师服务收费管理办法》不在本手册法源基准表内，依规则仅列制度名称，具体条款以现行文本为准。实务中以此作为禁止婚姻继承案件风险代理的依据。
别用「半风险」「后付费」绕过禁区

部分律师以「前期少收、后期按财产增值抽成」或「执行到位再补差」的名义变相风险代理。婚姻、继承案件的风险代理禁止是强制性规范，任何形式的实质风险代理约定均可能被认定违规，面临行业处分与退费风险。家事案件只能做固定收费或计件 + 标的额比例（事前约定、与结果脱钩）。

4.3 分段报价与预算管理

家事案件周期长、变数多，建议按程序阶段拆分报价，让当事人清楚每一阶段对应什么工作：

阶段一 · 前期咨询与方案

事实梳理、证据清单、策略报告、调解方案设计。可单独计费，即使不进入诉讼也有交付物。

阶段二 · 诉前与立案

管辖分析、起诉状与证据目录、财产线索摸排、保全申请。工作量集中，宜单独计收。

阶段三 · 一审审理

举证质证、庭前会议、开庭、调解谈判。核心阶段，按计件或标的额比例。

阶段四 · 二审 / 执行 / 探望监督

视需要单独约定，避免「包到终点」导致律师被无限绑定。

分段报价的另一个好处是给当事人退出权：调解在阶段二成功，阶段三就不发生，费用自然终止，避免「我已交全款他却和解了」的退费纠纷。

4.4 不承诺结果——把话说在前面

家事裁判高度依赖法官自由裁量（抚养权、财产分割比例、损害赔偿数额均无刚性标准）。委托代理协议与口头沟通中，一律不得承诺具体结果，应以「尽专业勤勉、争取最有利结果」表述。可在协议中写明：

  • 律师不对裁判结果作任何明示或默示保证；
  • 诉讼策略基于现有证据与法律，新证据出现可调整；
  • 费用不因结果好坏而增减（呼应风险代理禁区）。
报价话术的合规框架

「根据案情，我建议分三阶段推进，前期费用覆盖事实梳理与调解方案；若进入诉讼，再按财产分割标的计收。我无法向您保证法院一定判归您抚养或一定分到某比例，但我能保证：穷尽合法取证路径、把您的合法权益主张到位、每一步都让您知情。」——既专业又守住边界。

五、本章红线清单 / 自检清单

  • 接待前已要求带齐身份、婚姻、子女、财产四类基础材料原件，并完成身份核验与处分权确认。
  • 已完成婚姻效力疑点筛查（登记 / 无效 / 可撤销窗口 / 程序瑕疵），对超除斥期的撤销请求已按离婚路径处理。
  • 已绘制家庭财产图谱，且每项资产标注「登记名义 / 实际出资 / 取得时间 / 是否婚后」四要素，关键检索字段（公司全称、保单号）已逼出。
  • 已对当事人诉求做可诉性预判，明确告知「净身出户」「青春损失费」等概念无对应法定基础。
  • 已做冲突检索并留存记录；对方已起诉或已有生效文书的情形已识别并调整策略。
  • 已就伪造证据、虚假诉讼、转移财产、抢夺子女等刑事风险书面告知并让当事人签字。
  • 已识别情绪极端 / 要求违法协助 / 要求承诺结果的当事人，必要时拒绝接案。
  • 报价已排除婚姻、继承案件风险代理，采用计件或标的额比例（事前约定、与结果脱钩），并分段明确。
  • 委托代理协议与沟通中无任何结果承诺表述。
  • 所有《民法典》条号引用均出自法源基准表，表外法律仅列制度名称，未凭记忆编造条号。
