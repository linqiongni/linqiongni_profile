婚姻家事与遗产继承律师实务全流程手册

面向执业律师 / 法务：从首次接待到判决执行、从彩礼返还到遗产管理人制度的全流程办案操作指引

法源基准：《民法典》（2021-01-01 施行） 婚姻家庭编解释（一）（二） 继承编解释（一） 《反家庭暴力法》及保护令司法解释 《涉外民事关系法律适用法》 《民事诉讼法》（2023 修正）
家事案件不是「标的额小一点的商事案件」。它有独立的一套底层逻辑：人身关系先行于财产关系、调解优先、 不公开审理、本人原则上要到庭、证据隐蔽且不可再生、当事人情绪与案件走向深度交织。 本手册按律师真实办案顺序编排：第一部分写通用全流程（接待 → 诉前 → 保全 → 举证 → 调解 → 庭审 → 生效执行）， 第二部分按 10 类案由逐章展开（每章统一五节：争议焦点 / 文书起草 / 证据清单 / 法条引用 / 抗辩与坑点）， 第三部分写特殊程序与收尾实务（保护令、特别程序、执行难点、遗产管理人、再审与第三人撤销之诉）。 可直接作为办案时的操作底稿使用。

怎么用这本手册

  • 接案前：读 ch01（接待咨询与接案风险评估）+ ch08（家事与商事差异）——先校准对案件类型的认知，再用商事思维办案必踩坑。
  • 起诉前：读 ch02（管辖与财产线索摸排）+ ch03（保全）——家事案件财产线索一旦打草惊蛇，往往永远查不到。
  • 办案中：读对应案由章（ch09—ch18）+ ch04（调查取证）——每章第 ③ 节「证据收集清单」可直接当取证任务清单用。
  • 开庭前：读 ch05（调解）+ ch06（庭审）——家事案件六成以上以调解或调解性撤诉结案，庭审只是调解不成后的第二步。
  • 结案后：读 ch07（生效与执行）+ ch21（执行难点）——抚养费和探望权的执行才是客户满意度的最终裁判。

家事案件底层逻辑五条

一、人身关系先行

婚姻效力、亲子关系、继承资格先于财产分割。婚姻无效 / 被撤销的后果与离婚完全不同（共财构不成、不适用家务补偿与损害赔偿的多数规则）；亲子关系未定，抚养费与继承资格都无从谈起。接案先问「这个案子里的人身关系是否成立」，再谈财产。

二、调解不是缓冲带

《民法典》第 1079 条把「先行调解」写进了诉讼离婚程序。家事调解不是走流程，而是多数案件的终局解决方式——法院签发的调解书与判决书同等强制执行力。调解方案的设计能力（ch05）决定案件的实际收益与客户体验。

三、证据不可再生

家暴的伤情、出轨的同居记录、转移财产的流水、老人的真实意愿——都具有强烈的时间性与隐蔽性。诉讼启动的时点选择（先保全还是先起诉、先固定证据还是先谈判）比诉讼技巧本身更影响结果。

四、身份关系不适用自认

婚姻、亲子等身份关系案件不适用自认规则（婚姻家庭编解释（一）第 2 条相关精神），涉及身份关系的案件法院可依职权调查、可追加当事人——「双方都承认」不等于法院就认。财产部分的自认则照常适用。

五、未成年人利益最大化贯穿始终

抚养、探望、财产分割中涉及未成年子女的（如登记在子女名下的房产、离婚协议给子女的财产条款），法院裁量权大且政策取向明确：最有利于未成年子女（民法典第 1084 条）。方案设计时把「对未成年人的影响」写进文书，比事后抗辩有效得多。

十条铁律（每一章末尾都会回扣）

  1. 接案必查冲突与婚姻效力：对方当事人是否已另行起诉、委托人婚姻是否可能无效 / 被撤销，直接改变诉讼策略。
  2. 咨询阶段不承诺判离、不承诺抚养权归属、不承诺财产分割比例——「包离」是执业风险，也是投诉重灾区。
  3. 财产线索摸排在先、起诉在后；能保全的先保全，查控窗口一旦错过就打草惊蛇。
  4. 离婚案件本人原则上必须出庭（《民事诉讼法》相关规定）；代理时提前帮当事人做情绪与陈述管理。
  5. 调解书签收前逐条核对履行内容与违约条款；调解协议只要未出调解书，随时可能翻脸反悔。
  6. 家务补偿（1088）、经济帮助（1090）、损害赔偿（1091）三项请求权不主动主张法院一般不主动处理，起诉状里漏了就是失职。
  7. 隐藏、转移、变卖、毁损、挥霍共同财产或伪造债务的，可以少分或不分（第 1092 条）；离婚后发现的，另行起诉不受离婚协议拘束。
  8. 遗嘱形式要件零容忍：打印遗嘱两个以上见证人且每页签名注明年月日、录音录像遗嘱记录肖像与日期、口头遗嘱仅限危急情况——形式差一点，整份作废。
  9. 受遗赠必须在知道受遗赠后 60 日内作出接受的明确表示，否则视为放弃（第 1124 条）；这是遗赠案件最经典的「坑」。
  10. 涉港澳台案件先定管辖与法律适用再定策略，域外证据的公证认证/证明手续要赶在举证期限前启动，跨境程序动辄以月计。

常见错误速查表

常见错误后果正确做法
只诉离婚不提家务补偿 / 损害赔偿，宣判后想补无过错方请求离婚损害赔偿的应在离婚诉讼同时提出（解释（一）相关规定），另案起诉一般不被受理起诉状请求权一次列全；庭前核对 1088 / 1090 / 1091 三项
起诉后才申请调取对方银行流水对方已将存款转移；执行阶段仅能追已查明的余额诉前摸排 + 诉前保全；起诉状中列明已知账户并申请调查令
把聊天记录截图直接打印提交真实性被否定，且原始载体灭失后无法补证保留原始载体（手机原件）、当庭演示、必要时公证 / 区块链存证
离婚协议写「财产已分割完毕，再无争议」离婚后再发现隐匿财产，举证「不知情」负担重协议附财产清单；「如发现未列明财产，依法另行分割」条款兜底
打印遗嘱只有遗嘱人签名，无见证人形式要件不符合第 1136 条，遗嘱无效改自书或补足两名以上见证人全程见证、每页签名注明年月日
受遗赠人「默认收下」未作书面表示60 日内无接受表示，视为放弃受遗赠期限内出具书面接受声明并留痕（可公证送达）
忠诚协议约定「出轨净身出户」当作铁证起诉忠诚协议中限制离婚自由、处分身份权利的条款效力存疑，法院一般不作为分割依据直接执行财产约定与忠诚条款分开设计，违约后果落在具体财产处分上（见 ch12）
涉港澳台案件用内地诉讼思路直接起诉管辖异议、法律适用错误、域外证据手续不齐被退先按 ch18 核对管辖连接点与准据法，再定保全与取证路径
