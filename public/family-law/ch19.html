PART III · 特殊程序与收尾

19 人身安全保护令申请

保护令是独立的民事令状程序，不以离婚诉讼为前提，是家暴受害人最快的司法隔离带

法条《反家庭暴力法》第 2、23、25、27、28、29、34、37 条人身安全保护令司法解释（法释〔2022〕17 号）第 1—6、10、12 条《妇女权益保障法》第 29 条
人身安全保护令（以下简称「保护令」）是人民法院依申请签发的民事令状，目的是在诉讼前或诉讼外对家庭暴力受害人作出隔离与禁止性保护。它的底层逻辑与离婚诉讼完全不同：不解决身份关系、不分割财产、不要求先起诉离婚。实务中，保护令经常是客户生命安全的第一道防线，也是后续离婚诉讼中认定家暴事实的关键证据。本章按「制度定位 → 申请条件 → 管辖期限 → 证据 → 措施 → 违反后果 → 代为申请 → 与离婚诉讼协同 → 文书模板 → 坑点」的顺序给出可操作步骤。
本条必须写入每一次接待笔录

《反家庭暴力法》第 23 条规定，当事人因遭受家庭暴力或者面临家庭暴力的现实危险，即可向人民法院申请人身安全保护令。不以提起离婚诉讼为条件（法释〔2022〕17 号第 1 条）。客户还在犹豫是否离婚、甚至只是恋爱同居关系终结后被纠缠，都可以且应当先申请保护令。把保护令当成「离婚后才办的事」是实务中最常见的延误性错误。

一、制度定位：独立程序，三处范围扩展

保护令是特别民事程序，不是离婚诉讼的附属。理解三处扩展，才能准确判断「我的当事人能不能申请」。

1. 不以其他诉讼为前提（程序独立）

《最高人民法院关于办理人身安全保护令案件适用法律若干问题的规定》（法释〔2022〕17 号）第一条 当事人因遭受家庭暴力或者面临家庭暴力的现实危险，依照反家庭暴力法第二十三条向人民法院申请人身安全保护令的，人民法院应当受理。
向人民法院申请人身安全保护令，不以提起离婚等民事诉讼为条件。

2. 家暴行为定义扩展（冻饿、侮辱诽谤、跟踪骚扰）

法释〔2022〕17 号 第三条 家庭成员之间以冻饿或者经常性侮辱、诽谤、威胁、跟踪、骚扰等方式实施的身体或者精神侵害行为，应当认定为反家庭暴力法第二条规定的「家庭暴力」。 反家庭暴力法第二条原定义只列「殴打、捆绑、残害、限制人身自由以及经常性谩骂、恐吓」；2022 年规定把冻饿、经常性侮辱、诽谤、威胁、跟踪、骚扰明确纳入，覆盖了大量「不打你但折磨你」的精神控制型暴力，扩大了可保护性。

3. 保护主体扩展（恋爱同居终止后、共同生活人、离婚纠缠）

法释〔2022〕17 号 第四条 反家庭暴力法第三十七条规定的「家庭成员以外共同生活的人」一般包括共同生活的儿媳、女婿、公婆、岳父母以及其他有监护、扶养、寄养等关系的人。
《反家庭暴力法》第三十七条 / 《妇女权益保障法》第二十九条 第三十七条：家庭成员以外共同生活的人之间实施的暴力行为，参照本法规定执行。
第二十九条（2022 修订）：禁止以恋爱、交友为由或者终止恋爱关系、离婚之后，纠缠、骚扰妇女，泄露、传播妇女隐私和个人信息；妇女遭受上述侵害或者面临上述侵害现实危险的，可以向人民法院申请人身安全保护令。 据此，下列对象均可作为保护令申请人：配偶及前配偶、同居及已终止同居关系者、恋爱及已终止恋爱关系者、共同生活的儿媳女婿公婆岳父母、寄养监护扶养关系人。实务中「前男友离婚后持续骚扰」已落入第二十九条明确保护范围。
接待时快速判断「能不能申请」
  • 有婚姻关系、曾婚姻关系、同居或曾同居、恋爱或曾恋爱关系，且存在身体或精神侵害 → 可受理。
  • 侵害形态不限于殴打：冻饿、谩骂、恐吓、诽谤、威胁、跟踪、骚扰、泄露隐私均算。
  • 不需要「先去派出所报案」或「先起诉离婚」——直接立保护令案。
  • 被申请人不限于配偶，含前配偶、同居对象、共同生活的姻亲、寄养关系人。

二、申请条件：反家暴法第 27 条三要件

《反家庭暴力法》第二十七条 作出人身安全保护令，应当具备下列条件：（一）有明确的被申请人；（二）有具体的请求；（三）有遭受家庭暴力或者面临家庭暴力现实危险的情形。

三要件必须同时具备，且都需在申请书与证据中体现。逐条对照操作：

要件一：明确的被申请人

需提供被申请人姓名、性别、出生日期、住址、公民身份号码、联系方式；信息不全的，至少要有足以锁定身份的住址与称谓。代理律师可申请法院依职权或签发调查令补全身份信息（法释〔2022〕17 号第 5 条）。

要件二：具体的请求

必须写清要求法院禁止什么、责令什么，不能只写「请求法院依法保护」。请求项应逐条列明（见本节第五部分「措施要写具体」），例如「禁止被申请人对申请人实施殴打、谩骂、恐吓」「禁止被申请人通过电话、微信、短信骚扰申请人」「禁止被申请人进入申请人住所、工作单位、子女学校周边二百米范围」。

要件三：现实危险情形

这是最容易驳回的点。「面临现实危险」不是「过去吵过架」，而要呈现危险的具体性、紧迫性、针对性。证据上靠报警记录、悔过书、威胁信息、伤情照片、告诫书、邻居证言串联；文书上用时间线写清「最后一次施暴时间 + 威胁内容 + 申请人由此处于恐惧状态」。

最常驳回原因

只报「我们经常吵架、他脾气不好」而不论证现实危险的，法院多裁定驳回。家暴的核心是「恐惧 + 控制」，申请书要落在「如果不禁止，申请人及子女面临的人身危险是什么」上，而不是情绪宣泄。

三、管辖与期限：基层法院，72 小时 / 紧急 24 小时

《反家庭暴力法》第二十五条 / 第二十八条 第二十五条：人身安全保护令案件由申请人或者被申请人居住地、家庭暴力发生地的基层人民法院管辖。
第二十八条：人民法院受理申请后，应当在七十二小时内作出人身安全保护令或者驳回申请；情况紧急的，应当在二十四小时内作出。
事项规则实务操作
管辖法院申请人居住地、被申请人居住地、家庭暴力发生地任一基层法院优先选家庭暴力发生地或被申请人居住地法院，便于公安协助执行与送达；跨区的，选对申请人举证最便利的法院
受理时限一般 72 小时；情况紧急 24 小时「紧急」要在申请书显著位置标注并附紧急证据（刚发生的威胁、扬言报复、申请人已离家躲避）；紧急情况法院可当天裁定
审理形式以裁定形式作出（第二十六条）书面审查为主，一般不公开开庭；必要时可询问当事人
复议不服裁定自生效之日起 5 日内向作出法院申请复议一次，复议不停止执行（第三十一条）告知被申请人复议权，同时提醒己方裁定作出即具执行力
有效期不超过 6 个月，失效前可申请撤销、变更、延长（第三十条）与离婚诉讼周期对齐：离婚一审审限内保护令可能到期，需提前准备延长申请

四、证据：证明标准「较大可能性」+ 十类证据清单

保护令的证据门槛显著低于离婚诉讼中的家暴认定，这是制度设计的核心红利——掌握它才能说服当事人及时申请。

法释〔2022〕17 号 第六条 人身安全保护令案件中，人民法院根据相关证据，认为申请人遭受家庭暴力或者面临家庭暴力现实危险的事实存在较大可能性的，可以依法签发人身安全保护令。
前款所称「相关证据」包括：（一）当事人的陈述；（二）公安机关出具的告诫书、行政处罚决定书；（三）公安机关的出警记录、接警记录、报警回执或者民警的讯问笔录、询问笔录、调解书、受案登记表等；（四）被申请人曾出具的悔过书、保证书等；（五）视听资料；（六）被申请人与申请人或者其近亲属之间的电话录音、短信、即时通讯信息、电子邮件等；（七）医疗机构的诊疗记录；（八）申请人所在单位、民政部门、居民委员会、村民委员会、妇女联合会、残疾人联合会、未成年人保护组织、依法设立的老年人组织、救助管理机构、反家暴社会公益机构等单位收到投诉、反映或者求助的记录；（九）未成年子女提供的与其年龄、智力相适应的证言或者亲友、邻居等其他证人证言；（十）伤情鉴定意见。 注意证明标准是「较大可能性」而非「高度盖然性」，远低于一般民事案件。这意味着伤情照片 + 报警回执 + 威胁信息通常即足以签发；不必等司法鉴定结论。
告诫书制度的衔接价值

公安机关对家暴行为可出具《家庭暴力告诫书》（《反家庭暴力法》相关规定）。告诫书是保护令申请中证明力最高的证据之一——它本身就是公权力对家暴事实的初步确认。实务动作：客户报警后，主动向办案民警提示「请出具告诫书」；拿到告诫书后六个月内申请保护令，可几乎零成本锁定事实。

伤情鉴定时点

伤情鉴定不是「伤好了再做」，而是越早越好。操作要点：① 报警后立即要求民警开具验伤通知书或陪同就诊；② 首诊病历主诉必须写明致伤原因与施暴人，避免写成「自行摔伤」；③ 鉴定结论用于固定「达到何种伤害程度」，但保护令不要求达到轻伤以上——轻微伤甚至无明显外伤（纯精神暴力）也可依其他证据签发；④ 鉴定文书与诊疗记录、报警记录形成闭环，离婚诉讼主张损害赔偿时直接复用。

法释〔2022〕17 号 第五条 申请人或者其代理人因客观原因不能自行收集的证据，可以申请人民法院调查收集。人民法院应当依法调取、收集，并可以通知了解情况的未成年人出庭陈述。

五、保护措施内容：要写具体

《反家庭暴力法》第二十九条 / 法释〔2022〕17 号 第十条 第二十九条：保护令措施包括（一）禁止被申请人实施家庭暴力；（二）禁止被申请人骚扰、跟踪、接触申请人及其相关近亲属；（三）责令被申请人迁出申请人住所；（四）保护申请人人身安全的其他措施。
第十条：其他措施可包括：禁止被申请人以电话、短信、即时通讯工具、电子邮件等方式侮辱、诽谤、威胁申请人及其相关近亲属；禁止被申请人在申请人及其相关近亲属的住所、学校、工作单位等经常出入场所的一定范围内从事可能影响申请人及其相关近亲属正常生活、学习、工作的活动。
措施要写具体——这是和「措施请求过泛」坑点的直接对抗

申请书不能只写「禁止骚扰」。应按以下颗粒度逐项列明，法院才便于执行与认定违反：

  • 禁止接触方式：明确列举电话、短信、微信、QQ、电子邮件、抖音 / 微博私信等所有通讯渠道，并写明「不得通过他人转达」。
  • 禁止出现场所及半径：写明「不得进入申请人住所、工作单位、子女就读学校、经常就医医院周边____米范围」（建议 200—500 米，并可依小区实际规模调整）。
  • 禁止行为：不得尾随、不得在申请人上下班路线守候、不得在申请人亲属住所逗留、不得损毁申请人财物。
  • 迁出令：如双方同住，写「责令被申请人于裁定生效之日起____日内迁出申请人住所，并不得干扰申请人正常生活」；迁出令须配套临时居住安排的现实可行性提示。
  • 特定时段：涉及子女交接的，可写「每周____时段在____地点（第三方见证下）交接子女，被申请人不得在其他时段接触申请人」。

六、违反后果：训诫罚款拘留，直至拒执罪

《反家庭暴力法》第三十四条 / 法释〔2022〕17 号 第十二条 第三十四条：被申请人违反人身安全保护令，构成犯罪的，依法追究刑事责任；尚不构成犯罪的，人民法院应当给予训诫，可以根据情节轻重处以一千元以下罚款、十五日以下拘留。
第十二条：被申请人违反人身安全保护令，符合《刑法》第三百一十三条规定的，以拒不执行判决、裁定罪定罪处罚。

违反保护令存在两级制裁梯度：一般违反（仍属民事妨碍）→ 训诫、罚款、拘留；情节严重（有能力执行而拒不执行，如持续闯入禁止区域、造成人身危险）→ 按拒执罪移送刑事。实务中，申请人一方要做的配合动作是：每一次违反都报警、都固定证据、都向法院提交违反报告，把行政违法累积为刑事线索，才能形成真正威慑。

七、代为申请：主体已扩展

《反家庭暴力法》第二十三条第二款 / 法释〔2022〕17 号 第二条 第二十三条第二款：当事人因受到强制、威吓等原因无法申请人身安全保护令的，其近亲属、公安机关、妇女联合会、居民委员会、村民委员会、救助管理机构可以代为申请。
第二条：当事人因年老、残疾、重病等原因无法申请人身安全保护令，其近亲属、公安机关、民政部门、残疾人联合会、依法设立的老年人组织等可以依照当事人意愿代为申请。

代为申请的核心是「依当事人意愿」。老年人、残疾人、重病患者及受强制威吓者，律师可推动其近亲属或前述机构代为申请；代为申请时提交当事人授权或意愿声明，避免「违背本人意愿强行介入」引发后续争议。

八、与离婚诉讼的协同：保护令事实认定的免证价值

保护令裁定中确认的家暴事实，在后续离婚诉讼中具有重要证明价值。生效裁判确认的事实，对方当事人无相反证据足以推翻的，当事人无需重复举证（《民事诉讼法》相关规定）。

协同打法
  • 先立保护令、再诉离婚：保护令裁定书 + 告诫书 + 报警记录，构成离婚诉讼中认定「家庭暴力」「感情破裂」「离婚损害赔偿（第 1091 条）」「财产分割照顾无过错方（第 1087 条）」「抚养权不利于子女（解释（一）第 46 条相关）」的证据骨架。
  • 保护令审理周期短（72 小时），远快于离婚一审，可为客户抢出安全窗口。
  • 风险点：离婚诉讼中若当事人撤诉，保护令证据链可能中断——撤诉前务必固化已收集的家暴证据，把裁定书、告诫书、鉴定文书归档为独立卷宗，不随离婚案撤诉灭失。
  • 注意：保护令本身不当然等于离婚案中家暴事实的终局认定，对方仍可提出反证；但推翻生效裁定确认事实的证明负担在对方。

人身安全保护令申请书 申请人：____，女，____年__月__日出生，汉族，公民身份号码________________，住________省____市____区________路____号，联系电话：________。 被申请人：____，男，____年__月__日出生，汉族，公民身份号码________________，住________省____市____区________路____号，联系电话：________。 （申请人与被申请人系____关系：□配偶　□前配偶　□同居关系　□恋爱关系　□其他共同生活关系） 申请事项： 1. 禁止被申请人对申请人实施殴打、谩骂、恐吓、冻饿、侮辱、诽谤、威胁等任何形式的家庭暴力； 2. 禁止被申请人以电话、短信、微信、QQ、电子邮件、抖音 / 微博私信等任何方式骚扰、跟踪、接触申请人； 3. 禁止被申请人进入申请人住所、工作单位（________）、子女就读学校（________）及周边 200 米范围； 4. 禁止被申请人在申请人上下班路线及经常出入场所守候、尾随； 5. 责令被申请人于本令生效之日起____日内迁出申请人住所（________路____号），并不得干扰申请人正常生活； 6. 禁止被申请人通过第三方转达方式接触申请人及其近亲属。 事实与理由： 申请人与被申请人系____关系。自____年__月起，被申请人多次对申请人实施家庭暴力。主要事实如下： （一）____年__月__日，被申请人因____与申请人发生争执，对申请人实施____（殴打 / 谩骂 / 限制人身自由），致申请人____（伤情描述）。申请人当日报警，____派出所出具报警回执（编号____），申请人经____医院诊疗，诊断结论为____。 （二）____年__月__日，被申请人向申请人发送威胁信息（微信 / 短信内容：「____」），申请人已留存原始载体并截屏。 （三）____年__月__日，____（公安机关 / 妇联 / 居委会）出具告诫书 / 投诉记录（编号____），确认被申请人实施家庭暴力行为。 （四）____年__月__日，被申请人出具悔过书 / 保证书（附卷），承认____。 上述行为使申请人持续处于恐惧之中，面临家庭暴力的现实危险。为保护申请人人身安全，根据《反家庭暴力法》第二十三条、第二十七条及《最高人民法院关于办理人身安全保护令案件适用法律若干问题的规定》第一条、第三条、第六条规定，特申请签发人身安全保护令。相关证据材料已附卷。 此致 ________人民法院 申请人（签名）：____________ ____年__月__日 附：1. 申请人身份证明；2. 报警回执 / 出警记录；3. 告诫书 / 行政处罚决定书；4. 诊疗记录；5. 伤情鉴定意见（如有）；6. 悔过书 / 保证书；7. 微信 / 短信威胁内容截屏（附原始载体核对）；8. 妇联 / 居村委会求助记录；9. 邻居 / 亲友证言；10. 其他。
常见坑只报「吵架」，不论证现实危险

保护令第 27 条第三要件是「遭受或面临现实危险」，不是「关系不好」。法院驳回的高发情形：

  • 申请书只写「我们经常吵架、他脾气暴躁」，没有任何一次具体施暴 / 威胁的时间、方式、后果 → 不认定现实危险；
  • 补救：用时间线 + 报警记录 + 威胁信息把「危险的具体性」写出来，必要时附悔过书。

十、实务坑点

  • 坑 1：只报「吵架」不作现实危险论证——第 27 条第三要件落空，裁定驳回。必须把「过去施暴 + 当前威胁 + 恐惧状态」三要素串成时间线。
  • 坑 2：措施请求过泛——只写「禁止骚扰」导致执行时无法界定违反。按第五部分颗粒度逐项列明通讯方式、场所半径、具体行为。
  • 坑 3：离婚诉讼中撤诉导致保护令证据链断裂——撤诉前未独立归档家暴证据，离婚案卷随撤诉灭失。保护令裁定书、告诫书、鉴定应单独立卷。
  • 坑 4：错过告诫书——报警后未主动提示民警出具告诫书，损失最高证明力证据。报警时即口头 + 书面要求。
  • 坑 5：伤情鉴定拖延——伤愈后才鉴定，原始伤情无法对应。首诊即说明致伤原因，配合验伤通知。
  • 坑 6：误以为必须起诉离婚才能申请——依第 1 条无需以离婚为前提，恋爱 / 同居终止后亦可单独申请。
  • 坑 7：违反保护令不固定证据——被申请人每次违反都未报警留痕，无法累积到拒执罪。每次违反即报警 + 向法院提交违反报告。
  • 坑 8：有效期与离婚周期错配——6 个月有效期先于离婚一审到期，未及时申请延长，保护空窗。到期前 30 日准备延长申请。

十一、红线清单 / 自检清单

  • 已向客户说明：保护令不要求先起诉离婚，恋爱 / 同居终止后亦可申请（《反家庭暴力法》第 23 条、法释〔2022〕17 号第 1 条）。
  • 申请书写明三要件：明确被申请人、具体请求、现实危险情形（第 27 条）。
  • 管辖选在申请人居住地 / 被申请人居住地 / 家暴发生地基层法院之一（第 25 条）。
  • 紧急情形已在申请书显著位置标注，争取 24 小时内裁定（第 28 条）。
  • 证据按「较大可能性」标准组织，已覆盖第 6 条十类形式中的至少三类客观证据。
  • 已主动提示公安机关出具告诫书，并留存回执、笔录、诊疗记录、威胁信息原始载体。
  • 措施请求逐项具体化：通讯方式列举、场所半径写明、迁出令与临时居住可行。
  • 代为申请遵循「当事人意愿」，已取得授权或意愿声明（第 23 条、法释〔2022〕17 号第 2 条）。
  • 已向客户提示违反后果梯度：训诫 / 罚款 / 拘留 → 拒执罪（第 34 条、法释〔2022〕17 号第 12 条），并约定每次违反即报警留痕。
  • 已规划与离婚诉讼的协同：保护令裁定作为家暴事实免证证据，撤诉前独立归档家暴证据。
  • 已提示 6 个月有效期，计划到期前申请延长（第 30 条）。
