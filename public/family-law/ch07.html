PART I · 通用全流程

07 判决与调解书的生效、履行与强制执行

判项写得好不如履行落得实——家事案件的客户满意度，最终由执行到位率裁判

法条 《民法典》第 1092 条 婚姻家庭编解释（一）第六十一、六十六至六十八条、第八十三条、第八十四条 《民事诉讼法》（2023 修正，条号以现行文本为准）
家事案件的「结案」不是宣判或签收调解书那一刻，而是履行到位那一刻。判决书中「房屋归女方」若不过户、「折价款×万」若不支付、「每月探望」若被阻断，对客户而言案子就没赢。 本章按时间线展开：生效时点 → 身份效力 → 主动履行促成 → 强制执行启动 → 家事执行特殊手段 → 执行不能与预期管理 → 判后延伸（隐匿财产再诉）。 其中申请执行的期间为二年、执行依据类型、强制措施等均依《民事诉讼法》相关规定，因 2023 年修正后条文重编号，本章一律以「《民事诉讼法》相关规定」指代，条号以现行有效官方文本为准。

一、生效时点：判决与调解书的分水岭

《民事诉讼法》相关规定（判决与调解书的生效） 地方各级人民法院作出的判决，当事人在法定上诉期内未提出上诉的，上诉期届满发生法律效力；离婚判决中关于身份关系（是否准予离婚）的判项，须待判决生效后方可发生解除婚姻关系的效力。
调解达成协议，人民法院应当制作调解书；调解书经双方当事人签收后，即具有法律效力，与判决具有同等强制执行力。 民事判决的上诉期为十五日（自送达之日起算，《民事诉讼法》相关规定），条号以现行有效官方文本为准。调解书无上诉期，以双方签收为生效节点。
  • 判决书：送达后十五日内双方均未上诉，第十五日届满次日生效。注意是「双方均未上诉」——一方上诉则整体进入二审，一审判决不生效。
  • 调解书：双方当事人签收即生效，无上诉期。但如前所述（ch05），签收前任何一方可反悔，调解书不成立。
  • 实务含义：调解结案在「生效速度」上明显占优——签收即稳；判决还要熬过十五天上诉等待期，且对方可能上诉拖入二审。对客户「想尽快了断」的需求，调解的生效确定性是隐性价值。

二、离婚判决与调解书的身份效力

判决书未生效期间，婚姻关系仍在——不得再婚

这是家事领域最危险、也最常被当事人忽略的身份效力点：

  • 离婚判决未生效前，双方婚姻关系仍然存续。当事人在上诉期内与他人登记结婚，构成重婚（民法典第 1051 条、解释二第一条重婚绝对无效规则的精神）。
  • 即便一审判离，只要十五天上诉期未满或对方已上诉，当事人就还不能「恢复单身」；急于再婚的，必须等判决生效证明。
  • 调解书因签收即生效，身份关系解除时点清晰，相对不易出此错；但仍须以「签收且对方也签收」为节点。
  • 生效证明：判决生效后，律师应代当事人向法院申请《生效法律文书证明》（或调取送达回证），作为再婚、迁户、处置财产的前置凭证。
  • 身份判项与财产判项：离婚判决中「准予离婚」是身份判项，「房屋归×方」「支付折价款」是财产判项，二者同文书但效力独立。身份判项生效即解除婚姻；财产判项靠履行或执行落地。
  • 继承案件无此身份风险：继承判决 / 调解书生效即确定继承权与份额，不涉及「再婚」问题，但涉及遗产处分的，生效前处分可能构成无权处分，须等文书生效。

三、主动履行的促成：把执行风险挡在前面

最好的执行是「不用执行」。律师在文书生效前后应主动促成履行，而非坐等违约。

  • 履行宽限期条款：调解 / 判决可约定合理的自动履行期（如「本判决 / 调解书生效后×日内办理过户」），给义务人缓冲，也避免一生效就进入对抗。
  • 分期方案落地：折价款分期 + 加速到期 + 担保（见 ch05 范本二）应在文书中固化。义务人不按约付首期的，权利人可立即就全额申请执行，不必逐期等待。
  • 担保办理前置：约好的抵押担保，务必在文书生效后×日内实际办理抵押登记——只写「提供抵押」不办登记，担保不生效，等于没担保。
  • 主动催告留痕：履行期届满前发书面催告（律师函），既给义务人最后窗口，也为后续申请执行、主张迟延履行利息固定证据。

四、强制执行启动

《民事诉讼法》相关规定（申请执行期间） 申请执行的期间为二年，从法律文书规定的履行期间的最后一日起计算；法律文书规定分期履行的，从最后一期履行期限届满之日起计算；法律文书未规定履行期间的，从法律文书生效之日起算。申请执行时效适用有关诉讼时效中止、中断的规定。 上述「二年」为《民事诉讼法》相关规定确定的申请执行期间，条号以现行有效官方文本为准；家事案件同样适用，逾期申请且无中止中断事由的，法院不予受理。
  • 起算点：一次性给付的，从履行期最后日起算二年；分期给付的，从最后一期届满起算——意味着前面几期逾期，只要在最后一期到期起二年内申请执行，仍可就全部主张（但越早申请越利于财产控制）。
  • 管辖法院：一般向作出一审裁判的法院或与一审法院同级的被执行财产所在地法院申请执行（《民事诉讼法》相关规定）。家事案件多向原审理法院申请，便于承办法官衔接。
  • 执行依据类型：家事案件可执行的内容包括：
    • 给付抚养费 / 经济补偿 / 折价款 / 损害赔偿金；
    • 房屋过户、车辆变更登记；
    • 房屋腾退（配合迁出）；
    • 探望权的协助执行（配合交接子女）；
    • 户口迁出（部分法院受理，执行有难度但可留追责依据）。
  • 申请材料：执行申请书、生效文书、生效证明 / 送达回证、身份证明、财产线索清单（已知账户、房产、车辆、股权）、委托手续。
财产线索清单是执行的弹药

申请执行时附的财产线索越具体，法院查控越快。律师应在诉讼中（甚至诉前，见 ch03 保全）就摸清：义务人名下银行卡开户行与卡号、房产具体坐落与权证号、车辆牌号、股权所在公司与比例、工资发放单位。执行阶段再查，对方往往已转移。线索清单本身就是「可执行性」的保证书。

五、家事执行的特殊手段

5.1 抚养费：扣划工资、冻结账户

  • 抚养费是持续性给付，执行中可申请扣留、提取义务人的工资收入（《民事诉讼法》相关规定），由单位协助按月划扣，比一年一申请执行稳。
  • 对义务人名下银行存款、微信 / 支付宝余额、理财，可申请冻结、扣划。
  • 义务人换工作、隐身的，可申请法院向其新单位送达协助执行通知，或将其纳入限制消费 / 失信名单施压。

5.2 房产过户：协助执行通知书直接办理

  • 房屋归一方、对方拒配合过户的，法院可向不动产登记中心送达协助执行通知书，权利人可单方持文书办理过户，无需对方到场（《民事诉讼法》相关规定）。这是家事执行中最「硬」的手段之一。
  • 对方拒不腾退的，可申请腾退执行；拒不腾退情节严重的，依法采取强制措施。

5.3 拒不执行的强制措施

婚姻家庭编解释（一）第六十一条（抚养义务强制） 对拒不履行或者妨害他人履行生效判决、裁定、调解中有关抚养义务的，人民法院可依法采取强制措施。
注：该条所引旧《民事诉讼法》条款已重编号，写作时统一表述为「依法采取强制措施」。
  • 罚款、拘留：对拒不履行生效文书确定的给付、过户、腾退、协助探望等义务的，法院可依法罚款、拘留（《民事诉讼法》相关规定）。
  • 拒执罪线索固定：义务人隐藏、转移财产，有能力履行而拒不履行，情节严重的，可能构成拒不执行判决、裁定罪（《刑法》第三百一十三条，经人身安全保护令司法解释第十二条等关联）。律师应指导当事人固定线索：转移资产的银行流水、高消费记录、名下财产线索——为刑事追诉或司法拘留做准备。
  • 探望权的执行边界：解释一第六十六至六十八条明确，拒不协助行使探望权的可拘留、罚款，但不能对子女的人身、探望行为强制执行。即法院不能把孩子强行抱给一方，只能处罚阻碍的一方、责令其履行协助义务。这意味着探望权执行靠「罚阻拦者」而非「强带离子女」，律师应据此管理当事人预期，并优先用具体时间表条款降低冲突（见 ch05）。
常见坑「判了探望权，对方把孩子藏起来，申请强制执行却执行不了」

这是探望权执行最普遍的落差。根子在法律规定：探望权不能对子女人身强制（解释一第六十六条）。实务应对：

  • 调解书 / 判决书把探望写具体（「每月第一、三周周六 9 时至 18 时」），让「协助义务」可识别、可处罚；
  • 对方阻碍的，申请法院对其罚款、拘留，并记入笔录，形成持续压力；
  • 对方有抢夺、藏匿子女行为的，同步引用解释二第十二条申请人身安全保护令或人格权侵害禁令；
  • 长期阻碍且情形严重的，可据解释二第十四条主张变更抚养关系——把「执行难」转化为「抚养权变更」的实体请求，往往比单纯执行更有效。

六、执行不能与预期管理

  • 确无财产的处理：穷尽查控仍无足额财产的，法院可裁定终结本次执行程序（《民事诉讼法》相关规定），但并非不再执行——发现财产后可申请恢复执行，不受申请执行期间限制。
  • 中止与恢复：义务人下落不明、暂无财产、或需等待另一执行结果的，可中止执行；事由消失后恢复。律师应告知当事人「终本 / 中止≠输了」，重点是持续提供财产线索。
  • 预期管理话术：接案时就应把「执行到位率」写进风险告知——对方是「壳」、在外地、已转移的，判项金额再高也可能执行不到。与其承诺结果，不如承诺「全程财产线索追踪 + 终本后恢复执行机制」。
  • 限制消费与失信：对恶意不履行的，申请限制消费令、纳入失信名单，施加工商、出行、高消费压力，常比直接扣款更能倒逼履行。

七、判后延伸：财产发现后的再诉

《民法典》第一千零九十二条 + 婚姻家庭编解释（一）第八十三条、第八十四条 第一千零九十二条：夫妻一方隐藏、转移、变卖、毁损、挥霍夫妻共同财产，或者伪造夫妻共同债务企图侵占另一方财产的，在离婚分割夫妻共同财产时，对该方可以少分或者不分。离婚后，另一方发现有上述行为的，可以向人民法院提起诉讼，请求再次分割夫妻共同财产。
第八十三条：离婚后，一方以尚有夫妻共同财产未处理为由请求分割的，经审查该财产确属离婚时未涉及的，人民法院应当依法予以分割。
第八十四条：当事人依据第一千零九十二条规定请求再次分割夫妻共同财产的诉讼时效为三年，从当事人发现之日起计算。
  • 三种判后再诉路径：
    • ① 未处理的共同财产（解释一第八十三条）：离婚时压根没涉及的，可请求分割，无三年时效限制（属确权 / 分割请求权，不适用诉讼时效障碍，具体以现行司法解释与裁判口径为准）。
    • ② 隐匿、转移等法定行为（第 1092 条 + 解释一第八十四条）：发现之日起三年时效，可诉请再次分割，且可主张对方少分或不分。
    • ③ 离婚协议履行争议：登记离婚后因履行财产条款起诉的，应受理（解释一第六十九条第二款）；协议反悔请求撤销的，未发现欺诈胁迫驳回（解释一第七十条）。
  • 时效起算关键：「自发现之日起算」——所以当事人「早知道但没证据」与「实际发现」不同；律师应提示当事人一旦发现线索立即固定证据并起诉，不要等「凑齐再说」导致时效流逝。
  • 与「再无其他争议」条款的关系：解释一第八十四条的再诉针对法定隐匿行为，不受调解书「再无其他争议」兜底约束；但若是「明知而未列明、主动放弃」的，再诉难度显著增大（见 ch05 3.4）。区分「主动放弃」与「被隐匿未发现」，是再诉成败的分水岭。
  • 证据衔接：判后发现的财产线索，可凭新证据（银行流水、房产查档、对方自认）提起再诉；若诉讼中已申请调查令但对方隐瞒，再诉时可直接引用已调证据。
范本一 · 强制执行申请书（抚养费 / 折价款通用框架）
强 制 执 行 申 请 书 申请人：××（姓名、身份证号、住址、电话） 被执行人：××（同上） 请求事项： 1. 强制被执行人履行××法院（20××）××民初××号民事判决书 / 调解书第×项：支付申请人××款××元（含逾期利息××元）； 2. 强制被执行人配合办理位于××市××路××号×室房屋过户手续（向不动产登记中心送达协助执行通知书）； 3. 强制被执行人按调解书约定的探望时间表履行协助义务； 4. 本案执行费由被执行人承担。 事实与理由： 上述生效文书于×年×月×日发生法律效力，被执行人应于×年×月×日前履行。履行期届满后，申请人多次催告（律师函编号××），被执行人拒不履行（/仅支付×期后失联）。 被执行人可供执行财产线索：①××银行账户（开户行××，卡号尾号××）；②上述房屋；③工资由××单位发放（可扣留提取）。 依据《民事诉讼法》相关规定，申请执行期间为二年，申请人于期限内提出申请，恳请依法强制执行。 此致 ××人民法院 申请人（签名）： ×年×月×日 附：1. 生效文书复印件；2. 生效证明 / 送达回证；3. 催告留痕；4. 财产线索清单。
范本二 · 再次分割夫妻共同财产起诉状要点（第 1092 条）
民事起诉状（再次分割夫妻共同财产，节选） 原告：×× 被告：×× 诉讼请求： 1. 请求依法再次分割被告隐藏的夫妻共同财产：××银行卡（尾号××）内存款××元、××股权×%； 2. 判令被告少分或不分上述被隐藏财产（依据《民法典》第1092条）； 3. 本案诉讼费由被告承担。 事实与理由： 原被告于×年×月×日离婚（（20××）××民初××号调解书）。离婚后，原告于×年×月×日发现被告在婚姻关系存续期间隐藏如下财产：①×行账户（尾号××）在×年×月至×月转入××元，未列入离婚分割；②被告名下××公司×%股权实为婚内取得。 原告发现上述行为距起诉未逾三年（解释一第八十四条）。被告隐藏、转移夫妻共同财产，分割时应当少分或不分。恳请支持。 此致 ××人民法院 原告： ×年×月×日 附：1. 离婚文书；2. 银行流水 / 查档结果（发现证据）；3. 时效起算说明（发现日×年×月×日）。
常见坑「终本后就不管了，三年后发现财产已过申请执行期」

两个时效容易混：

  • 申请执行期间（二年）：从履行期最后日起算。终本不代表期间重算——你已在二年内申请了，终本是执行程序内的暂停，发现财产直接申请恢复，不受二年限制。
  • 再次分割时效（三年，自发现起算）：针对离婚后发现隐匿财产的再诉（解释一第八十四条），起算点是「发现之日」，不是离婚之日。所以「终本后三年才发现对方藏了房」仍可再诉，但要从发现日重新算三年。

关键动作：终本后保持财产线索追踪，一旦发现新财产，区分「原执行案恢复」还是「另案再诉」，分别走对应程序，不要因为一个「终本」就放弃。

八、红线清单 / 自检清单

  • 判决上诉期十五日，双方均未上诉方生效；调解书双方签收即生效，无上诉期——调解在生效确定性上占优。
  • 离婚判决未生效前婚姻关系仍存，当事人不得再婚，否则构成重婚；急于再婚须等生效证明。
  • 申请执行期间二年，分期给付从最后一期届满起算；逾期且无中止中断事由法院不予受理，务必在期内申请。
  • 执行申请必附财产线索清单（账户、房产、车辆、股权、工资单位），线索越具体查控越快，执行阶段再查多已转移。
  • 抚养费可扣划工资、冻结账户；房产过户凭协助执行通知书单方办理，无需对方配合。
  • 拒不履行可罚款、拘留；有能力履行而隐匿转移情节严重的，固定线索追究拒不执行判决、裁定罪（《刑法》第313条）。
  • 探望权不能对子女人身强制执行（解释一第六十六条），只能处罚阻碍方；落点是具体时间表条款 + 变更抚养关系路径。
  • 终本 / 中止≠不再执行，发现财产可申请恢复，不受二年申请执行期间限制；持续追踪线索是执行律师的常态工作。
  • 判后隐匿财产再诉依第 1092 条 + 解释一第八十四条，时效三年自发现起算；不受调解书「再无其他争议」约束，但「明知放弃」的除外。
  • 未处理共同财产再诉依解释一第八十三条，须证明确属离婚时未涉及；区分「主动放弃」与「被隐匿未发现」决定再诉成败。
