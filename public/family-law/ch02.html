PART I · 通用全流程

02 诉前准备

管辖错一步，全案退回；主体漏一人，分割重来

法条《民法典》第 1079 条婚姻家庭编解释（一）第 62 条继承编解释（一）第 44 条《民事诉讼法》相关规定（条号以现行文本为准）
诉前准备是把接待阶段梳理出的事实，转化为可被法院受理、且不会被程序瑕疵拖垮的之诉。这一阶段的核心交付物是三件事：确定去哪个法院、列对当事人、摸准财产线索。任何一项出错，轻则补正、重排期，重则裁定驳回、必须另案重诉。离婚与继承在管辖与主体规则上差异极大，不能套用同一套模板。

一、管辖确定

家事案件的管辖以《民事诉讼法》的一般地域管辖原则为底座（原告就被告），但因身份关系的人身属性，存在大量例外。判断管辖的第一步永远是先定性：这是离婚诉讼、继承诉讼，还是抚养 / 探望等衍生的身份财产之诉——不同案由的连接点不同。

1.1 离婚案件的一般管辖

离婚诉讼原则上由被告住所地人民法院管辖；被告住所地与经常居住地不一致的，由经常居住地人民法院管辖。实务中「经常居住地」的认定（公民离开住所地至起诉时已连续居住满一年以上的地方）是高频争点，须提前收集被告的居住证、租房合同、社保缴纳地、社区证明等佐证，避免立案时因「被告下落」不清被要求补正。

《民事诉讼法》相关规定（条号以现行文本为准） 对公民提起的民事诉讼，由被告住所地人民法院管辖；被告住所地与经常居住地不一致的，由经常居住地人民法院管辖。下列民事诉讼，由原告住所地人民法院管辖；原告住所地与经常居住地不一致的，由原告经常居住地人民法院管辖：（一）对不在中华人民共和国领域内居住的人提起的有关身份关系的诉讼；（二）对下落不明或者宣告失踪的人提起的有关身份关系的诉讼；（三）对被采取强制性教育措施的人提起的诉讼；（四）对被监禁的人提起的诉讼。 本段所引为《民事诉讼法》一般地域管辖与例外规则的制度性表述。2023 年修正后条文重编号，禁止凭记忆写具体条号，故统一标注「《民事诉讼法》相关规定，条号以现行文本为准」。

1.2 离婚案件的特殊管辖连接点

下列情形突破「原告就被告」，由原告住所地或经常居住地法院管辖，诉前必须逐条核对被告现状：

被告情形管辖连接点实务取证要点
夫妻一方离开住所地超过一年，另一方起诉离婚可由原告住所地法院管辖证明原告一直在原住所、被告已离住所地逾一年（居住证注销、外地居住证明）
双方均离开住所地超过一年由被告经常居住地法院管辖；无经常居住地的，由原告起诉时被告居住地法院管辖需分别证明双方离住所时长与被告现居地
被告下落不明或已被宣告失踪原告住所地 / 经常居住地法院（身份关系诉讼例外）需先有公安机关出具的下落不明证明或法院宣告失踪裁定
被告被采取强制性教育措施 / 被监禁原告住所地 / 经常居住地法院调取强制教育措施决定书或服刑地证明
被告不在中华人民共和国领域内居住原告住所地 / 经常居住地法院（身份关系诉讼例外）涉外 / 涉港澳台，需先定连接点（见 1.4）
「被告下落不明」不能口头主张

很多当事人说「他跑了、找不到」，但法院立案要求的是可证成的下落不明。仅有当事人陈述，通常不足以适用原告住所地管辖，立案庭会要求提供公安机关的查找记录、社区证明，或先走宣告失踪程序。诉前就应向当事人讲清：想走原告住所地管辖，必须先有官方文书支撑，否则仍回被告住所地。

1.3 继承案件的管辖与级别管辖惯例

继承纠纷由被继承人死亡时住所地或者主要遗产所在地人民法院管辖（《民事诉讼法》相关规定）。两个连接点择一即可，但实务中若主要遗产（如不动产）价值巨大，选择不动产所在地法院往往更利于后续保全与执行衔接。

  • 级别管辖：绝大多数家事案件由基层人民法院管辖；标的特别巨大、在当地有重大影响的，依级别管辖标准可能由中级人民法院一审，诉前应核对当地高院发布的级别管辖金额标准。
  • 专属情形：涉及不动产的继承、离婚后财产分割中不动产确权，仍按一般地域管辖确定，不适用不动产纠纷的专属管辖（该专属管辖仅针对因不动产权利确认、分割引起的物权纠纷）。家事案件中不动产作为标的物，通常不与专属管辖冲突，但诉请写为「分割夫妻共同财产中的房屋」与「确权」在管辖论证上需区分清楚。

1.4 涉港澳台与涉外：先定连接点再定管辖

涉港澳台及涉外家事案件，不能跳到「去哪个法院」，而要先解决连接点：

  • 管辖权连接点：被告（或原告）住所、经常居所、主要财产所在地、婚姻缔结地等，分别指向不同法院；涉外离婚中一方为中国公民的，中国法院对外籍配偶仍有管辖权路径。
  • 法律适用连接点：依《涉外民事关系法律适用法》——诉讼离婚适用法院地法律（第 27 条）；夫妻人身关系适用共同经常居所地法或国籍国法（第 23 条）；夫妻财产关系可协议选择（第 24 条）；法定继承适用被继承人死亡时经常居所地法律，不动产法定继承适用不动产所在地法律（第 31 条）；遗嘱方式与效力分别依第 32、33 条。
  • 区际送达与取证：涉港澳台存在独立的区际司法协助安排，送达周期与方式不同于纯内地案件，诉前应把送达可行性作为管辖选择的隐性变量。
管辖选择的策略维度

家事案件的管辖并非纯粹技术问题，往往蕴含策略：被告经常居住地与原告住所地分属不同法院时，选择更便于我方举证、更熟悉裁判口径、保全协调更顺畅的法院是正当且重要的。但不得通过虚构经常居住地制造连接点——这属于虚假陈述，一旦查实不仅管辖被推翻，还可能触发诚信惩戒。

常见坑立案被要求「先补正管辖材料」时怎么办

家事立案被退回补正，十有八九出在管辖。处理顺序：

  • 先核对被告身份证地址与现居地是否一致，不一致时立刻补经常居住地证明；
  • 若主张原告住所地管辖，确认四类例外情形之一，并把官方文书备齐；
  • 继承案件确认被继承人死亡时住所与主要遗产地，二者择一后固定；
  • 不要为赶时间随便选法院——管辖错误一旦进入实体审理，对方仍可提异议，届时移送成本远高于诉前一次核实。

二、当事人主体

家事案件的主体适格，比普通民事案件更讲究「一个都不能少」。漏列必要共同诉讼人，会导致分割范围不全、判决既判力无法覆盖，事后必须重诉或追加，成本极高。

2.1 离婚诉讼的双方主体

离婚诉讼的原告、被告必须是婚姻关系双方本人。下列特殊情形须提前处置：

  • 无民事行为能力人的离婚：无民事行为能力人配偶有监护侵害行为的，应先依法变更监护人，由新监护人作为法定代理人代理提起离婚诉讼（婚姻家庭编解释（一）第 62 条）。直接以配偶为法定代理人起诉离婚，主体资格存在硬伤。
  • 限制民事行为能力人：能否自主起诉离婚，取决于其辨认能力，必要时由法定代理人介入，但须避免监护人借离婚侵害被监护人财产利益。
  • 军婚：军人配偶起诉离婚，须军人一方同意（军人一方有重大过错的除外，民法典第 1081 条）；诉前应评估军人一方是否存在重大过错证据。
  • 男方起诉的时间限制：女方怀孕期间、分娩后一年内或终止妊娠后六个月内，男方不得提出离婚（民法典第 1082 条），女方提出或法院认为确有必要受理的除外。此期间男方起诉会被直接驳回。
婚姻家庭编解释（一）第六十二条 无民事行为能力人的配偶有民法典第三十六条第一款规定行为，其他有监护资格的人可以依照特别程序要求变更监护关系；变更后的监护人代理无民事行为能力一方提起离婚诉讼的，人民法院应予受理。 该条指向的监护侵害包括实施严重损害被监护人身心健康行为、怠于履职或无法履职且拒绝委托、实施严重侵权等行为。先变更监护、后代理诉讼，顺序不可颠倒。

2.2 继承案件：必须列全部继承人

继承诉讼是典型的必要共同诉讼。被继承人死亡后，第一顺序（配偶、子女、父母）、第二顺序（兄弟姐妹、祖父母、外祖父母）的继承人都可能成为当事人。遗漏任一继承人，判决对遗漏者无既判力，且分割份额必须重算。

继承编解释（一）第四十四条 继承诉讼开始后，如继承人、受遗赠人中有既不愿参加诉讼又不放弃实体权利的，应当追加为共同原告；继承人已书面表示放弃继承、受遗赠人在知道受遗赠后六十日内表示放弃受遗赠或者到期没有表示的，不再列为当事人。 「六十日」对应民法典第 1124 条受遗赠的表态期限：到期未表示的视为放弃受遗赠。诉前应向当事人核实全部潜在继承人名单，包括代位继承人、尽了主要赡养义务的丧偶儿媳 / 女婿（民法典第 1129 条作为第一顺序）、以及酌情分得遗产的继承人以外的人（民法典第 1131 条）。

继承案件中，当事人常隐瞒其他继承人（「我弟早就不管了，不用列」）。但是否放弃继承是程序权利，不能由他人代为推定。诉前必须让当事人如实提供全部继承人的姓名、住址、联系方式与现状，由法院依法通知或追加。漏列的代价是：判决生效后，被遗漏的继承人仍可主张权利，已分割的遗产面临回转。

2.3 无 / 限制行为能力继承人的法定代理

未成年子女、无 / 限制民事行为能力的继承人参与继承，须由监护人作为法定代理人。此处要特别防范利益冲突：当法定代理人本身也是继承人（如父代未成年子继承，父同时是配偶继承人），其代理行为不得损害被代理人利益，涉及财产代管、份额让渡的，应谨慎并保留记录。

三、财产线索摸排

诉前财产摸排的目标，是在起诉前尽可能锁定对方财产的位置与线索，为「先保全后起诉」或「起诉同时申请保全」提供坐标。但摸排手段有法律边界：公开渠道能查的尽量查，查不到的不能违法获取。

3.2 律师调查令的时点边界

律师调查令是家事案件中调取银行流水、不动产、公积金、保险、证券、工商内档的核心工具，但其适用有严格的时点边界：

  • 通常须在起诉后申请：法院受理案件后，律师可持法院签发的调查令向有关单位调取证据。诉前（尚未立案）一般无法申请调查令，因为调查令以「本案已进入诉讼」为前提。
  • 诉前只能靠当事人自证线索：起诉前，律师能做的，是指导当事人自行收集其可接触的线索（如共同账户截图、保单照片、房产证复印件），并把这些线索作为申请保全的「初步材料」。
  • 例外窗口：部分法院在诉前调解阶段允许持调解案号申请调查令，但非普遍做法，须以受理法院实操为准，不能假定。
诉前摸排的「两条腿」

一条腿是公开可查：能自己查的（公示系统、当事人手头材料）立刻查，形成财产清单；另一条腿是线索预设：把查不到但「应当存在」的财产（如对方口头提过的公司、疑似代持的房）写成线索清单，待立案后第一时间批量申请调查令与保全。诉前不做这步，立案后会手忙脚乱、错过保全黄金期。

3.3 「打草惊蛇」风险与先保全后起诉的权衡

家事财产摸排存在一个根本张力：查得越深，对方越容易察觉并加速转移。应对策略：

  • 先保全后起诉：对有紧迫转移风险的（如刚发现大额不明转出、对方正低价处置房产），可在起诉前申请诉前保全（须提供担保，并在法定期限内起诉，具体期限依《民事诉讼法》相关规定），把财产冻住再推进诉讼。
  • 起诉与保全同步：多数情形选择在提交起诉状的同时提交保全申请，缩短对方反应窗口。
  • 控制摸排范围：诉前尽量只做「确认存在」的轻量查询（如不动产登记中心一次性查档），避免反复、大范围查询引起对方警觉；深度调证留到立案后借调查令完成。
常见坑当事人要求「偷偷查他所有银行卡流水」

这是越界请求。律师无权在诉前以私人手段查询他人银行账户，只能通过：

  • 立案后申请法院调查令，由律师持令到银行调取（范围限于与案件有关的账户）；
  • 或申请法院依职权查询。任何通过非法渠道购买、黑客手段获取流水的行为，不仅证据可能被排除，律师自身面临执业纪律乃至刑事风险。应明确告知当事人合法路径与边界。

四、调解前置

家事案件的「调解」不是可选项，而是贯穿始终的法定程序环节。诉前准备阶段就必须把调解作为并行策略加以设计。

4.1 离婚的先行调解义务

《民法典》第一千零七十九条（节选） 夫妻一方要求离婚的，可以由有关组织进行调解或者直接向人民法院提起离婚诉讼。人民法院审理离婚案件，应当进行调解；如果感情确已破裂，调解无效的，应当准予离婚。 「应当进行调解」是法院的法定职责，也是律师可借力的节点：在调解阶段达成离婚协议并申请司法确认 / 出具调解书，效率远高于判决，且调解书具有强制执行力。

调解无效的法定破裂情形包括：重婚或与他人同居；实施家庭暴力或虐待、遗弃家庭成员；有赌博、吸毒等恶习屡教不改；因感情不和分居满二年；其他导致夫妻感情破裂的情形；一方被宣告失踪；判决不准离婚后又分居满一年再次起诉（民法典第 1079 条）。诉前就应把这些情形的证据成熟度评估清楚——若证据不足，调解或第一次诉讼判决不离是大概率，策略上应提前与当事人对齐。

4.2 法院诉前调解的现状与运用

在立案登记制下，法院普遍将家事案件导入诉前调解程序：当事人提交材料后，先进入调解阶段（通常有期限，依《民事诉讼法》相关规定及各地法院操作），调解不成再正式立案进入审理。律师应这样运用：

  • 把诉前调解当谈判桌：在调解阶段即可提出财产分割、抚养安排的具体方案，促成调解协议，避免开庭审理的对抗与曝光；
  • 调解阶段仍要防转移：诉前调解期间，对方转移财产的风险并不消失，必要时在调解阶段即申请保全（见下）；
  • 评估调解员的专业度：家事调解员对子女利益、财产分割的裁量倾向不一，律师应准备充分方案，而非把调解当成「走过场」。

4.3 诉前调解期间仍可申请保全

一个重要但常被忽略的实务点：诉前调解 / 诉前阶段并非不能保全。即便案件尚未正式立案审理，只要符合保全条件（存在转移、毁损财产的现实风险），即可申请诉前保全或保全，把财产先固定，再推进调解或诉讼。这对家事案件尤为关键——很多当事人在调解阶段「谈不拢就转起诉」，期间正是财产最危险的时候。

诉前准备的产出清单

完成本章后，律师手里应握有四项交付：① 管辖连接点与拟起诉法院及依据；② 完整当事人名单（离婚双方 / 全部继承人及代理关系）；③ 财产线索清单（已查实 + 待调查令调证）；④ 调解方案雏形与保全申请预案。缺任何一项，都不应仓促进入立案。

五、本章红线清单 / 自检清单

  • 已先定性案由（离婚 / 继承 / 抚养探望），并据此选择管辖连接点，未混淆不同案由的管辖规则。
  • 离婚案件已确认被告住所 / 经常居住地，特殊情形（离住所逾一年、下落不明、强制教育措施、监禁、境外居住）已对应到原告住所地管辖并有官方文书支撑。
  • 继承案件已依《民事诉讼法》相关规定锁定被继承人死亡时住所或主要遗产所在地，并核对级别管辖标准。
  • 涉港澳台涉外案件已先定管辖权连接点，再定法律适用连接点（援引《涉外民事关系法律适用法》相关规定），未颠倒顺序。
  • 离婚诉讼主体适格：无民事行为能力人已先变更监护再代理起诉（解释（一）第 62 条）；注意军婚与男方起诉时间限制。
  • 继承案件已列全部继承人，对「不参加诉讼也不放弃权利」者已准备追加（继承编解释（一）第 44 条），含代位、转继承、胎儿预留份。
  • 财产摸排已穷尽公开渠道并形成清单；律师调查令时点边界清楚（通常起诉后申请，诉前靠当事人自证）。
  • 已评估「打草惊蛇」风险，对紧迫转移情形制定了先保全后起诉或诉保同步方案。
  • 已将离婚先行调解（民法典第 1079 条）作为并行策略，并知悉诉前调解期间仍可申请保全。
  • 所有《民法典》及司法解释条号均出自法源基准表；民诉法条文统一标注「相关规定，条号以现行文本为准」，未凭记忆写具体条号。
