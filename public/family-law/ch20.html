PART III · 特殊程序与收尾

20 特别程序：宣告失踪、宣告死亡与行为能力认定

三类非讼程序，一审终审，是离婚、继承、监护案件中打开实体争议的前置钥匙

法条《民法典》第 40、46、48、24 条婚姻家庭编解释（一）第 62 条继承编解释（一）第 1 条《民事诉讼法》特别程序相关规定（条号以现行文本为准）
宣告失踪、宣告死亡、认定公民无民事 / 限制民事行为能力，都属于《民事诉讼法》规定的特别程序（非讼程序），一审终审、不适用普通程序的对审结构。它们在家事案件中不是「冷门程序」，而是频繁出现的前置关卡：一方失踪，离婚和继承都走不动；一方行为能力存疑，遗嘱效力和离婚代理都成问题。本章按三类程序分别给出「适用条件 → 管辖 → 证据 → 与家事实体联动 → 文书模板 → 坑点」。
本页民诉法条号口径

本章涉及的管辖、公告期、一审终审、救济路径均规定于《民事诉讼法》特别程序编。因 2023 年修正后条文重编号，本章统一写「《民事诉讼法》特别程序相关规定」并提示「条号以现行文本为准」，办理时以现行有效官方文本核对，不得凭记忆使用旧条号。

一、宣告失踪

《民法典》第四十条 自然人下落不明满二年的，利害关系人可以向人民法院申请宣告该自然人为失踪人。

宣告失踪的核心法律效果是设立财产代管人，保障下落不明人的财产不被悬空，也为利害关系人管理其财产提供合法身份。适用条件与操作：

1. 要件与起算

  • 下落不明满二年：起算点为「失去音讯之日」；战争期间下落不明的，从战争结束之日起算；有关机关证明下落不明时间的，从证明记载之日起算。
  • 利害关系人申请：配偶、父母、子女、近亲属、代管人等均可，顺序上无严格先后，但实务中由最密切的配偶或近亲属提出。
  • 非讼前置：未经宣告失踪，不能直接以「找不到人」为由处分其财产；但离婚诉讼中一方下落不明的，可走公告送达而非必须先宣告失踪（两条路径择一）。

2. 财产代管人制度

代管人职责边界

代管人从失踪人的财产中支付失踪人所欠税款、债务和应付的其他费用，并妥善管理财产。代管人不是财产权利人，不得擅自处分、赠与、转移代管财产；怠于履职或侵害财产利益的，其他利害关系人可申请变更代管人。实务中常被忽略：代管人代管期间，离婚 / 继承仍可另行推进，代管身份不阻断实体权利主张。

3. 证据与管辖

事项规则实务证据
管辖下落不明人住所地基层人民法院（《民事诉讼法》特别程序相关规定）准备住所地证明：户籍、居住证、居委会证明
下落不明满二年的证明公安机关 / 居村委会出具的下落不明证明、最后联系时间证据报警记录（人口走失登记）、最后一次通讯记录、亲友证言、单位出具的离岗证明
公告受理后发出寻找公告（《民事诉讼法》特别程序相关规定）公告期以现行文本为准；公告期满无人出现即判宣告失踪
财产状况申请时宜附财产线索，便于指定代管与后续管理房产、账户、股权线索清单

二、宣告死亡

《民法典》第四十六条 / 第四十八条 第四十六条：自然人有下列情形之一的，利害关系人可以向人民法院申请宣告该自然人死亡：（一）下落不明满四年；（二）因意外事件，下落不明满二年；（三）因意外事件下落不明，经有关机关证明该自然人不可能生存的，申请宣告死亡不受二年时间的限制。
第四十八条：被宣告死亡的人，人民法院宣告死亡的判决作出之日视为其死亡的日期；因意外事件下落不明宣告死亡的，意外事件发生之日视为其死亡的日期。

1. 三种情形对照

情形下落不明期间死亡日期确定
一般下落不明满四年判决作出之日视为死亡日期（第 48 条）
因意外事件下落不明满二年意外事件发生之日视为死亡日期（第 48 条）
意外事件经有关机关证明不可能生存不受二年限制意外事件发生之日视为死亡日期（第 48 条）

2. 宣告死亡与继承启动的联动

继承编解释（一）第一条 继承从被继承人死亡时开始。宣告死亡的，根据民法典第四十八条确定的死亡日期，为继承开始的时间。

宣告死亡判决是继承开始的法定触发点：判决作出（一般情形）或意外事件发生（意外情形）之日，即继承开始，配偶、子女、父母等第一顺序继承人得主张继承权。实务中常见场景：

  • 海上、空难、矿难等意外事件：凭有关机关（海事、民航、应急）证明「不可能生存」，可不受二年限制直接申请，加速继承与保险理赔。
  • 继承开始前须先完成宣告死亡程序：遗产处于悬空状态时，继承人不宜径行分割，应先立特别程序案，判决生效后再启动法定继承（参照 ch15）。
  • 死亡日期影响继承份额：涉及代位继承、转继承（第 1152 条）、胎儿预留份（第 1155 条）时，死亡日期的确定直接决定权利链条。

3. 婚姻关系与再婚效力

死亡宣告后婚姻与再婚的规则

自然人被宣告死亡，其与配偶的婚姻关系自死亡宣告之日起消除，配偶可再婚。若被宣告死亡人重新出现、死亡宣告被撤销，婚姻关系是否恢复适用民法典相关规定的例外规则（被宣告死亡人的配偶再婚或向婚姻登记机关书面声明不愿意恢复的除外情形）——本章不展开具体条号，办理时核对《民法典》「撤销死亡宣告」相关条文。核心风险：客户在宣告死亡后已再婚的，撤销死亡宣告不当然恢复前婚，律师须在前端告知再婚的法律稳定性。

4. 申请书要素

宣告死亡申请书应写明：申请人身份及与被申请人的关系、被申请人下落不明的事实与起算时间、符合第 46 条何种情形、有关机关证明（意外事件情形）、请求宣告死亡及确定死亡日期的依据。证据同宣告失踪，另附意外事件证明（如属情形二、三）。

三、民事行为能力认定

《民法典》第二十四条 不能辨认或者不能完全辨认自己行为的成年人，其利害关系人或者有关组织可以向人民法院申请认定该成年人为无民事行为能力人或者限制民事行为能力人。
被人民法院认定为无民事行为能力人或者限制民事行为能力人的，经本人、利害关系人或者有关组织申请，人民法院可以根据其智力、精神健康恢复的状况，认定该成年人恢复为限制民事行为能力人或者完全民事行为能力人。

1. 鉴定流程与周期

  • 鉴定意见是核心证据：行为能力认定以精神科司法鉴定为主要依据，法院通常委托具备资质的司法鉴定机构对被申请人进行精神状态与民事行为能力评定。
  • 周期：鉴定机构受理到出具意见一般数周，复杂案件可更长；法院审理在鉴定基础上推进。代理时需向客户提示整体周期，避免与离婚 / 继承时限冲突。
  • 鉴定不能的替代证据：被申请人无法配合鉴定（如重度监护状态、下落不明）时，可用病历、诊断证明、长期照护记录、居委会 / 近亲属证言、既往司法 / 行政文书形成证据链，但证明力弱于鉴定意见，法院可能要求补强。
  • 鉴定时点的行为能力状态：行为能力以「鉴定时」状况为准，既往曾有完全行为能力不影响当前认定；这对遗嘱能力（立遗嘱时须完全行为能力，继承编解释一第 28 条）的联动判断尤为关键。

2. 监护人确定与行为能力恢复

监护争议程序衔接

被认定为无 / 限制民事行为能力人后，监护人按《民法典》相关规定顺序确定（配偶、父母、成年子女等）；对监护人确定有争议的，由被监护人住所地的居委会、村委会或民政部门指定，对指定不服的可申请法院指定（《民法典》相关规定，条号以现行文本为准）。实务要点：监护争议与行为能力认定是两个程序——先认定行为能力，再定监护人；代理律师常为同一客户的连续两步走。

行为能力恢复路径见第 24 条第 2 款：经本人、利害关系人或有关组织申请，法院可依智力、精神健康恢复状况认定为限制或完全民事行为能力人。恢复后，原监护人职责终止，离婚诉讼等可本人进行。

四、家事律师的运用场景

1. 离婚诉讼中一方行为能力障碍

婚姻家庭编解释（一）第六十二条 无民事行为能力人的配偶有民法典第三十六条第一款规定行为，损害被监护人合法权益的，其他有监护资格的人可以要求撤销其监护资格，并依法指定新的监护人；被指定的监护人代理该无民事行为能力人提起离婚诉讼的，人民法院应予受理。

操作链条：配偶为无民事行为能力人且原监护人（其配偶）有监护侵害行为 → 其他有监护资格人申请撤销原监护人资格并指定新监护人 → 新监护人作为法定代理人代理提起离婚诉讼。注意：无民事行为能力人本人不能「自行」起诉离婚，必须由适格监护人代理；监护人就是配偶本人的，须先完成监护变更。

2. 继承案件中行为能力存疑者的遗嘱效力联动

  • 对被继承人立遗嘱时行为能力的质疑，是遗嘱无效抗辩的高频抓手（第 1143 条：无 / 限制民事行为能力所立遗嘱无效）。
  • 若继承人在继承开始时行为能力存疑，可能影响其继承权的行使与放弃（放弃继承须有相应行为能力，继承编解释一第 32 条相关）。
  • 律师应同步评估：是否需要先启动行为能力认定，再处理遗嘱效力和继承分割。

3. 重大财产处分的监护人权限

监护人处分被监护人财产的限制

监护人除为维护被监护人利益外，不得处分被监护人的财产（《民法典》相关规定）。家事场景中：以被监护人（无行为能力老人）名下房产为子女债务担保、低价转让被监护人财产，均可能被认定侵害被监护人利益而无效或可撤销。代理此类交易时，须先确认处分「为被监护人利益」且有据可查，否则建议先定监护人或取得法院许可。

常见坑把特别程序当普通程序救济

特别程序一审终审，救济路径不同于普通程序：

  • 判决、裁定一经送达即生效，不能上诉；
  • 被宣告失踪 / 死亡人重新出现，或行为能力恢复 / 新事实出现，走「撤销原判决、作出新判决」的特别程序纠错路径，而非二审或再审；
  • 利害关系人对认定不服的，应在法定期限内申请纠错，逾期须依《民事诉讼法》特别程序相关规定另行申请，不得直接上诉。

六、实务坑点

  • 坑 1：混淆一审终审与上诉——特别程序裁判不能上诉，误以为可上诉会错过纠错窗口。纠错走「撤销原判、作出新判」的特别程序路径。
  • 坑 2：监护人与代理人身份冲突——离婚诉讼中，无行为能力人的监护人若正是其配偶（被告），不能代理原告起诉；须先撤销配偶监护资格、指定新监护人，再由新监护人代理。
  • 坑 3：宣告死亡前径行分割遗产——遗产悬空时继承人直接分割无法律依据，应先完成宣告死亡，以第 48 条死亡日期为继承开始点。
  • 坑 4：行为能力鉴定时点错位——以「既往曾正常」推定当前有能力，忽略鉴定时状况；遗嘱能力须立遗嘱时具备（继承编解释一第 28 条），与当前认定是两回事。
  • 坑 5：鉴定不能时无替代证据链——仅靠「他精神不正常」口头陈述，法院不予认定；须病历、照护记录、单位 / 居委证明、证言形成闭环。
  • 坑 6：再婚稳定性误判——客户在死亡宣告后已再婚，撤销死亡宣告不当然恢复前婚，前端未告知导致后续纠纷。
  • 坑 7：监护人处分被监护人财产越权——非为被监护人利益的处分可被认定无效，重大财产交易前须确认权限与「为利益」证据。
  • 坑 8：民诉法条号凭记忆——2023 修正后特别程序条号重编，引用须写「《民事诉讼法》特别程序相关规定」并核对现行文本。

七、红线清单 / 自检清单

  • 已确认程序性质为非讼、一审终审，已告知客户无上诉权、纠错走特别程序路径。
  • 宣告失踪：下落不明满二年起算点正确，已备住所地管辖与下落不明证明（第 40 条）。
  • 宣告死亡：已对照第 46 条三情形确定适用哪一类，死亡日期按第 48 条确定；意外事件情形已附有关机关「不可能生存」证明。
  • 已引用继承编解释一第 1 条，向客户说明死亡宣告日为继承开始点，再启动继承。
  • 行为能力认定：已委托 / 准备精神科司法鉴定，明确鉴定周期；鉴定不能时已备替代证据链（第 24 条）。
  • 离婚诉讼中无行为能力人：已按解释（一）第 62 条规划「撤销配偶监护资格 → 指定新监护人 → 新监护人代理起诉」链条。
  • 监护人处分被监护人重大财产：已确认「为被监护人利益」并有据可查。
  • 所有《民事诉讼法》引用均写「特别程序相关规定」，未使用旧记忆条号。
  • 已提示死亡宣告撤销后婚姻、再婚的例外规则，避免客户误判再婚稳定性。
