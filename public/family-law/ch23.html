PART III · 特殊程序与收尾

23 再审、第三人撤销之诉与案外人执行异议

家事继承虚假诉讼高发，三把救济武器各有定位，用错程序即被驳回

法条婚姻家庭编解释（二）第 3 条婚姻家庭编解释（一）第 35 条《民法典》第 1089 条《民事诉讼法》再审 / 第三人撤销之诉 / 执行异议相关规定（条号以现行文本为准）
家事与继承案件是虚假诉讼的高发区：假债务稀释共同财产、假离婚逃避债权人、虚假遗嘱排除真继承人。当生效文书已损害客户权益，律师手里有三把救济武器——第三人撤销之诉、案外人执行异议（及异议之诉）、再审。三者适用主体、对象、期限、程序截然不同，选错即被驳回。本章先给共同背景与对照表，再逐项拆解家事典型场景、期限与攻防要点，最后给起诉状骨架与坑点。
本页民诉法条号口径

第三人撤销之诉、执行标的异议与异议之诉、再审事由与期限均规定于《民事诉讼法》。因 2023 年修正后条文重编号，本章统一写「《民事诉讼法》相关规定」并提示「条号以现行文本为准」，办理时以现行有效官方文本核对，不得凭记忆使用旧条号（如旧「第 56 条第三人撤销之诉」「第 227 条执行异议」等已重编）。

一、共同背景：家事继承虚假诉讼的三类形态

  • 假债务：一方与案外人串通伪造借条，在离婚 / 继承中虚构共同债务或遗产债务，稀释可分割财产或挤占继承份额。
  • 假离婚逃债：夫妻通过离婚协议把财产全部归一方、债务归另一方，损害债权人利益；债权人可依据解释（二）第 3 条撤销财产分割条款。
  • 虚假遗嘱：伪造、篡改遗嘱排除真继承人，或恶意串通确认遗嘱效力，侵害法定继承人、受遗赠人权益。

三、第三人撤销之诉

1. 家事典型场景

  • 债权人撤销离婚协议财产分割条款：与解释（二）第 3 条债权人撤销权存在竞合，见下文选择。
  • 重婚案合法婚姻当事人未参加财产分割诉讼：前婚合法配偶对后婚所涉财产分割判决不知情、未参诉，权益受损，可提第三人撤销之诉。
  • 继承案件遗漏的真正继承人：遗产分割调解 / 判决未列某法定继承人（如不知情的远房继承人、被隐瞒的子女），其可提撤销之诉主张份额。

2. 与解释（二）第 3 条债权人撤销权的竞合与选择

婚姻家庭编解释（二）第三条 夫妻一方的债权人有证据证明离婚协议中财产分割条款影响其债权实现，请求参照民法典第五百三十八条、第五百三十九条规定撤销该财产分割条款的，人民法院应当综合考虑夫妻共同财产整体分割及履行情况、子女抚养费负担、离婚过错等事实，依法予以支持。
两条路径怎么选

债权人对「离婚协议财产分割条款」受损，有两条路：① 依解释（二）第 3 条请求撤销该财产分割条款（聚焦「条款」本身，参照民法典债权人撤销权）；② 依第三人撤销之诉撤销生效文书中对应内容（聚焦「生效判决 / 调解书」）。选择逻辑：离婚协议尚未经诉讼确认、仅登记离婚后的财产条款 → 优先走第 3 条撤销条款之诉，更直接；离婚协议内容已被生效调解书 / 判决吸收 → 走第三人撤销之诉撤销该生效文书对应部分。两路径均须证明「债权受影响 + 财产分割明显不合理」，且法院会综合抚养费、离婚过错等因素衡量，并非一律撤销。

3. 期限与证明要点

六个月期限与「非因本人原因未参诉」

第三人撤销之诉期限为自知道或应当知道权益受损之日起六个月（《民事诉讼法》相关规定）。关键证明两点：① 权益受损——自己对诉讼标的有独立请求权或案件处理结果影响其民事权益；② 不能归责于本人的事由未参加诉讼——如不知诉讼存在、未被通知、非自身懈怠。家事隐蔽性强，代理人应重点收集「客户确不知情」的证据（未收到文书、对方隐瞒诉讼、户籍不在同址等）。注意：第三人撤销之诉不以案件处理本人权益为前提的错误理解要纠正——须证明生效文书内容损害其民事权益，而非仅「有关系」。

四、案外人执行异议

1. 路径：异议 → 异议之诉

第一步：书面执行异议

案外人对执行标的主张实体权利，在执行标的执行程序终结前向执行法院提出书面异议（《民事诉讼法》相关规定）。法院审查后裁定中止执行或驳回。

第二步：异议之诉

案外人或申请执行人对异议裁定不服，向执行法院提起执行异议之诉（《民事诉讼法》相关规定）。异议之诉是实体审理，解决「执行标的实体权利归属」。

2. 家事典型场景

  • 被执行人配偶主张共同财产份额：执行被执行人名下财产时，配偶以「属夫妻共同财产、仅半数归被执行人」提出执行异议，要求先析产再执行。
  • 受遗赠人主张遗产：执行被继承人遗产时，受遗赠人以其受遗赠权主张特定财产不属可执行范围，须在 60 日接受期内已作接受表示（第 1124 条）。

3. 与「离婚协议不能对抗债权人共同债务」规则的交叉

婚姻家庭编解释（一）第三十五条 / 《民法典》第一千零八十九条 解释（一）第三十五条：当事人的离婚协议或者人民法院生效判决、裁定、调解书已经对夫妻财产分割问题作出处理的，债权人仍有权就夫妻共同债务向男女双方主张权利；一方就夫妻共同债务承担连带清偿责任后，基于离婚协议或者人民法院的法律文书向另一方主张追偿的。
第一千零八十九条：离婚时，夫妻共同债务应当共同偿还。共同财产不足清偿或者财产归各自所有的，由双方协议清偿；协议不成的，由人民法院判决。
先析产还是债权人优先：攻防要点

配偶提执行异议主张「这是共同财产、只能执行一半」时，债权人一方反击的核心就是第 35 条：离婚协议对财产分割的处理不能对抗债权人就夫妻共同债务的追偿。攻防结构：

  • 配偶（案外人）方：主张被执行财产中自己的份额，要求先析产；但须证明该债务非共同债务，或财产确为其个人所有（如婚前财产、第 1063 条个人财产）。
  • 债权人方：主张属夫妻共同债务，依第 35 条、第 1089 条向双方追偿，离婚协议的内部分配不约束债权人；可主张整体执行，被执行人配偶清偿后依离婚协议向另一方追偿。
  • 法院裁量：共同债务情形下，配偶的「份额异议」通常不足以阻却对共同债务的整体执行，但权属确属配偶个人的部分应予剔除。

五、再审

1. 家事案件中的再审事由适用特点

  • 伪造证据：虚假遗嘱、伪造借条、虚假亲子鉴定——家事再审最高频事由。鉴定（笔迹、DNA、文书形成时间）是关键反制手段。
  • 基本事实缺乏证据证明：如分割依据的财产线索未经质证、继承人范围认定错误（遗漏或虚列）。
  • 管辖、送达违法：未通知必须到庭的当事人、未合法送达即缺席判决，可能构成程序违法事由。

2. 判决不准离婚 / 调解和好的离婚案件不得申请再审

特殊除外规则

《民事诉讼法》相关规定明确：当事人对已经发生法律效力的解除婚姻关系的判决、调解书，不得申请再审（婚姻关系已解除，无再审必要）；判决不准离婚或调解和好的离婚案件，当事人不得申请再审（但就财产分割、子女抚养等可另行起诉或就财产部分另有救济路径）。代理时须识别：客户若对「不准离婚」判决想翻案，再审路径不通，应引导其依新事实重新起诉离婚，而非申请再审。

3. 检察机关抗诉 / 检察建议路径

依《民事诉讼法》相关规定，当事人可申请检察监督：① 法院驳回再审申请、逾期未裁定或再审裁判仍有错误的，可向检察机关申请抗诉或检察建议；② 家事虚假诉讼损害国家 / 社会公共利益或第三人权益的，检察机关可依职权监督。代理中应把「检察监督」作为再审被驳回后的后续武器，尤其虚假诉讼线索明确时。

常见坑用第三人撤销之诉替代上诉

第三人撤销之诉是非因本人原因未参诉的第三人的救济，不是败诉当事人的「第二次上诉」：

  • 原案当事人本人对一审判决不服，应上诉而非提第三人撤销之诉，法院将径直驳回；
  • 第三人撤销之诉须证明「未参诉 + 不能归责于本人 + 权益受损」三要件，缺一不可；
  • 期限自知道或应当知道权益受损起六个月，超期丧失诉权。

七、实务坑点

  • 坑 1：用第三人撤销之诉替代上诉——原审当事人不服应上诉；撤销之诉只给「未参诉的第三人」，主体不符直接驳回。
  • 坑 2：执行异议超期——须在「执行标的执行程序终结前」提出（《民事诉讼法》相关规定）。房产过户裁定送达、款项发还后即可能视为终结，超期异议不被受理。发现执行即第一时间提书面异议。
  • 坑 3：再审事由笼统罗列——「事实不清、程序违法」式泛泛而谈，不聚焦具体事由（如「原案遗嘱系伪造，附 DNA / 笔迹鉴定申请」），再审审查不予采纳。事由须具体、有证据指向。
  • 坑 4：忽略债权人撤销权与撤销之诉的竞合——离婚协议财产条款受损，未区分「条款尚未经诉讼确认」与「已被生效文书吸收」，选错路径。先判断条款是否已被判决 / 调解吸收。
  • 坑 5：配偶异议忽视第 35 条——只喊「这是共同财产」不证明债务性质，债权人以第 35 条反击，异议被驳回。须同步论证债务非共同债务或财产属个人。
  • 坑 6：对「不准离婚」判项申请再审——该路径不通，应重新起诉离婚；浪费期限且不被受理。
  • 坑 7：六个月期限起算点错——以「文书作出日」而非「知道权益受损日」起算，导致误判未超期。起算点是知悉权益受损之日，须留存知悉证据。
  • 坑 8：民诉法条号凭记忆——第三人撤销之诉、执行异议、再审条号 2023 修正后已重编，一律写「《民事诉讼法》相关规定」并核对现行文本。

八、红线清单 / 自检清单

  • 已向客户说明家事虚假诉讼三类形态（假债务、假离婚逃债、虚假遗嘱）及对应救济武器。
  • 已对照三武器定位表，确认本案主体、对象、期限、程序匹配：第三人撤销之诉 / 案外人执行异议 / 再审，未选错。
  • 债权人撤销离婚协议财产条款：已区分「条款未经诉讼确认」（走解释二第 3 条）与「已被生效文书吸收」（走第三人撤销之诉），并备「债权受影响 + 分割明显不合理」证据。
  • 第三人撤销之诉：已证明三要件——权益受损、未参诉不能归责本人、生效文书内容错误；期限自知悉日起算未超六个月。
  • 案外人执行异议：已在执行标的执行程序终结前提书面异议；配偶主张共同财产份额时同步论证债务性质（第 35 条、第 1089 条交叉攻防）。
  • 受遗赠人主张遗产：已确认其在 60 日接受期内作出接受表示（第 1124 条）。
  • 再审：已识别「不准离婚 / 调解和好」判项不得申请再审，引导重新起诉；再审事由具体聚焦（伪造证据、基本事实无证据），附鉴定申请。
  • 再审被驳回或逾期：已规划检察监督（抗诉 / 检察建议）作为后续路径。
  • 所有《民事诉讼法》引用均写「相关规定」，未使用旧记忆条号。
  • 起诉状 / 异议书已附期限计算说明与「未参诉不知情」证据，避免主体与期限抗辩失利。
