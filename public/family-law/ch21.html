PART III · 特殊程序与收尾

21 家事案件执行难点

家事执行的特殊性在于「行为」与「人身」不可强制，调解书不具体就执行不动

法条婚姻家庭编解释（一）第 53、68 条《民法典》第 1086 条《民事诉讼法》执行程序相关规定（条号以现行文本为准）
判决和调解书「生效」不等于「拿到」。家事案件执行的难点集中在三类：抚养费（持续性金钱给付）、探望权（行为执行、不可对人身强制）、房产过户与财产交付（需被执行人配合且税费约定常缺失）。区别于商事执行，家事执行大量涉及人身与未成年子女利益，法院对「直接强制」极为审慎。本章按四类执行对象给出操作清单、间接强制手段、财产查控差异与文书模板。
本页民诉法条号口径

执行申请期限、执行措施、执行异议、迟延履行利息、网络查控等均规定于《民事诉讼法》执行程序编。因 2023 年修正后条文重编号，本章统一写「《民事诉讼法》执行程序相关规定」并提示「条号以现行文本为准」，办理时以现行有效官方文本核对。

一、抚养费执行

抚养费是持续性金钱给付，执行对象是被执行人可持续的收入与财产，而非一次性总额。

1. 执行措施

  • 扣划工资：向被执行人工作单位送达协助执行通知书，按月扣留、提取其工资收入中应付抚养费部分，保留本人及其所扶养家属的生活必需费用。
  • 冻结、划拨银行存款：通过执行查控系统冻结账户并划拨到期及逾期抚养费。
  • 公积金划扣：被执行人有住房公积金且符合提取条件的，可裁定划拨（各地操作口径不一，需核当地法院与公积金中心协作规则）。
  • 迟延履行利息：被执行人未按期给付的，依《民事诉讼法》执行程序相关规定计收迟延履行期间的债务利息，申请书与执行中一并主张。

2. 给付至 18 周岁的执行依据范围

婚姻家庭编解释（一）第五十三条 抚养费的给付期限，一般至子女十八周岁为止。十六周岁以上不满十八周岁，以其劳动收入为主要生活来源，并能维持当地一般生活水平的，父母可以停止给付抚养费。
未来到期部分的分期执行申请

调解书 / 判决常写「每月支付____元至子女 18 周岁」。对未来到期部分，可在申请执行时一并列明分期执行请求，法院通常裁定「按生效文书确定的周期持续执行」，不必每月重复立案。已到期未付的按月累加，未到期的按月滚动执行。注意第 53 条但书：子女 16 周岁以上以劳动收入为主要生活来源的，可停止给付，执行中遇此情形应及时举证调整。

二、探望权执行：行为执行的特殊性

婚姻家庭编解释（一）第六十八条 对于拒不协助另一方行使探望权的有关个人或者组织，人民法院可以依法采取拘留、罚款等强制措施，但是不能对子女的人身、探望行为进行强制执行。

这是探望权执行的总纲：强制对象只能是拒不协助的成年代养人（直接抚养方），绝不能是子女本人。把子女「强行抱走」交付探望既违法也违背未成年人利益最大化。

1. 间接强制手段清单

手段适用情形操作要点
罚款、拘留直接抚养方多次阻挠、藏匿子女、拒不按文书履行协助义务针对义务人本人，而非子女；须先告诫、留足履行机会
纳入失信名单有履行能力而拒不协助探望以「拒不履行生效文书确定义务」列入，形成社会压力
心理疏导介入双方敌意深、子女出现抗拒探望心理借助法院心理评估 / 家事调查员，先修复再执行
变更抚养关系阻挠探望情节严重、严重影响子女身心健康（终局武器）另行起诉变更抚养关系；是探望权执行失灵后的根本救济，非执行措施本身

2. 执行和解与探访见证方案

  • 执行和解：双方可就探望的时间、地点、交接方式达成更细化的执行和解协议（如「每月第一、三周周六 9:00 在____地点由第三方见证交接」），法院据此推进。
  • 探访见证：引入居委会、妇联、社工或法院家事调查员作为交接见证人，降低冲突、固定履行事实，避免「送了又不认」的扯皮。
  • 明确化请求：申请执行时把探望方式写具体（频率、时长、地点、交接人），便于法院监督与认定违反。

三、房产过户执行

1. 生效文书直接裁定过户

无需被执行人配合

离婚判决 / 调解书明确房产归一方的，权利人可持生效文书直接申请强制执行，法院向登记机构送达协助执行通知书 + 裁定过户文书，无需被执行人到场或签字。这与「双方协议过户」不同——有生效文书背书，登记机构应协助办理。实务动作：申请时一并请求法院向不动产登记中心送达协助执行通知，避免被执行人拖延不配合。

2. 税费承担条款缺失的补救

最常见漏洞

离婚文书常写「房屋归甲方所有」，却不写过户税费由谁负担。过户时登记机构按税法核定契税、个税等，双方互相推诿导致执行卡顿。补救：① 申请执行时一并请求法院在裁定中明确税费承担（依文书原意或公平原则）；② 如文书确未约定，可另诉或依执行裁量由取得方先行垫付后追偿；③ 前端起草调解书时务必把「过户税费由____方承担」写进条款（见 ch07 生效与执行）。

四、交付财产与腾退

  • 未成年子女居住利益冲突：执行腾退被执行人或交付房屋时，若房屋系直接抚养方与子女实际居住且为子女稳定生活所需，法院通常审慎处理，避免损害未成年子女利益。代理时应将「子女实际居住、就学便利」作为抗辩或执行方案考量提交。
  • 唯一住房的现实约束：被执行人名下唯一住房的执行受生存保障限制，强制腾退与拍卖有严格条件（如提供安置或预留租金）。家事执行中尤须评估：是否属唯一住房、是否有老人子女同住，制定渐进方案而非一步强执。
  • 交付特定动产：家具、车辆、首饰等，依文书逐项交付；被执行人隐匿的，结合搜查、罚款等间接强制。

五、执行障碍应对：财产查控体系差异

1. 网络查控的覆盖面与局限

执行查控系统可在线查询、冻结被执行人银行存款、网络资金、证券、车辆、股权、不动产等。但家事案件有大量非标准财产不在常规覆盖内，须针对性查控。

2. 家事特有财产的执行差异

财产类型执行特点操作提示
保险现金价值保单现金价值属被执行人责任财产，可强制执行，但生存保险金 / 理赔金有专属保护向保险公司送达协助执行通知，提取现金价值；须区分「现金价值」与「受益人专属理赔金」
住房公积金符合条件可划拨，各地协作口径不同核当地法院与公积金中心规则，申请书列明账户信息
虚拟财产网络平台账号、虚拟货币、数字资产执行规则不成熟，价值认定难先固定账号权属与价值证据，必要时评估；以「变价 / 划转」而非「交付账号」推进
股权 / 合伙份额需评估与优先购买权处理，且受公司人合性影响参照离婚股权分割规则（解释一第 73 条相关），另诉变价或入册

3. 案外人（配偶 / 子女名下）财产的限制与追加

登记在案外人名下的财产

登记在被执行人配偶、子女名下的财产，不能直接执行。路径：① 属夫妻共同财产的，先析产（确认被执行人份额）再执行该份额；② 子女名下财产原则上推定为子女所有，除非有证据证明系规避执行或实际为被执行人出资且约定不明；③ 发现被执行人与配偶恶意转移财产的，依《民法典》第 1092 条（隐藏转移挥霍）或债权人撤销规则追回，再执行。追加被执行人须有法定事由，不得仅因「夫妻 / 父子关系」径行追加。

六、文书模板：强制执行申请书

范本 · 强制执行申请书（完整可抄正文）
强制执行申请书 申请执行人：____，男 / 女，____年__月__日出生，汉族，公民身份号码________________，住________，联系电话：________。 被执行人：____，男 / 女，____年__月__日出生，汉族，公民身份号码________________，住________，联系电话：________。 执行依据： ________人民法院（____）____民初____号民事判决书 / 调解书，已于____年__月__日发生法律效力（或：________法院作出的____号民事裁定书）。 执行请求： 1. 强制被执行人按生效文书向申请执行人支付抚养费 / 财产分割款 / 折价补偿款共计人民币________元（其中已到期未付________元，自____年__月起按月支付____元至____止）； 2. 强制被执行人支付迟延履行期间的债务利息（按《民事诉讼法》执行程序相关规定计算，自____年__月__日起算）； 3. 强制被执行人协助办理位于________路____号房屋的不动产过户登记手续，并向不动产登记中心送达协助执行通知书（过户相关税费由____方承担）； 4. 强制被执行人按生效文书履行探望协助义务，每月____时段在____地点交付子女由申请执行人探望； 5. 本案执行费用由被执行人承担。 事实与理由： 生效文书已确认被执行人应向申请执行人履行上述义务。文书生效后，被执行人未履行 / 未完全履行（具体：____）。申请执行人曾于____催告，被执行人仍以____理由拒绝。 被执行人可供执行的财产线索：（1）工资收入：工作单位________，可按月扣留____元；（2）银行存款：开户行________，账号尾号____；（3）住房公积金：账户____；（4）房产 / 车辆：____；（5）保险现金价值：保单号____；（6）其他____。 根据《民事诉讼法》执行程序相关规定，特申请强制执行，恳请依法采取查询、冻结、划拨、扣留收入、裁定过户、罚款、拘留等执行措施。 此致 ________人民法院（执行局） 申请执行人（签名）：____________ ____年__月__日 附：1. 执行依据文书原件 / 生效证明；2. 申请执行人身份证明；3. 被执行人财产线索清单及证据；4. 催告记录；5. 委托手续（如代理）。
常见坑调解书内容不具体，执行局立不了案

家事调解书最常见的执行败笔：

  • 探望写「男方定期探望子女」——「定期」无频率、无时长、无地点，执行局无法监督，被执行人一句「我同意他来」即可敷衍；必须写「每月第____周周六 9:00—17:00 在____地点交接」。
  • 房产写「归甲方所有」但不过户税费、不写协助义务，登记中心要被执行人配合，被执行人消失即卡死。
  • 把「抚养费」与「探望权」捆绑写「不付抚养费就不让看孩子」——这类违约条款法院不认，探望权是独立权利，不因抚养费违约而消灭，捆绑条款反而导致两项都执行不了。

七、实务坑点

  • 坑 1：过了 2 年申请执行时效——执行申请期限为二年（《民事诉讼法》执行程序相关规定），从文书确定的履行期间最后一日起算。抚养费分期给付的，从每次履行期届满分别起算。时效可因申请执行、当事人提出履行要求、同意履行而中断；中断后重新计算。超期须举证中断事由，否则法院不予受理。
  • 坑 2：调解书内容不具体——探望「定期」、过户无税费、交付无清单，导致无法执行。前端起草务必颗粒化（见第六部分坑点提示）。
  • 坑 3：抚养费与探望权捆绑违约条款——法院不认「不付抚养费就不让探望」，两项独立，捆绑反而双输。探望权请求应单独、明确。
  • 坑 4：唯一住房 / 子女居住利益忽视——强行腾退唯一住房或子女实际居所，法院审慎甚至中止，须备安置方案。
  • 坑 5：虚拟财产 / 保险现金价值漏查——只查存款房产，忽视保单现金价值、公积金、网络资金、虚拟资产，执行标的缩水。
  • 坑 6：径行执行配偶 / 子女名下财产——无析产、无追加法定事由直接执行案外人财产，被提执行异议阻却。先析产或另诉追回。
  • 坑 7：探望权对子女人身强制——误把子女当执行标的强行交付，违反解释（一）第 68 条。强制对象限于拒不协助的成人义务主体。
  • 坑 8：未来到期抚养费未一并申请执行——逐月立案浪费资源；申请时列明分期执行，由法院滚动执行。

八、红线清单 / 自检清单

  • 已确认执行申请未超二年时效；分期抚养费已分别起算履行期，并主张时效中断事由（《民事诉讼法》执行程序相关规定）。
  • 抚养费执行已列明工资扣划、账户冻结、公积金划扣、迟延履行利息等具体措施与财产线索。
  • 给付至 18 周岁的，已引用解释（一）第 53 条，并提示 16 周岁以上以劳动收入为主可停付的例外。
  • 探望权执行严格遵循解释（一）第 68 条：强制对象限于拒不协助的成人义务主体，绝不对子女人身 / 探望行为强制。
  • 探望权调解书条款已颗粒化（频率、时长、地点、交接人），未写「定期」等模糊字眼。
  • 未将抚养费与探望权捆绑为违约条款；两项独立请求分别列明。
  • 房产过户已请求法院裁定过户 + 协助执行通知书，无需被执行人配合；税费承担条款已补正或一并请求明确。
  • 腾退 / 交付已评估唯一住房与子女居住利益，备安置方案。
  • 财产查控已覆盖保险现金价值、公积金、虚拟财产、股权等非标准财产，并区分专属保护部分。
  • 案外人（配偶 / 子女）名下财产已走析产或另诉追回路径，未径行追加执行。
