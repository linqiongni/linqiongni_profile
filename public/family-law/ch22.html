PART III · 特殊程序与收尾

22 遗产管理人制度实务

《民法典》新增的遗产管理人，是律师切入继承业务的制度入口，但权限边界必须钉死

法条《民法典》第 1145—1149、1153、1161、1163 条继承编解释（一）第 1、43、44 条
《民法典》继承编新增「遗产管理人」制度（第 1145—1149 条），填补了被继承人死亡后、遗产分割前「无人管事」的制度空白。对律师而言，这是继承业务的核心入口：既可作为遗嘱执行人受聘管理遗产，也可在继承纠纷中代理当事人申请法院指定遗产管理人以处分登记在被继承人名下的财产。本章逐条拆解制度框架、律师业务入口、职责履行清单、责任风险与委托条款模板，并提示公证试点的衔接。

一、制度框架：1145—1149 逐条

1. 确定顺序（第 1145 条）

《民法典》第一千一百四十五条 继承开始后，遗嘱执行人为遗产管理人；没有遗嘱执行人的，继承人应当及时推选遗产管理人；继承人未推选的，由继承人共同担任遗产管理人；没有继承人或者继承人均放弃继承的，由被继承人生前住所地的民政部门或者村民委员会担任遗产管理人。
顺位确定方式实务含义
第一顺位遗嘱执行人当然为遗产管理人立遗嘱时指定执行人，是最高效的安排；律师可受聘为遗嘱执行人
第二顺位继承人推选继承人协商一致推选一人或数人；推选僵局见坑点
第三顺位继承人共同担任未推选则全体继承人共同管理，重大事项易陷入僵局
第四顺位（兜底）民政部门 / 村委会无继承人或均放弃继承时，由被继承人生前住所地民政部门或村委会担任

2. 争议指定（第 1146 条）

《民法典》第一千一百四十六条 对遗产管理人的确定有争议的，利害关系人可以向人民法院申请指定遗产管理人。
指定路径：特别程序

遗产管理人指定属于非讼特别程序（《民事诉讼法》特别程序相关规定，条号以现行文本为准）。实务场景：继承人对由谁担任遗产管理人争议不休，导致登记在被继承人名下的不动产无法过户、银行账户无法支取。代理一方申请法院指定时，应提交继承人范围、遗产清单、争议事实与「由申请人担任更有利于遗产处理」的理由。律师本人亦可被申请指定为遗产管理人。

3. 职责六项（第 1147 条）

《民法典》第一千一百四十七条 遗产管理人应当履行下列职责：（一）清理遗产并制作遗产清单；（二）向继承人报告遗产情况；（三）采取必要措施防止遗产毁损、灭失；（四）处理被继承人的债权债务；（五）按照遗嘱或者依照法律规定分割遗产；（六）实施与管理遗产有关的其他必要民事法律行为。

4. 责任（第 1148 条）与报酬（第 1149 条）

《民法典》第一千一百四十八条 / 第一千一百四十九条 第一千一百四十八条：遗产管理人应当依法履行职责，因故意或者重大过失造成继承人、受遗赠人、债权人损害的，应当承担民事责任。
第一千一百四十九条：遗产管理人可以依照法律规定或者按照约定获得报酬。

二、律师业务入口

1. 担任遗嘱执行人的委托条款设计

  • 职责边界：在遗嘱或委托合同中明确「遗嘱执行人 = 遗产管理人」，职责限于第 1147 条六项，不得扩张为「遗产所有权人」或「概括处分权人」。
  • 报酬：依第 1149 条可约定报酬；建议按遗产总额比例 + 实际工作量结合计费，并约定差旅、评估、公证等第三方费用由遗产列支。
  • 离任交接：约定离任（辞任、被撤销、遗产处理完毕）时的清单移交、账目结清与签署确认义务，避免「管完走人、账说不清」。
  • 免责边界：仅对故意或重大过失负责（第 1148 条），非正常市场波动、善意信赖第三方文件造成的损失应排除在赔偿责任外。

2. 继承案件中的遗产管理人指定申请

现实需求驱动

继承人之间对分割有争议，但客观上急需处分登记在被继承人名下的不动产、支取银行存款、领取保险金时，最务实的路径是先申请指定遗产管理人，由管理人依法处理债权债务、制作清单、推进分割，而非僵在「谁都不让谁管」。代理时向客户说明：指定管理人不等于放弃继承份额，只是先把「管事的人」定下来。

3. 与公证遗产管理人试点的衔接

提示口径

部分地区公证机构已开展遗产管理人公证探索，可通过公证赋予遗产管理人身份与职责以更强的公示与执行便利。办理时提示客户：公证路径与法院指定路径并行存在，选择取决于是否已进入诉讼、遗产分布与当事人合意程度；具体公证规则以当地公证机构现行办法为准，本章不展开地区细则。

三、职责履行清单

① 清产核资、制作遗产清单

全面摸排被继承人名下不动产、存款、股权、保险、债权、虚拟财产、个人物品；与夫妻共同财产先析产（第 1153 条：分割遗产先分一半为配偶所有），避免把配偶财产误列为遗产。清单应记载财产名称、权属、估值、线索，由管理人签署并报告继承人。

② 通知债权人、公告

已知债权人逐一通知；对未知债权人可公告。注意受遗赠人 60 日接受期限（第 1124 条），逾期未表示的视为放弃，管理人在分割前须确认受遗赠人意思。

③ 防止毁损灭失

对易损、易贬损财产采取保管、保险、及时变价等必要措施，费用由遗产列支。

④ 处理债权债务与清偿

依限定继承（第 1161 条：以所得遗产实际价值为限清偿）与清偿顺位（第 1163 条）处理；详见下节。

⑤ 制作分配方案、分割遗产

按遗嘱或法定继承（第 1130 条分配原则）拟定方案，报告继承人后执行；有异议的可引导诉讼。

⑥ 诉讼代表

管理人可作为遗产代表参与相关诉讼（如被继承人债权催收、债务抗辩），实施与管理遗产有关的必要民事法律行为。

税款与债务清偿顺序

《民法典》第一千一百六十一条 / 第一千一百六十三条 第一千一百六十一条（限定继承）：继承人以所得遗产实际价值为限清偿被继承人依法应当缴纳的税款和债务；超过遗产实际价值部分，继承人自愿偿还的不在此限；继承人放弃继承的，对被继承人依法应当缴纳的税款和债务可以不负清偿责任。
第一千一百六十三条（清偿顺位）：既有法定继承又有遗嘱继承、遗赠的，由法定继承人用其所得遗产清偿；不足清偿的，由遗嘱继承人和受遗赠人按比例以所得遗产清偿。
未清偿先分配的责任

管理人若在未清偿税款债务前即向继承人分配遗产，导致债权人无法受偿，可能依第 1148 条承担重大过失赔偿责任。履行顺序应是：清产 → 通知债权人 → 清偿税款债务（限定继承）→ 余下分割。遗产不足清偿的，按比例清偿，不得擅自「先分给亲人再管债」。

四、责任风险：规则式提示（不编案号）

  • 擅自处分：超越第 1147 条职责，将遗产赠与无关第三人、低价转让给关联方、挪用遗产资金，属明显越权，承担返还与赔偿责任，严重的可能涉及侵权甚至刑事。
  • 拖延致损：明知遗产（如股票、季节性货物、保鲜资产）面临贬值却怠于处置，造成继承人损失，可能被认定重大过失。
  • 未清偿先分配：如上节，违反限定继承与清偿顺位，对债权人损失担责。
  • 清单不实：故意隐匿、侵吞或争抢遗产的继承人本身可被酌情减少应继承份额（继承编解释一第 43 条）；管理人协助隐匿的，同负赔偿责任。
  • 未通知利害关系人：遗漏继承人或受遗赠人致其权益受损，管理人未尽报告 / 通知义务的，可能担责。继承诉讼当事人确定规则见继承编解释一第 44 条。

五、文书模板：遗嘱执行人委托条款

范本 · 遗嘱执行人（遗产管理人）委托条款（完整可抄正文）
遗嘱执行人（遗产管理人）委托条款 一、选任 立遗嘱人（委托人）____自愿指定____律师事务所 / ____（身份证号____）为其遗嘱执行人，依《民法典》第一千一百四十五条，遗嘱执行人同时担任遗产管理人，履行遗产管理职责。 二、权限范围 执行人 / 管理人在下列范围内行使职权，不超越： 1. 清理遗产并制作遗产清单，向继承人报告遗产情况； 2. 采取必要措施防止遗产毁损、灭失； 3. 处理被继承人的债权债务，通知已知债权人并在合理范围内公告； 4. 按本遗嘱及法律规定分割、交付遗产； 5. 以遗产管理人身份参与与遗产有关的诉讼、仲裁、执行及其他必要民事法律行为； 6. 实施与管理遗产有关的其他必要行为。 执行人不得将被继承人财产赠与、转让、处分给遗嘱指定范围以外的主体，不得为自己谋取遗嘱约定以外的利益。 三、报酬 执行人可依《民法典》第一千一百四十九条获得报酬，标准为：遗产总额的____% 或固定人民币____元（二者择一 / 结合），于遗产分割前从遗产中优先列支。办理遗产产生的评估费、公证费、诉讼费、差旅费等第三方费用，由遗产列支，凭票据实报实销。 四、履职与报告 执行人应妥善保管遗产、独立履职，重大事项（单笔超过____元的处分、债务人豁免、遗产变价）须书面记录并说明理由；每半年 / 每____向继承人提交一次遗产管理与财务报告。 五、免责边界 执行人仅对其故意或重大过失造成的损失承担民事责任。因下列情形致损的，执行人不承担责任：（1）善意信赖继承人、债权人或有关机构提供的文件；（2）遗产市场价值正常波动；（3）非因执行人过错导致的第三人行为或不可抗力。 六、离任与交接 出现下列情形之一，执行人离任：辞任（提前____日书面通知）、被依法撤销、遗产处理完毕。离任时执行人应向继承人或新任管理人移交遗产清单、财务账目、权属凭证原件，并签署交接确认书。 七、争议解决 本委托条款履行争议，双方协商不成提交____人民法院诉讼 / ____仲裁委员会仲裁。 立遗嘱人（签名）：____________　　执行人（签名）：____________ ____年__月__日
常见坑把遗产管理人当「遗产处置人」

第 1145—1149 条赋予的是管理、清理、报告、按既定方案分割的职责，不是「所有权」或「概括处分权」。高频越权：

  • 未经继承人一致同意，将遗产低价「处理」给关联方；
  • 用遗产资金为自己或他人清偿私人债务；
  • 在遗嘱 / 法定份额之外「重新分配」遗产。

这些均超出权限，触发第 1148 条赔偿责任。委托条款必须把「不得超越」写在显眼位置。

六、实务坑点

  • 坑 1：遗嘱未指定执行人，继承人推选僵局——谁都不愿管或都想管，遗产悬空。补救：依第 1146 条申请法院指定；前端起草遗嘱时务必指定执行人。
  • 坑 2：共同担任时意思不一致——全体继承人共同管理，重大事项需一致行动，常陷僵局。建议在推选时约定表决机制或指定单一管理人。
  • 坑 3：把遗产管理人当「遗产处置人」——超越第 1147 条权限处分、赠与、挪用，触发赔偿责任（见第五部分坑点）。
  • 坑 4：未先析产即列遗产清单——把夫妻共同财产整笔列为遗产，侵害配偶份额（第 1153 条）。清单制作先分一半为配偶。
  • 坑 5：未清偿先分配——违反限定继承与第 1163 条顺位，对债权人损失担责。
  • 坑 6：遗漏受遗赠人 60 日期限——未在分割前确认受遗赠人意思，逾期视为放弃（第 1124 条），引发后续争议。
  • 坑 7：报酬与免责未约定——事后就报酬、责任范围扯皮。委托条款须写明报酬标准、列支方式、免责边界。
  • 坑 8：指定程序路径选错——已进诉讼的走法院指定（特别程序），未进诉讼且愿公证的可走公证试点，混用导致反复。

七、红线清单 / 自检清单

  • 已引用第 1145 条，向客户说明确定顺序：遗嘱执行人 → 继承人推选 → 共同担任 → 民政 / 村委会兜底。
  • 对管理人确定有争议的，已规划依第 1146 条申请法院指定（特别程序路径），并备继承人范围与遗产清单。
  • 职责严格限定在第 1147 条六项，未将管理人等同于遗产所有权人。
  • 制作遗产清单前已先析产（第 1153 条），区分夫妻共同财产与被继承人个人财产。
  • 清偿严格遵循限定继承（第 1161 条）与顺位（第 1163 条）：先税款债务、后分割，未清偿不先分配。
  • 已提示受遗赠人 60 日接受期（第 1124 条），分割前确认受遗赠意思。
  • 遗嘱执行人委托条款已写明：选任、权限边界、报酬与列支、免责边界（仅故意 / 重大过失）、离任交接。
  • 已向客户提示公证遗产管理人试点可作为非诉替代路径，具体规则以当地公证机构为准。
  • 已提示责任风险：擅自处分、拖延致损、未清偿先分配、清单不实均可能依第 1148 条担责。
  • 继承诉讼当事人确定已参照继承编解释一第 44 条，避免遗漏或错误列当事人。
