# MEMORY.md —— 融资法务站点项目记忆

## 项目是什么
- `/Users/linqiongni/Downloads/linqiongni_profile/融资法务/`：13 个本地静态 HTML（index + ch01–ch13），讲「霓光珠宝」从档口到港交所的融资法务全流程。无框架、无构建、无 CDN。
- 共用资源：`assets/style.css`（国风主题，CSS 变量控制深浅色）、`assets/app.js`（顶栏 + 左目录 + 右本页目录 + 上下篇 + 折叠控件）。
- 部署：源站是本目录，副本在 `linqiongni_profile/public/financing-legal/`，同步命令 `npm run sync:financing`。

## 关键约定（踩过/已确认）
- **折叠块三件套**：`details.peek` 详解、`details.tpl` 模板、`details.dlg` 法务对话（2026-09-19 新增）。批量按钮 `data-fold-kind` 自动适配，**加新 kind 不用改 JS**。
- **主题**：默认浅色，深色走 `html[data-theme="dark"]` 变量覆盖；新增样式必须用 `var()`，禁止硬编码颜色（否则深色模式翻车）。
- **本页目录**：app.js 自动抓 `h2/h3` 生成，因此新增章节标题请用 `h2/h3`，不要跳级。
- **法源基准**：《公司法》2023 修订（2024-07-01 施行）、《证券法》2019 修订、九民纪要第 5 条（对赌）。九民纪要引用的旧条号 35/142/166 → 现行 53/162/210。
- **准确性红线**：主线案例虚构；ch13 案例库为真实案件，标 ⚠️ 者口径存疑，引用时保留标注。条号写进正式文件前必须复核现行文本。

## Andy 的偏好（本项目内）
- **新增内容放进 `<details>` 时，第一块必须 `open`**：默认全收起时用户会认为「页面没变」（ch03 踩过，2026-09-19）。页首要有「展开全部」批量按钮。
- **静态站资源必须带版本号**：`assets/style.css?v=YYYYMMDDx`、app.js 同理；主页 iframe tab 的 src 也要挂 `?v=`（用 `new Date().toISOString().slice(0,10)` 自动取值）。否则浏览器命中旧 CSS，新增样式类不生效，看起来像没改。
- 看不懂的章节要「法务对话体」：老板/投资人说大白话 → 法务用大白话答 → 再翻译成条款。ch03 已按此改造（2026-09-19），后续章节沿用同一套 `.dlg` 组件。
- **三段式写法（Andy 明确要求，硬规则）**：① 法律结论 → ② 立刻跟 `.sim`「就好比……」日常场景比方 → ③ `.dlg-note` 里翻成条款。比方必须紧贴那句难懂的话，不能攒到段末。
- 比方素材库（已用，可复用）：卖房划面积／合伙摆摊散伙／电影票降价补票／车险「全损」／欠条签本人还是签店／利滚利／夫妻共有房过户／小区卖楼／婚介独家期／挂牌前拆挂钩／团购凑满减／班级平均分。
- 术语要就地注释：行内 `.anno` 虚线下划线 + 悬停提示，不另开术语表打断阅读。
- 所有扩展默认折叠，主路径不被打断。
