# 购物好官 · 开发说明

> 一张「给店员的卡」：提前填好身材、风格、本次需求、要不要导购、希望店员帮什么；到店亮屏或保存图片给店员看，零开口拿精准服务。
> 定位：在「完全无人」与「全程导购」之间补一个**中间态**——保留店员帮助，但边界由你定。

## 一、交付物清单（都在 `购物好官/`）
- `购物好官_原型.html`：手机视角高保真原型（浏览器直接打开），作为小程序 WXML 的蓝本，两者字段/逻辑保持一致。
- `miniprogram/`：可直接导入微信开发者工具的**独立小程序工程**（当前 tourist 模式即可预览）。
- `构思初稿.md`：研究结论 + 字段草案。
- `开发说明.md`：本文。

## 二、目录结构
```
miniprogram/
├─ project.config.json      # 当前 appid=touristappid，可免账号预览
├─ sitemap.json
├─ app.js / app.json / app.wxss
├─ utils/size.js            # 尺码粗算（身高体重+版型偏好）
└─ pages/index/             # 唯一页面：表单 + 卡片预览 + 本地存档
   ├─ index.wxml / wxss / js / json
```

## 三、本地预览（不用注册账号）
1. 下载安装「微信开发者工具」。
2. 打开 → 导入项目 → 选择 `购物好官/miniprogram/` 目录。
3. AppID 选「测试号 / touristappid」即可直接运行（project.config.json 已配好）。
4. 模拟器里填一遍 → 点「👀 预览我的购物卡」→ 看给店员的卡 →「保存图片」会请求相册授权。

## 四、注册独立小程序并发布
1. 微信公众平台（mp.weixin.qq.com）注册**小程序**账号，起名「购物好官」（名称需审核，建议备 2-3 个备选）。
2. 拿到专属 AppID 后，把 `project.config.json` 里的 `"appid": "touristappid"` 改成你的 AppID。
3. 开发者工具里「上传」代码 → 公众平台「提交审核」→ 审核通过「发布」。
4. 类目建议选「工具 > 生活服务」或「生活 > 购物」类，避免卡审。

## 五、CloudBase 跨设备同步（可选升级）
当前用 `wx.setStorageSync` 本地存档，换手机不继承。若要跨设备：
1. 公众平台开通 CloudBase，建一个环境，复制环境 ID。
2. `app.js` 取消 `wx.cloud.init` 注释并填入环境 ID。
3. 把 `pages/index/index.js` 的 `saveProfile` / `loadProfile` 改为云端读写（存 `wx.cloud.database().collection('profiles')`）。
   逻辑结构不变，仅数据层替换。

## 六、HTML 原型 ↔ 小程序 字段映射
| 原型(html) | 小程序(wxml/data) | 说明 |
|---|---|---|
| `#sex` 单选 | `sex` + `setSex` | 性别 |
| `#height/#weight` | `height/weight` + `onInput` | 身高体重 |
| `#bust/#waist/#hip/#age` | 同名 `onInput` | 三围/年龄（可选） |
| `#shape` chips | `shapeList/shapeSel` + `toggle` | 体型 |
| `#fit` 单选 | `fit` + `setFit` | 版型偏好（新增） |
| `#style` chips | `styleList/styleSel` + `toggle` | 风格 |
| `#likeColor/#dislike` | 同名 | 喜欢色/雷区 |
| `#mode` 单选 | `mode` + `setMode` | 沟通模式开关（核心） |
| `#cat/#occ` chips | `catSel/occSel` + `toggle` | 品类/场景 |
| `#budget/#qty` | 同名 | 预算/数量 |
| `#help` chips | `helpSel` + `toggle` | 希望店员帮的事 |
| `#note` textarea | `note` + `onInput` | 礼貌提示语 |
| `calcSize()` | `utils/size.js` | 尺码粗算（同算法） |

## 七、已知限制
- 尺码为**身高体重+版型偏好的粗算**，仅作参考，以试穿为准（已在卡面标注）。
- 卡片「保存图片」用 canvas 绘制，个别机型 emoji 可能不显，但文字完整。
- 当前为单页面 + 本地存档，未做账号体系；如需「多套身材档案 / 历史出行」可后续迭代。
